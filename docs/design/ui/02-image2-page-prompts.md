使用方式：

- 首轮优先使用 `珍珠玉蓝 · 温暖记忆点缀版`。
- 如果某一页太花、太营销、太像网页海报，就回退到更克制的主方案。
- 首轮建议先出这 4 页：
  - 登录页
  - 照片首页
  - 相册页
  - 小相册详情页

## 1. 全局前置提示词

先把下面这段作为每一页的前置共用要求：

```text
为一款中文 Android 移动端 app 设计中高保真页面原型，页面需要稍微精美一点，但仍然是可落地的产品界面，不是营销海报，不是网页首页，不是企业后台。

产品主题是“纪念、记录、共同生活、两个人长期共享的私人空间”。产品结构不是社交帖子流，而是围绕“照片浏览、相册分类、进入小相册、沉浸查看、生活工具入口”组织内容。整体气质要清透、温柔、安静、有层次、有高级感，但不能甜腻，不能社交 feed 化，不能赛博，不能紫色主导。

全部界面文案使用简体中文。
画面为 Android 竖屏 app 页面。
界面要适合后续导入即时设计继续手动细修。

颜色系统要求：
以“珍珠玉蓝 · 温暖记忆点缀版”为首轮主方向。
页面大底必须是珍珠浅蓝背景，不能大面积退回纯白。
空白区、滚动区、卡片外留白、顶栏下留白、底栏上留白都要继续参与配色。
珍珠白卡片要有轻层次。
浅蓝只负责主操作容器、选中态和轻流光，不作为文字或图标色。
石墨负责标题、图标、正文和结构强调。
浅玉绿只用于相册、小相册、生活工具等辅助分区。
旧金只做日期、数量和旧金细节。
温暖记忆色只用于精选、纪念、未读、同步结果、关系状态、重要提醒和局部 badge。
温暖记忆色不是分类色，不进入主按钮，不铺满普通内容卡片。

请尽量参考这组颜色 token：

primaryContainer #BDEFFF
onPrimaryContainer #1F2933
selectedPillBg #BDEFFF
primaryAction #BDEFFF
primaryActionPressed #A7E9FF
titleAccent #26313A
softGreenContainer #D8F2E6
goldAccent #9A6A2A
memoryAccent #A94C42
memoryContainer #FFE1DA
onMemoryContainer #3A2724
memoryWash #FFF1EE
dividerSoft #C7E6EC
glassStroke #A9E5F2
glowWash #E7FAFF
textPrimary #1F2933
textSecondary #5E7580

禁止：
- 企业后台风
- 登录落地页海报风
- 深色赛博风
- 紫色主导
- 甜腻恋爱粉色风
- 过重玻璃拟态
- 深蓝主按钮白字
- 网页横向布局
- 社交帖子流产品感
- 让图片素材刻意配合 UI 颜色
```

```text

这是正式产品登录页，不是开发调试页。

- 邮箱输入框
- 密码输入框
- 主登录按钮
- 轻量提示信息区域

- 安静、清透、可信
- 有“进入共同空间”的感觉
```

当基础登录页已经跑通、但画面仍偏素时，优先使用下面这条 `v5` 专用提示词继续迭代，不要回退到大白卡方案。

```text
在上面的全局要求基础上，继续深化“映世”app 的登录页。

这是一张真实可落地的 Android 竖屏静态登录页高保真原型，不是品牌海报，不是营销落地页，不是网页首屏。

页面结构严格只保留：
- 品牌名“映世”
- 邮箱输入框
- 密码输入框

- 主登录按钮

- 副标题
- 登录说明
- 邀请说明
- 协议提示
- 忘记密码

- 第三方登录
- baseUrl
- demo
- REAL / FAKE
- 联调、诊断、开发信息
- 手机系统状态栏图标

本轮目标气质是：
- 轻奢雅致
- 安静
- 纪念感
- 产品化
- 蓝绿雾层
- 克制点金

标题“映世”要有更强设计感，使用现代宋感中文字标风格：
- 横画更细
- 竖向更稳

- 保留现代感

- 不要普通系统黑体的朴素字样

- 以浅蓝壳层为主背景
- 叠加更明显但克制的浅绿雾层
- 回收首轮方案里底部蓝绿交叠的存在感
- 保留柔和弧线、空气感、薄雾层、浅色形状承托

- 可以有极少量旧金日期细线、小高光点缀，以及温暖记忆色关键状态点，但都不能进入主按钮和大面积背景

输入区继续采用轻浮层化处理：
- 两个输入框分别独立漂浮
- 不要套进同一个大容器
- 输入框为半透明浅表面加细描边
- 边界清楚，但整体融入背景
- 密码框允许保留眼睛图标

登录按钮要比上一轮更精致：
- 仍然是唯一主 CTA
- 层次更干净
- 阴影更高级
- 不做厚重发光
- 不做夸张玻璃拟态

“高级功能”只是一行静态折叠入口：
- 只显示标题和箭头
- 不展开内容
- 不承载新功能

整体效果要做到：
- 比保守版更精致，但不是简单加花
- 比最早的氛围版更产品化
- 背景层次明显，但主流程依然一眼清楚
- 适合后续导入 Figma 继续细修

输出 1 张 Android 竖屏登录页高保真原型。
```

当登录页已经具备稳定结构、只差最后一轮“更惊艳但仍像真实产品”的提升时，使用下面这条 `v6` 专用提示词。

```text
在上面的全局要求基础上，继续深化“映世”app 的登录页。

页面结构严格只保留：

- 不展开内容

登录按钮做轻度雕塑化：
```

### 2.3 登录页色彩回正补丁：v7 轻透蓝平衡版

如果 `v6` 的标题和主按钮仍然偏深蓝，已经接近 Viewer 深色系统，而不是浅色登录页该有的珍珠玉蓝感，就使用下面这条 `v7` 补丁提示词，只修正颜色权重，不推翻 `v6` 的结构和雕塑感。

```text
在保留上一轮登录页整体结构、雕塑感背景和高级感的前提下，做一版色彩回正优化。

页面结构不要改，仍然只保留：
- 品牌名“映世”
- 邮箱输入框
- 密码输入框
- 一行静态“高级功能”折叠入口
- 主登录按钮

本轮只修正颜色权重：
- 标题不要再使用深蓝，改为石墨结构强调
- 标题接近 `titleAccent #26313A`，高级但不压暗页面
- 主登录按钮不要再用深蓝底或白字，请回到浅蓝光面主操作
- 主按钮接近 `primaryContainer #BDEFFF`，文字接近 `onPrimaryContainer #1F2933`
- 按钮按压感可以靠层次、轻玻璃边和浅蓝按压色表达，不要靠更深的底色表达

背景、输入框和整体雕塑感继续保留：
- 保留蓝绿流光、薄纱、微金细节和轻雕塑质感
- 不要回退成保守版本
- 不要丢掉上一轮的高级感和记忆点

整体效果要做到：
- 比上一轮更轻、更透、更平衡
- 标题和按钮重新融入浅色系颜色系统
- 仍然是高阶产品登录页，不是普通保守稿

不要出现任何新增文案、流程入口、状态栏、调试信息或大白卡。

输出 1 张 Android 竖屏登录页高保真原型。
```

当你选中某一页的第一轮结果后，可以继续在原提示词后追加下面这些局部改图要求。

### 让页面更清透更亮


