# 映世 Logo 探索 v2

Updated: 2026-06-02

本轮不替换当前 launcher 资源，只做方向探索。核心概念从“相册图标”改为“记忆冰匣”：一个圆角冰窗 / 光门，把照片、聊天、账本和生活片段的光温柔封存起来。

## 共同规则

- 主轮廓是圆角冰窗 / 光门，柔中带利。
- 彩虹是门内光带，不是外圈装饰，也不是直白彩虹弧。
- 内容只用抽象光影暗示，不画照片、账本、聊天气泡等具体小图标。
- 关系感暗含即可，通过双层光、双折射或双光点表达。
- 明确避开冷硬科技、儿童卡通、普通相册模板和高饱和炫彩海报。

## 方向 A：记忆冰窗

文件：`a-memory-ice-window.png`

圆角冰窗为主形，门内有克制虹光带和抽象生活光影。它最贴“记忆冰匣”的产品解释，也最容易和现有 `月白冰蓝 / 珍珠玉蓝` UI 接上。

适合：希望 logo 仍然能让人感到“这里保存着生活片段”，但不变成照片 App 模板。

风险：如果后续继续加强内部光影，可能重新变得像相册图标；深化时应保留抽象，不增加具体小物件。

## 方向 B：光被封存

文件：`b-sealed-light.png`

更抽象，强调一束彩虹光被冰窗温柔收住。它更像品牌符号，照片、聊天、账本等模块都不会被某个具体功能抢走。

适合：希望映世的 logo 更高级、更耐看、更不像任何单一模块。

风险：产品关联更弱；如果用户第一次看到，可能需要 App 名和界面气质一起帮助理解。

## 方向 C：温柔棱镜匣

文件：`c-gentle-prism-box.png`

在圆角冰窗里加入更明确的柔和切面，折射感更强，冰晶和虹光更容易被看见。

适合：希望“冰晶折光”更明确，logo 更有视觉记忆点。

风险：切面一多就容易向冷硬科技感靠近；深化时要减少尖锐边、降低深色线条权重。

## 建议

优先从 A 和 B 中选一个深化：

- 如果你想要“梦幻治愈，但仍然贴生活内容”，选 A。
- 如果你想要“更高级、更抽象、更不像相册”，选 B。
- 如果你觉得目前冰晶感还不够，再从 C 借一点切面语言给 A 或 B。

下一步一旦选定方向，再替换 Android adaptive icon、legacy PNG、monochrome themed icon，并同步更新品牌说明文档。
