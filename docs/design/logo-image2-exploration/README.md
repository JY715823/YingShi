# 映世 Logo image2 原型

Updated: 2026-06-02

本目录保存使用 MeiGen 工具中的 OpenAI-compatible `gpt-image-2` 通道生成的 logo 原型图。当前 `provider: meigen` 未配置，实际可用 provider 为 `openai`，模型为 `gpt-image-2`。

这些图只用于选择方向，不替换 Android launcher 资源。

## 方向 A：记忆冰窗

文件：`a-memory-ice-window-image2.png`

最干净的圆角冰窗方向。冰质感、月白冰蓝、内部虹光都比较克制，整体最像“一个装着生活记忆光影的冰窗”。

适合：想要梦幻治愈、高级、和现有 UI 搭。

风险：如果直接照搬，可能略像单枚冰块，需要后续抽象成更明确的品牌符号。

## 方向 B：光被封存

文件：`b-sealed-light-image2.png`

光门感最强，像一束彩虹光被透明冰窗收住。它不绑死相册、聊天或账本，更像品牌概念。

适合：想要更抽象、更高级、不像某个单一模块。

风险：主体偏淡，小尺寸 launcher 里识别力需要加强。

### B v03：冷光云与记忆彩虹

文件：

- `b-v03-frost-cloud-rainbow-01.png`
- `b-v03-frost-cloud-rainbow-02.png`
- `b-v03-frost-cloud-rainbow-03.png`
- `b-v03-frost-cloud-rainbow-comparison-sheet.png`

这一轮继续保留 B 的高级清透感，但把彩虹从竖向光束改成“云后出现一道彩虹”。冰不再作为冰块、冰窗或冰匣实体出现，只保留为月白冰蓝冷光、云边薄霜、半透明雾感和轻微折射。

三张判断：

- 01 最干净稳定，小尺寸下云和彩虹弧还能组成清楚符号，适合继续做主方向。
- 02 冰质和霜感最明显，但两朵云加彩虹更接近天气图标，后续要压低可爱感。
- 03 最抽象高级，已经明显避开冰块感，但小尺寸下云的语义会弱一些。

建议：优先以 01 深化，借 03 的流动抽象感降低天气图标气质；02 只作为材质参考，不建议直接作为 launcher 方向。

### B v04：冰虹记忆

文件：

- `b-v04-ice-rainbow-memory-01.png`
- `b-v04-ice-rainbow-memory-02.png`
- `b-v04-ice-rainbow-memory-03.png`
- `b-v04-ice-rainbow-memory-comparison-sheet.png`

这一轮根据“冰虹记忆 / 小霜云 / 薄冰折射 / 清晰但克制彩虹 / 抽象品牌标 / 浅冰蓝底”继续修正。云不再作为完整主体，只保留为霜雾托底；彩虹改为更清晰的右上半藏短弧；冰感通过薄冰光膜、冷蓝折射、边缘高光和细微冰面光纹表达，避免回到冰块、冰窗、冰匣或玻璃罩。

三张判断：

- 01 冰膜和彩虹的融合最明显，气质最接近“冰蓝薄冰里的记忆彩虹”，但云的柔软体积仍可再压低。
- 02 小尺寸识别最好，彩虹最清楚，适合判断 launcher 识别力；风险是完整弧度和霜雾托底仍略接近天气图标。
- 03 最像抽象品牌符号，云意象最弱，冰面折射和浅蓝底最稳定；风险是更容易被看成冰坡或光学风景。

建议：若继续走 B，优先从 01 的“冰膜包住彩虹”与 03 的“抽象冰面秩序”合并，保留 02 作为小尺寸识别参考。下一步不建议继续强化云，而是把霜雾托底矢量化成 2 到 3 条柔和曲线，彩虹保持短弧半藏。

## 方向 C：温柔棱镜匣

文件：`c-gentle-prism-casket-image2.png`

冰晶边框和虹光最明显，视觉记忆点最强。相比原始 C 版去掉了叶片和风景，更接近抽象 logo 原型。

适合：想要“冰 + 彩虹”第一眼更明确。

风险：光效和冰晶细节偏多，正式落地时要降低炫光，保留核心轮廓和内侧虹光。

## 建议

优先选 A 或 C 深化：

- A 更贴映世现有 UI 气质，适合做长期品牌。
- C 更有“冰晶虹光”记忆点，适合从中提炼正式 logo。
- B 可以作为抽象高级感参考，但不建议直接作为 launcher 方向。
