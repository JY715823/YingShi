# Current Task: 多选范围选择边缘自动滚动

## 背景

照片流和系统媒体页已经支持长按进入多选、点击右下角选择圆点、横向滑动范围选择，以及“起点未选中则批量选中 / 起点已选中则批量取消”的模式。

当前缺口是：手指拖到屏幕顶部或底部时，列表不会自动滚动，导致用户只能在当前可视区域内做范围选择。

## 目标

1. 照片流滑动范围多选拖到底部时自动向下滚动并继续更新范围选择。
2. 照片流滑动范围多选拖到顶部时自动向上滚动并继续更新范围选择。
3. 系统媒体页具备同样能力。
4. 保持现有起点模式：
   - 起点未选中：批量选中。
   - 起点已选中：批量取消。
5. 自动滚动时继续用当前手指位置命中可见项，并更新跨行范围。
6. 手势结束、退出多选或页面离开后停止自动滚动。

## 范围

- `MultiSelectSwipeGesture.kt`
- `PhotoFeedScreen.kt`
- `SystemMediaScreen.kt`
- 本文档

## 不做内容

- 不做 UI 大改。
- 不重构无关模块。
- 不影响 Viewer、帖子详情、回收站等无关页面。
- 不改变右下角选择圆点的点击行为。
- 不改变普通纵向滚动优先级。

## 验收

1. 照片流多选拖到底部能自动向下滚动并继续选中。
2. 照片流多选拖到顶部能自动向上滚动并继续选中/取消。
3. 系统媒体页多选拖到底部能自动向下滚动并继续选中。
4. 系统媒体页多选拖到顶部能自动向上滚动并继续选中/取消。
5. 普通纵向滚动不被滑动多选抢占。
6. 点击右下角选择圆点仍正常选中/取消。
7. 横向范围选择仍保持原有起点模式。
8. `assembleDebug` 通过。
