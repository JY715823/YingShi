# Roadmap

当前路线已经完成从壳层、照片核心交互到真实后端联调的主要阶段。后续重点不再是“补页面壳子”，而是把现有链路做稳、做细、做可回归。

## 已完成阶段

### Stage 0-1：项目壳层与设计基线

- Android 工程初始化。
- 全局底部导航：主页、照片、生活、我的。
- 中央新增入口。
- Compose + Material 3 主题、颜色、字号、间距和圆角 token。
- ShellPage、TitleTabs、占位页等基础组件。
- 文档、协作约束和阶段任务框架。

### Stage 2：照片流

- 全局媒体流模型。
- 媒体去重与按时间倒序展示。
- 2 / 3 / 4 / 8 / 16 列密度切换。
- 月份/日期分组。
- 时间滑条。
- 长按进入多选、多选操作栏、滑动范围选择。
- 照片流打开 Viewer。

### Stage 3：Viewer

- 全屏媒体查看。
- 图片/视频混排。
- 左右切换。
- 图片缩放、长图适配。
- 原图按需加载与全帖原图加载。
- 评论入口。
- 所属帖子入口。
- Viewer 内删除和缓存入口。

### Stage 4：相册与帖子详情

- 相册列表。
- 帖子卡片列表。
- 帖子详情页。
- 帖子媒体区。
- 帖子内 Viewer 入口。
- 帖子评论区。

### Stage 5：评论系统

- 帖子评论与媒体评论分流。
- 评论列表、输入、创建。
- 评论编辑、删除、局部状态更新。
- FAKE 评论仓库与 REAL 评论 ViewModel。

### Stage 6：帖子编辑与媒体管理

- 帖子基础信息编辑。
- 相册归属编辑。
- 封面设置。
- 帖子内媒体排序。
- 帖子内媒体移除。
- 帖子删除。
- 媒体管理页。

### Stage 7：回收站

- 帖子删除记录。
- 帖子内媒体移除记录。
- 媒体系统删记录。
- 回收站列表与详情。
- 恢复、移出、24h 可撤销分类。
- FAKE / REAL 回收站链路。

### Stage 8：系统媒体工具区

- MediaStore 图片/视频查询。
- 系统媒体筛选：全部、相机、截图、视频、已发帖、未发帖。
- 时间分区与时间滑条。
- 多选、滑动范围选择。
- 系统媒体 Viewer。
- 导入 App、发成新帖子、加入已有帖子。
- Android 系统回收站请求。

### Stage 9：原图、长图、视频和缓存

- 原图加载状态。
- 全帖原图加载。
- 长图查看适配。
- 视频缩略图和播放状态 UI。
- 预览、原图、视频缓存管理占位与清理入口。

### Stage 10：通知、设置与工具入口

- 通知中心。
- 通知详情。
- 未读 badge。
- 通知目标跳转。
- 我的页设置入口。
- 设置页。
- 缓存管理页。
- 后端联调诊断入口。

### Stage 11：后端契约与真实接入

- Retrofit API：auth、album、post、media、comment、trash、upload、health。
- JWT session 与认证拦截。
- FAKE / REAL RepositoryProvider。
- 真实照片流、相册、帖子、评论、回收站、上传链路。
- 后端联调诊断页。

### Stage 12：产品化与稳定性

- 创建帖子完整链路。
- 系统媒体导入上传任务。
- 传输中心。
- 上传剩余任务 badge 和汇总提示。
- 时间滑条修正。
- 系统媒体按时间分区。
- 帖子 UI 中文化。
- 回收站 24h 可撤销分类改为同页 chip 内容。
- 多选手势精修：横向意图识别、行列命中、选择数字闪现。

## 后续建议

### Stage 13：回归与验收基线

- 为核心页面补最小 UI smoke test。
- 为 Repository mapper 和关键业务分支补单元测试。
- 建立 FAKE / REAL 双模式验收清单。
- 固化真机联调步骤和常见故障排查。

### Stage 14：真实数据体验补强

- 更完整的登录过期处理。
- 上传失败重试和取消的真实状态收敛。
- 大列表分页和增量刷新。
- 媒体文件错误、权限错误、网络错误的统一提示。

### Stage 15：发布前整理

- release 构建配置。
- signing 配置说明。
- 隐私权限说明。
- 崩溃和日志策略。
- 文档与截图同步。
