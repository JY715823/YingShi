## 二、用户流程

### 流程1: 创建小相册
用户从照片流/大相册选择媒体 → CreatePostScreen → produceState 加载大相册列表和 App 媒体 → 填写标题/简介/选大相册/选所属/设时间 → submitDraft() → 有系统媒体走 WorkManager 上传队列 / 仅 App 媒体走 postRepository.createPost → 跳转详情页。

涉及: PostComposerScreen.kt, SmallAlbumApi.kt, RealPostRepository

### 流程2: 编辑小相册
详情页点击编辑 → GearEditScreen → RealGearEditViewModel.init → refresh() 加载大相册列表+小相册详情 → 用户修改 → save() → updatePostBasicInfo + 逐个 deleteMediaFromPost + updatePostMediaOrder + setPostCover → notifyRealBackendPostChanged → 返回。

涉及: GearEditScreen.kt, RealPostEditingViewModels.kt, SmallAlbumApi.kt

### 流程3: 查看小相册详情
从大相册/创建完成/路由跳转 → PostDetailScreen → PostDetailRealViewModel.init → refresh() → SmallAlbumDetailBodyLayout（氛围背景+信息卡+媒体网格）→ 密度缩放/视频播放/评论/选择模式。

涉及: PostDetailScreen.kt (4352行), RealPhotoViewModels.kt (PostDetailRealViewModel)

### 流程4: 详情页密度缩放
双指缩放 → discreteZoomLevelGesture → 4 阶段 morph 动画（IDLE→PREVIEWING→REBOUNDING→COMMITTING）→ overlay 插值预览 → 提交后重建 blocks。

涉及: PostDetailScreen.kt SmallAlbumMediaGridSection (~760行)

### 流程5: 媒体列表子页
从创建/编辑页进入 → PostMediaListScreen → AUTO_APPLY 模式下单删直接生效/CONFIRM 模式需保存 → 拖拽排序 → 设封面（双封面替换队列）→ 批量删除 → 清空。

涉及: PostMediaListScreen.kt (1291行)

## 三、数据流向

### 3.1 状态管理架构

```
PostComposerScreen (创建页) — 无 ViewModel，纯 Composable 状态
  |-- rememberSaveable + produceState
  |-- route.source + mediaKey 作为状态 key

RealGearEditViewModel (编辑页) — MutableStateFlow<RealGearEditUiState>
  |-- recalculate() 计算 hasChanges
  |-- save() → 4 步网络请求（updateBasicInfo + deleteMedia×N + updateOrder + setCover）

PostDetailRealViewModel (详情页) — MutableStateFlow<PostDetailRealUiState>
  |-- refresh() → getPostDetail() + getPostComments()
  |-- 含评论状态、选择模式、密度缩放状态
```

### 3.2 API → Repository → ViewModel → UI

```
SmallAlbumApi (8 endpoints)
  |-- POST   api/posts                    -> createPost
  |-- PATCH  api/posts/{postId}           -> updatePostBasicInfo
  |-- GET    api/posts/{postId}           -> getPostDetail
  |-- PATCH  api/posts/{postId}/cover    -> setPostCover
  |-- PATCH  api/posts/{postId}/media-order -> updatePostMediaOrder
  |-- POST   api/posts/{postId}/media    -> addMediaToPost
  |-- DELETE api/posts/{postId}           -> deleteSmallAlbum
  |-- GET    api/posts                    -> getPosts (列表)
       |
RealPostRepository (runCatching -> ApiResult)
       |
PostDetailRealViewModel / RealGearEditViewModel
       |
PostDetailScreen / GearEditScreen (Compose)
```

### 3.3 与其他模块的数据交互
