### 2.3 Repository 契约

**PostRepository.createPost**（Contracts.kt L93）:
```kotlin
suspend fun createPost(payload: CreatePostPayload): ApiResult<RemotePostSummary>
```

### 2.4 FR-8 实施判断

**关键约束**: submitDraft() 含系统媒体上传分支（LocalSystemMediaBridgeRepository），该逻辑涉及 Context、上传队列、FAKE/REAL 双模式，提取到 ViewModel 需保持全部 6 分支语义不变。

**方案**: PostComposerViewModel 持有 UiState + 所有状态更新方法 + submitDraft 逻辑；Composable 改用 viewModel() + collectAsState()；rememberSaveable 改为 ViewModel 内 MutableStateFlow（配置变更由 ViewModel 自动保留）。

## 六、技术约束

1. **颜色系统受保护**: 不得更换主色调，新增 Composable 必须使用 `YingShiThemeTokens.colors.*`
2. **视觉改动不改布局结构**: 仅改颜色/阴影/圆角/排版，不改组件层级
3. **FR-8 需保持 6 分支语义**: submitDraft() 的 REAL/FAKE × 系统/App/无媒体分支不能丢失
4. **配置变更恢复**: ViewModel 自动保留状态，但 rememberSaveable 的 SavedStateHandle 语义需对齐
5. **编译验证**: 每个 FR 完成后 `gradlew.bat assembleDebug`
