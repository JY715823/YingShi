### 1.4 PostComposerScreen.kt 改造

- 删除 22 个 rememberSaveable/remember/produceState 声明
- 删除 submitDraft()、toggleAlbum()、handleClose() 局部函数
- 改为:
```kotlin
val viewModel: PostComposerViewModel = viewModel(key = "post-composer-${route.source}", factory = PostComposerViewModel.factory(route))
val uiState by viewModel.uiState.collectAsState()
```
- UI 组件回调改为调用 viewModel 方法
- submitDraft 调用改为 `viewModel.submitDraft(context, scope, onCreated, onSubmittedToBackground)`

### 1.5 关键约束
- submitDraft 的 6 分支语义不变
- Context 和 CoroutineScope 仍由 Composable 传入（ViewModel 不持有 Context 引用）
- 配置变更后 ViewModel 自动保留状态（ViewModel lifecycle > Composable）
