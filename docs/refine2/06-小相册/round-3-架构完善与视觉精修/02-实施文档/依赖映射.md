## 三、数据流图

### 3.1 FR-8 数据流

```
CreatePostRoute (initialMediaItems/initialAlbumId/source)
    ↓
PostComposerViewModel.init()
    ↓
refresh() → albumRepository.getAlbums() + CollaboratorDirectoryStore.snapshot()
    ↓
PostComposerUiState (albums, collaboratorDirectory, availableAppMediaItems)
    ↓
PostComposerScreen.collectAsState()
    ↓
用户交互 → viewModel.updateTitle/toggleAlbum/updateMediaDraft/...
    ↓
viewModel.submitDraft(context, scope, onSuccess, onSubmittedToBackground)
    ↓
6 分支: REAL/FAKE × 系统/App/无媒体
    ↓
onCreated(PostDetailPlaceholderRoute) / onSubmittedToBackground()
```

### 3.2 FR-9 数据流

```
YingShiThemeTokens.colors (glassSurfaceBase, glassStroke, glowWash, ...)
    ↓
SmallAlbumMediaGrid.kt → SmallAlbumGridMediaTile (Surface + shadow + border)
SmallAlbumDetailHeader.kt → SmallAlbumDetailTopBar (fontSize 24sp Bold)
PostComposerScreen.kt → CreatePostMediaPreviewSection (Surface 玻璃容器)
PostComposerScreen.kt → SelectableAlbumChip (升级风格)
PostComposerScreen.kt → Color.Black/White → token 替换
GearEditScreen.kt → GearEditMediaPreviewSection (Surface 玻璃容器)
GearEditScreen.kt → 按钮间距 4dp
GearEditScreen.kt → Color.White → token 替换
```
