## 一、FR-8 影响分析

### IA-1: PostComposerViewModel.kt 新建

| 路径 | 影响 |
|------|------|
| 新文件 → PostComposerScreen.kt | PostComposerScreen 改用 viewModel() 引用 |
| 新文件 → CreatePostRoute | 构造函数接收 route 参数 |
| 新文件 → PostRepository.createPost | submitDraft 调用 |
| 新文件 → AlbumRepository.getAlbums | refresh 调用 |
| 新文件 → LocalSystemMediaBridgeRepository | 系统媒体分支调用 |
| 新文件 → FakeAlbumRepository | FAKE 分支调用 |

### IA-2: PostComposerScreen.kt 改造

| 路径 | 影响 |
|------|------|
| 删除 rememberSaveable → ViewModel UiState | 配置变更恢复机制变化（ViewModel 自动保留）|
| 删除 produceState → ViewModel init | 异步加载时机变化（ViewModel.init 触发）|
| 删除 submitDraft 局部函数 → ViewModel.submitDraft | Context/Scope 参数传入 |
| 删除 toggleAlbum 局部函数 → ViewModel.toggleAlbum | 回调路径变化 |
| CreatePostScreen 签名不变 | 调用方（导航）不受影响 |
| CreatePostRoute 不变 | 路由数据不受影响 |

### IA-3: 配置变更恢复

| 路径 | 影响 |
|------|------|
| rememberSaveable → ViewModel | ViewModel 在配置变更时自动保留（不依赖 SavedStateHandle）|
| 弹窗状态（showXxx）| 原为 remember（非 Saveable），现改为 ViewModel UiState，行为一致（不持久化）|
| localMessage | 原 rememberSaveable，现 ViewModel UiState，配置变更后保留（ViewModel 生命周期更长）|
