## 二、FR-2: 编码损坏字符串清理

### 目标
修复 2 处编码损坏的中文字符串。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `app/.../feature/photos/PostDetailScreen.kt` | Android | 修改 | L4115 乱码字符串替换 |
| 2 | `app/.../feature/photos/GearEditScreen.kt` | Android | 修改 | L1189 乱码字符串替换 |

### 修复方案

#### 修复点1: PostDetailScreen.kt L4115

**位置**: `meaningfulPostSummaryOrNull()` 函数（FR-1 拆分后保留在主文件）

**修改前**:
```kotlin
internal fun String?.meaningfulPostSummaryOrNull(): String? {
    val normalized = this?.trim()?.takeIf { it.isNotBlank() } ?: return null
    return normalized.takeUnless {
        it == "还没有简介" || it == "杩樻病鏈夌畝浠?"
    }
}
```

**修改后**:
```kotlin
internal fun String?.meaningfulPostSummaryOrNull(): String? {
    val normalized = this?.trim()?.takeIf { it.isNotBlank() } ?: return null
    return normalized.takeUnless {
        it == "还没有简介"
    }
}
```

**说明**: `"杩樻病鏈夌畝浠?"` 是 `"还没有简介"` 的 GBK→UTF-8 mojibake。已有 `it == "还没有简介"` 判断，mojibake 判断冗余，直接删除。

#### 修复点2: GearEditScreen.kt L1189

**位置**: `GearEditEntryRow()` 函数

**修改前**:
```kotlin
if (title.contains("缓存") || title.contains("缂撳瓨")) {
    return
}
```

**修改后**:
```kotlin
if (title.contains("缓存")) {
    return
}
```

**说明**: `"缂撳瓨"` 是 `"缓存"` 的 GBK→UTF-8 mojibake。已有 `title.contains("缓存")` 判断，mojibake 判断冗余，直接删除。
