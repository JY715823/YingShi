## 八、Bug 修复记录

### BUG-1: listSmallAlbums_success JsonPath 格式化错误

**问题**: `PostIntegrationTest.java:152` 的 `jsonPath("$.data[?(@.smallAlbumId == '%s')]").exists()` 中 `'%s'` 被 `JsonPathResultMatchers` 当作 `String.format()` 格式化字符，触发 `MissingFormatArgumentException`。

**根因**: `JsonPathResultMatchers` 内部使用 `String.formatted()` 格式化期望值字符串，`%s` 被误认为格式化占位符。

**修复**: 将 `'%s'` 替换为字符串拼接 `'" + smallAlbumId + "'`，直接使用变量值而非格式化占位符。

**修复前**:
```java
.andExpect(jsonPath("$.data[?(@.smallAlbumId == '%s')]").exists());
```

**修复后**:
```java
.andExpect(jsonPath("$.data[?(@.smallAlbumId == '" + smallAlbumId + "')]").exists());
```

**验证**: 重新运行测试，15/15 全部通过。
