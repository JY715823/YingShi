# 06-小相册 需求文档

> 版本: v1.0 | 日期: 2026-07-10 | 状态: 已确认

## 一、模块目标

在 Codex 首轮精修（功能完整：创建/编辑/详情三端 + 所属语义 + 密度缩放 + 封面缓存）基础上，进行 refine2 深度打磨：拆分 4352 行超大文件、清理编码损坏字符串、补齐服务端测试、统一硬编码颜色 token、优化编辑保存批量删除、同步 API 文档、统一重复合并逻辑，并对详情页/创建页/编辑页进行全面视觉精修，使三端视觉达到与 04-照片根目录和 05-大相册同等的成品级质感。

## 三、非功能需求

### NFR-1: 文件结构规范
拆分后的新文件遵循同包 `internal fun` 可见性，不引入新的跨包依赖。PostDetailScreen.kt ≤ 800 行。

### NFR-2: 编译与回归安全
每轮实施完成后：Android `gradlew.bat assembleDebug` 编译通过、Server `mvnw.cmd compile` 编译通过、`mvnw.cmd test` 全部通过。

### NFR-3: 视觉一致性
所有新增/修改的视觉元素必须通过 YingShiThemeTokens 引用颜色、间距、圆角。与 04-照片根目录和 05-大相册的视觉风格保持一致。

## 四、范围边界

### 在范围内
- PostDetailScreen 文件拆分
- 编码损坏字符串清理
- 服务端测试覆盖补齐
- 硬编码颜色 token 化
- 编辑保存批量删除优化
- post-api.md 文档同步
- 重复合并逻辑统一
- 创建页 ViewModel 引入
- 三端视觉精修

### 不在范围内
- 多大大相册归属
- 查看器协议重做
-  broader ownership 头像铺到所有未触达的小相册卡片变体

### 不可协商项
- 创建仍保留最终创建边界
- 所属可以是一位或两位，但不能为零
- FAKE/REAL 两套行为保持一致
