## 二、需求文档与代码库的关键偏差（需修正）

### 偏差 1：FR-5 端点路径

| 项 | 需求文档描述 | 代码库实际约定 | 决策 |
|----|------------|--------------|------|
| 基路径 | `/api/posts/{postId}/media-batch` | `/api/small-albums/{smallAlbumId}/...`（PostController @RequestMapping("/api/small-albums")） | **采用代码库约定**：`PATCH /api/small-albums/{smallAlbumId}/media-batch` |

### 4.2 服务端新增端点设计

**路径**：`PATCH /api/small-albums/{smallAlbumId}/media-batch`

**Controller 方法签名**：
```java
@Operation(summary = "Batch remove media from small album", security = @SecurityRequirement(name = "bearerAuth"))
@PatchMapping("/{smallAlbumId}/media-batch")
public ApiResponse<PostDetailDto> batchRemoveSmallAlbumMedia(
    @PathVariable String smallAlbumId,
    @Valid @RequestBody UpdatePostMediaBatchRequest request,
    @CurrentUser AuthenticatedUser currentUser,
    HttpServletRequest httpRequest)
```

**DTO**（新建 UpdatePostMediaBatchRequest.java）：
```java
public record UpdatePostMediaBatchRequest(
    @NotEmpty(message = "removeMediaIds is required.")
    List<@NotBlank(message = "removeMediaId is required.") String> removeMediaIds
) {}
```

**PostService 方法**（新增 batchRemovePostMedia，@Transactional）：
- requirePost 校验
- validateDistinctIds 校验去重
- 加载全部关系 + 校验 removeMediaIds 都属于本小相册
- 防止清空（relations.size - removeMediaIds.size > 0）
- deleteAll + flush + 重排 sortOrder + 封面补偿
- buildPostDetail + notifyContentUpdated

**异常处理**：
| 场景 | HTTP | ErrorCode |
|------|------|-----------|
| 小相册不存在 | 404 | SMALL_ALBUM_NOT_FOUND |
| removeMediaIds 含重复 | 400 | SMALL_ALBUM_MEDIA_ORDER_INVALID |
| mediaId 不属于本小相册 | 400 | MEDIA_NOT_FOUND |
| 批量删除会清空 | 409 | DELETE_CONFLICT |
| removeMediaIds 为空 | 400 | VALIDATION_ERROR（@NotEmpty 自动拦截）|

- 文件：`E:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/photos/RealPostEditingViewModels.kt`
- 定义：L737-757
- 调用：L226（syncExternalContent 内）

- 特征：同类型合并

### 6.2 差异点对比

**相同骨架**：
- currentIds = currentItems.mapTo(linkedSetOf()) { it.id }
- latestById = latestItems.associateBy { it.id }
- buildList { 遍历 current 用 latest 覆盖 → 遍历 latest 新增不在 currentIds 且不在 previousBaselineIds 的项 }

**差异点 1（类型）**：A 跨类型，B 同类型

**差异点 2（转换调用）**：
- A 覆盖行：`latestById[item.id]?.toPostMediaListItem() ?: item`
- A 新增行：`add(media.toPostMediaListItem())`
- B 覆盖行：`latestById[item.id]?.copy(isCover = false) ?: item.copy(isCover = false)`
- B 新增行：`add(media.copy(isCover = false))`

**差异点 3（isCover 语义）**：A 不重置 isCover；B 显式强制 isCover = false（封面由调用方另行指派）

### 6.3 共享函数设计

**推荐路径**：`E:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/photos/PostMediaMergeUtils.kt`
