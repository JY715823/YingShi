## 四、数据流图

### FR-5 批量删除数据流

```
[用户在编辑器删除 N 个媒体]
  ↓
[RealGearEditViewModel.save()]
  → removedIds = initialMediaIds.filterNot { finalMediaIds.contains(it) }
  ↓
[postRepository.updatePostMediaBatch(postId, removedIds)]（新，1 次请求）
  ↓
[SmallAlbumApi.updatePostMediaBatch]（新 Retrofit 方法）
  ↓ HTTP PATCH
[PATCH /api/small-albums/{smallAlbumId}/media-batch]（新端点）
  ↓
[PostController.batchRemoveSmallAlbumMedia]（新）
  ↓
[PostService.batchRemovePostMedia]（新，@Transactional）
  → requirePost（library 隔离）
  → validateDistinctIds（去重校验）
  → findByLibraryIdAndPostIdOrderBySortOrderAsc（加载全部关系）
  → 校验 removeMediaIds 都属于本小相册
  → 防清空校验
  → deleteAll(toRemove) + flush
  → 重排剩余 sortOrder
  → 封面补偿（若封面被删）
  → postRepository.save(post)
  → notifyContentUpdated（异步推送）
  ↓
[返回 PostDetailDto]
  ↓
[Android 收到 SmallAlbumDetailDto]
  → ApiResult.Success
  → mediaChanged = true
  → committedMediaIds.filterNot { removedIds.contains(it) }
  ↓
[后续 updatePostMediaOrder（若 orderChanged）]
[后续 setPostCover（若封面变化）]
  ↓
[save() 完成，UI 更新]
```

### FR-4 颜色替换数据流

```
[Composable 渲染]
  → MaterialTheme.colorScheme.background（旧）
  → colors.appBackground（新，YingShiThemeTokens.colors.appBackground）
  → LocalYingShiColors.current.appBackground
  → YingShiAppBackground（Colors.kt 默认值）
  ↓
[UI 显示（视觉无变化，token 值一致）]
```

### FR-7 合并逻辑数据流

```
[LaunchedEffect / syncExternalContent 触发]
  → localMediaDirty || localCoverDirty
  ↓
[mergeMediaDraftWithRemoteAdditions]（共享函数，新）
  → currentIds = currentItems.mapTo(linkedSetOf()) { currentIdSelector(it) }
  → latestById = latestItems.associateBy { latestIdSelector(it) }
  → buildList {
      遍历 currentItems：latest 有则 transformLatest(latest) 否则 item
      遍历 latestItems：不在 currentIds 且不在 previousBaselineIds 则 transformLatest(media)
    }
  ↓
[返回合并结果]
  → GearEditScreen: List<PostMediaListItem>（transformLatest = toPostMediaListItem）
  → RealPostEditingViewModels: List<ManagedPostMediaUiModel>（transformLatest = { copy(isCover = false) }）
```
