## 四、发现的 Bug

### BUG-1: SystemMediaScreen.kt 超过 1000 行限制
- **问题**: FR-2 AC-1 要求无单一文件超过 1000 行，初始拆分后为 1185 行
- **根因**: 主 Composable 函数体过大（约 1007 行），未充分精简胶水代码
- **修复**: 提取 6 个 remember helper 函数到 SystemMediaSelection.kt 和 SystemMediaGrid.kt
  - rememberSystemMediaHitTestAdapter → SystemMediaSelection.kt
  - SystemMediaThumbnailWarmer → SystemMediaGrid.kt
  - rememberSystemMediaInlineVideoController → SystemMediaGrid.kt
  - SystemMediaPendingScrollHandler → SystemMediaGrid.kt
  - buildSystemMediaRowMapping → SystemMediaSelection.kt
  - visibleSystemMediaVideoIds + centeredSystemMediaVideoId → SystemMediaGrid.kt
- **验证**: 行数降至 974 行 → 进一步删除 44 个未使用 import 后降至 930 行 ✅
- **状态**: ✅ 已修复

### BUG-2: 颜色 token 合规性违规（5 处）
- **问题**: 5 处 `MaterialTheme.colorScheme.error*` 违反设计约束"新增 Composable 必须使用 YingShiThemeTokens.colors.*"
- **根因**: 从原文件迁移时未将 Material3 error 色替换为 YingShiThemeTokens destructive token
- **修复**:
  - SystemMediaComponents.kt: 3 处 `MaterialTheme.colorScheme.error*` → `colors.destructive*`
  - SystemMediaViewerControls.kt: 2 处 `MaterialTheme.colorScheme.error` → `colors.destructive`
- **验证**: compileDebugKotlin BUILD SUCCESSFUL ✅
- **状态**: ✅ 已修复

### BUG-3: SystemMediaScreen.kt 44 个未使用 import
- **问题**: 拆分后原文件的 import 未清理，遗留 44 个未使用 import
- **根因**: 从 2547 行文件提取代码后，import 清理不彻底
- **修复**: 逐个 grep 验证后删除 44 行未使用 import
- **验证**: compileDebugKotlin BUILD SUCCESSFUL，行数从 974 降至 930 ✅
- **状态**: ✅ 已修复
