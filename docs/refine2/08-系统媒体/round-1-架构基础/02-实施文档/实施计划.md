## 一、总体策略

### 1.1 实施顺序

```

  ├─ B1: 新建 OperationBus.kt（最独立）
  ├─ B2: 新建 ImportOverlayStore.kt
  ├─ B3: 新建 UploadManager.kt（入口 + 调度 + 生命周期，~700 行）
  ├─ B4: 新建 SystemMediaUploadReal.kt（Real 实现 + 收尾，~800 行）
  ├─ B5: 新建 SystemMediaUploadSupport.kt（持久化 + 远程历史 + picked 媒体 + API 工具，~600 行）
  └─ B6: 缩减 LocalSystemMediaBridgeRepository.kt 为薄代理（~200 行）

阶段C: FR-2 SystemMediaScreen 拆分
  ├─ C1: 新建 SystemMediaStates.kt
  ├─ C2: 新建 SystemMediaSelection.kt（含 SystemMediaRowMapping）
  ├─ C3: 新建 SystemMediaGrid.kt（含 SystemMediaGridBlock / SystemMediaDensityGhost / 网格 helper）
  ├─ C4: 新建 SystemMediaScrubber.kt（滑条 helper，不含死代码 SystemMediaTimeScrubber）
  ├─ C5: 新建 SystemMediaComponents.kt（ActionChip 公共组件 + IconButton + TopBar + AtmosphereLayer）
  └─ C6: 缩减 SystemMediaScreen.kt 为纯主容器

阶段D: FR-3 SystemMediaViewerScreen 拆分
  ├─ D1: 新建 SystemMediaViewerCanvas.kt
  ├─ D2: 新建 SystemMediaViewerControls.kt
  └─ D3: 缩减 SystemMediaViewerScreen.kt 为纯主容器
```

### 1.2 编译验证策略

- 每个步骤完成后立即 `gradlew.bat :app:compileDebugKotlin`（增量编译 ~30-60s）
- 每个阶段完成后 `gradlew.bat :app:assembleDebug`（完整构建 ~60-90s）
- 关键检查: object 单例外壳 + public 函数签名不变 + 外部调用方零改动

### 步骤 A1: 新建 SystemMediaPalette.kt

**目标**: 提取 palette 函数到公共位置，统一为 6 组调色板。

**文件**: `feature/photos/SystemMediaPalette.kt`（新建，~80 行）

**内容**:
- `internal val systemMediaPalettes: List<PhotoThumbnailPalette>` — 6 组调色板（取自 SystemMediaRepository.kt:425-452 的 6 组颜色）
- `internal fun paletteForSystemMediaId(mediaStoreId: Long): PhotoThumbnailPalette` — 按 mediaStoreId % 6 选择
- `internal fun paletteForPickedMedia(index: Int, type: SystemMediaType): PhotoThumbnailPalette` — 按 (index + videoOffset) % 6 选择，复用 6 组调色板

**关键决策**:
- pickedPaletteFor 原 4 组 → 改用 6 组。选择算法从 `(index+offset)%4` 变为 `(index+offset)%6`，颜色分布变化但视觉差异极小（前 4 组颜色不变，新增 2 组轮换）
