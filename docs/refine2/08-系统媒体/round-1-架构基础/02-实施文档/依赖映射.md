## 四、数据流图

### 4.1 导入状态数据流（拆分后）

```
[MediaStore 查询]
    ↓
SystemMediaRepository.queryMedia()
    ↓
LocalSystemMediaBridgeRepository.applyOverlay(items)  ← 薄代理
    ↓
ImportOverlayStore.applyOverlay(items)  ← 实际实现
    ↓
合并 appMediaIdBySystemSourceKey / linkedPostIdsByMediaId / hiddenMediaIds
    ↓
SystemMediaViewModel.uiState  ← 通过 latestMutationEvent 触发刷新
    ↓
SystemMediaScreen 网格渲染
```

### 4.2 上传数据流（拆分后）

```
[用户操作: 导入/新建/加入]
    ↓
LocalSystemMediaBridgeRepository.enqueue*  ← 薄代理
    ↓
UploadManager.enqueue*  ← 实际调度
    ↓
SystemMediaUploadReal.enqueueRealUploadTask  ← Real 实现
    ↓
POST /api/uploads/*  ← 服务端
    ↓
上传成功
    ↓
ImportOverlayStore.rememberAppMediaIdForSource  ← 状态合并
ImportOverlayStore.linkMediaToPost  ← 关联维护
ImportOverlayStore.publishMutation  ← 通知刷新
OperationBus.publishOperationSummaryIfReady  ← 事件发布
    ↓
LocalSystemMediaBridgeRepository.latestMutationEvent  ← 薄代理 getter
LocalSystemMediaBridgeRepository.uploadTasks  ← 薄代理 getter
LocalSystemMediaBridgeRepository.operationResults  ← 薄代理 getter
    ↓
外部调用方（TransferCenterScreen / YingShiApp / SystemMediaScreen）
```

### 4.3 Viewer 缩放数据流（拆分后）

```
[用户双指缩放]
    ↓
Modifier.systemViewerZoomGesture  ← 迁出到 ViewerZoomState.kt
    ↓
ViewerZoomState.applyTransform(...)  ← 共享类
    ↓
ViewerZoomState.scale / offset 更新
    ↓
SystemMediaViewerCanvas  ← 拆分后文件
    ↓
graphicsLayer { scaleX / scaleY / translationX / translationY }
    ↓
图片渲染
```

### 4.4 palette 数据流（拆分后）

```
[MediaStore 查询]
    ↓
SystemMediaRepository.queryMedia()
    ↓
paletteForSystemMediaId(mediaStoreId)  ← 引用 SystemMediaPalette.kt
    ↓
SystemMediaItem.palette
    ↓
SystemMediaGrid.kt → SystemMediaCard  ← 拆分后文件
    ↓
systemMediaCardBackground(item, density)  ← 使用 item.palette
    ↓
缩略图占位渐变背景

[Picked 媒体]
    ↓
SystemMediaUploadSupport.toPickedSystemMediaItem
    ↓
paletteForPickedMedia(index, type)  ← 引用 SystemMediaPalette.kt
    ↓
SystemMediaItem.palette
```
