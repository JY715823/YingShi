## 三、发现的 Bug

### BUG-1 (P1): 媒体刷新后相册列表（albums）不同步

**问题**: `loadAlbums()` 仅在 ViewModel 的 `init` 中调用一次。后续 `refresh()` / `startBackgroundRefresh()` / `handleBridgeMutation(MEDIA_STORE_CHANGED)` 重新加载媒体后均未重新调用 `loadAlbums()`。当用户拍摄新照片、删除照片或系统媒体库变更时，`AlbumSheet` 中显示的相册分组与计数仍是首次加载时的快照，造成数据不一致。

**根因**: Round 3 实施时只关注 init 流程，忽略了后续刷新路径的同步。

**修复**: 在 `startBackgroundRefresh` 和 `refresh` 的 onSuccess 中追加 `loadAlbums()` 调用。
- [SystemMediaViewModel.kt#L91](file:///E:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/photos/SystemMediaViewModel.kt#L91) (startBackgroundRefresh onSuccess)
- [SystemMediaViewModel.kt#L138](file:///E:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/photos/SystemMediaViewModel.kt#L138) (refresh onSuccess)

**验证**: `gradlew.bat compileDebugKotlin assembleDebug` BUILD SUCCESSFUL，Exit Code 0

---

### BUG-2 (P1): Viewer Overlay 动画硬编码 220ms，未使用 motion token

**问题**: `SystemMediaViewerScreen` 中顶部/底部 overlay 的 `fadeIn/fadeOut/slideInVertically/slideOutVertically` 共 8 处使用硬编码 `tween(if (motionEnabled) 220 else 0, ...)`，未使用 `YingShiThemeTokens.motion` 中的 token，违反 token 使用合规性约束。

**根因**: 实施时直接写死 220ms，未对齐 motion token 体系。

**修复**: 用 `motion.floatingMillis` (= 220) 替换全部 8 处硬编码 220。
- [SystemMediaViewerScreen.kt#L275-L326](file:///E:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/photos/SystemMediaViewerScreen.kt#L275-L326)
- 替换: `tween(if (motionEnabled) 220 else 0, ...)` → `tween(if (motionEnabled) motion.floatingMillis else 0, ...)`

**验证**: `gradlew.bat compileDebugKotlin assembleDebug` BUILD SUCCESSFUL，Exit Code 0

### BUG-3 (P1): SystemMediaDataSource.queryAlbums() 为完整死代码

**问题**: `SystemMediaDataSource` 接口声明了 `queryAlbums()`，`MediaStoreSystemMediaDataSource` 也完整实现了该方法（约 54 行），但全代码库无任何调用方。`LocalSystemMediaRepository.loadAlbums()` 实际使用的是 `groupAlbumsFromItems()` 私有扩展函数，从 media items 中分组，而非调用 `dataSource.queryAlbums()`。

**根因**: Round 3 实施时先实现了 MediaStore 原生查询，后改为基于缓存 items 分组，但未清理前一种方案的代码。

**修复**: 删除 `SystemMediaDataSource.queryAlbums()` 接口声明 + `MediaStoreSystemMediaDataSource.queryAlbums()` 实现（保留 `buildContentUri` 因为 queryMedia 仍在使用）。
- [SystemMediaRepository.kt#L155](file:///E:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/photos/SystemMediaRepository.kt#L155) 删除接口声明
- [SystemMediaRepository.kt](file:///E:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/photos/SystemMediaRepository.kt) 删除 54 行实现

**验证**: `gradlew.bat compileDebugKotlin assembleDebug` BUILD SUCCESSFUL，Exit Code 0
