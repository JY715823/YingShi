## 实施顺序与结果

### 1. FR-12 + FR-9: 去掉筛选文案 + 系统相册筛选

#### SystemMediaModels.kt
- 新增 `SystemMediaAlbum` data class（bucketName, displayName, mediaCount, coverUri, coverMediaType）
- `SystemMediaUiState` 新增 `selectedAlbum: SystemMediaAlbum? = null` 和 `albums: List<SystemMediaAlbum> = emptyList()` 字段

#### SystemMediaRepository.kt
- `SystemMediaRepository` 接口新增 `suspend fun loadAlbums(): List<SystemMediaAlbum>`
- `SystemMediaDataSource` 接口新增 `suspend fun queryAlbums(): List<SystemMediaAlbum>`
- `MediaStoreSystemMediaDataSource` 实现 `queryAlbums()`: 按 BUCKET_DISPLAY_NAME 分组，每组取最新一条作为封面
- `LocalSystemMediaRepository` 实现 `loadAlbums()`: 优先复用缓存 items 分组，避免重复 MediaStore 查询
- 新增 `groupAlbumsFromItems()` 扩展函数

#### SystemMediaViewModel.kt
- 新增 `loadAlbums()` 方法: 协程调用 repository.loadAlbums()
- 新增 `onAlbumSelected(album: SystemMediaAlbum?)` 方法
- `applyFilter` 签名改为 `applyFilter(filter, album)`: 先按 album 筛选，再按 filter 筛选
- `publishState` 从 `_uiState.value` 读取并保持 `selectedAlbum` 和 `albums`
- init 中调用 `loadAlbums()`

#### SystemMediaComponents.kt
- `SystemMediaTopBar` 新增参数: `totalCount`, `selectedAlbum`, `onOpenAlbums`
- 副标题文案: "当前筛选：${selectedFilter.label}" → "共 $totalCount 项$albumPart"
- 三横线菜单左侧新增相册按钮: `Icons.Filled.PhotoLibrary`
- 新增 `SystemMediaAlbumSheet` Composable: ModalBottomSheet + 2列 LazyVerticalGrid
- 新增 `SystemMediaAlbumItem` Composable: 封面缩略图+相册名+数量+选中高亮

#### SystemMediaScreen.kt
- 新增 `showAlbumSheet` 状态
- TopBar 调用传入 `totalCount`, `selectedAlbum`, `onOpenAlbums`
- 新增 AlbumSheet 渲染

### 2. FR-5: 网格视觉升级

#### MediaVisualComponents.kt
- `YingShiMediaFrame` 新增可选参数 `selectedBorderColor: Color? = null`
- 选中态 border color: `selectedBorderColor ?: colors.primaryContainer.copy(alpha = 0.58f)`

#### SystemMediaGrid.kt
- `SystemMediaCard` 调用 YingShiMediaFrame 传入 `selectedBorderColor = colors.viewerAccent.copy(alpha = 0.58f)`
- 选中态 `bottomGlowAlpha`: 0.24f → 0.30f
- `SystemMediaBadge` token 替换:
  - 底色: `raisedSurface.copy(alpha = 0.86f)` → `memoryContainer.copy(alpha = 0.96f)`
  - 边线: `dividerSoft.copy(alpha = 0.50f)` → `memoryAccent.copy(alpha = 0.28f)`
  - 文字: `titleAccent` → `onMemoryContainer`

### 3. FR-6: Viewer 视觉升级

#### 新建 SystemMediaViewerOverlayChrome.kt
- `SystemMediaViewerTopScrim`: 三段 verticalGradient(0.62→0.24→Transparent) + drawBehind 顶部边缘微光线(viewerOverlayEdgeGlow, 1.dp)
- `SystemMediaViewerBottomScrim`: 三段 verticalGradient(Transparent→0.20→0.58) + drawBehind 底部边缘微光线

#### SystemMediaViewerScreen.kt
- 顶部 AnimatedVisibility: fadeIn/fadeOut 加 `tween(220, easing = motion.easing)` + slideInVertically/slideOutVertically
- 底部 AnimatedVisibility: 同样加 tween + slide（向下滑入）
- 新增 `SystemMediaViewerTopScrim`(124.dp) 和 `SystemMediaViewerBottomScrim`(188.dp) 背景层

#### SystemMediaViewerControls.kt
- `SystemMediaViewerInfoCard`: 添加 drawBehind linearGradient(viewerSurface 0.82→0.55) + color=Transparent + border=viewerOverlayBorder + shadowElevation=4.dp
- `SystemMediaViewerCircleButton`: 添加 drawBehind linearGradient(viewerSurface 0.68→0.46) + color=Transparent + border=viewerOverlayBorder + size 46.dp + icon 23.dp
- `SystemMediaVideoControls`: border 改为 viewerOverlayBorder + 添加 drawBehind 渐变
- `SystemMediaViewerMenuAction`: danger 色从 `MaterialTheme.colorScheme.error` → `colors.destructive`

### 4. FR-13: 缩放动画美化

#### SystemMediaGrid.kt — SystemMediaDensityGhostOverlay
- alpha 动画: 硬编码 `tween(520)` → `tween(motion.densityMorphMillis, easing = motion.easing)`
- scale: 固定 `0.998f` → `Animatable(1f)` → `animateTo(0.96f, tween(motion.densityMorphMillis, easing = motion.easing))`
- alpha 和 scale 并发动画: `coroutineScope { async {} + async {} + awaitAll }`

#### SystemMediaScreen.kt — 主 grid 淡入
- 新增 `gridEnterAlpha = Animatable(1f)`
- `LaunchedEffect(densityName)`: snapTo(0f) → animateTo(1f, tween(densityPreviewMillis + densitySettleMillis, easing))
- 主 LazyVerticalGrid 添加 `.graphicsLayer { alpha = gridEnterAlpha.value }`
