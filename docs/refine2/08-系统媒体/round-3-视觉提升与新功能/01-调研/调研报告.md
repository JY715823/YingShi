- **MediaStore 查询**: `SystemMediaRepository.kt` line 309-454（`MediaStoreSystemMediaDataSource`）

- **onFilterSelected**（line 149-156）: 仅切换 filter，无 album 逻辑

#### 实施方案

2. **SystemMediaRepository.kt**:
   - `SystemMediaDataSource` 接口新增 `queryAlbums(): List<SystemMediaAlbum>`

### FR-13: 缩放动画美化

- **文件**: `SystemMediaGrid.kt` line 469-542（`SystemMediaDensityGhostOverlay`）
- **当前实现**:
  - alpha: `Animatable(1f)` → `animateTo(0f, tween(durationMillis = 520))`，无 easing 显式指定，duration 硬编码 520ms
  - scale: `graphicsLayer { scaleX = 0.998f; scaleY = 0.998f }` 固定常量，几乎不可见，无 Animatable 驱动
  - 新网格淡入: 当前无新网格淡入动画，density 切换后新 grid 直接替换，可能闪烁
- **可用 motion token**（`Tokens.kt` line 103-105）:
  - `densityPreviewMillis = 140`
  - `densityMorphMillis = 280`
  - `densitySettleMillis = 160`
- **FR-13 AC 要求**:
  - AC-1: 旧网格淡出更平滑（调整 alpha 曲线）
  - AC-2: 新网格淡入无闪烁
  - AC-3: 过渡期间无布局抖动
  - AC-4: 16列↔3列大跨度切换也流畅

#### 方案

1. **alpha 曲线优化**:
   - duration 从硬编码 520ms 改用 `motion.densityMorphMillis`（280ms）+ `motion.densitySettleMillis`（160ms）= 440ms 总过渡
   - 显式指定 `easing = motion.easing`
   - ghost alpha: 1f → 0f 用 `tween(densityMorphMillis, easing = motion.easing)`
2. **scale 动画化**:
   - 用 Animatable 驱动 scale: 1f → 0.96f（可见的轻微缩小），配合 alpha 淡出
   - `graphicsLayer { scaleX = scale.value; scaleY = scale.value }`
3. **新网格淡入**:
   - 在 `SystemMediaScreen.kt` 的主 LazyVerticalGrid 添加 `AnimatedVisibility` 或 alpha 渐入
   - 新 grid 出现时 alpha 从 0 → 1，`tween(densityPreviewMillis + densitySettleMillis, easing = motion.easing)`
   - 使用 `LaunchedEffect(density)` 触发淡入

## 三、数据流向

### FR-9 相册筛选数据流

```
MediaStore (BUCKET_DISPLAY_NAME)
  → MediaStoreSystemMediaDataSource.queryAlbums()
    → LocalSystemMediaRepository.loadAlbums()
      → SystemMediaViewModel.loadAlbums()
        → SystemMediaUiState.albums
          → SystemMediaAlbumSheet (ModalBottomSheet)
            → 用户选择 album
              → SystemMediaViewModel.onAlbumSelected(album)
                → applyFilter(filter, album)
                  → SystemMediaUiState.filteredItems 更新
                    → 网格重新渲染
```

### FR-5/FR-6 视觉数据流

```
YingShiThemeTokens.colors.viewerAccent / memoryContainer / onMemoryContainer / viewerOverlayEdgeGlow / viewerOverlayBorder
  → SystemMediaCard / YingShiMediaFrame (FR-5 网格)
  → SystemMediaViewerTopScrim / SystemMediaViewerBottomScrim / InfoCard / CircleButton (FR-6 Viewer)
```

## 五、技术约束

1. **颜色系统受保护**: 不引入新色相，所有新增视觉效果使用 `YingShiThemeTokens.colors.*` 现有 token
2. **YingShiMediaFrame 共享组件**: 被 4 个文件调用，修改需加可选参数，不改变默认行为
3. **不破坏现有入口**: 照片模块→系统媒体、生活控制台→系统媒体 等入口不受影响
4. **Round 1+2 已完成的文件稳定**: 刷新机制、导入状态、滑条回弹、16列性能已修复，本轮不改这些逻辑
5. **motion token 已定义**: densityMorphMillis/densityPreviewMillis/densitySettleMillis 已在 Tokens.kt 定义，FR-13 直接使用
