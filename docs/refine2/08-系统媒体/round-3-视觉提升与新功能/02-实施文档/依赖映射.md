## 四、数据流图

### FR-9 相册筛选数据流

```
[MediaStore]
  BUCKET_DISPLAY_NAME
    ↓
[MediaStoreSystemMediaDataSource.queryAlbums()]
  按 bucket 分组 → count + 封面
    ↓
[LocalSystemMediaRepository.loadAlbums()]
  优先复用已加载 items
    ↓
[SystemMediaViewModel.loadAlbums()]
  → _uiState.albums
    ↓
[SystemMediaScreen] → SystemMediaAlbumSheet
  用户选择 album
    ↓
[SystemMediaViewModel.onAlbumSelected(album)]
  → _uiState.selectedAlbum
  → publishState(filter, album)
    ↓
[applyFilter(filter, album)]
  先 album 筛选 → 再 filter 筛选
    ↓
[filteredItems 更新] → 网格重新渲染
```

### FR-5/FR-6 视觉数据流

```
[YingShiThemeTokens.colors]
  viewerAccent / memoryContainer / onMemoryContainer
  viewerOverlayEdgeGlow / viewerOverlayBorder / viewerSurface
    ↓
[FR-5 网格]
  YingShiMediaFrame(selectedBorderColor=viewerAccent)
  SystemMediaBadge(memoryContainer + onMemoryContainer)
    ↓
[FR-6 Viewer]
  SystemMediaViewerTopScrim/BottomScrim(viewerOverlayEdgeGlow)
  InfoCard/CircleButton(drawBehind 渐变 + viewerOverlayBorder)
```

### FR-13 动画数据流

```
[用户捏合密度切换]
  → updateDensity(nextDensity)
    → densityGhost = SystemMediaDensityGhost(...)
    → densityName = nextDensity.name
      ↓
  [Ghost Overlay 旧网格]
    alpha: 1→0 (tween(densityMorphMillis))
    scale: 1→0.96 (tween(densityMorphMillis))
    → onFinished() → densityGhost = null
      ↓
  [主 grid 新密度]
    gridEnterAlpha: 0→1 (tween(densityPreviewMillis + densitySettleMillis))
    → 淡入完成
```
