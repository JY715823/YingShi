### 组件级计划

#### SystemMediaModels.kt
```kotlin
@Immutable
data class SystemMediaAlbum(
    val bucketName: String,          // MediaStore BUCKET_DISPLAY_NAME
    val displayName: String,         // 显示名（bucketName 为 null 时显示"未分组"）
    val mediaCount: Int,             // 该相册媒体数量
    val coverUri: Uri?,              // 封面缩略图 Uri（取最新一条）
    val coverMediaType: SystemMediaType,  // 封面类型
)
```
- SystemMediaUiState 新增:
  - `selectedAlbum: SystemMediaAlbum? = null`
  - `albums: List<SystemMediaAlbum> = emptyList()`

#### SystemMediaRepository.kt
- `SystemMediaDataSource` 接口新增:
  ```kotlin
  suspend fun queryAlbums(): List<SystemMediaAlbum>
  ```
- `MediaStoreSystemMediaDataSource.queryAlbums()`:
  - 查询 MediaStore.Files，projection 包含 BUCKET_DISPLAY_NAME + _ID + MEDIA_TYPE
  - sortOrder = "datetaken DESC, DATE_MODIFIED DESC"
  - 遍历 cursor，按 bucketName 分组，记录 count + 首条（最新）作为封面
  - bucketName 为 null 的归入"未分组"（displayName = "未分组"）
- `SystemMediaRepository` 接口新增:
  ```kotlin
  suspend fun loadAlbums(): List<SystemMediaAlbum>
  ```
- `LocalSystemMediaRepository.loadAlbums()`:
  - 优先复用已加载的 items（peekCachedMedia 或内存缓存）分组
  - 若缓存为空，调用 dataSource.queryAlbums()

#### SystemMediaViewModel.kt
- 新增 `private val _albums` StateFlow
- 新增 `fun loadAlbums()`: 协程调用 repository.loadAlbums()
- 新增 `fun onAlbumSelected(album: SystemMediaAlbum?)`:
  - 更新 _uiState.selectedAlbum
  - 重新 publishState（带 album 筛选）
- `applyFilter` 签名改为:
  ```kotlin
  private fun List<SystemMediaItem>.applyFilter(
      filter: SystemMediaFilter,
      album: SystemMediaAlbum?,
  ): List<SystemMediaItem>
  ```
  - 先按 album 筛选（bucketName 匹配），再按 filter 筛选
- init 中加载 albums

#### SystemMediaComponents.kt
- `SystemMediaTopBar` 新增参数:
  - `onOpenAlbums: () -> Unit`
  - `selectedAlbum: SystemMediaAlbum?`
  - `totalCount: Int`
- TopBar Row 布局变为: `[返回][标题+副标题][刷新][相册按钮][Menu三横线]`
- 相册按钮: `Icons.Default.PhotoLibrary` + `SystemMediaIconButton` 样式，选中 album 时高亮
- 新增 `SystemMediaAlbumSheet`:
  ```kotlin

      albums: List<SystemMediaAlbum>,
      selectedAlbum: SystemMediaAlbum?,
      onDismiss: () -> Unit,
      onAlbumSelected: (SystemMediaAlbum?) -> Unit,

  ```
  - ModalBottomSheet，containerColor = sectionBackground
  - LazyVerticalGrid(columns = GridCells.Fixed(2))，2 列网格
  - 每项: 封面缩略图（rememberSystemMediaThumbnail）+ 相册名 + 数量 badge

## FR-13: 缩放动画美化

### 目标
密度切换 Ghost Overlay 过渡更流畅，新网格淡入无闪烁。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `feature/photos/SystemMediaGrid.kt` | Android | 修改 | SystemMediaDensityGhostOverlay: alpha 用 motion token、scale Animatable 化 |
| 2 | `feature/photos/SystemMediaScreen.kt` | Android | 修改 | 主 grid 新增淡入动画 |

### 组件级计划

#### SystemMediaGrid.kt — SystemMediaDensityGhostOverlay
```kotlin
// alpha 动画
val motion = YingShiThemeTokens.motion
LaunchedEffect(ghost.nonce) {
    val alphaJob = async {
        alpha.animateTo(
            targetValue = 0f,
            animationSpec = tween(
                durationMillis = motion.densityMorphMillis,
                easing = motion.easing,
            ),
        )
    }
    val scaleJob = async {
        scale.animateTo(
            targetValue = 0.96f,
            animationSpec = tween(
                durationMillis = motion.densityMorphMillis,
                easing = motion.easing,
            ),
        )
    }
    awaitAll(alphaJob, scaleJob)
    onFinished()
}

// scale Animatable
val scale = remember { Animatable(1f) }
// graphicsLayer
.graphicsLayer {
    this.alpha = alpha.value
    scaleX = scale.value
    scaleY = scale.value
}
```

#### SystemMediaScreen.kt — 主 grid 淡入
- 新增 `var gridEnterAlpha by remember { mutableStateOf(0f) }`
- `LaunchedEffect(densityName) { gridEnterAlpha = 0f; gridEnterAlpha = animateTo(1f, tween(motion.densityPreviewMillis + motion.densitySettleMillis)) }`
- 主 LazyVerticalGrid 的 graphicsLayer.alpha = gridEnterAlpha
- density 切换时先重置为 0 再动画到 1
