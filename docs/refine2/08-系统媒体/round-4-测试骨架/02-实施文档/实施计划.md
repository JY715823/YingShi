## 二、FR-7: 测试骨架搭建

### 目标

为 ViewModel 筛选逻辑和导入预览查重逻辑添加基础单元测试，聚焦核心逻辑，不追求高覆盖率。

### 变更文件 1: SystemMediaViewModel.kt

**变更**: L256 `private fun List<SystemMediaItem>.applyFilter` → `internal fun List<SystemMediaItem>.applyFilter`

**理由**: applyFilter 是纯函数，但当前是文件级 private，无法从测试文件访问。改为 internal 后可在同 module 的测试文件中直接调用，与项目现有纯函数测试模式一致（如 `buildSystemMediaImportPreview` 已是 internal）。

**影响**: 仅可见性扩大，无行为变更。internal 在 Kotlin module 内可见，本模块（app）内的测试代码可访问。不影响外部模块（其他 module 无法访问 internal）。

### 变更文件 2: SystemMediaTestFixtures.kt (新建)

**目标**: 提供共享的测试数据构造工具，避免两个测试类各自维护重复的 helper。

**内容**:
```kotlin
package com.example.yingshi.feature.photos

import android.net.UriTestDouble
import androidx.compose.ui.graphics.Color

/**
 * 测试专用 SystemMediaItem 工厂。
 * 参数都有默认值，调用方按需覆盖。
 */
internal fun sampleSystemMediaItem(
    id: String,
    mediaStoreId: Long,
    type: SystemMediaType = SystemMediaType.IMAGE,
    mimeType: String = "image/jpeg",
    displayName: String = "$id.jpg",
    bucketName: String? = "Camera",
    capturedAtMillis: Long? = 1_780_600_000_000L,
    fileModifiedAtMillis: Long? = 1_780_601_000_000L,
    importedAppMediaId: String? = null,
    width: Int = 1080,
    height: Int = 1440,
    videoDurationMillis: Long? = null,
    sizeBytes: Long? = 2_048_000L,
): SystemMediaItem
```

**扩展点**（相比原 private helper 新增的参数）:
- `type` — 支持 VIDEO 测试
- `bucketName` — 支持不同相册测试（默认 "Camera"）
- `importedAppMediaId` — 支持 IMPORTED/UNIMPORTED 测试
- `videoDurationMillis` — 支持视频元数据测试

### 变更文件 3: SystemMediaViewModelTest.kt (新建)

**目标**: FR-7 AC-1 — 测试 6 种 filter + album 组合筛选逻辑。

**测试用例清单**:

| # | 测试名 | 验证点 |
|---|--------|-------|
| 1 | `allFilterReturnsAllItems` | ALL 不筛选，返回全部 |
| 2 | `cameraFilterMatchesCameraBucket` | CAMERA 匹配 bucket 含 "Camera" |
| 3 | `cameraFilterMatchesDcimBucket` | CAMERA 匹配 bucket 含 "DCIM"（大小写不敏感） |
| 4 | `cameraFilterExcludesNonCameraBucket` | CAMERA 排除非 camera/dcim 的 bucket |
| 5 | `cameraFilterHandlesNullBucketName` | CAMERA 对 bucketName=null 用空字符串，不崩溃 |
| 6 | `screenshotFilterMatchesBucketName` | SCREENSHOT 匹配 bucket 含 "screenshot" |
| 7 | `screenshotFilterMatchesDisplayName` | SCREENSHOT 匹配 displayName 含 "Screenshot" |
| 8 | `screenshotFilterExcludesNonScreenshot` | SCREENSHOT 排除不含 screenshot 的项 |
| 9 | `videoFilterReturnsOnlyVideos` | VIDEO 只返回 type==VIDEO |
| 10 | `videoFilterExcludesImages` | VIDEO 排除 type==IMAGE |
| 11 | `importedFilterReturnsOnlyImported` | IMPORTED 只返回 importedAppMediaId 非空的 |
| 12 | `unimportedFilterReturnsOnlyUnimported` | UNIMPORTED 只返回 importedAppMediaId 为空的 |
| 13 | `albumFilterNarrowsToSpecificBucket` | album 筛选缩小到指定 bucketName |
| 14 | `albumNullSkipsAlbumFiltering` | album==null 跳过 album 筛选 |
| 15 | `albumPlusFilterIsAndCombination` | album + filter 是 AND 组合（先 album 后 filter） |
| 16 | `albumPlusCameraCombination` | album + CAMERA 组合：先按 bucket 筛选再按 camera 筛选 |
| 17 | `emptyListReturnsEmpty` | 空列表输入返回空列表 |
| 18 | `cameraFilterIsCaseInsensitive` | "CAMERA"/"camera"/"Camera" 都匹配 |

**测试模式**: 纯函数直测，直接调用 `listOf(...).applyFilter(filter, album)` 断言结果。
