## 四、数据流图

### 4.1 刷新数据流（FR-8 重构后）

```
[用户进入页面]
    ↓
SystemMediaViewModel.init
    ↓
repository.peekCachedMedia(maxAgeMillis = 5min)
    ↓
[缓存未过期] → 显示缓存 + startBackgroundRefresh()  ← 后台静默刷新
    ↓                                                  ↓
[缓存过期/无缓存]                                 repository.loadMedia(true)
    ↓                                                  ↓
refresh() (isRefreshing = true, 显示 loading)         publishState (isBackgroundRefreshing = false)
    ↓                                                  ↓
repository.loadMedia(true)                       网格更新（无 loading 动画）
    ↓
publishState (isRefreshing = false)
    ↓
网格更新

[ContentObserver 触发]
    ↓
SystemMediaContentObserver.onChange (debounce 500ms)
    ↓
startBackgroundRefresh()
    ↓
repository.loadMedia(true)
    ↓
publishState (isBackgroundRefreshing = false)
    ↓
网格更新

[手动刷新按钮 / 下拉刷新]
    ↓
refresh(forceRefresh = true) (isRefreshing = true, 显示 loading)
    ↓
repository.loadMedia(true)
    ↓
publishState (isRefreshing = false)
    ↓
网格更新
```

### 4.2 导入状态数据流（FR-10 重构后）

```
[MediaStore 查询]
    ↓
SystemMediaRepository.queryMedia()
    ↓
LocalSystemMediaBridgeRepository.applyOverlay(items)  ← overlay 是单一来源
    ↓
ImportOverlayStore.applyOverlay(items)
    ↓
合并 appMediaIdBySystemSourceKey + linkedPostIdsByMediaId + hiddenMediaIds
    ↓ (不再回退到 item.importedAppMediaId，因为缓存层不存此字段)
SystemMediaViewModel.uiState
    ↓
SystemMediaScreen 网格渲染

[删除 App 媒体流程]
    ↓
RealPhotoFeedViewModel.deleteMedia()
    ↓
forgetImportStatusByAppMediaId(mediaId)  ← 持久化 invalidatedAppMediaIds
    ↓
invalidateSystemMediaMetadataCache(clearDisk = true)  ← 清磁盘缓存
    ↓
重启 App 后从磁盘读到 invalidatedAppMediaIds → 已删除媒体不再显示"已导入"

[上传成功流程]
    ↓
UploadManager.enqueueRealUploadTask
    ↓
SystemMediaUploadReal.kt: 上传成功
    ↓
ImportOverlayStore.rememberAppMediaIdForSource()  ← 立即更新 overlay
    ↓
invalidateSystemMediaMetadataCache(clearDisk = true)  ← 清磁盘缓存
    ↓
publishMutation(OVERLAY_ONLY)  ← 触发 publishState，网格立即显示"已导入"
```

### 4.3 指纹数据流（FR-10 修复后）

```
[上传时]
    ↓
normalizeSystemMediaForImport()  ← 归一化 displayTimeMillis
    ↓
mediaItem.stableImportMetadataSourceFingerprint()
    ↓
stableImportMetadataKey() = "meta:image|mime|name|size|wxh|duration"  ← 不含 displayTimeMillis
    ↓
SHA-256(key)
    ↓
上传到服务端 sourceFingerprint 字段

[查询时]
    ↓
mediaItem.stableImportMetadataSourceFingerprint()
    ↓
stableImportMetadataKey() = "meta:image|mime|name|size|wxh|duration"  ← 同上
    ↓
SHA-256(key)
    ↓
发送给服务端，按 sourceFingerprint 字段查 → 匹配成功

[历史已上传媒体]
    ↓
旧 sourceFingerprint = SHA-256("meta:image|...|displayTimeMillis|...")  ← 含 displayTimeMillis
    ↓
新查询发送 metadataFingerprint = SHA-256("meta:image|...")  ← 不含 displayTimeMillis
    ↓
不匹配 → 该媒体不显示"已导入"
    ↓
但客户端查询也发送 sourceFingerprint (基于 mediaStoreId)
    ↓
服务端按 sourceFingerprint 字段查不到（因为存的是 metadata 指纹）
    ↓
历史媒体首次查询显示"未导入"
    ↓
[缓解] 用户重新上传时新指纹生效
```

### 4.4 滑条数据流（FR-11 修复后）

```
[用户开始拖拽]
    ↓
PhotoFeedTimeScrubber.onInteractingChanged(true)
    ↓
SystemMediaScreen.onInteractingChanged:
    scrubberInteracting = true
    scrubberDragProgress = currentScrollProgress
    ↓ (非16列)
renderedCount = uiState.filteredItems.size  ← 一次性全量扩展
    ↓
visibleItems / gridBlocks / scrubberTargetBlockIndexByMediaId 一次重建后稳定

[拖拽中]
    ↓
PhotoFeedTimeScrubber.onSeekToProgress(progress)
    ↓
SystemMediaScreen.onSeekToProgress:
    targetIndex 计算
    scrubberDragProgress / scrubberDragLabel 更新
    ↓ (不再修改 renderedCount)
    scrubberScrollJob.cancel() + launch {
        gridState.scrollToItem(targetBlockIndex, scrollOffset)
    }
    ↓
gridState 滚动到目标位置
    ↓
LazyVerticalGrid 不 relayout（renderedCount 已全量）
    ↓
gridState.firstVisibleItemIndex 变化 → 更新 displayedScrubberProgress
    ↓
滑条 UI 跟随手指位置（不回弹）

[用户松手]
    ↓
PhotoFeedTimeScrubber.onInteractingChanged(false)
    ↓
SystemMediaScreen.onInteractingChanged:
    scrubberInteracting = false
    scrubberDragProgress = null
    ↓ (renderedCount 保持当前值，不回收)
    网格稳定在目标位置
```

### 4.5 16 列渲染数据流（FR-14 优化后）

```
[16 列模式]
    ↓
initialRenderCount = uiState.filteredItems.size  ← 全量
    ↓
SystemMediaThumbnailWarmer:
    warmWindow = 240  ← 减少（原 420）
    warmBatchSize = 10  ← 减少（原 18）
    ↓
prefetchSystemMediaThumbnail(context, uri, 96)
    ↓
SystemMediaBitmapThumbnailCache.get(cacheKey, 96)
    ↓
缓存命中 → 返回 Bitmap
    ↓ (未命中)

    ↓
SystemMediaBitmapThumbnailCache.put(cacheKey, bitmap)
    ↓
overviewCache.put (LruCache 48MB)  ← 增大（原 24MB）
    ↓

```

## 七、依赖映射总结

- **本模块依赖外部**: 服务端 API（7 个，本轮不改）+ Android 系统组件（MediaStore + ContentObserver + SharedPreferences）+ Material3 PullToRefreshBox
- **外部调用本模块**: 11 个文件通过 LocalSystemMediaBridgeRepository 薄代理调用（零改动）；4 处调用 invalidateSystemMediaMetadataCache（2 处改 clearDisk=true）；2 处新增 invalidate 调用
- **共享组件**: 仅 SystemMediaUiState 新增字段（向后兼容）；PhotoFeedTimeScrubber / PullToRefreshBox 不改
- **API 契约**: 4 个对外契约全部向后兼容（可选参数 + 默认值）
- **回归测试**: 16 项功能回归 + 8 项跨模块回归 + 4 项 API 回归
