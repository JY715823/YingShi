## 如何验证

### 快速验证（10 分钟核心验证）

1. **编译**: `gradlew.bat assembleDebug` → BUILD SUCCESSFUL
2. **进入系统媒体**: 照片模块 → 系统媒体 → 确认网格加载正常，无刷新按钮旋转
3. **刷新**: 手动点击刷新 → 确认按钮旋转 → 完成后停止
4. **导入状态**: 查看已导入/未导入标记是否准确
5. **时间滑条**: 拖拽滑条 → 确认网格滚动到目标位置 → 松手后不跳回
6. **16列模式**: 双指捏合缩到最小 → 确认滚动流畅无卡顿
7. **相册筛选**: 点击相册按钮 → 确认弹窗显示系统相册列表 → 选择后网格过滤

### 完整验证（每个 FR 的验证方法）

**FR-1~4 拆分验证**: 所有功能与精修前一致（导入/新建/加入/删除/Viewer/密度/筛选/滑条）

**FR-5 网格视觉**: 选中卡片有 viewerAccent 边线光泽，已导入标记为 memoryContainer 浅底 badge

**FR-6 Viewer 视觉**: 进入 Viewer → 确认顶部/底部 overlay 有边缘光线和渐变

**FR-7 测试**: `gradlew.bat testDebugUnitTest` → SystemMedia* 测试全部 PASS

**FR-8 刷新**: 退出再进入 → 确认不自动旋转；新增照片后等待 → 确认自动感知更新

**FR-9 相册筛选**: 点击相册按钮 → 2列网格弹窗 → 选择相册 → 网格只显示该相册媒体

**FR-10 导入状态**: 导入媒体 → 标记立即变为"已导入"；在 App 媒体库删除 → 标记清除

**FR-11 滑条**: 快速拖拽 → 不跳回顶部；慢速拖拽 → 精确跳转

**FR-12 筛选文案**: 标题下方无"当前筛选：xx"文案

**FR-13 缩放动画**: 密度切换时旧网格平滑淡出，新网格无闪烁

**FR-14 16列性能**: 大量媒体(500+)下快速滚动 → 帧率流畅，无明显掉帧
