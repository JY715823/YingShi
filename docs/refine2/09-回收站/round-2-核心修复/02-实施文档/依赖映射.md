## 一、本模块依赖的外部模块/服务

| 外部依赖 | 依赖方向 | 本轮是否改动接口 | 影响说明 |

## 四、数据流图

### 4.1 FR-6 导航修复数据流

```
[用户从回收站列表点击条目]
    ↓
onOpenTrashDetail(route) 
    ↓ [新增] photosTopDestinationName = TRASH
    ↓
trashDetailRoute = route
    ↓
YingShiApp when 块命中 trashDetailRoute != null 分支
    ↓ [PhotosRootScreen 被销毁]
TrashDetailScreen 渲染
    ↓
[用户按系统返回]
    ↓
trashDetailRoute BackHandler 触发
    ↓ [修改] 不再调 restoreNotificationCenter()
    ↓
trashDetailRoute = null
    ↓
YingShiApp when 块命中 else 分支
    ↓
PhotosRootScreen 重建
    ↓ [修复] initialPage = PhotosTopDestination.valueOf("TRASH").ordinal = 2
    ↓
回收站 Tab 显示 ✓
```

### 4.2 FR-9 purge 彻底清理数据流

```
[用户在待清理页点击永久删除]
    ↓
RealTrashPendingCleanupScreen onPurge
    ↓
viewModel.purgePendingCleanupEntries
    ↓
trashRepository.purgeTrashItem(id) → 后端 POST /api/trash/items/{id}/purge
    ↓
TrashService.purgeTrashItem
    ├→ purgeItemData (按类型分发)
    │   ├→ [MEDIA_SYSTEM_DELETED] purgeMediaSystemDeleted
    │   │   ├→ localMediaStorageService.deleteStoredMediaFiles [增强] 彻底删 MinIO 所有尺寸
    │   │   ├→ postMediaRepository.deleteByLibraryIdAndMediaId
    │   │   ├→ commentRepository.deleteByLibraryIdAndMediaId
    │   │   └→ mediaRepository.delete
    │   ├→ [SMALL_ALBUM_DELETED] purgeSmallAlbumDeleted [增强]
    │   │   ├→ purgeMediaRemovedItemsForSmallAlbum (原有)
    │   │   ├→ [新增] purgeMediaSystemDeletedItemsForSmallAlbum (级联清理子媒体)
    │   │   ├→ postMediaRepository.deleteByLibraryIdAndPostId
    │   │   ├→ commentRepository.deleteByLibraryIdAndPostId
    │   │   └→ postRepository.delete
    │   └→ [LARGE_ALBUM_DELETED] purgeLargeAlbumDeleted [增强]
    │       ├→ for each smallAlbumId: purgeSmallAlbumCascade [新增共用方法]
    │       └→ albumRepository.delete
    └→ trashItemRepository.delete(item)
    ↓
SyncVersionTracker.markLocalMutation(TRASH, PHOTO_FEED, ALBUMS)
```

### 4.3 FR-10 restore 关系迁移数据流

```
[用户点击恢复 MEDIA_SYSTEM_DELETED 条目]
    ↓
TrashService.restoreTrashItem
    ↓
restoreMediaSystemDeleted
    ├→ 检查指纹冲突
    │   ├→ [无冲突] 恢复媒体本体 + post_media 关系 + 封面
    │   └→ [有冲突] [新增] 迁移关系到已存在媒体 + 恢复封面 + 物理删除当前媒体
    ↓
SyncVersionTracker.markLocalMutation(PHOTO_FEED, ALBUMS, TRASH, NOTIFICATIONS, [新增] SYSTEM_MEDIA)
    ↓
SystemMediaViewModel 监听 systemMediaStale [新增]
    ↓
refresh(forceRefresh = true)
    ↓
SyncVersionTracker.markRefreshed(SYSTEM_MEDIA)
```
