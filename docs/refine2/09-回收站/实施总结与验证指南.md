## 如何验证

### 快速验证（10 分钟核心验证）

1. **编译**: `gradlew.bat assembleDebug` → BUILD SUCCESSFUL
2. **进入回收站**: 照片模块 → 回收站 → 确认四类列表正常
3. **分类名**: 确认顶栏下方显示当前分类名
4. **待清理入口**: 分类菜单中有待清理选项（有待清理条目时）
5. **导航**: 进入详情 → Viewer → 系统返回 → 确认回到回收站列表
6. **恢复**: 恢复一个条目 → 确认照片流/相册更新
7. **移出+待清理**: 移出回收站 → 待清理页出现 → 撤销/永久删除

### 完整验证（每个 FR 的验证方法）

**FR-1/FR-2 拆分验证**: 所有功能与精修前一致（列表/详情/待清理/Viewer/恢复/移出/永久删除）

**FR-3 视觉**: 列表卡片有渐变+边框，待清理有三色倒计时徽章

**FR-4 切换**: 切换分类时先显示缓存内容，不闪空

**FR-5 测试**: `gradlew.bat testDebugUnitTest` → RealTrash* 测试全部 PASS

**FR-6 导航**: 从回收站 Viewer 按系统返回 → 回到回收站列表（当前分类）

**FR-7 分类名**: 顶栏下方显示分类名 + 条目数

**FR-8 排版**: 媒体/小相册/大相册详情排版整齐

**FR-9 待清理**: 分类菜单有待清理入口 → 倒计时+撤销+永久删除 → purge 后 DB+MinIO 无残留

**FR-10 关系**: 恢复后评论/关系/导入状态正确，照片流不重复

### 跨模块验证

| 模块 | 验证方法 | 预期 |
|------|---------|------|
| 照片流 | 恢复系统媒体后切回照片流 → 确认不重复 | 去重正常 |
| 相册/小相册 | 恢复相册后 → 确认子小相册/媒体数量正确 | 关系恢复正常 |
| 系统媒体 | 恢复后 → 确认导入状态标记更新 | 导入状态刷新 |
| 评论 | purge 系统媒体后 → 确认评论已删除 | 评论清理正常 |
