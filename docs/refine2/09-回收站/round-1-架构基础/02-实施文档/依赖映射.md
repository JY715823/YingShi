## 四、数据流图

```
[用户进入回收站]
    ↓
PhotosRootScreen.kt → TrashPageScreen.kt → RealTrashPageScreen (RealTrashListScreen.kt)
    ↓
RealTrashListViewModel.factory() → viewModel()
    ↓
refresh(selectedType)
    ├→ trashRepository.getTrashItems() → 后端 GET /api/trash/items
    ├→ trashRepository.getPendingCleanupItems() → 后端 GET /api/trash/pending-cleanup
    ├→ 磁盘缓存 (AppReadCacheStore) → 离线兜底
    └→ [原] RealTrashMemoryCache → [新] 已删除
    ↓
uiState → RealTrashPageScreen 渲染列表

[用户点击详情]
    ↓
YingShiApp.kt → TrashDetailScreen.kt → RealTrashDetailScreen (RealTrashDetailScreen.kt)
    ↓
RealTrashDetailViewModel.factory(route) → viewModel()
    ↓
refresh()
    ├→ trashRepository.getTrashDetail() → 后端 GET /api/trash/items/{id}
    ├→ 磁盘缓存 (AppReadCacheStore) → 离线兜底
    └→ [原] RealTrashMemoryCache → [新] 已删除
    ↓
uiState → RealTrashDetailScreen 渲染详情
```
