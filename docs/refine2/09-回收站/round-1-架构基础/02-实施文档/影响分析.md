## 一、变更影响链

### 1.1 FR-1: RealTrashScreens.kt 拆分

```
RealTrashScreens.kt (删除)
  ├→ 内容迁移到 4 个新文件 (同包，无需 import 变更)
  │    ├→ RealTrashShared.kt
  │    ├→ RealTrashViewer.kt
  │    ├→ RealTrashListScreen.kt (含 RealTrashPageScreen 公开入口)
  │    └→ RealTrashDetailScreen.kt (含 RealTrashDetailScreen 公开入口)
  │
  ├→ 外部调用方 (同包，无需修改)
  │    ├→ TrashPageScreen.kt:79 — 调用 RealTrashPageScreen
  │    ├→ TrashDetailScreen.kt:76 — 调用 RealTrashDetailScreen
  │    ├→ NotificationCenterScreen.kt:1738 — 调用 realTrashMediaSource (internal)
  │    └→ RealPhotoUiMappers.kt:202 — 调用 realTrashMediaSource (internal)
  │
  └→ 删除的遗留死代码 (无调用方，零影响)
       ├→ RealTrashSelectionActionRow
       ├→ RealTrashGridMonthHeader + RealTrashMonthGroup + realTrashMonthGroups
       └→ RealTrashMediaViewerDetailContent
```

**影响说明**: 所有文件均在 `com.example.yingshi.feature.photos` 同包内，Kotlin 同包无需显式 import。拆分后公开 Composable 和 internal 函数的可见性不变，调用方无需修改。

### 1.2 FR-2: RealTrashMemoryCache 删除

```
RealTrashViewModels.kt (修改)
  ├→ 删除 RealTrashMemoryCache object (L47-81)
  │    ├→ RealTrashListViewModel — 移除 6 处引用
  │    └→ RealTrashDetailViewModel — 移除 2 处引用
  │
  ├→ 直接影响
  │    └→ RealTrashScreens.kt (拆分后的 RealTrashListScreen.kt / RealTrashDetailScreen.kt)
  │         └→ viewModel(factory = ...) 调用 — factory 签名不变，零影响
  │
  └→ 间接影响
       ├→ TrashPageScreen.kt — 间接通过 RealTrashPageScreen 使用 VM，零影响
       └→ TrashDetailScreen.kt — 间接通过 RealTrashDetailScreen 使用 VM，零影响
```

**影响说明**: RealTrashMemoryCache 是 private object，文件外零引用。删除后仅影响同文件内两个 ViewModel 的缓存逻辑，VM 的 factory 签名和 uiState 暴露不变。

## 三、前端影响链

### ViewModel → Composable 影响

```
RealTrashListViewModel
  ├→ uiState.entries → RealTrashPageScreen 列表渲染
  ├→ uiState.pendingEntries → RealTrashPendingCleanupScreen 待清理列表
  ├→ uiState.isLoading → 列表加载态
  ├→ uiState.isOfflineReadOnly → 离线只读提示
  └→ uiState.errorMessage → 错误提示

RealTrashDetailViewModel
  ├→ uiState.detail → RealTrashDetailScreen 详情渲染
  ├→ uiState.isLoading → 详情加载态
  └→ uiState.errorMessage → 错误提示
```

**影响**: uiState 数据结构不变，Composable 侧零修改。

### Composable → 共享组件影响

```
RealTrashSectionCard (迁移到 RealTrashShared.kt)
  ├→ RealTrashListScreen.kt 多处使用
  ├→ RealTrashDetailScreen.kt 多处使用
  └→ RealTrashViewer.kt 不使用

RealTrashViewerMetaCapsule (迁移到 RealTrashShared.kt)
  ├→ RealTrashListScreen.kt — RealTrashPostGridCard 使用
  └→ RealTrashViewer.kt — RealTrashViewerTopBar 使用

realTrashMediaSource (迁移到 RealTrashShared.kt, internal)
  ├→ RealTrashListScreen.kt — RealTrashEntryPreview 使用
  ├→ RealTrashDetailScreen.kt — RealTrashMediaStrip 使用
  ├→ RealTrashViewer.kt — TrashViewerMediaCanvas 使用
  ├→ NotificationCenterScreen.kt (跨模块)
  └→ RealPhotoUiMappers.kt (跨模块)
```

**影响**: 所有共享组件迁移到 RealTrashShared.kt 后，同包内引用不变。internal 可见性在同 module 内有效。
