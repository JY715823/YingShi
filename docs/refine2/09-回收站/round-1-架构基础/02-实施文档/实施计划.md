## 三、FR-2: ViewModel 架构改进

### 目标

删除 `RealTrashMemoryCache`（private object）全局单例，消除内存泄漏和多账号串号风险。两个 ViewModel 保持现有 class+StateFlow 模式不变，改用磁盘缓存兜底。

### 变更文件 6: RealTrashViewModels.kt（修改）

**删除**: `RealTrashMemoryCache` object（L47-81，35 行）

**修改 RealTrashListViewModel**:

| 行号 | 原代码 | 新代码 | 说明 |
|------|--------|--------|------|
| 87 | `activeListKey = RealTrashMemoryCache.listKey(initialSelectedType)` | `activeListKey = initialSelectedType?.name ?: "ALL"` | 内联 key 计算 |
| 88-90 | `RealTrashMemoryCache.readListState(initialSelectedType) ?: RealTrashListUiState(isLoading = true)` | `RealTrashListUiState(isLoading = true)` | 移除内存缓存读取 |
| 95-98 | `RealTrashMemoryCache.listKey/readListState/hasListState` | 删除内存缓存相关变量 | 保留 `cachedList` 磁盘缓存 |
| 101-108 | `cachedState` 相关逻辑 | 简化为：`if (nextListKey != activeListKey) { activeListKey = nextListKey; _uiState.value = cachedList?.toUiState() ?: RealTrashListUiState(isLoading = true) }` | Tab 切换改用磁盘缓存 |
| 132 | `!hasCachedState` 条件 | 移除该条件 | 不再有内存缓存 |
| 196 | `RealTrashMemoryCache.writeListState(selectedType, nextState)` | 删除此行 | 不再写入内存缓存 |

**修改 RealTrashDetailViewModel**:

| 行号 | 原代码 | 新代码 | 说明 |
|------|--------|--------|------|
| 415-417 | `RealTrashMemoryCache.readDetailState(route.entryId) ?: RealTrashDetailUiState(isLoading = true)` | `RealTrashDetailUiState(isLoading = true)` | 移除内存缓存读取 |
| 468 | `RealTrashMemoryCache.writeDetailState(route.entryId, nextState)` | 删除此行 | 不再写入内存缓存 |

### 行为变化说明

| 场景 | 原行为 | 新行为 | 影响 |
|------|--------|--------|------|
| 首次进入列表 | 内存缓存命中→立即显示；否则 loading | loading→网络获取 | 无缓存时行为不变 |
| 切换 Tab 回来 | 内存缓存命中→立即显示 | 磁盘缓存命中→立即显示；否则 loading | 磁盘缓存读取快（~100ms），体验差异极小 |
| 返回列表页 | 内存缓存命中→不闪空 | 磁盘缓存命中→不闪空 | 同上 |
| 多账号切换 | 内存缓存串号（bug） | 无串号（修复） | **bug 修复** |
| VM 销毁后重建 | 内存缓存残留（泄漏） | 无残留 | **内存泄漏修复** |
