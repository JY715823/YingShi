## 四、数据流图

### 4.1 分类切换数据流

```
用户点击 DropdownMenu 分类项
  → onSelectedTypeNameChange(typeName)
  → selectedTypeName 状态更新
  → LaunchedEffect(selectedTypeName) 触发 viewModel.refresh(selectedType)
  → ViewModel 读缓存 → 显示缓存内容（AC-1）
  → ViewModel 请求后端 → 成功更新 / 失败显示只读（AC-2）
  → AnimatedContent 检测 selectedType 变化 → fadeIn/fadeOut 切换（AC-3）
  → RealTrashCategoryHeader 检测 selectedType 变化 → Crossfade 更新分类名（FR-7）
```

### 4.2 待清理倒计时数据流

```
后端返回 pendingCleanupItems
  → ViewModel 更新 lastKnownPendingEntries
  → UI 渲染 RealTrashPendingCleanupRow
  → RealTrashCountdownBadge 计算 remainingMillis = undoDeadlineMillis - now
  → 根据 remainingMillis/24h 比例选择颜色档位
  → 渐变背景 + shadowElevation + 图标 + 文字
```

### 4.3 大相册详情数据流

```
后端返回 trash detail
  → entry.albumSnapshot.postSnapshots
  → RealTrashLargeAlbumChildList 渲染
  → 每项: 缩略图 + 标题 + 媒体数
```

### 4.4 离线只读态数据流

```
后端请求失败
  → ViewModel 设置 isOfflineReadOnly = true + statusMessage
  → RealTrashOfflineBanner 在顶部展示
  → 操作按钮 enabled = !isMutating && !isOfflineReadOnly
  → ReconnectRefreshEffect 监听网络恢复 → 自动刷新
```
