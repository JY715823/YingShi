## 二、必须测试的影响路径清单（IA）

### IA-1: RealTrashIconActionButton 签名不变但视觉变化影响所有调用方

- **变更**: token 替换 + 渐变背景 + shadowElevation
- **影响路径**: RealTrashIconActionButton → 列表顶栏按钮 + 详情顶栏按钮 + 待清理按钮 + 对话框按钮
- **必须测试**: 列表/详情/待清理/对话框 四处按钮视觉正确 + 点击响应正常
- **回归风险**: 低（签名不变，仅视觉变化）

### IA-2: RealTrashDetailTopBar 替换原 RealTrashPostDetailTopBar

- **变更**: 小相册详情顶部栏从 RealTrashPostDetailTopBar → RealTrashDetailTopBar
- **影响路径**: RealTrashDetailTopBar → 小相册详情导航（onBack/onRestore/onRemove）
- **必须测试**: 小相册详情返回/恢复/移出按钮功能正常
- **回归风险**: 中（需确保回调正确连接，Round 2 FR-6 导航修复不破坏）

### IA-3: RealTrashLargeAlbumChildList 替换原文字卡

- **变更**: 大相册详情预览区从文字卡 → 子小相册列表
- **影响路径**: albumSnapshot.postSnapshots → RealTrashLargeAlbumChildList 渲染
- **必须测试**: 大相册详情显示子小相册列表 + 数据正确
- **回归风险**: 低（新组件，数据源已存在）

### IA-4: 小相册 Pager 高度从 372dp → 动态计算

- **变更**: HorizontalPager 高度按当前媒体宽高比计算
- **影响路径**: PostMediaArea → PostMediaCard → HorizontalPager
- **必须测试**: 小相册详情竖图/宽图/方图展示正确，无压缩无大量留白
- **回归风险**: 中（需确保高度上下界合理，不超屏）

### IA-5: AnimatedContent 包裹三类列表分支

- **变更**: when 分支用 AnimatedContent 包裹
- **影响路径**: selectedType → AnimatedContent → 三类列表
- **必须测试**: 切换四类分类时动画流畅，列表内容正确，滚动状态不丢失
- **回归风险**: 中（AnimatedContent 可能影响 LazyGrid 状态保持）

### IA-6: 离线态按钮禁用

- **变更**: 离线态下操作按钮 enabled=false
- **影响路径**: isOfflineReadOnly → 按钮 enabled → 用户操作
- **必须测试**: 离线态下按钮不可点击 + 视觉半透明 + 在线后恢复
- **回归风险**: 低（仅 enabled 条件增加）

### IA-7: RealTrashDaysBadge token 替换

- **变更**: error → destructive
- **影响路径**: RealTrashDaysBadge → RealTrashPostGridCard + RealTrashMediaGridCell
- **必须测试**: days > 25 的 badge 颜色正确
- **回归风险**: 低（仅色值替换）

### IA-8: 删除死代码 RealTrashPostMediaGridTile + RealTrashViewerOverlayButton

- **变更**: 删除无调用方的 Composable
- **影响路径**: 无（无调用方）
- **必须测试**: 编译通过
- **回归风险**: 无
