## 三、FR-4 分类切换优化 — 现状

### 3.1 缓存策略（AC-1, AC-2 已满足）

- **AC-1**: 切换分类时已先显示缓存内容（RealTrashViewModels.kt L60-66），不闪空。✅
- **AC-2**: 后台刷新失败时已通过 `OfflineAccessManager.enterReadOnly(message)` + `cachedList.toUiState(isOfflineReadOnly=true)` 显示只读提示。✅

### 3.2 切换动画（AC-3 缺失）

- **AC-3**: 三个 LazyVerticalGrid/LazyColumn 分支切换是 `when` 直接分流，**无 AnimatedContent/Crossfade**，从一种列表类型切到另一种时立即整体替换。
- **修复方向**: 引入 `AnimatedContent` 包裹三类分支，targetState = selectedType，transitionSpec 用 fadeIn/fadeOut + slideInVertically。

## 九、调研结论

Round 3 涵盖 4 个 P1 FR，全部 Android 端。主要缺口：
- FR-3: 列表卡片扁平无质感 + 待清理倒计时无视觉升级 + Token 违规
- FR-4: 缺少切换动画（AC-1/AC-2 缓存策略已满足）
- FR-7: 顶栏下方完全无分类名展示
- FR-8: 大相册子小相册列表缺失 + 三类详情操作按钮不统一 + 离线只读态无视觉区分

参照 07/08 模块视觉标准，使用 YingShiThemeTokens 中的 viewer 深色 token + destructive token + memory token 实现视觉升级。建议按 P1-1 到 P1-10 的顺序实施，每步编译验证。
