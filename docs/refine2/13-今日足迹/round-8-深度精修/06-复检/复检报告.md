## 二、本轮（第六轮迭代）改动盘点

### 2.1 问题 — 三页里还是只有个人的，对方没有也该显示空态

**根因（关键 Bug）**: 上一轮虽然修了服务端让 partner 能回退查所有 media，但**今日 (2026-07-19) 数据库里 partner 完全没有任何 media**（连普通相册都没有），所以 partner slot 仍然是空的。

更关键的根因是**客户端 UI 设计问题**：之前是"聚合模式" — self + partner 的 media 混在一起到一个 `aggregated` 列表。当 self 有数据 partner 没数据时：
- aggregated 列表非空 → UI 走"有数据"分支
- partner 的存在完全不可见
- 用户看到的就是"只有自己的"

**修复方案**: 重写 `LifeConsoleTodayMediaPage`，改为**双方各自独立框上下排列**：
- 自己一个框，对方一个框
- 每方独立 HorizontalPager 左右滑动自己的照片
- 没数据的一方显示空态卡片（图标+提示"对方还没记录..."+ 不可上传的占位）
- 自己的框可上传/删除，对方的框不可上传

**修复**: [LifeConsoleScreen.kt LifeConsoleTodayMediaPage L1560-1666](file:///e:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/life/LifeConsoleScreen.kt#L1560-L1666) 重写为双方独立框

```kotlin
Column(
    modifier = Modifier.fillMaxWidth().verticalScroll(scrollState),
    verticalArrangement = Arrangement.spacedBy(spacing.md),
) {
    // 我 — 独立框
    LifeConsoleTodayMediaSlotCard(
        label = selfLabel,
        labelColor = colors.memoryAccent,
        count = slot1.mediaItems.size,
        mediaItems = slot1.mediaItems,
        pagerState = selfPagerState,
        ...
        emptyHint = if (isMeal) "记录今天的一餐" else "记录今天的身影",
        canUpload = slot1.editable && !isBusy,
    )
    // 对方 — 独立框 (没数据显示空态)
    LifeConsoleTodayMediaSlotCard(
        label = partnerLabel,
        labelColor = colors.goldAccent,
        count = slot2.mediaItems.size,
        mediaItems = slot2.mediaItems,
        pagerState = partnerPagerState,
        ...
        emptyHint = if (isMeal) "对方还没记录今天的一餐" else "对方还没记录今天的身影",
        canUpload = slot2.editable && !isBusy,
    )
}
```

**新增**: [LifeConsoleTodayMediaSlotCard L1673-1905](file:///e:/Study/App/YingShi/app/src/main/java/com/example/yingshi/feature/life/LifeConsoleScreen.kt#L1673-L1905) 单个 slot 通用卡片组件

每个 slot 卡片结构：
- 第1行：标签 + 数量 (e.g. "我 · 3 张" / "对方 · 0 张")
- 有数据：
  - HorizontalPager 左右滑动照片
  - 圆点指示器
  - 时间行 `🕐 {时间}`
  - 地点行 `📍 {地点}` 或 `📍 添加地点` (可点击)
  - 底部操作栏：页码 + 删除/上传按钮 (仅自己的框可操作)
- 无数据：
  - 空态卡片 (图标 + "对方还没记录...")
  - 自己的框可上传，对方的框不显示上传按钮
