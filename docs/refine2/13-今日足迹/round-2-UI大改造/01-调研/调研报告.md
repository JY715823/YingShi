## 五、FR 详细调研

### FR-2: 今日足迹 UI 大改造

**当前现状**:
- 四宫格布局：`LifeConsoleGrid` 用两个 `Row` 嵌套 `LifeMediaFrame`，每个 `Modifier.weight(1f)` 等宽
- 卡片内空状态：`EmptyFrame` 简单图标+文字（灰方块+加号/餐具图标）
- 大便卡片：`BowelCard` 简约行式布局（标题+次数+时间）
- 入场动画：`yingShiRouteReveal` + `contentVisible` 控制（单帧渐入，非 staggered）

**改造目标**:
1. 不等高卡片布局：人物卡（高）和吃饭卡（矮）不等高，使用 `LazyColumn` 或自定义 `Column` 布局
2. 左侧彩色竖条：每张卡片左侧加 4dp 宽的彩色竖条（人物蓝 #4A7CBA，吃饭暖 #C4874A）
3. 微阴影：`YingShiMistCard` 已有 mist 风格，但需要更明显的层级感
4. 大号标题：卡片标题从 `titleSmall` 升级为 `titleMedium` 或 `titleLarge`
5. 空态升级：引导型插画区（温暖剪影/餐具插画）+ 温度文案，不用灰方块
6. 横滑 Pager：`HorizontalPager` 已有但需增强圆点指示器（当前是文字 "1/5"）
7. 大便卡片：大号数字 + 时间戳 + emoji 表情
8. 入场动画：staggered reveal（4 帧 staggered）

**技术方案**:
- 不等高卡片：用 `Column` + 自定义 `Modifier.heightIn(min=...)` 替代等宽 `Row`
- 左侧竖条：`Box` 内用 `Row` 布局，左侧 `Box(Modifier.width(4.dp).fillMaxHeight().background(color))`
- 圆点指示器：自定义 `Row` + `Canvas` 或 `Box` 圆点
- 空态插画：使用 Material Icons 或自定义 `Icon` 组合，配合温暖文案
- 大便卡：`Text` 大号数字 + `Text` 时间戳 + emoji 作为 `Text` 内容
- Staggered reveal：`LaunchedEffect` + `animateFloatAsState` + `delay` 实现逐帧

### FR-3: 历史页 UI 改造

**当前现状**:
- 扁平列表：`HorizontalPager` 三个 Tab 各一个 `Column` + `verticalScroll` 内嵌 `YingShiMistCard`
- 无时间线：直接卡片堆叠
- 筛选器：`DropdownMenu` 下拉菜单
- 三 Tab 切换：`TitleTabs` + `HorizontalPager` 左右滑动（有 `animateScrollToPage`）

**改造目标**:
1. 时间轴卡片流：左侧淡色时间线（竖线 + 日期节点圆点）+ 右侧内容卡片
2. 三 Tab 切换：已有 `HorizontalPager` + `animateScrollToPage`，需增加上滑动画（`AnimatedContent` 或 `slideInVertically`）
3. 胶囊选择器：`Row` + 圆角 `Surface` + selected 态（`primaryContainer` 底 + `titleAccent` 字）
4. 每日卡片：缩略图网格 + 双方标签 + 统计信息
5. 顶部统计美化："共 X 天记录" 用 `labelLarge` + `goldAccent` 数字

**技术方案**:
- 时间轴：`Row` 布局，左侧 `Column`（时间线 + 节点），右侧 `Column`（内容卡片）
  - 时间线：`Box(Modifier.width(2.dp).fillMaxHeight().background(dividerSoft))`
  - 节点：`Box(Modifier.size(8.dp).background(titleAccent, CircleShape))`
- 胶囊选择器：`Row` 内三个 `Surface`，`selected` 时用 `primaryContainer` 底
- 上滑动画：`AnimatedContent(targetState = page, transitionSpec = slideInVertically + fadeIn)`
- 缩略图网格：现有 `chunked(2)` 保留，增强圆角投影

### FR-4: 历史页排除今天提示

**当前现状**: 无提示文字

**改造目标**: 历史页时间轴顶部或空状态区域加一行小字 "今日记录在上方展示"

**技术方案**:
- 在 `LifeConsoleHistoryPanel` 的时间轴顶部加一行 `Text`
- 使用 `textSecondary` + `bodySmall`，不抢焦点
- 始终显示（非条件显示）

### FR-8: AMOLED accent gradient 调优

**当前现状**:
```kotlin
private val LifePersonGradient = listOf(
    Color(0xFF4A7CBA).copy(alpha = 0.06f),
    Color(0xFF4A7CBA).copy(alpha = 0.03f),
    Color.Transparent,
)
private val LifeMealGradient = listOf(
    Color(0xFFC4874A).copy(alpha = 0.06f),
    Color(0xFFC4874A).copy(alpha = 0.03f),
    Color.Transparent,
)
```

**改造目标**: 在暗色模式下提高 gradient alpha（如 0.08f → 0.04f → transparent），亮色模式保持当前值

**技术方案**:
- 使用 `isSystemInDarkTheme()` 判断
- 暗色模式：`alpha = 0.10f → 0.05f → transparent`
- 亮色模式：保持 `alpha = 0.06f → 0.03f → transparent`
- 将硬编码的 `Color(0xFF4A7CBA)` 和 `Color(0xFFC4874A)` 改为引用 token 色调
