## 一、本模块依赖的外部模块/服务

| 依赖模块 | 依赖内容 | 本轮是否改动接口 | 说明 |

| YingShiMistBackground | 页面背景 | 否 | 复用 |
| ShellPage | 页面壳 | 否 | 复用 |
| TitleTabs | Tab 切换 | 否 | 复用 |
| YingShiNotice / YingShiNoticeHost | 通知组件 | 否 | 复用 |
| StaleBanner | 离线提示 | 否 | 复用 |
| AppContentMediaThumbnail | 媒体缩略图 | 否 | 复用 |
| yingShiClickable | 点击交互 | 否 | 复用 |
| LifeConsoleViewModel | 数据/状态 | 否 | 接口不变 |
| RemoteLifeConsoleToday | 数据模型 | 否 | 不变 |
| RemoteLifeConsoleHistory | 数据模型 | 否 | 不变 |
| LifeConsoleUploadBridge | 上传逻辑 | 否 | 不变 |
| LifeConsoleWidgetProvider | Widget 更新 | 否 | 不变 |

## 二、依赖本模块的外部调用方

| 调用方 | 调用内容 | 本轮是否影响 | 说明 |
|--------|---------|:---:|------|
| LifeScreen.kt | 导航到 LifeConsoleScreen | 否 | 导航参数不变 |
| 底部导航栏 | 路由入口 | 否 | 不变 |
| LifeConsoleWidgetProvider | 读取 LifeConsoleScreen 数据 | 否 | 数据流不变 |

**结论**: 本轮纯 UI 层改动，不影响任何外部调用方。
