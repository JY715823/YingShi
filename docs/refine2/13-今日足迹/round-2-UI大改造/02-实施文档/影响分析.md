# Round 2 UI大改造 — 影响分析

> 基于: 实施计划 v1.0
> 日期: 2026-07-18

---

## 变更范围

本轮仅改动 1 个文件：`LifeConsoleScreen.kt`

---

## 影响链路

### 变更1: LifeConsoleGrid 重写（不等高卡片）

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `LifeConsoleGrid` Composable | 从 `Row` 嵌套改为 `Column` 布局 |
| 直接 | `LifeMediaFrame` 调用处 | aspectRatio 参数从 0.82f 改为 0.82f(人物) / 0.72f(吃饭) |
| 间接 | 今日页布局 | 视觉上从四宫格变为不等高卡片流 |
| 间接 | 卡片内媒体预览 | 人物卡稍高，吃饭卡稍矮，H-Pager 适配 |
| 无影响 | ViewModel | 数据流不变 |
| 无影响 | 后端 API | 不涉及 |

### 变更2: LifeMediaFrame 加左侧竖条 + 大号标题 + 圆点指示器

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `LifeMediaFrame` Composable | 内部布局从 `Box`+`Column` 改为 `Row`+`Column` |
| 直接 | `accentGradient` 参数 | 竖条颜色替代/补充 accent gradient |
| 直接 | 页码指示器 | 从文字 "1/5" 改为圆点 |
| 间接 | `LifeMediaPreview` | 仍调用 `AppContentMediaThumbnail`，不变 |
| 间接 | 上传/删除按钮 | 按钮样式从 `LifeConsoleSmallIconButton` 改为胶囊按钮 |
| 无影响 | 数据模型 | 不变 |

### 变更3: EmptyFrame → 温度空态

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `EmptyFrame` Composable | 图标尺寸、颜色、文案全部变化 |
| 无影响 | 其他 | 仅影响卡片内空状态展示 |

### 变更4: BowelCard → 健康日志风

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `BowelCard` Composable | 布局从简约行式改为大号数字+emoji |
| 间接 | 大便操作按钮 | 保持 `LifeConsoleSmallIconButton`，不变 |
| 无影响 | 数据模型 | 不变 |

### 变更5: 入场动画 staggered reveal

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `LifeConsoleScreen` 主入口 | 移除 `contentVisible` 控制，新增 `visibleFrames` 状态 |
| 直接 | 各卡片 `Modifier` | 从 `yingShiRouteReveal` 改为 `AnimatedVisibility` |
| 无影响 | 路由 | 不变 |

### 变更6: LifeConsoleHistoryPanel → 时间轴布局

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `LifeConsoleHistoryPanel` | 从 `Column` 列表改为时间轴 `LazyColumn` |
| 直接 | `LifeConsoleHistoryDaySection` | 嵌入时间轴 `Row` 右侧 |
| 间接 | 历史页滚动体验 | 从 `verticalScroll` 改为 `LazyColumn`（性能更好） |
| 无影响 | ViewModel | 数据流不变 |

### 变更7: 三 Tab 上滑动画

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `HorizontalPager` 内容 | 新增 `AnimatedVisibility` 包裹 |
| 间接 | Tab 切换体验 | 视觉上增加上滑过渡 |
| 无影响 | `TitleTabs` | 不变 |

### 变更8: 胶囊选择器替代 DropdownMenu

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | 筛选器 UI | 移除 `DropdownMenu`，新增 `Row`+`Surface` |
| 直接 | `filterExpanded` 状态 | 移除 |
| 无影响 | `onRangeChange` 回调 | 不变 |

### 变更9: 历史页今日提示

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `LifeConsoleHistoryPanel` | 统计下方新增一行 `Text` |
| 无影响 | 其他 | 不影响任何功能 |

### 变更10: AMOLED gradient 调优

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `LifePersonGradient`/`LifeMealGradient` | 从 `val` 改为 `@Composable fun` |
| 直接 | `LifeMediaFrame` 调用处 | 从 `accentGradient = LifePersonGradient` 改为 `accentGradient = lifePersonGradient()` |
| 间接 | 暗色模式视觉 | 暗色模式下 gradient 更明显 |
| 无影响 | 亮色模式 | 保持不变 |
