## FR-2: 今日足迹 UI 大改造

**目标**: 将今日页四宫格改为生活手账风不等高卡片布局

### 2.1 LifeConsoleGrid → 重写为不等高卡片流

**当前**: 两个 `Row` 嵌套等宽 `LifeMediaFrame`，`Modifier.weight(1f)`
**改为**: 一个 `Column`，人物卡（上排）和吃饭卡（下排）不等高，人物卡 `aspectRatio(0.82f)` 保持不变，吃饭卡降低 `aspectRatio(0.72f)`

变更点:
- 移除 `Row(horizontalArrangement = Arrangement.spacedBy(spacing.md))` 外层
- 改用 `Column(verticalArrangement = Arrangement.spacedBy(spacing.md))`
- 每个人物/吃饭对保持 `Row` 内两个 `weight(1f)` 卡片
- 人物卡 `aspectRatio(0.82f)` — 高
- 吃饭卡 `aspectRatio(0.72f)` — 矮

### 2.2 LifeMediaFrame → 加左侧彩色竖条 + 大号标题 + 圆点指示器

**当前**: `YingShiMistCard` + `Box` 内 accent gradient + `Column` 布局
**改为**: `YingShiMistCard` + `Row` 布局（左侧竖条 + 右侧内容）

变更点:
- 卡片内改用 `Row` 布局：
  ```
  Row {
    // 左侧竖条
    Box(Modifier.width(4.dp).fillMaxHeight().clip(RoundedCornerShape(2.dp)).background(accentColor))
    Spacer(Modifier.width(spacing.sm))
    // 右侧内容
    Column { ... }
  }
  ```
- 标题从 `titleSmall` 升级为 `titleMedium`，`fontWeight = FontWeight.Bold`
- 计数文字从 `labelSmall` 升级为 `labelLarge`，用 `goldAccent` 色
- 页码指示器从文字 "1/5" 改为圆点指示器：
  ```
  Row(horizontalArrangement = Arrangement.Center) {
    repeat(pageCount) { index ->
      Box(
        Modifier.size(if (index == currentPage) 8.dp else 6.dp)
          .background(if (index == currentPage) colors.titleAccent else colors.dividerSoft, CircleShape)
      )
    }
  }
  ```
- 上传/删除按钮从 `LifeConsoleSmallIconButton` 改为更精致的胶囊按钮（icon + 文字）

### 2.3 EmptyFrame → 温度空态

**当前**: 简单图标 + 文字（灰方块+加号/餐具图标）
**改为**: 引导型空态——温暖插画区 + 温度文案

变更点:
- 人物空态：大号 `Icons.Filled.Person` 图标（36dp），`memoryAccent` 色调，下方 "记录今天的身影" 标题 + "拍下今天的第一张照片吧" 副文案
- 吃饭空态：大号 `Icons.Filled.Restaurant` 图标（36dp），`softGreenAction` 色调，下方 "记录今天的一餐" 标题 + "拍下今天的美食吧" 副文案
- 图标背景用 `memoryWash`（人物）或 `softGreenContainer.copy(alpha=0.6f)`（吃饭）圆形容器
- 整体 padding 增大，留白更多

### 2.4 BowelCard → 健康日志风

**当前**: 简约行式布局（标题+次数+时间）
**改为**: 大号数字 + 时间戳 + emoji 表情

变更点:
- 卡片标题改为 emoji 前缀：`"💩 今日健康日志"`
- 每个用户的次数用大号数字展示：`Text("${user.count}", style = ...displayLarge, color = colors.titleAccent)`，下方 "次" 小字
- 时间戳用 `goldAccent` 色展示最近一次时间
- 加/减按钮保持 `LifeConsoleSmallIconButton`
- 用 `softGreenContainer.copy(alpha = 0.38f)` 做卡片底色（更柔和）
- 卡片内加 `Row` 布局：左侧数字区 + 右侧按钮区

### 2.5 入场动画 staggered reveal

**当前**: `yingShiRouteReveal` 单帧渐入
**改为**: 4 帧 staggered reveal

变更点:
- 移除 `yingShiRouteReveal` 的 `contentVisible` 控制
- 新增 `LaunchedEffect(Unit)` 逐帧触发：
  ```kotlin
  var visibleFrames by remember { mutableIntStateOf(0) }
  LaunchedEffect(Unit) {
    delay(80) // 帧1: 人物·我
    visibleFrames = 1
    delay(80) // 帧2: 人物·对方
    visibleFrames = 2
    delay(80) // 帧3: 吃饭·我
    visibleFrames = 3
    delay(80) // 帧4: 吃饭·对方 + 大便卡
    visibleFrames = 4
  }
  ```
- 每个卡片用 `AnimatedVisibility(visible = frameIndex <= visibleFrames, enter = fadeIn(tween(200)) + scaleIn(initialScale = 0.96f, tween(200)))`

## FR-3: 历史页 UI 改造

**目标**: 将扁平列表改为时间轴卡片流 + 胶囊筛选器

### 3.1 LifeConsoleHistoryPanel → 时间轴布局

**当前**: `HorizontalPager` 三个 Tab 各一个 `Column` + `verticalScroll` 内嵌 `YingShiMistCard`
**改为**: 时间轴卡片流——左侧时间线 + 右侧内容卡片

变更点:
- 每个 Tab 页面内容改为 `LazyColumn` 内嵌时间轴条目
- 时间轴条目结构：
  ```
  Row {
    // 左侧时间线列
    Column(horizontalAlignment = CenterHorizontally, width = 32.dp) {
      Box(Modifier.size(10.dp).background(titleAccent, CircleShape)) // 节点圆点
      if (!isLast) Box(Modifier.width(2.dp).weight(1f).background(dividerSoft)) // 竖线
    }
    // 右侧内容卡片
    Column(Modifier.weight(1f)) {
      Text(day.displayLabel) // 日期标题
      YingShiMistCard { ... }  // 内容卡片
    }
  }
  ```

### 3.2 三 Tab 上滑动画

**当前**: `HorizontalPager` + `animateScrollToPage`（左右滑动）
**改为**: 增加上滑过渡动画

变更点:
- 每个 Tab 内容用 `AnimatedVisibility` 包裹：
  ```kotlin
  AnimatedVisibility(
    visible = page == pagerState.currentPage,
    enter = slideInVertically(tween(200)) { it / 4 } + fadeIn(tween(200)),
    exit = slideOutVertically(tween(150)) { -it / 4 } + fadeOut(tween(150)),
  ) { ... }
  ```

### 3.3 胶囊选择器替代 DropdownMenu

**当前**: `Box` + `DropdownMenu` 下拉
**改为**: `Row` + 三个 `Surface` 胶囊

变更点:
- 移除 `DropdownMenu` 和 `filterExpanded` 状态
- 新增胶囊选择器：
  ```kotlin
  Row(horizontalArrangement = spacedBy(spacing.xxs)) {
    LifeConsoleHistoryRange.entries.forEach { range ->
      val selected = range == selectedRange
      Surface(
        shape = RoundedCornerShape(radius.capsule),
        color = if (selected) colors.primaryContainer else Color.Transparent,
        border = BorderStroke(1.dp, if (selected) colors.glassStroke else colors.dividerSoft),
        modifier = Modifier.yingShiClickable { onRangeChange(range) },
      ) {
        Text(range.label, color = if (selected) colors.titleAccent else colors.textSecondary, ...)
      }
    }
  }
  ```

### 3.4 每日卡片增强

**当前**: `LifeConsoleHistoryDaySection` + `LifeConsoleHistoryMediaColumn`
**改为**: 增强缩略图网格 + 双方标签 + 统计信息

变更点:
- `LifeConsoleHistoryDaySection` 保持 `YingShiMistCard` 外壳
- 双方标签用 `memoryAccent` 小圆点 + `labelLarge` 文字
- 统计信息（媒体数量）用 `goldAccent` 色
- 缩略图圆角从 `radius.sm` 升级为 `radius.md`
- 增加微投影：`Modifier.shadow(elevation = 1.dp, shape = RoundedCornerShape(radius.md))`

### 3.5 顶部统计美化

**当前**: "共 X 天记录" 用 `labelLarge` + `Medium` 字重
**改为**: 美化展示

变更点:
- "共" 字用 `textSecondary` + `bodySmall`
- 数字用 `goldAccent` + `titleLarge` + `Bold`
- "天记录" 用 `textSecondary` + `bodySmall`
- 整体居中或左对齐，增加呼吸感

## FR-8: AMOLED accent gradient 调优

**目标**: 暗色模式下提高 gradient alpha

### 变更点

将硬编码的 `LifePersonGradient` 和 `LifeMealGradient` 改为 `@Composable` 函数：

```kotlin
@Composable
private fun lifePersonGradient(): List<Color> {
    val dark = isSystemInDarkTheme()
    val baseAlpha = if (dark) 0.10f else 0.06f
    val midAlpha = if (dark) 0.05f else 0.03f
    return listOf(
        Color(0xFF4A7CBA).copy(alpha = baseAlpha),
        Color(0xFF4A7CBA).copy(alpha = midAlpha),
        Color.Transparent,
    )
}

@Composable
private fun lifeMealGradient(): List<Color> {
    val dark = isSystemInDarkTheme()
    val baseAlpha = if (dark) 0.10f else 0.06f
    val midAlpha = if (dark) 0.05f else 0.03f
    return listOf(
        Color(0xFFC4874A).copy(alpha = baseAlpha),
        Color(0xFFC4874A).copy(alpha = midAlpha),
        Color.Transparent,
    )
}
```

调用处从 `accentGradient = LifePersonGradient` 改为 `accentGradient = lifePersonGradient()`
