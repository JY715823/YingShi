## 数据流验证

### 媒体上传位置链路
```
Android LocationHelper.currentLocation()
  → UploadBridge metadata.copy(latitude, longitude)
  → CreateUploadTokenPayload(latitude, longitude)
  → CreateUploadTokenRequestDto(latitude, longitude)
  → Server UploadService → UploadTaskEntity
  → buildMediaFromTask → MediaEntity(latitude, longitude)
  → GeocodingService.reverseGeocode() → locationLabel
  → MediaDto → Android UI 展示
```
**验证: 链路完整贯通**

### 排便事件位置链路
```
Android LocationHelper.currentLocation()
  → ViewModel.addBowelEvent(latitude, longitude)
  → Repository.addBowelEvent(zoneId, lat, lng)
  → LifeConsoleBowelEventRequestDto(latitude, longitude)
  → Server @RequestBody → AddBowelEventRequest
  → LifeConsoleService.addBowelEvent → BowelEventEntity
  → GeocodingService.reverseGeocode() → locationLabel
  → BowelEventDto → Android UI 展示
```
**验证: 链路完整贯通**

### 历史页位置聚合
```
Server buildHistoryDays → pickDayLocationLabel(取当天最新媒体的 locationLabel)
  → HistoryDayDto.locationLabel
  → Android LifeConsoleHistoryTimelineItem(locationLabel)
  → "📍 $locationLabel" 胶囊展示
```
**验证: 链路完整贯通**
