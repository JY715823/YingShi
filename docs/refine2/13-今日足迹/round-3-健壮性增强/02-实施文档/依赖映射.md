# Round 3 健壮性增强 — 依赖映射

> 基于: 实施计划 v1.0 + 影响分析 v1.0
> 日期: 2026-07-18

---

## 一、本模块依赖的外部模块/服务

| 依赖模块 | 依赖内容 | 本轮是否改动接口 | 说明 |
|---------|---------|:---:|------|
| AppReadCacheStore | 缓存读写 | 否 | 新增 scope 方法，不改变现有 API |
| ApiResult | 结果封装 | 是 | 可能新增 `isFromCache` 字段 |
| LifeConsoleApi | 网络请求 | 否 | 调用不变 |
| YingShiThemeTokens | 颜色/间距 | 否 | 仅使用 |
| YingShiNoticeHost | 通知组件 | 否 | 复用 |
| Gson | 序列化 | 否 | 复用 |

---

## 二、依赖本模块的外部调用方

| 调用方 | 调用内容 | 本轮是否影响 | 说明 |
|--------|---------|:---:|------|
| LifeScreen.kt | 导航到 LifeConsoleScreen | 否 | 导航参数不变 |
| LifeConsoleWidgetProvider | 读取快照 | 否 | 数据流不变 |
| SyncVersionTracker | 消费 SyncVersionsDto | 否 | 默认值兼容 |

**结论**: 本轮不影响外部调用方接口。

---

## 三、前后端共享组件依赖

| 组件 | 是否受影响 | 说明 |
|------|:---:|------|
| AppReadCacheStore | 是 | 新增 scope 方法 |
| ApiResult | 是 | 可能新增字段 |
| YingShiNoticeHost | 否 | 复用现有 API |
| LifeConsoleApi | 否 | 不变 |
