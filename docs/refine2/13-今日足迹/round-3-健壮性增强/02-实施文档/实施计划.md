## FR-5: 离线读缓存

### 5.1 AppReadCacheStore 新增 scope

在 `AppReadCacheStore` 中新增两个 scope 和对应的 read/write 方法：

```kotlin
// 新增 scope
private const val LIFE_CONSOLE_TODAY_SCOPE = "life-console-today"
private const val LIFE_CONSOLE_HISTORY_SCOPE = "life-console-history"

// 新增方法
fun readLifeConsoleToday(): CachedPayload<RemoteLifeConsoleToday>?
fun writeLifeConsoleToday(payload: RemoteLifeConsoleToday)
fun readLifeConsoleHistory(): CachedPayload<RemoteLifeConsoleHistory>?
fun writeLifeConsoleHistory(payload: RemoteLifeConsoleHistory)
```

实现复用 `read<T>(scope, userId, payloadType)` 和 `write<T>(scope, userId, payload, payloadType)`。

### 5.2 RealLifeConsoleRepository 加缓存层

`getToday()` 改造:
```kotlin
override suspend fun getToday(...): ApiResult<RemoteLifeConsoleToday> {
    val result = runCatching { ... }.fold(...)
    return when (result) {
        is ApiResult.Success -> {
            AppReadCacheStore.writeLifeConsoleToday(result.data) // 写缓存
            result
        }
        is ApiResult.Error -> {
            // 读缓存 fallback
            val cached = AppReadCacheStore.readLifeConsoleToday()
            if (cached != null && !isExpired(cached.cachedAtMillis)) {
                ApiResult.Success(cached.payload, isFromCache = true)
            } else {
                result
            }
        }
        else -> result
    }
}
```

`getHistory()` 同理。

缓存过期判断: `System.currentTimeMillis() - cachedAtMillis > 7 * 24 * 60 * 60 * 1000`

### 5.3 LifeConsoleViewModel 离线状态

`LifeConsoleUiState` 新增字段:
```kotlin
val offlineMode: Boolean = false,
val isCacheData: Boolean = false,
```

`loadToday()` 改造:
- `ApiResult.Success` 时: `offlineMode = false, isCacheData = result.isFromCache`
- 如 `isCacheData = true`，设置 `offlineMode = true`

## FR-6: 错误处理分级

### 6.1 错误类型枚举

在 `LifeConsoleViewModel.kt` 中新增:
```kotlin
enum class LifeConsoleErrorType {
    NETWORK,    // 无网络
    TIMEOUT,    // 超时
    SERVER,     // 服务端错误
    UNKNOWN,    // 未知
}
```

### 6.2 ApiResult 扩展

在 `ApiResult` 中（或新文件）新增扩展方法:
```kotlin
fun Throwable.toLifeConsoleErrorType(): LifeConsoleErrorType = when (this) {
    is java.net.UnknownHostException, is java.net.ConnectException -> LifeConsoleErrorType.NETWORK
    is java.net.SocketTimeoutException -> LifeConsoleErrorType.TIMEOUT
    is retrofit2.HttpException -> if (code() in 500..599) LifeConsoleErrorType.SERVER else LifeConsoleErrorType.UNKNOWN
    else -> LifeConsoleErrorType.UNKNOWN
}
```

### 6.3 ViewModel 错误处理

`LifeConsoleUiState` 新增:
```kotlin
val errorType: LifeConsoleErrorType? = null,
val errorMessage: String? = null,
```

`loadToday()` 改造:
```kotlin
is ApiResult.Error -> {
    val errorType = result.throwable?.toLifeConsoleErrorType() ?: LifeConsoleErrorType.UNKNOWN
    _uiState.update { it.copy(errorType = errorType, errorMessage = result.message) }
}
```

### 6.4 LifeConsoleScreen 错误展示

用 `actionMessage` 展示过渡为用 `YingShiNoticeHost`:
```kotlin
// 在 LifeConsoleScreen 中监听 errorType
LaunchedEffect(uiState.errorType, uiState.errorMessage) {
    val msg = uiState.errorMessage ?: return@LaunchedEffect
    val tone = when (uiState.errorType) {
        LifeConsoleErrorType.NETWORK -> YingShiNoticeTone.WARNING
        LifeConsoleErrorType.TIMEOUT -> YingShiNoticeTone.WARNING
        LifeConsoleErrorType.SERVER -> YingShiNoticeTone.ERROR
        else -> YingShiNoticeTone.ERROR
    }
    viewModel.showNotice(msg, tone)
}
```
