# Round 3 健壮性增强 — 影响分析

> 基于: 实施计划 v1.0
> 日期: 2026-07-18

---

## 变更范围

| # | 文件 | 变更程度 |
|---|------|---------|
| 1 | AppReadCacheStore.kt | 小改（新增 4 个方法） |
| 2 | RealRepositories.kt | 中改（getToday/getHistory 加缓存层） |

| 4 | LifeConsoleScreen.kt | 小改（离线 Banner + 错误 SnackBar） |
| 5 | SyncApi.kt | 小改（加 1 个字段） |

## 影响链路

### 变更1: AppReadCacheStore 新增 scope

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `AppReadCacheStore` 代码 | 新增 4 个 public 方法 |
| 间接 | `RealLifeConsoleRepository` | 调用新方法做缓存读写 |
| 无影响 | 其他模块 | 仅新增方法，不改变现有 API |

### 变更2: RealLifeConsoleRepository 加缓存层

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `getToday()` / `getHistory()` | 成功时写缓存，失败时读缓存 |
| 直接 | 异常捕获 | 从统一 `onFailure` 改为分类捕获 |
| 间接 | `LifeConsoleViewModel` | 可能收到 `isFromCache = true` 的 Success |
| 间接 | 网络断开时用户体验 | 自动 fallback 到缓存数据 |
| 无影响 | 写操作（addMedia/deleteMedia/addBowelEvent） | 不涉及缓存 |

### 变更3: LifeConsoleViewModel 错误分级

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `LifeConsoleUiState` | 新增 `errorType`, `errorMessage`, `offlineMode`, `isCacheData` |
| 直接 | `loadToday()` / `loadHistory()` / `onUploadResult()` 等 | 错误处理改为分类 |
| 间接 | `LifeConsoleScreen` | 接收新的 UiState 字段展示 |
| 兼容 | `actionMessage` | 保留过渡，不影响现有逻辑 |

### 变更4: LifeConsoleScreen 离线 Banner + 错误 SnackBar

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | 今日页顶部 | 新增离线 Banner（AnimatedVisibility） |
| 直接 | 错误展示 | 从 Text 改为 SnackBar/Notice |
| 间接 | 页面布局 | 今日页顶部可能多一行 Banner |
| 无影响 | 历史页 | 不涉及布局变化 |

### 变更5: SyncVersionsDto 加 chatVersion

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接 | `SyncApi.kt` | 新增字段 |
| 间接 | `SyncVersionTracker` | 自动兼容（默认值 0L），不需改代码 |
| 间接 | 所有反序列化 SyncVersionsDto 的地方 | 默认值 0L 确保兼容 |
| 无影响 | 服务端 | 不涉及 |
