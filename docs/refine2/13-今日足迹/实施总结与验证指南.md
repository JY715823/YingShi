## 如何验证

### 快速验证（5 分钟核心验证步骤）

1. **编译**: `gradlew.bat assembleDebug` 通过 + `mvnw.cmd compile` 通过
2. **Docker**: `docker compose up -d` 全部 healthy
3. **今日页 UI**: 打开 App → 生活 → 今日痕迹，确认不等高卡片布局+彩色竖条+温度空态
4. **历史页 UI**: 点击"历史记录"，确认时间轴卡片流+胶囊选择器+"今日记录在上方展示"提示
5. **排便操作**: 点击 +/- 按钮，确认正常增减
6. **上传媒体**: 点击上传，选择图片，确认上传成功且媒体出现在对应格子
