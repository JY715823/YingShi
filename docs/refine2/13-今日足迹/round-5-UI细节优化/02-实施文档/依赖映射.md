## 本模块依赖的外部模块/服务

| 依赖 | 本轮是否改动 | 说明 |
|------|:--:|------|
| YingShiMistCard (YingShiSurfaces.kt) | 是 (FR-13) | 增加 borderless 参数 |

| MaterialTheme.typography | 否 | 作为 typography token 的基础 |

| LifeConsoleApi / Repository | 否 | 不修改 |
