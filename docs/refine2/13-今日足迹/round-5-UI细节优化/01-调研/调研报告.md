## 二、关键背景发现

### 2.1 YingShiThemeTokens 现状

**文件**: `app/src/main/java/com/example/yingshi/ui/theme/Tokens.kt` (L125-145)

`YingShiThemeTokens` 对象当前只有 4 个字段：
- `spacing` (YingShiSpacing)
- `radius` (YingShiRadius)
- `colors` (YingShiColors)
- `motion` (YingShiMotion)

**没有 `typography` 字段，也没有 `elevation` 字段**。所有 Text 组件直接使用 `MaterialTheme.typography.*`。

### 2.2 YingShiMistCard 实现

**文件**: `app/src/main/java/com/example/yingshi/ui/components/YingShiSurfaces.kt` (L355-373)

```
fun YingShiMistCard(
    modifier, shape, color, borderColor, content
) {
    Surface(
        color = color ?: raisedSurface.copy(alpha=0.94f),
        tonalElevation = 0.dp,
        shadowElevation = 2.dp,
        border = BorderStroke(1.dp, borderColor ?: dividerSoft.copy(alpha=0.70f)),
    )
}
```

**关键**: border 硬编码 1.dp + dividerSoft(alpha=0.70)，shadowElevation 硬编码 2.dp。没有 borderless 参数，没有 shadowElevation 参数。

### 2.3 TitleTabs 实现

**文件**: `app/src/main/java/com/example/yingshi/ui/components/AppShell.kt` (L179-238)

- 内部 Row.fillMaxWidth()
- 每个 Tab Box **没有 weight(1f)**，也没有 minWidth
- Tab Text: maxLines=1, overflow=Ellipsis
- 选中态: titleLarge + SemiBold (22sp)
- 未选中: labelLarge + Medium (14sp)

### FR-15: 大便 Tab 截断修复

**调用处**: LifeConsoleScreen.kt L541-550
```
TitleTabs(
    tabs = listOf("人物", "吃饭", "大便"),
    selectedIndex = pagerState.currentPage,
    modifier = Modifier.weight(1f),
    ...
)
```

**实现处**: AppShell.kt L190-234
- L191: `Row.fillMaxWidth()` — 占满 TitleTabs 分配的宽度
- L203: 每个 Tab `Box` **没有 weight(1f)**，也没有 `widthIn(min=...)`
- L217-220: padding 在 selected(sm) / unselected(xs) 间切换，导致 tab 宽度抖动
- L227-228: `maxLines=1, overflow=Ellipsis` — 空间不足时截断

**截断根因**: TitleTabs 拿到 `weight(1f)` 与右侧胶囊 Row 共享水平空间。当右侧胶囊("近7天/近30天/全部")占空间较多时，TitleTabs 内部 3 个 Tab 按内容尺寸分配，"大便"（2字最短）被挤压后触发 Ellipsis 截断为"大…"。

## 四、技术约束

| 约束 | 说明 |
|------|------|
| 颜色系统受保护 | 不得改变现有 color token，新增 Composable 必须用 `YingShiThemeTokens.colors.*` |
| 设计计划为指引 | 目标"安静但有华彩、克制但有温度"，去框是做减法 |
| YingShiMistCard 是共享组件 | 修改签名需评估全项目影响 |
| TitleTabs 是共享组件 | 修改需评估全项目影响 |
| 无 typography token | 当前 YingShiThemeTokens 无 typography 字段 |

## 五、修改方案预判

### FR-13 方案

**策略**: 给 `YingShiMistCard` 增加 `borderless: Boolean = false` 参数。当 `borderless=true` 时不渲染 border，保留 shadowElevation。

**影响范围**: 
- `YingShiSurfaces.kt` — 修改 MistCard 签名（向后兼容，默认 false）
- `LifeConsoleScreen.kt` — 4 处调用传 `borderless = true`
- 其他模块使用 MistCard 的地方 — 不受影响（默认 false）

### FR-14 方案

**策略**: 在 `Tokens.kt` 新增 `YingShiTypography` data class，定义语义化 token（cardTitle, cardHeadline, body, caption, statNumber），在 `YingShiThemeTokens` 中添加 `typography` 字段。在 `LifeConsoleScreen.kt` 中替换关键 Text 的 style。

**影响范围**:
- `Tokens.kt` — 新增 typography token（纯新增，不影响现有）
- `LifeConsoleScreen.kt` — 约 15-20 处 Text style 替换

### FR-15 方案

**策略**: 在 `AppShell.kt` 的 TitleTabs 实现中，给每个 Tab Box 加 `.weight(1f)`，确保 3 个 Tab 等分宽度。同时统一 selected/unselected 的 horizontal padding 为 `spacing.sm`，消除宽度抖动。

**影响范围**:
- `AppShell.kt` — TitleTabs 实现（L203 Box modifier）
- 其他使用 TitleTabs 的地方 — 视觉上 Tab 变等宽，无功能影响

### FR-16 方案

**策略**: 直接删除 LifeConsoleScreen.kt L603-608。

### FR-17 方案

**策略**: 删除 LifeConsoleScreen.kt L823-828 的 `day.displayLabel` Text，保留 L829-833 的"共 X 张"标签。将 Row 改为只显示张数（右对齐）或直接移除 Row 只留 Text。
