## 三、发现并修复的 Bug

### BUG-1: Android 上传不传 domain（P0）

**问题**: `CreateUploadTokenRequestDto` 缺少 `domain` 字段，`RealUploadRepository.createUploadToken` 未传递 `payload.domain`。导致所有 Android 上传的媒体默认归入 `photo` 域，足迹上传的媒体无法标记为 `life` 域，存储三域隔离在 Android 端断裂。

**根因**: Round 1 实施时只改了服务端（UploadService 接受 domain），漏了 Android DTO 层和 Repository 层的传递链路。

**修复**:
1. `UploadTokenDto.kt`: `CreateUploadTokenRequestDto` 加 `val domain: String? = null`
2. `RealRepositories.kt`: `createUploadToken` 传 `domain = payload.domain`
3. 验证 `LifeConsoleUploadBridge.toTokenPayload()` 已设置 `domain = "life"`（无需修改）

**验证**: Android 编译通过，上传链路 domain 字段完整传递。

---

### BUG-2: Android 不传 zoneId（P1）

**问题**: `LifeConsoleApi.addBowelEvent()` 和 `deleteLatestBowelEvent()` 无 zoneId 参数。服务端虽 `required = false`，但 Android 端用户时区无法正确传递，跨时区操作可能导致日期不一致。

**根因**: Round 1 只改了服务端 Controller 接受 zoneId，漏了 Android API 接口→Repository→ViewModel 的调用链。

**修复**:
1. `LifeConsoleApi.kt`: 两个方法加 `@Query("zoneId") zoneId: String? = null`
2. `Contracts.kt`: 接口方法加 `zoneId: String = "Asia/Shanghai"`
3. `RealRepositories.kt`: 实现传 zoneId 给 API
4. `FakeRepositories.kt`: 接口签名同步
5. `LifeConsoleViewModel.kt`: 调用处传 `zoneId` 属性

**验证**: Android 编译通过，排便操作时区参数完整传递。

---

### BUG-3: ensureSystemAlbum/ensureMonthlySmallAlbum 查找未过滤 domain（P1）

**问题**: `LifeConsoleService.ensureSystemAlbum()` 和 `ensureMonthlySmallAlbum()` 查找已有记录时使用不带 domain 的 Repository 方法（`findByLibraryIdAndSystemKeyAndDeletedAtIsNull`），与读路径（`buildMediaSlot` 使用带 domain 的方法）不一致。

**根因**: Round 1 新增了 domain-aware 的 Repository 方法，但 ensure 方法的查找未同步更新。

**修复**:
1. `ensureSystemAlbum`: 改用 `findByLibraryIdAndSystemKeyAndDomainAndDeletedAtIsNull(libraryId, systemKey, "life")`
2. `ensureMonthlySmallAlbum`: 改用 `findByLibraryIdAndAlbumIdAndSystemKeyAndDomainAndDeletedAtIsNull(libraryId, albumId, systemKey, "life")`

**验证**: Server 编译通过，测试通过。

---

### BUG-4: BowelEventRepository findTop50 未过滤 deletedAt（P1）

**问题**: `findTop50ByLibraryIdOrderByOccurredAtMillisDesc` 方法未过滤 `deletedAt IS NULL`，被 `NotificationService` 调用时会返回已软删除的排便事件，导致通知内容包含已删除数据。

**根因**: Round 1 新增 deletedAt 字段后，此方法未同步更新。

**修复**:
1. `BowelEventRepository.java`: 方法名改为 `findTop50ByLibraryIdAndDeletedAtIsNullOrderByOccurredAtMillisDesc`
2. `NotificationService.java`: 调用处同步更新方法名

**验证**: Server 编译通过，测试通过。

---

### BUG-5: 未使用 import（P2）

**问题**: `LifeConsoleScreen.kt` 中 `slideInVertically` 和 `slideOutVertically` 已 import 但未使用，产生编译警告。

**修复**: 移除两个未使用的 import。

**验证**: Android 编译通过。
