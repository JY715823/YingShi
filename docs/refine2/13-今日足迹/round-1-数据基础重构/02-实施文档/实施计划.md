### 后端函数级计划

**AlbumEntity.java — 新增 domain 字段**
- 签名: `@Column(length = 20) private String domain = "photo";`
- 逻辑: 默认值 "photo"，新增 getDomain()/setDomain()
- 边界: 不允许 null，不允许空字符串

**PostEntity.java — 新增 domain 字段**
- 签名: `@Column(length = 20) private String domain = "photo";`
- 逻辑: 同 AlbumEntity

**MediaEntity.java — 新增 domain 字段**
- 签名: `@Column(length = 20) private String domain = "photo";`
- 逻辑: 同 AlbumEntity

**LifeConsoleService.ensureSystemAlbum() — 设 domain='life'**
- 逻辑: 创建 AlbumEntity 时 `album.setDomain("life")`
- 边界: 已存在的 album 不需要改（由 V26 迁移处理）

**LifeConsoleService.ensureMonthlySmallAlbum() — 设 domain='life'**
- 逻辑: 创建 PostEntity 时 `post.setDomain("life")`
- 边界: 已存在的 post 不需要改

**LifeConsoleService.addMedia() — 设 domain='life'**
- 逻辑: 将 media 的 domain 设为 "life"（如果当前为 null 或默认值 photo），调用 `media.setDomain("life")` + `mediaRepository.saveAll(mediaItems)`
- 边界: 如果 media 已有 domain='chat' 则报错

**LifeConsoleService.buildMediaSlot() — 加 domain='life' 过滤**
- 逻辑: albumRepository 查询加 domain='life' 条件；postRepository 查询加 domain='life' 条件
- 新增 Repository 方法: `AlbumRepository.findByLibraryIdAndSystemKeyAndDomainAndDeletedAtIsNull()`
- 新增 Repository 方法: `PostRepository.findByLibraryIdAndAlbumIdAndSystemKeyAndDomainAndDeletedAtIsNull()`

**LifeConsoleService.buildHistoryDays() — 加 domain='life' 过滤**
- 逻辑: postRepository 查询加 domain='life' 条件
- 新增 Repository 方法: `PostRepository.findByLibraryIdAndAlbumIdAndDomainAndDeletedAtIsNullOrderByDisplayTimeMillisDescUpdatedAtDesc()`

**UploadTokenRequest.java — 新增 domain 字段**
- 签名: `@Size(max=20) String domain`
- 默认: null（后端默认 'photo'）

**UploadService.createUploadToken() — 接受 domain 参数**
- 逻辑: 从 request.domain() 获取，null 时默认 "photo"；传给 objectKey 生成
- 边界: domain 必须是 photo/life/chat 之一

**LocalMediaStorageService.originalObjectKeyForUpload() — 路径加 domain 前缀**
- 签名改为: `originalObjectKeyForUpload(String mediaId, long displayTimeMillis, MediaType mediaType, String originalFileName, String domain)`
- 逻辑: 路径从 `originals/{month}/{mediaId}.ext` 改为 `{domain}/originals/{month}/{mediaId}.ext`

**UploadService.uploadFile() — 设 domain**
- 逻辑: MediaEntity 创建时 `media.setDomain(domain)`

**MediaRepository.findFeedPage() — 加 domain='photo'**
- 逻辑: JPQL 查询加 `AND m.domain = 'photo'`

**SyncService.getVersions() — lifeConsoleVersion 加 domain 过滤**
- 逻辑: postRepository 新增 `findLatestUpdatedAtByLibraryIdAndDomainAndDeletedAtIsNullAndSystemKeyIsNotNull()`

### Flyway 迁移

**V26__data_domain_isolation.sql**
```sql
ALTER TABLE albums ADD COLUMN IF NOT EXISTS domain VARCHAR(20) DEFAULT 'photo' NOT NULL;
ALTER TABLE small_albums ADD COLUMN IF NOT EXISTS domain VARCHAR(20) DEFAULT 'photo' NOT NULL;
ALTER TABLE media ADD COLUMN IF NOT EXISTS domain VARCHAR(20) DEFAULT 'photo' NOT NULL;
```
- 回滚: 无法回滚（不可逆），但可以删除列（需手动）
- 幂等: `ADD COLUMN IF NOT EXISTS` 确保可重跑

### Android 组件级计划

**CreateUploadTokenPayload — 新增 domain 字段**
- 签名: `val domain: String? = null`
- 位置: `UploadModels.kt` L11-29

**LifeConsoleUploadBridge.toTokenPayload() — 传 domain='life'**
- 逻辑: `CreateUploadTokenPayload(..., domain = "life")`
- 位置: `LifeConsoleUploadBridge.kt` L291-308

## FR-10: 大便事件改软删除 (P2, Server)

**目标**: BowelEventEntity 加 deletedAt 字段，deleteLatestBowelEvent 改为软删除。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `YingShi-Server/src/main/resources/db/migration/postgresql/V27__bowel_soft_delete.sql` | Server | 新增 | bowel_events 加 deleted_at 列 |
| 2 | `BowelEventEntity.java` | Server | 修改 | 新增 deletedAt 字段 |
| 3 | `BowelEventRepository.java` | Server | 修改 | 查询加 deletedAt IS NULL 过滤 |
| 4 | `LifeConsoleService.java` | Server | 修改 | deleteLatestBowelEvent 改为 setDeletedAt + save |

### 后端函数级计划

**BowelEventEntity.java — 新增 deletedAt**
- 签名: `@Column private Long deletedAt;`
- 默认: null

**BowelEventRepository.java — 查询加 deletedAt IS NULL**
- `findByLibraryIdAndOccurredAtMillis...`: 加 `AND b.deletedAt IS NULL`
- `findFirstByLibraryIdAndUserIdAndOccurredAtMillis...`: 加 `AND b.deletedAt IS NULL`

**LifeConsoleService.deleteLatestBowelEvent() — 改软删除**
- 逻辑伪代码:
  ```
  event = bowelEventRepository.findFirstBy...(...) // 自动过滤 deletedAt IS NULL
  event.setDeletedAt(Instant.now().toEpochMilli())
  bowelEventRepository.save(event)
  ```
- 边界: 重复删除已软删除的事件 → 查询返回空 → 抛 NOT_FOUND

**LifeConsoleService.buildBowelSummary() — 查询加 deletedAt IS NULL**
- 逻辑: 查询已经自动过滤（Repository 层已加条件）

**LifeConsoleService.buildBowelHistoryDays() — 查询加 deletedAt IS NULL**
- 逻辑: 同上

### Flyway 迁移

**V27__bowel_soft_delete.sql**
```sql
ALTER TABLE bowel_events ADD COLUMN IF NOT EXISTS deleted_at BIGINT DEFAULT NULL;
```
- 回滚: `ALTER TABLE bowel_events DROP COLUMN deleted_at;`
- 幂等: `ADD COLUMN IF NOT EXISTS`
