## 二、依赖本模块的外部调用方

| 调用方 | 依赖方向 | 依赖内容 | 本轮是否影响接口 | 说明 |
|--------|---------|---------|----------------|------|
| LifeConsoleController | 双向 | 6 端点调用 | 是 | addMedia/addBowelEvent/deleteLatestBowelEvent 签名变更 |
| UploadController | 单向 | createUploadToken | 是 | 请求体新增 domain 字段 |
| SyncService | 双向 | lifeConsoleVersion 计算 | 是 | 查询加 domain 过滤 |
| MediaService | 单向 | 照片流查询 | 是 | findFeedPage 加 domain='photo' |
| AlbumService | 单向 | 大相册操作 | 间接 | 创建时默认 domain='photo' |
| PostService | 单向 | 小相册操作 | 间接 | 创建时默认 domain='photo' |
| PushDeviceController | 单向 | RegisterPushToken DTO | 是 | import 路径变更 |
| Android LifeConsoleRepository | 双向 | API 调用 | 否 | 接口签名不变 |
| Android UploadRepository | 单向 | 上传 API | 是 | CreateUploadTokenPayload 新增 domain |
| Android LifeConsoleUploadBridge | 单向 | 上传桥接 | 是 | 传 domain='life' |
| Android SyncVersionTracker | 双向 | 版本同步 | 否 | 仅消费 lifeConsoleVersion |

## 五、回归测试范围

### 后端 API 回归

| 端点 | 方法 | 回归原因 | 严重度 |
|------|------|---------|--------|
| GET /api/life-console/today | GET | addMedia 后返回数据一致性 | 高 |
| GET /api/life-console/history | GET | domain 过滤后历史数据正确 | 高 |
| POST /api/life-console/media | POST | zoneId 参数 + domain 设置 | 高 |
| DELETE /api/life-console/media/{id} | DELETE | 删除逻辑不变 | 中 |
| POST /api/life-console/bowel-events | POST | zoneId + 软删除影响 | 高 |
| DELETE /api/life-console/bowel-events/latest | DELETE | 软删除行为变更 | 高 |
| POST /api/uploads/token | POST | domain 参数新增 | 高 |
| POST /api/uploads/{id}/file | POST | domain 设置 + 路径变更 | 高 |
| GET /api/sync/versions | GET | lifeConsoleVersion 计算 | 中 |
| GET /api/photos/feed | GET | domain='photo' 过滤 | 高 |
| POST /api/push/device-tokens | POST | DTO 包迁移 | 中 |
