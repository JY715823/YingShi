## 二、用户流程

### 流程 1：进入今日足迹
底部导航 → 生活 Tab → LifeScreen（三张入口卡片）→ 点击"今日痕迹" → LifeConsoleScreen。页面同时请求今日快照 + 历史数据，展示四格媒体卡片 + 排便记录卡。

涉及：`LifeScreen.kt`, `LifeConsoleScreen.kt`, `LifeConsoleViewModel.kt`, `LifeSubRoute.kt`, `YingShiApp.kt`(lifeSubRoute 状态)

### 流程 2：上传媒体
在某格子点击上传 → PhotoPicker 选择（最多20张）→ UploadBridge 逐个上传（创建 token → 上传文件流 → 获得 mediaId）→ 批量调用 addMedia API 关联 → UI 刷新 + Widget 同步 + SyncVersion 标记本地变更。

涉及：`LifeConsoleUploadBridge.kt`, `UploadRepository`, `RealLifeConsoleRepository.addMedia()`, `LifeConsoleController.addMedia()`, `LifeConsoleService.addMedia()`

### 流程 3：删除媒体
点击删除 → 确认弹窗 → 乐观更新（先从 UI 移除）→ 调用 deleteMedia API → 成功则刷新，失败则恢复。服务端走 TrashService 软删除。

涉及：`LifeConsoleScreen.kt`(LifeMediaFrame), `RealLifeConsoleRepository.deleteMedia()`, `LifeConsoleService.deleteMedia()`, `TrashService.systemDeleteMedia()`

### 流程 4：排便记录
点击 +/- 按钮 → 乐观更新（计数立即变化）→ 后台调用 addBowelEvent / deleteLatestBowelEvent → 成功则用服务端数据覆盖，失败则回滚。

涉及：`BowelCard`(LifeConsoleScreen.kt), `LifeConsoleViewModel.kt`, `RealLifeConsoleRepository`, `LifeConsoleController`, `BowelEventRepository`

### 流程 5：查看历史
点击"历史记录" → LifeConsoleHistoryPage → 三 Tab（人物/吃饭/大便）+ HorizontalPager + 右上角时间范围下拉。每天一个卡片展示双方媒体缩略图或排便统计。

涉及：`LifeConsoleHistoryPage`, `LifeConsoleHistoryPanel`, `LifeConsoleHistoryDaySection`, `LifeConsoleHistoryBowelDayCard`

### 流程 6：推送/Widget 进入
推送点击 → LifePushDispatchActivity → 拉取今日快照 → LifeMediaQuickViewerActivity。Widget 点击媒体 → QuickViewer。Widget 操作 → LifeConsoleWidgetProvider 处理。

涉及：`LifePushDispatchActivity.kt`, `LifeMediaQuickViewerActivity.kt`, `LifeConsoleWidgetProvider.kt`, `WidgetPendingIntentFactory.kt`

## 三、数据流向

### 数据源
- **后端存储**：person/meal 媒体存在 PostMediaEntity（月度小相册 small_album_media），通过 createdAt 过滤当日；排便事件存在 BowelEventEntity（bowel_events），均 PostgreSQL
- **上传链路**：LifeConsoleUploadBridge → UploadRepository.createUploadToken() → uploadLocalStream() → mediaId → LifeConsoleRepository.addMedia()
- **读取链路**：6 个 Retrofit 端点（GET today / GET history / POST media / DELETE media / POST bowel / DELETE bowel-latest）

### 数据处理
- RealLifeConsoleRepository 通过 toRemoteModel() 将 DTO 转换为 domain model
- ViewModel 维护 LifeConsoleUiState 单一状态流
- 月度小相册按月自动创建（systemKey="2026-07"），每日通过 PostMediaEntity.createdAt 过滤当天媒体
- "今日"按客户端传入时区计算，默认 Asia/Shanghai

### 跨模块交互

| 交互模块 | 交互方式 |
|----------|----------|
| UploadRepository | UploadBridge 调用 createUploadToken + uploadLocalStream |
| SyncVersionTracker | 监听 lifeConsoleStale 自动刷新；操作后 markLocalMutation(LIFE_CONSOLE) |
| Widget 系统 | 数据变更后 LifeConsoleWidgetProvider.applySnapshot() 更新桌面组件 |
| 推送系统 | PushNotificationPresenter 处理 life:trace / life:bowel 路由 |
| 相册模块 | 复用 Album/Post/PostMedia 三层结构，通过 systemKey 区分 |
| 回收站 | deleteMedia 走 TrashService.systemDeleteMedia() 软删除 |
| 照片流 | 上传媒体同时存在于照片流，删除痕迹不影响照片流 |
| LifeScreen | LifeScreen 调用 lifeConsoleRepository.getToday() 获取媒体数量作摘要 |
