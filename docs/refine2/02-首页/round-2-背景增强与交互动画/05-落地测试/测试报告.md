## 四、FR-7: 协作人圆点交互优化

### AC-1: 颜色过渡动画 200ms ✅

**代码**: `HomeScreen.kt L499-510`
```kotlin
val bgColor by animateColorAsState(
    targetValue = if (selected) primaryContainer@0.96 else raisedSurface@0.78,
    animationSpec = tween(if (motionEnabled) 200 else 0),
)
val textColor by animateColorAsState(
    targetValue = if (selected) titleAccent else textSecondary,
    animationSpec = tween(if (motionEnabled) 200 else 0),
)
```

两个颜色动画，tween(200ms)，当前硬编码色改为 `bgColor`/`textColor` 变量引用。✅

### AC-2: 选中态外圈光晕 ✅

**代码**: `HomeScreen.kt L511-520`
```kotlin
Box(modifier = Modifier.size(if (selected) 34.dp else 30.dp)) {
    if (selected) {
        Box(Modifier.size(34.dp).background(glassStroke.copy(alpha=0.24f), CircleShape))
    }
    Surface(modifier = Modifier.size(30.dp), ...) { ... }
}
```

- 选中态: 外层 34dp Box + glassStroke@0.24 外圈
- 未选中态: 仅 30dp（无外圈）

**判定**: 外圈光晕仅在选中时渲染，glassStroke 半透明。✅

### AC-3: 遵循 motionEnabled ✅

**代码**: `tween(if (motionEnabled) 200 else 0)` + `shadowElevation = if (selected && motionEnabled) 1.dp else 0.dp`

motionEnabled=false 时动画时长为 0，阴影为 0。✅
