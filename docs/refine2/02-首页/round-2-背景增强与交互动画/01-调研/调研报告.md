## 二、FR-6: 卡片入场动画增强

### 2.1 代码位置
- 文件: `app/.../feature/home/HomeScreen.kt`
- yingShiSoftReveal 使用:
  - L159: 标题「映世」
  - L170: 状态药丸（条件渲染 `if (uiState.isReadOnly)`）
  - L178: 照片卡片
  - L192: 账本卡片
- 铃铛按钮: **无 yingShiSoftReveal**，需新增

### 2.2 yingShiSoftReveal 签名

```kotlin
// YingShiMotion.kt L52-81
fun Modifier.yingShiSoftReveal(
    visible: Boolean = true,
    enterScale: Float = YingShiThemeTokens.motion.sectionEnterScale,
    motionEnabled: Boolean = rememberYingShiMotionEnabled(),
): Modifier
```

**关键发现**: 无 `delayMillis` 参数，不支持 stagger 延迟。当前所有调用使用默认 `visible = true`，即 Composable 首次组合时立即播放入场动画。

### 2.3 实现 staggered reveal 的方案

由于 yingShiSoftReveal 不支持延迟参数，需通过 `visible` 状态控制 + `LaunchedEffect` 延迟实现：

```kotlin
// 方案: 逐级延迟 visible
var photoVisible by remember { mutableStateOf(false) }
var ledgerVisible by remember { mutableStateOf(false) }
var bellVisible by remember { mutableStateOf(false) }

LaunchedEffect(Unit) {
    photoVisible = true           // 0ms: 照片先入场
    delay(120)                    // 120ms 延迟
    ledgerVisible = true          // 账本延迟入场
    delay(80)                     // 80ms 延迟
    bellVisible = true            // 铃铛最后入场
}
```

对应修改 yingShiSoftReveal 调用:
- L159 标题: 保持 `visible = true`（立即入场，不改）
- L170 状态药丸: 保持 `visible = true`（条件渲染，与之前一致）
- L178 照片卡片: `visible = photoVisible`
- L192 账本卡片: `visible = ledgerVisible`
- 铃铛: 新增 `Modifier.yingShiSoftReveal(visible = bellVisible)`

### 2.4 AC 满足情况

| AC | 要求 | 当前状态 | 差距 |
|----|------|---------|------|
| AC-1 | 照片卡片淡入+上移 | ⚠️ 有 softReveal 但无 stagger | 需 visible 控制 |
| AC-2 | 账本延迟 100-150ms | ❌ 无延迟 | 需 LaunchedEffect |
| AC-3 | 铃铛延迟入场 | ❌ 无 softReveal | 需新增 |
| AC-4 | 减少动画退化 | ✅ yingShiSoftReveal 内置 motionEnabled | 已满足 |

## 三、FR-7: 协作人圆点交互优化

### 3.1 代码位置
- 文件: `app/.../feature/home/HomeScreen.kt`
- HomeCollaboratorDot: L467-498

### 3.2 当前实现

```kotlin
// L467-498
@Composable
private fun HomeCollaboratorDot(label, selected, onClick) {
    val colors = YingShiThemeTokens.colors
    Surface(
        modifier = Modifier.size(30.dp).yingShiClickable(...),
        shape = CircleShape,
        color = if (selected) primaryContainer@0.96 else raisedSurface@0.78,  // 硬切换，无动画
        border = BorderStroke(1.dp, glassStroke@0.86),
        shadowElevation = if (selected) 1.dp else 0.dp,
    ) {
        Box(Modifier.fillMaxSize(), contentAlignment = Center) {
            Text(label, color = if (selected) titleAccent else textSecondary)  // 硬切换
        }
    }
}
```

**关键发现**: 
- 无 `animateColorAsState`，颜色切换无过渡动画
- 无外圈光晕效果
- selected 状态直接切换 `color` 和 `textColor`

### 3.3 AC 满足情况

| AC | 要求 | 当前状态 | 差距 |
|----|------|---------|------|
| AC-1 | 颜色过渡动画 200ms | ❌ 硬切换 | 需 animateColorAsState |
| AC-2 | 选中态外圈光晕 | ❌ 无光晕 | 需新增 glassStroke 外圈 |
| AC-3 | 遵循 motionEnabled | ❌ 无动画，无需守卫 | 需添加 motionEnabled 守卫 |

### 3.4 实施建议

```kotlin
val motionEnabled = rememberYingShiMotionEnabled()
val bgColor by animateColorAsState(
    targetValue = if (selected) primaryContainer@0.96 else raisedSurface@0.78,
    animationSpec = tween(if (motionEnabled) 200 else 0),
    label = "dotBgColor",
)
val textColor by animateColorAsState(
    targetValue = if (selected) titleAccent else textSecondary,
    animationSpec = tween(if (motionEnabled) 200 else 0),
    label = "dotTextColor",
)
// 选中态外圈光晕: 在 Surface 外层包裹 Box + border
```

private fun HomeBookFilterChip(label, accentColor, enabled, onClick) {
    val colors = YingShiThemeTokens.colors
    Surface(
        color = sectionBackground@(if (enabled) 0.90 else 0.70),

## 六、技术约束

- yingShiSoftReveal 不支持延迟参数，需通过 `visible` 状态 + `LaunchedEffect` 实现 stagger
- YingShiBackdropVariant 是 enum，HOME 是独立分支，修改不影响其他 variant
- breathPhase 是 shared transition（所有 variant 共享），修改 HOME 粒子参数不影响呼吸机制
- Icons.Rounded.ExpandMore 是 Material Icons Extended 库提供，确认项目已引入
- `animateColorAsState` 是 Compose 基础 API，无需额外依赖
