## 三、FR-6: 卡片入场动画增强

### 3.1 落点
- 文件: `HomeScreen.kt`
- 位置: `HomeScreen()` 函数，L140-202

### 3.2 组件级计划

**方案**: 通过 `visible` 状态 + `LaunchedEffect` 延迟实现 staggered reveal。

**改动 1: 新增状态变量 (L141 附近)**
```kotlin
var photoVisible by remember { mutableStateOf(false) }
var ledgerVisible by remember { mutableStateOf(false) }
var bellVisible by remember { mutableStateOf(false) }
```

**改动 2: 新增 LaunchedEffect stagger 延迟 (L141 附近)**
```kotlin
LaunchedEffect(Unit) {
    photoVisible = true            // 0ms: 照片卡片先入场
    delay(120)                     // 120ms 延迟
    ledgerVisible = true           // 账本卡片延迟入场
    delay(80)                      // 80ms 延迟
    bellVisible = true             // 铃铛最后入场
}
```

**改动 3: 修改 yingShiSoftReveal 调用**
- 标题 L159: 保持 `visible = true`（不改，立即入场作为锚点）
- 状态药丸 L170: 保持 `visible = true`（不改，条件渲染时自然入场）
- 照片卡片 L178: `visible = photoVisible`（0ms 入场）
- 账本卡片 L192: `visible = ledgerVisible`（120ms 延迟入场）
- 铃铛按钮: 新增 `Modifier.yingShiSoftReveal(visible = bellVisible, motionEnabled = motionEnabled)`

**改动 4: 铃铛按钮新增 softReveal**
- 在 `HomeNotificationBellButton` 的调用处（L161-163 附近）外层包裹 Box 或直接在 modifier 追加

### 3.3 验收标准对照

| AC | 要求 | 实现方式 |
|----|------|---------|
| AC-1 | 照片卡片淡入+上移 | yingShiSoftReveal(visible=photoVisible) |
| AC-2 | 账本延迟 100-150ms | delay(120) → ledgerVisible=true |
| AC-3 | 铃铛和药丸延迟入场 | delay(200) → bellVisible=true; 药丸保持条件渲染 |
| AC-4 | 减少动画退化 | yingShiSoftReveal 内置 motionEnabled 守卫 |

## 四、FR-7: 协作人圆点交互优化

### 4.1 落点
- 文件: `HomeScreen.kt`
- 组件: `HomeCollaboratorDot` (L467-498)

### 4.2 组件级计划

**改动 1: 新增 animateColorAsState 颜色过渡 (L475 前)**
```kotlin
val motionEnabled = rememberYingShiMotionEnabled()
val bgColor by animateColorAsState(
    targetValue = if (selected) colors.primaryContainer.copy(alpha = 0.96f)
                  else colors.raisedSurface.copy(alpha = 0.78f),
    animationSpec = tween(if (motionEnabled) 200 else 0),
    label = "dotBgColor",
)
val textColor by animateColorAsState(
    targetValue = if (selected) colors.titleAccent
                  else colors.textSecondary,
    animationSpec = tween(if (motionEnabled) 200 else 0),
    label = "dotTextColor",
)
```

**改动 2: 替换 Surface color 为 animated 值**
- `color = if (selected) ...` → `color = bgColor`
- Text color 同理 → `color = textColor`

**改动 3: 选中态外圈光晕 (AC-2)**
- 在 Surface 外层包裹 `Box`，添加条件渲染的边框光晕：
```kotlin
Box(
    modifier = Modifier.size(if (selected) 34.dp else 30.dp),
    contentAlignment = Alignment.Center,
) {
    if (selected) {
        Box(
            modifier = Modifier
                .size(34.dp)
                .background(CircleShape, colors.glassStroke.copy(alpha = 0.24f))
        )
    }
    Surface(...) { ... }  // 原 Surface
}
```

### 4.3 验收标准对照

| AC | 要求 | 实现方式 |
|----|------|---------|
| AC-1 | 颜色过渡 200ms | animateColorAsState + tween(200) |
| AC-2 | 选中态外圈光晕 | glassStroke@0.24 外圈 Box |
| AC-3 | 遵循 motionEnabled | tween(if(motionEnabled) 200 else 0) |
