## 六、关键路径与瓶颈

### 6.1 FR-6 stagger 关键路径

```
HomeScreen 首次组合
  ↓ (0ms)
photoVisible = true → 照片卡片入场
  ↓ (120ms)
ledgerVisible = true → 账本卡片入场
  ↓ (200ms)
bellVisible = true → 铃铛入场
```

**瓶颈**: 无。stagger 延迟是刻意的动画设计，不阻塞渲染。motionEnabled 关闭时全部 `visible=true` 瞬间显示。

### 6.2 性能影响

| 动画 | 帧率依赖 | 开销 |
|------|---------|------|
| FR-4 粒子呼吸 | 已有，无变化 | 0 增量 |
| FR-6 yingShiSoftReveal × 3 | 已有 2 个，新增 1 个铃铛 | 220ms 一次性 |
| FR-7 animateColorAsState × 2 | 仅 selected 切换时触发 | 200ms 一次性 |
| FR-8 无动画 | — | 0 |

**结论**: 性能影响可忽略。
