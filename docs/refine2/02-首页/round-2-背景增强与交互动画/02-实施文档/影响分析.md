## 二、影响路径分析

### 2.1 YingShiAuroraBackdrop.kt 变更（FR-4）

```
YingShiAuroraBackdrop.kt
  └─ yingShiAuroraSpec(when HOME) → HOME variant 渲染
      ├─ gradient 参数修改 (memoryWash 0.62→0.82)
      ├─ warmSparkleAlpha 0.38→0.52
      ├─ goldTrace 颜色加深
      ├─ upperAurora 硬编码 → memoryWash 派生
      ├─ lowerAurora 硬编码 → memoryWash 派生
      ├─ lowerBloom alpha 增强
      └─ upperAurora alpha 增强
      └─ 影响: 仅 HOME variant 渲染，其他 variant 不受影响
          └─ 消费方:
              ├─ HomeScreen (首页) — 直接使用 YingShiAuroraBackdrop(HOME)
              ├─ 其他页面 (AUTH/PHOTOS/SHELL/LIFE/ME) — 不受影响
```

**关键结论**: `YingShiBackdropVariant` 是 enum，`when` 分支独立。修改 HOME 分支不会影响其他 variant。

### 2.2 HomeScreen.kt 变更（FR-6/7/8）

```
HomeScreen() 入口
  │
  ├─ FR-6: 新增 remembered state (mutableStateOf(false)×3)
  ├─ FR-6: 新增 LaunchedEffect(Unit) delay stagger
  │
  ├─ FR-6: yingShiSoftReveal(visible = photoVisible) — 照片卡片
  │   └─ 影响: 照片卡片入场延迟 0ms（立即），visible 控制
  │
  ├─ FR-6: yingShiSoftReveal(visible = ledgerVisible) — 账本卡片
  │   └─ 影响: 账本卡片入场延迟 120ms，visible 控制
  │
  ├─ FR-6: yingShiSoftReveal(visible = bellVisible) — 铃铛 (NEW)
  │   └─ 影响: 铃铛首次有入场动画，延迟 200ms
  │
  ├─ FR-7: HomeCollaboratorDot 动画化
  │   ├─ animateColorAsState (bgColor) — 200ms 过渡
  │   ├─ animateColorAsState (textColor) — 200ms 过渡
  │   └─ 外圈光晕 Box — 仅 selected 时渲染
  │   └─ 影响: 仅视觉，无逻辑/布局变化
  │
  └─ FR-8: HomeBookFilterChip 精修
      ├─ Text "▾" → Icon ExpandMore
      ├─ Surface color: sectionBackground → accentColor 派生
      └─ 边框: dividerSoft → accentColor 派生
      └─ 影响: 仅视觉，无逻辑/布局变化
```
