## 四、Repository 调用链映射

### 4.1 照片 Feed 拉取链

```
HomeScreen.LaunchedEffect (FR-5)
  → RepositoryProvider.mediaRepository
    → RealMediaRepository (RepositoryProvider.kt L14-15)
      → RemoteServiceFactory.mediaApi.getMediaFeedPage(cursor, pageSize)
        → HTTP GET /api/media/feed
      → 返回 ApiResult<RemoteMediaFeedPage>
  → AppReadCacheStore.writePhotoFeed(userId, CachedPhotoFeed(...))
    → 文件 I/O 写入 (Dispatchers.IO)
    → changeVersion++
```

### 4.2 通知拉取链

```
HomeScreen.LaunchedEffect (FR-5)
  → RepositoryProvider.notificationRepository
    → RealNotificationRepository (RepositoryProvider.kt L26-27)
      → RemoteServiceFactory.notificationApi.getNotifications(limit)
        → HTTP GET /api/notifications
      → 返回 ApiResult<List<RemoteNotification>>
  → AppReadCacheStore.writeNotifications(userId, notifications)
    → 文件 I/O 写入 (Dispatchers.IO)
    → changeVersion++
```

### 4.3 既有调用链对比

| 调用方 | 既有/新增 | 拉取方法 | 写入方法 |
|--------|----------|---------|---------|
| RealPhotoFeedViewModel (照片页) | 既有 | mediaRepository.getMediaFeedPage | writePhotoFeed (private persistFeed) |
| NotificationCenterScreen (通知页) | 既有 | notificationRepository.getNotifications | writeNotifications |
| **HomeScreen (FR-5)** | **新增** | 同上 | 同上 |

**关键结论**: FR-5 复用与照片页/通知页完全相同的 Repository 和 AppReadCacheStore 方法，无新接口。`readPhotoFeed == null` 守卫确保三处触发不会重复写入（首次预热后，后续进入子页面时缓存已存在）。

## 六、关键路径与瓶颈分析

### 6.1 FR-5 预热关键路径

```
首页渲染 (0ms)
  ↓ (并行，不阻塞)
LaunchedEffect 启动 (~10ms)
  ↓
网络请求 getMediaFeedPage + getNotifications (并行)
  ↓ (网络延迟，通常 200-2000ms)
写入 AppReadCacheStore (文件 I/O, ~20ms)
  ↓
changeVersion++ → HomeSummary 重组 (~30ms)
  ↓
首页更新显示数据
```

**瓶颈**: 网络请求是主要瓶颈（200-2000ms）。AC-1 要求 3 秒内显示，网络正常时完全满足。

**最坏情况**: 网络超时（无超时控制）→ 预热阻塞直到网络失败。但 `runCatching` 会捕获异常，首页不受影响。

### 6.2 视觉渲染关键路径（FR-1/2/3）

```
HomeScreen 重组
  ├─ HomePhotoCard: +1 层边框绘制 + 5色渐变 (vs 3色) — 增量 ~1ms
  ├─ HomeLedgerCard: +shimmer Modifier (infiniteTransition) — 增量 ~2ms
  └─ HomeNotificationBellButton: +breathTransition — 增量 ~1ms
```

**结论**: 视觉改动对渲染性能影响可忽略（<5ms 增量），motionEnabled 关闭时增量为 0。
