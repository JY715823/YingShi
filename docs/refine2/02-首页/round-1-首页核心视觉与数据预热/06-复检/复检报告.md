## 四、发现并修复的 Bug

### BUG-1: Hero Surface 背景 Color.White 硬编码 → 已修复
**问题**: HomeLedgerHeroSignal 的 Surface color 使用 `Color.White.copy(alpha=0.60f)` 而非 token。
**根因**: Round 3 颜色治理遗漏此位置。
**修复**: 改为 `colors.raisedSurface.copy(alpha=0.60f)`。
**验证**: 编译通过，raisedSurface 色值 #FFFFFC 与 Color.White 视觉差异极微。

## 六、实施亮点

1. **数据预热 IO 调度优化**: 缓存读写和网络请求显式使用 Dispatchers.IO，避免阻塞主线程
2. **staggered reveal motionEnabled 分支**: LaunchedEffect 内增加 motionEnabled 守卫，减少动画模式下无延迟直接显示
3. **shimmer 复用设计语言**: yingShiShimmerSweep 与登录页按钮 shimmer 一致的设计语言
4. **Hero 渐变 token 化**: 使用 raisedSurface 替代 Color.White，更符合 token 化方向
