### 2.2 新增 Modifier.yingShiShimmerSweep() (L147-179)

**设计参照**: `YingShiSurfaces.kt` L425-484 `YingShiPrimaryMistButton` shimmer

```kotlin
@Composable
fun Modifier.yingShiShimmerSweep(
    enabled: Boolean = true,
    motionEnabled: Boolean = rememberYingShiMotionEnabled(),
): Modifier {
    if (!enabled || !motionEnabled) return this
    val transition = rememberInfiniteTransition(label = "yingShiShimmer")
    val offset by transition.animateFloat(
        initialValue = 0f,
        targetValue = 1f,
        animationSpec = infiniteRepeatable(
            animation = tween(durationMillis = 3500, easing = LinearEasing),
            repeatMode = RepeatMode.Restart,
        ),
        label = "yingShiShimmerOffset",
    )
    return this.background(
        Brush.linearGradient(
            colors = listOf(
                Color.Transparent,
                Color.White.copy(alpha = 0.18f),
                Color.Transparent,
            ),
            start = Offset(offset * 3f - 1f, 0f),
            end = Offset(offset * 3f, 0f),
        ),
    )
}
```

**关键设计**:
- 周期 3500ms（在 FR-2 要求的 3-5 秒范围内）
- LinearEasing + Restart（与登录页按钮 shimmer 一致）
- `Transparent → White@0.18 → Transparent`（与登录页一致的设计语言）
- motionEnabled 守卫：关闭动画时直接 `return this`
- offset * 3f - 1f：光泽从左侧外移入到右侧外移出，覆盖完整宽度

### 3.2 FR-5: 首页数据预热 (L95-132)

**落点**: `HomeScreen()` 函数，`rememberHomeUiState` 调用之后

```kotlin
// FR-5: 首页数据预热 — 启动后并行拉取照片 feed 和通知，写入缓存后 changeVersion 触发重组
LaunchedEffect(uiState.currentUser?.userId) {
    val userId = uiState.currentUser?.userId ?: return@LaunchedEffect
    runCatching {
        coroutineScope {
            launch {
                if (AppReadCacheStore.readPhotoFeed(userId) == null) {
                    val result = RepositoryProvider.mediaRepository.getMediaFeedPage(pageSize = 60)
                    if (result is ApiResult.Success) {
                        withContext(Dispatchers.IO) {
                            AppReadCacheStore.writePhotoFeed(
                                userId = userId,
                                payload = CachedPhotoFeed(
                                    items = result.data.items,
                                    nextCursor = result.data.nextCursor,
                                    hasMore = result.data.hasMore,
                                ),
                            )
                        }
                    }
                }
            }
            launch {
                if (AppReadCacheStore.readNotifications(userId) == null) {
                    val result = RepositoryProvider.notificationRepository.getNotifications(limit = 100)
                    if (result is ApiResult.Success) {
                        withContext(Dispatchers.IO) {
                            AppReadCacheStore.writeNotifications(
                                userId = userId,
                                notifications = result.data,
                            )
                        }
                    }
                }
            }
        }
    }.onFailure { /* 静默失败，不阻塞首页 */ }
}
```

**关键设计**:
- key 为 `uiState.currentUser?.userId`：用户切换时重新触发
- `coroutineScope { launch{}; launch{} }`：照片和通知并行拉取
- `readPhotoFeed == null` / `readNotifications == null`：缓存存在性守卫，不重复拉取
- `withContext(Dispatchers.IO)`：文件写入在 IO 线程
- `runCatching {}.onFailure {}`：静默失败，不阻塞首页

### 3.5 FR-3: 通知铃铛精修 (HomeNotificationBellButton)

```kotlin
// 新增: 在 val colors 之后
val motionEnabled = rememberYingShiMotionEnabled()
val hasUnread = unreadCount > 0
val breathTransition = rememberInfiniteTransition(label = "bellBreath")
val breathAlpha by breathTransition.animateFloat(
    initialValue = 0.20f,
    targetValue = if (hasUnread && motionEnabled) 0.44f else 0.20f,
    animationSpec = infiniteRepeatable(
        animation = tween(durationMillis = 2400, easing = FastOutSlowInEasing),
        repeatMode = RepeatMode.Reverse,
    ),
    label = "bellBreathAlpha",
)
val effectiveBreathAlpha = when {
    !hasUnread -> 0f           // 无未读：光晕不可见
    !motionEnabled -> 0.36f    // 减少动画：静态光晕
    else -> breathAlpha        // 正常：呼吸光晕 0.20↔0.44
}
```

**关键设计**:
- 周期 2400ms（在 FR-3 要求的 2-3 秒范围内）
- Reverse 模式：0.20 → 0.44 → 0.20 循环
- targetValue 条件化：`hasUnread && motionEnabled` 为 false 时 target=initial，动画不变化，避免无效重组
- effectiveBreathAlpha 三态：无未读(0) / 减少动画(0.36) / 正常呼吸(breathAlpha)

## 六、代码审查修复

代码审查发现 2 个 P1 问题，已全部修复：

### P1-1: yingShiShimmerSweep 条件性 remember 违反 Compose 契约

**问题**: `rememberInfiniteTransition` 和 `animateFloat` 在 early-return 之后调用，违反 Compose slot table 一致性契约。

**修复**: 将状态创建前移到 early-return 之前，与 `yingShiMemoryGlow` 范式一致。

```kotlin
// 修复前: early-return 在 rememberInfiniteTransition 之前
if (!enabled || !motionEnabled) return this
val transition = rememberInfiniteTransition(...)

// 修复后: rememberInfiniteTransition 在 early-return 之前
val transition = rememberInfiniteTransition(...)
val offset by transition.animateFloat(...)
if (!enabled || !motionEnabled) return this
return this.background(...)
```

### P1-2: FR-5 缓存读取未切换 IO dispatcher

**问题**: `readPhotoFeed` 和 `readNotifications` 涉及磁盘 I/O + JSON 反序列化，但未包裹 `withContext(Dispatchers.IO)`，在主线程执行有 ANR 风险。

**修复**: 将缓存读取也包裹进 `withContext(Dispatchers.IO)`。

```kotlin
// 修复前:
if (AppReadCacheStore.readPhotoFeed(userId) == null) { ... }

// 修复后:
val cachedFeed = withContext(Dispatchers.IO) { AppReadCacheStore.readPhotoFeed(userId) }
if (cachedFeed == null) { ... }
```

### P2-4: hasUnread 一致性修复

**问题**: `radialGradient` 的 colors 分支用 `unreadCount > 0` 而非 `hasUnread`，风格不一致。

**修复**: 统一使用 `if (hasUnread)`。
