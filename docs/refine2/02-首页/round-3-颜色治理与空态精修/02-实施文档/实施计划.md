## 二、FR-9: 首页硬编码颜色 token 化

### 目标
将 9 处 `Color.White` 和硬编码 `Color(0x...)` 替换为 `YingShiThemeTokens.colors.*` token 派生，同时保留拼贴 fallback 装饰色。

### 2.1 照片遮罩渐变 (HomePhotoCard, L315-316)

**当前**:
```kotlin
Color.White.copy(alpha = 0.16f),
Color.White.copy(alpha = 0.04f),
```

**改为**:
```kotlin
colors.raisedSurface.copy(alpha = 0.16f),
colors.raisedSurface.copy(alpha = 0.04f),
```

**AC 覆盖**: AC-1 (照片卡片遮罩色改为 token 派生)

### 2.2 HomeMetaPill (L554-555)

**当前**:
```kotlin
color = Color.White.copy(alpha = 0.18f),
border = BorderStroke(1.dp, Color.White.copy(alpha = 0.24f)),
```

**改为**:
```kotlin
color = colors.raisedSurface.copy(alpha = 0.18f),
border = BorderStroke(1.dp, colors.raisedSurface.copy(alpha = 0.24f)),
```

**注意**: HomeMetaPill 函数内部需要新增 `val colors = YingShiThemeTokens.colors` 来获取 token。

**AC 覆盖**: AC-1

### 2.3 账本卡片渐变 (HomeLedgerCard, L601-602)

**当前**:
```kotlin
Color(0xFFEAF7F3).copy(alpha = 0.94f),
Color(0xFFFFF2E8).copy(alpha = 0.88f),
```

**改为**:
```kotlin
colors.glowWash.copy(alpha = 0.94f),
colors.memoryWash.copy(alpha = 0.88f),
```

**AC 覆盖**: AC-2 (账本卡片渐变薄荷/暖橙改为 token 派生)

### 2.4 Hero 渐变 (HomeLedgerHeroSignal, L723)

**当前**:
```kotlin

```

**改为**:

**AC 覆盖**: AC-3 (Hero 暖色改为 token 派生)

### 2.5 铃铛按钮 (HomeNotificationBellButton, L911, L932)

## 三、FR-10: 空态视觉精修

### 目标
为 HomePhotoPane 空态和 HomeLedgerRecentSignal 空态增加有质感的图标轮廓，所有颜色使用 token。

### 3.1 HomePhotoPane 空态 (L460-475)

**当前**: 仅 pastel 背景 + 径向光晕，无图标。

**修改**: 在空态 Box 内增加居中的极轻图标轮廓

```kotlin
if (tile == null) {
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(fallbackBrush)
            .background(
                Brush.radialGradient(
                    colors = listOf(
                        colors.raisedSurface.copy(alpha = 0.24f),
                        Color.Transparent,
                    ),
                    center = Offset(120f, 120f),
                    radius = 520f,
                ),
            ),
        contentAlignment = Alignment.Center,
    ) {
        Icon(
            imageVector = Icons.Rounded.Landscape,
            contentDescription = null,
            modifier = Modifier.size(32.dp),
            tint = colors.raisedSurface.copy(alpha = 0.14f),
        )
    }
}
```

**变更**:
- 新增 `contentAlignment = Alignment.Center` 到外层 Box
- 新增 `Icons.Rounded.Landscape` Icon，32dp，alpha 0.14
- 注意: L468 `Color.White.copy(alpha=0.24f)` 同步改为 `colors.raisedSurface.copy(alpha=0.24f)` (FR-9 已覆盖)

**需要新增 import**: `Icons.Rounded.Landscape`（或 `PhotoLibrary`）

**AC 覆盖**: AC-1 (有质感的空态，非纯白/纯渐变), AC-3 (颜色使用 token)

### 3.2 HomeLedgerRecentSignal 空态 (L855-873)

**当前**: 文字空态，已使用 token 颜色。

**修改**: 在空态文案旁增加极轻的账本图标

```kotlin
} else {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(horizontal = 14.dp, vertical = 14.dp),
        verticalArrangement = Arrangement.spacedBy(4.dp),
    ) {
        Row(
            verticalAlignment = Alignment.CenterVertically,

            Icon(
                imageVector = Icons.Rounded.AccountBalanceWallet,
                contentDescription = null,

            )
            Text(
                text = "最近一笔",
                style = MaterialTheme.typography.labelMedium.copy(fontWeight = FontWeight.SemiBold),
                color = colors.textSecondary,
            )
        }
        Text(
            text = if (hasBook) "暂无记录" else "进入记账",
```

**变更**:

**AC 覆盖**: AC-2 (轻空态文案), AC-3 (颜色使用 token)
