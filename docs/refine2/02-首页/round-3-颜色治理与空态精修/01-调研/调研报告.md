## 二、FR-10: 空态现状

### 2.1 HomePhotoPane 空态 (L460-475)

**当前实现**: 当 `tile == null` 时：
1. 填充 `fallbackBrush`（4 种 pastel 颜色按位置不同）
2. 叠加 `radialGradient`（白色→透明，从左上角 120px/120px 处，半径 520px）

**现状评估**: 已有层次感（pastel 底色 + 径向光晕），但缺少图标点缀，视觉上仍是"纯色块"。

**精修方向**: 增加极轻的图标轮廓（如 `Icons.Rounded.PhotoLibrary` 或 `Icons.Rounded.Landscape`），alpha 约 0.12-0.18，居中放置，使空态有设计感。

### 2.2 HomeLedgerRecentSignal 空态 (L855-873)

**当前实现**: 当 `hasTransaction == false` 时：
- `"最近一笔"` 标签（textSecondary）
- `"暂无记录"` 或 `"进入记账"`（titleAccent，取决于是否有账本）

**现状评估**: 已满足 AC-2（轻空态文案，无大报错）。颜色已使用 token（textSecondary / titleAccent），满足 AC-3。

**精修方向**: 可选增加极轻的账本图标轮廓（`Icons.Rounded.AccountBalanceWallet`），与文案形成呼应。

## 三、技术约束

| 约束 | 说明 |
|------|------|
| Token 体系 | 不新增 token，仅使用现有 `YingShiColors` 中已定义的 token + alpha 派生 |
| 颜色保真 | `raisedSurface = 0xFFFFFFFC` 与 `Color.White` 视觉差异极小（R=G=B=252 vs 255） |
| 设计约束 | 遵循 `docs/design/design-plan.md`，安静但有华彩、克制但有温度 |
| 编译 | 仅 Android 端，`gradlew.bat assembleDebug` |
