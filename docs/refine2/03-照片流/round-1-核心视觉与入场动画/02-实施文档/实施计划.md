## 二、FR-4: 氛围层增强 (先实施)

### 目标
提升氛围层 alpha 值，增加粒子呼吸闪烁，使照片流背景更有质感。

### 2.1 Alpha 提升 (PhotoFeedAtmosphereLayer, L2020-2024)

**当前**:
```kotlin
motion.feedAtmosphereAlpha * 1.28f  // MAIN_STREAM
motion.feedAtmosphereAlpha * 0.74f  // EMBEDDED
```

**改为**:
```kotlin
motion.feedAtmosphereAlpha * 1.42f  // MAIN_STREAM
motion.feedAtmosphereAlpha * 0.82f  // EMBEDDED
```

**AC 覆盖**: AC-1 (alpha 提升 ~10%)

在 `PhotoFeedAtmosphereLayer` 中增加呼吸动画覆盖层：
- 使用 `rememberInfiniteTransition` + `animateFloat` 创建 4000ms 呼吸周期
- 追加一层 `Box` 覆盖 `radialGradient`，中心点 dynamic，alpha 通过 `breathAlpha` 控制
- 参考 `YingShiAuroraBackdrop.kt` L51-60 的 breathPhase 模式

**AC 覆盖**: AC-2 (粒子呼吸闪烁)

### 2.3 颜色 token 化

## 六、FR-5: 照片卡片入场 stagger

### 6.1 实现方案

在 `PhotoFeedGridRowContent` (L3287) 中，为每行卡片增加 `yingShiSoftReveal` 的 visible 控制：

```kotlin
// 新增状态
var visible by remember { mutableStateOf(false) }
LaunchedEffect(Unit) {
    if (motionEnabled) {
        delay(rowIndex * 40L) // 40ms stagger
        visible = true
    } else {
        visible = true
    }
}

// 应用到 PhotoFeedCard
PhotoFeedCard(
    modifier = Modifier
        .weight(1f)
        .yingShiSoftReveal(visible = visible, motionEnabled = motionEnabled),
    ...
)
```

**问题**: `PhotoFeedGridRowContent` 是 `private` 函数，且 `rowIndex` 需从 `items()` 回调中传递。方案是在 `PhotoFeedGridRow` 数据模型中增加 `rowIndex` 字段，或在 `PhotoFeedGridRowContent` 中通过 `remember` 跟踪行号。

**更简方案**: 在 `PhotoFeedGridRowContent` 中直接使用 `LaunchedEffect(Unit)` + `delay(blockIndex * 40L)`，其中 `blockIndex` 从 `PhotoFeedGridRow` 的 `blocks` 列表索引推导。

**AC 覆盖**: AC-1 (卡片逐行入场, 40ms stagger)

### 6.2 motionEnabled 守卫

通过 `yingShiSoftReveal(visible, motionEnabled)` 和 LaunchedEffect 中的 `if (motionEnabled)` 分支实现。
**AC 覆盖**: AC-2
