## 一、FR-1: 照片卡片视觉精修

### 1.1 卡片边框

**文件**: `MediaVisualComponents.kt` L28-92 — `YingShiMediaFrame`

双层边框结构：
- 外层: 1dp/1.5dp `glassStroke` (默认) 或 `memoryAccent` (新导入) 或 `primaryContainer` (选中)
- 内层: 1dp `viewerText.copy(alpha=0.14f)` (标准) 或 `0.22f` (高亮)

**问题**: 边框固定 `glassStroke@borderAlpha(0.54f)`，无 token 颜色变化，视觉略显单调。

### 1.2 视频播放按钮

**文件**: `PhotoFeedScreen.kt` L3477-3485 — `InlineVideoPlaybackButton`

- 当前: 标准 Material 播放/暂停图标，BottomStart 对齐
- 无特殊视觉效果

### 1.3 新导入/恢复光晕

**文件**: `YingShiMotion.kt` L119-145 — `yingShiMemoryGlow`

- `warm=true`: 使用 `memoryAccent` (暖色)
- `warm=false`: 使用 `primaryContainer` (冷色)
- radialGradient 半径 360f，alpha 由 `ambientGlowAlpha` 控制

**问题**: 当前 PhotoFeedCard 调用 `yingShiMemoryGlow(visible = isNewImported || isRestored || isHighlighted, warm = isNewImported || isRestored)`，但 `isNewImported` / `isRestored` 同时触发 `memoryActive` 边框高亮，光晕与边框重叠时视觉层次可优化。

## 二、FR-2: 时间标题 shimmer 扫过

### 2.1 年标题 (YEAR)

**文件**: `PhotoFeedScreen.kt` L3010-3141 — `PhotoFeedTimeHeaderText`

MAIN_STREAM 模式下年标题使用 **4 层文字叠加**：
1. `mist@0.34f` — 底层雾状，scale(1.016, 1.04), shadow blur 28f
2. `glint@0.56f` — 第二层光泽，offset(-1, -2), shadow blur 24f
3. `glow@0.36f` — 第三层光晕，scale(1.008, 1.02), shadow blur 34f
4. `mist@0.28f` — 阴影层，offset(0, 4.4), shadow blur 22f
5. `glint@0.48f` — 高光层，offset(1, -2), shadow blur 22f
6. `base@0.98f` — 顶层，scale(1.012, 1.018), shadow blur 28f

**问题**: 年标题已有 4 层叠加，但缺少 shimmer 扫过效果。`yingShiShimmerSweep` (YingShiMotion.kt L153-178) 可实现 3500ms 光泽扫过。

### 2.2 月/日标题

**文件**: `PhotoFeedScreen.kt` L3202-3281 — `photoFeedTimeTitlePalette`

按季节分配色相：
- 12-2月 (冬): 蓝灰系 `base=0xFF35546E`
- 3-5月 (春): 翠绿系 `base=0xFF2F665C`
- 6-8月 (夏): 天蓝系 `base=0xFF325B7A`
- 9-11月 (秋): 暖棕系 `base=0xFF70553C`

**问题**: 季节色相已实现，但月标题非 MAIN_STREAM 时渲染较简单（仅单层文字 + 轻微 shadow），缺少层次感。

### 2.3 可复用动画

**文件**: `YingShiMotion.kt` L153-178 — `yingShiShimmerSweep`

- 3500ms 线性光泽扫过
- 白色 `Color.White.copy(alpha=0.18f)` 扫过
- 已支持 `motionEnabled` 守卫

## 四、FR-4: 氛围层增强

### 4.1 当前实现

**文件**: `PhotoFeedScreen.kt` L2014-2062 — `PhotoFeedAtmosphereLayer`

三层渐变:
1. `radialGradient`: glowWash → sectionBackground → transparent (center=0,0, radius=820f)
2. `verticalGradient`: glowWash → transparent → sectionBackground

## 五、FR-5: 照片卡片入场 stagger

### 5.1 当前列表结构

**文件**: `PhotoFeedScreen.kt` L1585-1603

```
LazyColumn(
    state = listState,
    items = blocks,
    key = { it.key },
) { block ->
    when (block) {
        is PhotoFeedSectionHeader -> PhotoFeedSectionHeaderRow(...)
        is PhotoFeedDayHeader -> PhotoFeedDayHeaderRow(...)
        is PhotoFeedGridRow -> PhotoFeedGridRowContent(...)
        ...
    }
}
```

- 使用 LazyColumn，按 block 分组渲染
- 照片卡片通过 `PhotoFeedGridRow` → `PhotoFeedGridRowContent` → `PhotoFeedCard` 渲染
- 每行 2-16 列，按密度变化

### 5.2 可复用入场动画

**文件**: `YingShiMotion.kt` L57-86 — `yingShiSoftReveal`

- 参数: `visible: Boolean`, `enterScale: Float`, `motionEnabled: Boolean`
- 动画: alpha (0→1) + scale (enterScale→1) + translationY (18f→0)
- 时长: `motion.floatingMillis` (220ms)
- 不支持内置 delay 参数，需通过 `visible` 状态 + `LaunchedEffect` + `delay()` 实现 stagger

**方案**: 在 `PhotoFeedGridRowContent` 中为每行卡片设置 `visible` 状态，通过 `LaunchedEffect(Unit)` + `delay(rowIndex * staggerDelay)` 实现逐行入场。
