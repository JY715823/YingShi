## 四、发现并修复的 Bug

### BUG-1: FR-3 AC-3 标尺拖拽手柄缺少交互反馈动画 → 已修复
**问题**: PhotoFeedTimeScrubber 手柄拖拽时无缩放反馈，需求要求 scale 1.12。
**根因**: Trae 实施时遗漏了本地 isInteracting 状态和 thumbScale 动画。
**修复**: 添加 isInteracting 状态 + animateFloatAsState(1.12f, tween(120ms)) + graphicsLayer 缩放。
**验证**: 编译通过。

### BUG-2: FR-8 AC-2 删除动画缺少 animateItemPlacement → 已修复
**问题**: LazyColumn items() 内未添加 Modifier.animateItem()，删除后卡片瞬间跳位。
**根因**: Trae 实施时遗漏了 LazyColumn 的重排动画修饰符。
**修复**: 5 个 Header/Divider Box + PhotoFeedGridRowContent 添加 `.then(if (motionEnabled) Modifier.animateItem() else Modifier)`。
**验证**: 编译通过。
