## 一、本模块依赖的外部模块/服务

| 依赖模块 | 依赖内容 | 本轮是否改动接口 | 说明 |

## 二、依赖本模块的外部调用方

| 调用方 | 调用内容 | 本轮是否影响 | 说明 |
|-------|---------|------------|------|
| RealPhotoFeedPage | PhotoFeedScreen | 是 | 新增参数传递 |
| AppPhotoFeedPickerScreen | PhotoFeedScreen(EMBEDDED) | 否 | 默认值 false |
| SmallAlbumDetailScreen | PhotoFeedScreen(EMBEDDED) | 否 | 默认值 false |

## 三、数据流图

```
RealPhotoFeedViewModel.startRefresh()
  → feedItems 非空 → isSilentlyRefreshing = true
  → 网络请求
  → 成功/失败 → isSilentlyRefreshing = false

RealPhotoFeedPage
  → uiState.isSilentlyRefreshing → PhotoFeedScreen(isSilentlyRefreshing)
  → PhotoFeedScreen 顶部 AnimatedVisibility 指示器

Fake 模式 (FakePhotoFeedRepository)
  → isSilentlyRefreshing 默认 false，不显示指示器
```
