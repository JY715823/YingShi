## FR-11: 加载更多视觉反馈

**目标**: 静默刷新时顶部增加极轻的刷新指示器，不阻断用户操作。

### 变更文件清单

| 文件路径 | 端 | 变更类型 | 变更内容 |
|---------|-----|---------|---------|
| `app/.../feature/photos/RealPhotoFeedViewModel.kt` | Android | 修改 | UiState 新增 `isSilentlyRefreshing`，refresh 中控制 |
| `app/.../feature/photos/PhotoFeedScreen.kt` | Android | 修改 | 新增 `isSilentlyRefreshing` 参数 + 顶部指示器 |
| `app/.../feature/photos/RealPhotoFeedPage.kt` | Android | 修改 | 传递 `isSilentlyRefreshing` 给 PhotoFeedScreen |

### 组件级计划

**RealPhotoFeedUiState** (L26-37):
- 新增字段: `val isSilentlyRefreshing: Boolean = false`

**startRefresh()** (L64-160):
- 在 L107 处（`_uiState.update`），当 `showBlockingLoading = false` 时，额外设置 `isSilentlyRefreshing = true`
- 在成功回调 (L130-140) 和失败回调 (L155-159) 中，设置 `isSilentlyRefreshing = false`

**PhotoFeedScreen**:
- 新增参数: `isSilentlyRefreshing: Boolean = false`
- 在 `Column` 顶部（LazyColumn 上方、协作人控制行下方）或使用 `Box` overlay 添加指示器
- 指示器: 使用 `AnimatedVisibility` + 一条极细的渐变线
  - 宽度: 从 0f 到 fillMaxWidth，动画通过 `animateFloatAsState` 或 `Animatable`
  - 高度: 1.5dp
  - 颜色: `colors.glassStroke.copy(alpha = 0.44f)` 渐变
  - 位置: 贴在 LazyColumn 顶部，不推动内容
  - 遵循 `motionEnabled` 守卫

**简化方案**: 使用 `LinearProgressIndicator` 的极简变体，或直接用 `Box` + `graphicsLayer` 做宽度动画。

**RealPhotoFeedPage**:
- 在 `PhotoFeedScreen` 调用处新增 `isSilentlyRefreshing = uiState.isSilentlyRefreshing`

### 实施顺序
1. ViewModel: UiState + startRefresh 逻辑
2. PhotoFeedScreen: 参数 + 指示器
3. RealPhotoFeedPage: 传递参数
4. 编译验证
