## 一、FR-11: 加载更多视觉反馈

### 1.1 静默刷新现状

**文件**: `RealPhotoFeedViewModel.kt`

`startRefresh()` (L64-160) 已实现静默刷新逻辑：
- L103: `val showBlockingLoading = _uiState.value.feedItems.isEmpty()`
- 当 feedItems 非空时，`showBlockingLoading = false`，刷新不显示 loading 态
- L112: `isLoading = showBlockingLoading` — 仅空列表时设 isLoading=true
- 刷新完成后 (L130-140): `isLoading = false`

**问题**: 静默刷新虽然有数据刷新，但 UI 层面没有任何反馈。用户不知道后台在刷新。

### 1.2 RealPhotoFeedUiState

**文件**: `RealPhotoFeedViewModel.kt` L26-37

当前状态字段：`isLoading`, `isLoadingMore`, `loadMoreErrorMessage`, `isDeleting`, `isOfflineReadOnly`, `tokenMissing`, `hasMore`, `errorMessage`, `statusMessage`, `feedItems`

**缺少**: 无 `isSilentlyRefreshing` 字段用于标记静默刷新状态。

### 1.3 PhotoFeedScreen 参数

**文件**: `PhotoFeedScreen.kt` L212-233

当前参数中无 `isSilentlyRefreshing`。顶部区域由 `PhotoFeedAtmosphereLayer` + `Column` 组成，暂无刷新指示器。

### 1.4 RealPhotoFeedPage 调用

**文件**: `RealPhotoFeedPage.kt` L373-389

`PhotoFeedScreen` 在 `Box(modifier = Modifier.weight(1f))` 中渲染，`YingShiNoticeHost` 在顶层 `Box` 的 `TopCenter` 对齐。

## 二、实施建议

1. **ViewModel**: `RealPhotoFeedUiState` 新增 `isSilentlyRefreshing: Boolean = false`，在 `startRefresh()` 中 feedItems 非空时设为 true，刷新完成后设为 false
2. **PhotoFeedScreen**: 新增 `isSilentlyRefreshing` 参数，在 LazyColumn 顶部增加极轻的刷新指示器（AnimatedVisibility + 细线动画）
3. **RealPhotoFeedPage**: 传递 `uiState.isSilentlyRefreshing` 给 `PhotoFeedScreen`

**指示器设计**: 顶部一条极细的渐变线（1.5dp），在加载时从 0→1 宽度展开，完成后淡出。不阻断用户操作，覆盖在内容上方。
