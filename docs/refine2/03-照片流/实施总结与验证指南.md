## 如何验证

### 快速验证（5 分钟核心验证步骤）

1. `gradlew.bat installDebug` 安装到真机
2. 进入照片流 → 观察四季色相标题（冬蓝/春绿/夏蓝/秋棕）
3. 切换到 16 列 → 观察年标题 shimmer 扫过效果
4. 双指捏合切换密度 → 观察标题缩放、标尺滑动、圆点弹性缩放
5. 往下滚动 → 新分组卡片 stagger 入场（淡入+上移）
6. 往上滚回 → 已加载分组直接显示，无重复动画
7. 长按进入多选 → 顶栏/底栏滑入滑出动画
8. 删除照片 → 卡片缩小淡出 + 后续卡片平滑上移
9. 切换协作人 → 内容 fade 过渡
10. 观察右侧标尺拖拽 → 手柄缩放反馈
