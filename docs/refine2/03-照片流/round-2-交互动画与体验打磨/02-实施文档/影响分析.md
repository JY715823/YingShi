## 变更文件影响分析

### 1. PhotoFeedScreen.kt

**变更范围**: FR-10/FR-9/FR-7/FR-8/FR-6 全部涉及此文件

| 变更位置 | 直接影响 | 间接影响 | 影响说明 |
|---------|---------|---------|---------|
| `PhotoFeedEmptyCollaboratorState` (L2953-2980) | 空态 UI 渲染 | 无 | 仅影响空态展示，不涉及数据流 |
| `PhotoFeedCollaboratorControlsRow` (L2724-2788) | 协作人筛选 UI | 协作人筛选状态 → `blocks` 重算 | 增加 `AnimatedContent` 包裹后，blocks 切换有 fade 过渡 |
| `PhotoFeedCard` 选中态 | 卡片选中 UI | 多选体验 | 增加 scale 动画不影响选中逻辑 |
| LazyColumn `animateItemPlacement()` | 列表布局动画 | 列表条目位置变动 | 可能影响删除/密度切换/筛选时的列表重排 |
| `PhotoFeedGridRowContent` 删除参数 | 卡片删除动画 | 胶囊删除标识 → ViewModel 删除调用 | 新增参数传递 `animatingDeleteMediaIds` |
| `densityTransitionPreviewScene.liveHeaderScale` | 标题缩放 | 密度转场视觉 | 修改 `liveHeaderScale` 从常量 1f 变为动态值 |
| `PhotoFeedTimeScrubber` 标签动画 | 标尺标签过渡 | 标尺交互 | 标签动画不影响 seek 功能和进度计算 |
