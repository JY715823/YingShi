## 四、数据流图

### FR-10: 空态数据流
```
feedItems (空) → blocks (空) → blocks.isEmpty() → PhotoFeedEmptyCollaboratorState
                                                    ↓
                                            图标 + 柔和文案
```

### FR-9: 协作人筛选数据流
```
点击 CollaboratorFilterChip
  → onToggleCollaborator(userId)
  → selectedCollaboratorUserIds 更新
  → blocks 重新计算
  → AnimatedContent(selectedCollaboratorUserIds) 触发 fade 过渡
  → LazyColumn 内容切换
```

### FR-7: 多选进入/退出数据流
```
长按卡片 (PhotoFeedScreen)
  → selectionState.enterWith(mediaId)
  → isInSelectionMode = true
  → PhotosRootScreen: AnimatedVisibility(visible=true) 顶栏滑入
  → YingShiApp: AnimatedVisibility(visible=true) 底栏滑入
  → PhotoFeedCard: animateFloatAsState(scale=0.97f)

点击取消 / 返回
  → selectionState.clear()
  → isInSelectionMode = false
  → 顶栏滑出 + 底栏滑出 + 卡片 scale 恢复
```

### FR-8: 删除动画数据流
```
确认删除对话框
  → animatingDeleteMediaIds = selectedIds
  → PhotoFeedScreen 接收 animatingDeleteMediaIds
  → PhotoFeedCard: isDeleting=true → alpha→0, scale→0.8 (200ms)
  → delay(200ms)
  → viewModel.deleteSelectedMedia(selectedIds)
  → feedItems 更新 (filterNot)
  → LazyColumn animateItemPlacement() 平滑重排
  → animatingDeleteMediaIds 清空
```

### FR-6: 密度切换数据流
```
双指捏合
  → discreteZoomLevelGesture
  → onPreviewStateChange → syncDensityPreview
  → densityTransitionStage = PREVIEWING
  → liveHeaderScale = 1f - 0.04f * previewProgress
  → 协作人圆点 scale = 0.92f (spring)
  → 标尺标签 AnimatedContent 过渡

双指释放
  → onGestureFinished
  → 提交: beginDensityTransition → COMMITTING → SETTLING → IDLE
  → 回弹: reboundDensityPreview → REBOUNDING → IDLE
  → liveHeaderScale 恢复到 1f
  → 协作人圆点 scale 恢复到 1f (spring)
```
