> 基于: 实施计划 v1.0
> 日期: 2026-07-17

## 变更文件影响分析

### 文件1: 新建 `feature/life/LifeConsoleViewModel.kt`

| 影响层级 | 影响对象 | 影响说明 |
|---------|---------|---------|
| 直接 | LifeConsoleScreen.kt | 原状态管理逻辑迁移到 ViewModel，Screen 改为只做 UI 渲染 |
| 间接 | LifeConsoleWidgetProvider | 原 `WidgetProvider.applySnapshot(context, snapshot)` 在 loadToday 中调用，现移至 ViewModel |
| 间接 | LifeMediaQuickViewerActivity | 原 `context.startActivity(intent)` 在 Frame 点击回调中，现需通过 ViewModel 事件或回调处理 |
| 间接 | 大相册/小相册/照片查看器 | 城市今日/媒体条目/帧点击 → 导航到对应模块，通过回调处理 |

### 文件2: 修改 `feature/life/LifeConsoleScreen.kt`

| 影响层级 | 影响对象 | 影响说明 |
|---------|---------|---------|
| 直接 | AppShell 导航 | `LifeConsoleScreen` 是 `YingShiApp.kt` 中的独立路由目的地，导航入口不变 |
| 直接 | LifeConsoleWidgetProvider | 原 `loadToday()` 末尾调用 `LifeConsoleWidgetProvider.applySnapshot(...)`，改为 ViewModel 调用 |
| 直接 | LifeMediaQuickViewerActivity | 原 `startActivity` 调用，改为 ViewModel 发出事件 |
| 间接 | 无 | ViewModel 只影响 LifeConsoleScreen 内部，不影响其他模块 |

### 文件3: 修改 `feature/life/LifeScreen.kt`

| 影响层级 | 影响对象 | 影响说明 |
|---------|---------|---------|
| 直接 | LifeConsoleScreen | LifeScreen 是 LifeConsoleScreen 的上一级页面（生活首页 Tab），变动不影响 |
| 直接 | 记账模块 | 读取 Room Ledger 数据，只读不写，不影响记账功能 |
| 直接 | 聊天模块 | 读取 Room Chat 数据，只读不写，不影响聊天功能 |
| 间接 | AppShell 导航 | LifeScreen 是生活首页的入口，导航到 LifeConsoleScreen 的逻辑不变 |
| 间接 | 无 | LifeScreen 变更仅影响自身 UI |

## 边界条件分析

| # | 边界条件 | 处理方式 |
|---|---------|---------|
| 1 | LifeConsoleRepository.getToday() 返回 null | 显示空状态，提示"暂无数据" |
| 2 | Ledger Room 数据库未初始化 | 降级为静态文案"进入账本" |
| 3 | Chat Room 数据库未初始化 | 降级为静态文案"打开记录" |
| 4 | 网络异常 | LifeConsoleScreen 已有错误处理，ViewModel 不变 |
| 5 | 快速切换页面 | ViewModel 使用 viewModelScope，自动取消挂起的协程 |
| 6 | 历史日期无数据 | 显示"这一天没有记录"空状态 |
| 7 | 设备旋转 | StateFlow 自动恢复，UI 重新渲染 |
