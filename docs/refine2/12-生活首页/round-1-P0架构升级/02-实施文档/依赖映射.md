# Round 1 依赖映射

> 基于: 实施计划 v1.0, 影响分析 v1.0
> 日期: 2026-07-17

---

## 一、本模块依赖的外部模块/服务

| 依赖 | 接口/方法 | 本轮是否改动 | 说明 |
|------|----------|------------|------|
| LifeConsoleRepository | `getToday()`, `getHistory()`, `deleteMedia()`, `uploadMedia()` | 否 | 只读复用，不修改接口 |
| LifeConsoleApi | Retrofit 接口 | 否 | 不修改 |
| RepositoryProvider | `lifeConsoleRepository` | 否 | 复用现有引用 |
| LedgerDao (Room) | `getTransactions()`, `getTransactionCount()` | 否 | FR-2 只读 |
| ChatDao (Room) | `getMessageCount()` 或类似方法 | 否 | FR-2 只读 |
| AppDatabase | `ledgerDao()`, `chatDao()` | 否 | 数据库访问 |
| LifeConsoleWidgetProvider | `applySnapshot(context, snapshot)` | 否 | 原调用位置从 Screen 移到 ViewModel |
| SyncVersionTracker | `staleState` | 否 | 原 LaunchedEffect 监听移到 ViewModel |
| 记账模块 | 导航路由 | 否 | 生命周期卡片点击 → 导航 |
| 聊天模块 | 导航路由 | 否 | 聊天记录卡片点击 → 导航 |
| 系统媒体模块 | 导航路由 | 否 | 今日痕迹卡片点击 → 导航 |
| LifeMediaQuickViewerActivity | `startActivity` | 否 | 帧点击需要 Context |

## 四、数据流图

```
LifeScreen (FR-2)
  ├── LifeConsoleRepository.getToday() ──→ RemoteLifeConsoleToday (媒体数量)
  ├── LedgerDao (Room) ──→ 最近交易/本月笔数
  └── ChatDao (Room) ──→ 消息总数
  ↓ 点击卡片
LifeConsoleScreen (FR-1)
  └── LifeConsoleViewModel
       ├── LifeConsoleRepository.getToday() ──→ RemoteLifeConsoleToday
       ├── LifeConsoleRepository.getHistory() ──→ RemoteLifeConsoleHistory
       ├── LifeConsoleRepository.uploadMedia() ──→ 上传
       ├── LifeConsoleRepository.deleteMedia() ──→ 删除
       └── SyncVersionTracker.staleState ──→ 同步检测
       └── LifeConsoleWidgetProvider.applySnapshot() ──→ Widget 更新
```
