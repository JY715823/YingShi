## FR-2: LifeScreen 卡片接入动态摘要数据

**目标**: 在 LifeScreen 三张入口卡片上展示实时摘要数据。

### 变更文件清单

| # | 文件 | 端 | 变更类型 | 变更内容 |
|---|------|-----|------|------|
| 1 | `feature/life/LifeScreen.kt` | Android | 修改 | 添加动态摘要数据加载和展示 |

### 数据获取方案

#### 1. 今日痕迹卡片 — 媒体数量

从 `LifeConsoleApi.getToday()` 获取。计算今日媒体总数 = `personSelf.mediaItems.size + personPartner.mediaItems.size + mealSelf.mediaItems.size + mealPartner.mediaItems.size`。

**实现**: 在 `LifeScreen` 中用 `LaunchedEffect(Unit)` 调用 `RepositoryProvider.lifeConsoleRepository.getToday()`，将结果存入 `remember { mutableStateOf<RemoteLifeConsoleToday?>(null) }`。

**展示**:
- 加载中: 显示 "加载中…"
- 成功: 显示 "今日 N 张" 或 "今天还没有痕迹"（N=0 时）
- 失败: 降级为静态文案 "查看今天"

#### 2. 记账卡片 — 最近交易

从 Room `LedgerDao` 获取最近交易。需要查询 `transactions` 表，按时间倒序取第一条。

**实现**: 在 `LifeScreen` 中通过 `RepositoryProvider` 获取 Application context，查询 Room 数据库。

**注意**: 需要确认 LedgerDao 是否可以直接访问。如果 Ledger 模块的 DAO 不在 `data/` 层，可能需要通过 `@RawQuery` 或直接访问 RoomDatabase。

**展示**:
- 加载中: 显示 "加载中…"
- 有交易: 显示 "最近: -¥35 午餐" 或 "本月 23 笔"
- 无交易: 显示 "还没有记录"
- 失败: 降级为静态文案 "进入账本"

#### 3. 聊天记录卡片 — 消息数

从 Room `ChatDao` 获取消息总数。

**展示**:
- 加载中: 显示 "加载中…"
- 有消息: 显示 "N 条消息"
- 无消息: 显示 "还没有导入"
- 失败: 降级为静态文案 "打开记录"

### 状态管理

在 `LifeScreen` 中添加：
```kotlin
var lifeConsoleSummary by remember { mutableStateOf<LifeSummaryState>(LifeSummaryState.Loading) }
var ledgerSummary by remember { mutableStateOf<LifeSummaryState>(LifeSummaryState.Loading) }
var chatSummary by remember { mutableStateOf<LifeSummaryState>(LifeSummaryState.Loading) }
```

### 降级策略

所有数据加载失败时，卡片降级为原始静态文案，确保导航功能不受影响。

### LifeEntryCard 参数扩展

在 `LifeEntryCard` 的 `status` 参数基础上，增加 `summaryState: LifeSummaryState` 参数（可选，默认 `null` 表示不显示动态数据），当 `summaryState` 不为 null 时，`status` 位置显示动态内容。

或更简单：直接在 `LifeScreen` 中根据 `summaryState` 计算 `status` 字符串，不修改 `LifeEntryCard` 签名。
