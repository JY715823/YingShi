## FR-1: LifeConsoleScreen 提取 ViewModel

### 新建文件

#### `feature/life/LifeConsoleViewModel.kt`

**变更类型**: 新建
**内容概述**: 提取 LifeConsoleScreen 中所有状态管理和业务逻辑

**UiState 定义**:
```kotlin
data class LifeConsoleUiState(
    val snapshot: RemoteLifeConsoleToday? = null,
    val history: RemoteLifeConsoleHistory? = null,
    val isLoading: Boolean = false,
    val isHistoryLoading: Boolean = false,
    val actionMessage: String? = null,
    val pendingUploadCategory: String? = null,
    val historyRange: LifeConsoleHistoryRange = LifeConsoleHistoryRange.ALL,
    val showHistoryPage: Boolean = false,
    val notice: YingShiNotice? = null,
    val pendingDeleteTarget: Pair<String, String>? = null,
    val contentVisible: Boolean = false,
)
```

**公开方法**:
| 方法 | 说明 |
|------|------|
| `loadToday()` | 加载今日数据，支持日期变化检测 |
| `loadHistory(limitDays)` | 加载历史数据，过滤今天日期 |
| `refreshHistory()` | 使用当前range刷新历史 |
| `setHistoryRange(range)` | 设置历史范围 |
| `setShowHistoryPage(show)` | 设置历史页面显隐 |
| `setPendingUploadCategory(c)` | 设置待上传分类 |
| `onUploadResult(uris, category)` | 处理上传结果，更新Widget和Sync |
| `setPendingDeleteTarget(mediaId, category)` | 设置待删除目标 |
| `cancelDeleteMedia()` | 取消删除 |
| `confirmDeleteMedia()` | 确认删除，乐观更新+Widget+Sync |
| `addBowelEvent()` | 乐观增加排便，API同步 |
| `removeBowelEvent()` | 乐观减少排便，API同步 |
| `showNotice(message, tone)` | 显示通知 |
| `dismissNotice(nonce)` | 关闭通知 |
| `onResume()` | ON_RESUME 刷新 |

**生命周期处理**:
- `init{}`: 加载今日数据 + 历史数据 + 启动 sync stale observer + 跨零点定时器
- `onCleared()`: 取消所有协程
- `startSyncStaleObserver()`: 监听 SyncVersionTracker.staleState
- `startCrossMidnightTimer()`: 跨零点自动刷新

**Factory 模式**:
```kotlin
companion object {
    fun factory(application: Application, zoneId: String): ViewModelProvider.Factory
}
```

## FR-2: LifeScreen 卡片接入动态摘要数据

### 修改文件

#### `feature/life/LifeScreen.kt`

**变更类型**: 修改
**内容概述**: 添加动态摘要数据加载，三张卡片展示实时信息

**新增导入**:
- `androidx.compose.ui.platform.LocalContext`
- `com.example.yingshi.data.remote.result.ApiResult`
- `com.example.yingshi.data.repository.RepositoryProvider`
- `com.example.yingshi.feature.chat.data.ChatImportDatabase`
- `com.example.yingshi.feature.ledger.data.LedgerDatabase`
- `kotlinx.coroutines.Dispatchers`
- `kotlinx.coroutines.withContext`

**新增状态**:
```kotlin
var traceSummary by remember { mutableStateOf<String?>(null) }
var ledgerSummary by remember { mutableStateOf<String?>(null) }
var chatSummary by remember { mutableStateOf<String?>(null) }
```

**新增 LaunchedEffect**:
1. **今日痕迹摘要**: 调用 `RepositoryProvider.lifeConsoleRepository.getToday()`，统计4个slot的媒体总数
2. **记账摘要**: 通过 `LedgerDatabase.getInstance(context).ledgerDao()` 查询所有活跃账本的交易总数
3. **聊天摘要**: 通过 `ChatImportDatabase.getInstance(context).chatImportDao()` 查询所有聊天的消息总数

**卡片状态映射**:
| 卡片 | 状态 | 显示 |
|------|------|------|
| 今日痕迹 | 有媒体 | "今日 N 张" |
| 今日痕迹 | 无媒体 | "今天还没有痕迹" |
| 今日痕迹 | 加载中/失败 | "查看今天"（静态） |
| 记账 | 有交易 | "共 N 笔记录" |
| 记账 | 无交易 | "还没有记录" |
| 记账 | 加载中/失败 | "进入账本"（静态） |
| 聊天 | 有消息 | "N 条消息" |
| 聊天 | 无导入 | "还没有导入" |
| 聊天 | 仅对话 | "N 个对话" |
| 聊天 | 加载中/失败 | "打开记录"（静态） |

**降级策略**: 所有异常和加载失败时，卡片保持原始静态文案，不影响导航功能。
