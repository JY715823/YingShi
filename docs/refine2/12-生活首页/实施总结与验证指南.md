## 如何验证

### 快速验证（5分钟核心验证）

1. **生活首页**: 打开生活 Tab → 三张卡片显示动态摘要（今日痕迹 N 张 / 记账 N 笔 / 聊天 N 条）
2. **今日痕迹**: 点击"今日痕迹"卡片 → LifeConsoleScreen 正常加载 → 上传/删除/排便操作正常
3. **路由切换**: 在生活模块内切换（首页↔痕迹↔记账↔聊天）→ 返回键正确回退
4. **问候语**: 上午打开显示"早安"，下午打开显示"午安"
5. **Widget**: 桌面 Widget 正常显示和交互
