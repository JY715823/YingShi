## 一、影响链路

### FR-7: Widget Controller 拆分

| 变更文件 | 直接影响 | 间接影响 | 影响说明 |
|---------|---------|---------|---------|
| `WidgetPendingIntentFactory.kt` (新建) | 无 | 被 ConsoleWidgetBuilder 和 PeopleWidgetBuilder 引用 | 新增共享 Intent 工厂 |
| `ConsoleWidgetBuilder.kt` (新建) | 无 | 被 LifeConsoleWidgetController 引用 | 新增 Console 视图构建 |
| `PeopleWidgetBuilder.kt` (新建) | 无 | 被 LifeConsoleWidgetController 引用 | 新增 People 视图构建 |
| `LifeConsoleWidgetProvider.kt` (修改) | 删除大量私有函数 | 无外部调用方 | 仅 Controller 内部使用 |

**影响路径清单**:
- IA-1: Console Widget 渲染 → buildConsoleViews → ConsoleWidgetBuilder.build()
- IA-2: People Widget 渲染 → buildPeopleViews → PeopleWidgetBuilder.build()
- IA-3: PendingIntent 构建 → WidgetPendingIntentFactory
- IA-4: bindSlot 共享 → ConsoleWidgetBuilder → PeopleWidgetBuilder 引用
