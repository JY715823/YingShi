# Round 3 依赖映射

> 基于: 实施计划 v1.0
> 日期: 2026-07-17

---

## 一、本模块依赖的外部模块/服务

| 依赖模块 | 依赖方向 | 依赖内容 | 本轮是否改动接口 |
|---------|---------|---------|:---:|
| LifeConsoleWidgetStore | 内→外 | 快照/状态/缓存/索引 | 否 |
| LifeConsoleWidgetSlotKey | 内→外 | slot 枚举 | 否 |
| LifeConsoleUtils (isVideo) | 内→外 | 共享工具函数 | 否 |
| LifeConsoleUploadBridge | 内→外 | 上传 | 否 |
| AppNavigationRequests | 内→外 | 导航常量 | 否 |
| RepositoryProvider | 内→外 | API 调用 | 否 |

## 二、依赖本模块的外部调用方

| 调用方 | 依赖内容 | 本轮是否影响接口 |
|--------|---------|:---:|
| LifeConsoleViewModel | applySnapshot | 否 |
| LifeConsoleWidgetProvider (类) | refreshAll | 否 |
| Android AppWidgetManager | onUpdate/onReceive | 否 |

## 三、共享组件依赖

| 共享组件 | 是否受影响 | 说明 |
|----------|:---:|------|
| ConsoleWidgetBuilder | 新建 | 被 LifeConsoleWidgetController 引用 |
| PeopleWidgetBuilder | 新建 | 被 LifeConsoleWidgetController 引用 |
| WidgetPendingIntentFactory | 新建 | 被 ConsoleWidgetBuilder 引用 |

## 四、数据流图

```
[LifeConsoleWidgetProvider.onUpdate]
    → LifeConsoleWidgetController.renderAllFromStore
        → ConsoleWidgetBuilder.build(context, status, snapshot)
            → WidgetPendingIntentFactory.openMainIntent(...)
            → WidgetPendingIntentFactory.slotIntent(...)
            → WidgetPendingIntentFactory.widgetBroadcast(...)
            → bindSlot(...) → WidgetPendingIntentFactory.openMediaViewer(...)
        → PeopleWidgetBuilder.build(context, status, snapshot)
            → WidgetPendingIntentFactory.widgetBroadcast(...)
            → ConsoleWidgetBuilder.bindSlot(...) [同包共享]
```

## 五、回归测试范围

| 回归范围 | 说明 |
|---------|------|
| Console Widget 渲染 | 4个slot + 记账按钮 + 刷新按钮 + 排便按钮 |
| People Widget 渲染 | 2个slot + 刷新按钮 |
| Widget 交互 | 点击 slot/prev/next/delete/upload → PendingIntent 正确 |
