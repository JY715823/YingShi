## 实施详情

### 1. WidgetPendingIntentFactory.kt (新建)

**职责**: PendingIntent 构建逻辑集中管理

**函数清单**:
- `openMainIntent()` - 打开 MainActivity 的 PendingIntent
- `openMediaEntry()` - 打开 WidgetMediaEntryActivity 的 PendingIntent
- `openMediaViewer()` - 打开 LifeMediaQuickViewerActivity 的 PendingIntent
- `slotIntent()` - slot 操作的 PendingIntent (getBroadcast)
- `widgetBroadcast()` - Widget 广播 PendingIntent
- `requestCodeFor()` / `laneFor()` / `providerClassFor()` / `widgetRequestCode()` - 辅助函数

**依赖**: `AppNavigationRequests`, `LifeMediaQuickViewerActivity`, `WidgetMediaEntryActivity`, `MainActivity`

### 2. ConsoleWidgetBuilder.kt (新建)

**职责**: Console Widget 的 RemoteViews 构建 + 共享的 bindSlot/bindBowel

**核心函数**:
- `build()` - Console Widget 主入口，构建 RemoteViews
- `RemoteViews.bindConsoleActions()` - 绑定记账/刷新/排便/上传按钮
- `RemoteViews.bindSlot()` - 共享的 slot 绑定逻辑（图片/前后翻页/打开/上传/删除），被 PeopleWidgetBuilder 复用
- `RemoteViews.bindBowel()` - 排便数据显示
- `SlotViews` data class + 4个实例 (PersonSelfViews, PersonPartnerViews, MealSelfViews, MealPartnerViews)
- 工具函数: `currentMedia`, `latestText`, `emptyHintFor`, `formatTime`, `formatAbsoluteTime`, `updateStatus`, `widgetTodayDate`, `initRuntime`

### 3. PeopleWidgetBuilder.kt (新建)

**职责**: People Widget 的 RemoteViews 构建

**核心函数**:
- `build()` - People Widget 主入口
- `RemoteViews.bindPeopleActions()` - 绑定刷新/上传按钮
- 复用 `ConsoleWidgetBuilder.bindSlot()` 进行 slot 绑定

### 4. LifeConsoleWidgetProvider.kt (瘦身)

**保留内容**:
- `LifeConsoleWidgetProvider` 类 (L1-41) - AppWidgetProvider 骨架
- `LifeConsoleWidgetController` 对象 (L43-232)
  - 常量 (ACTION_*, LANE_*, widgetActions, widgetScope)
  - 公共 API: `refreshAll`, `applySnapshot`, `handleReceive`, `renderAllFromStore`, `fetchAndUpdateAll`
  - 业务逻辑: `deleteCurrentMedia`
  - 委托: `updateConsoleWidgets` → `ConsoleWidgetBuilder.build()`，`updatePeopleWidgets` → `PeopleWidgetBuilder.build()`
  - 辅助: `slotKeyOrNull`

**删除内容** (已提取到新文件):
- `buildConsoleViews`, `buildPeopleViews` → ConsoleWidgetBuilder/PeopleWidgetBuilder
- `bindConsoleActions`, `bindPeopleActions` → ConsoleWidgetBuilder/PeopleWidgetBuilder
- `bindSlot`, `bindBowel` → ConsoleWidgetBuilder
- `openMainIntent`, `openMediaEntry`, `openMediaViewer`, `slotIntent`, `widgetBroadcast` → WidgetPendingIntentFactory
- `requestCodeFor`, `laneFor`, `providerClassFor`, `widgetRequestCode` → WidgetPendingIntentFactory
- `formatTime`, `formatAbsoluteTime`, `updateStatus`, `widgetTodayDate`, `initRuntime`, `latestText`, `emptyHintFor`, `currentMedia` → ConsoleWidgetBuilder
- `SlotViews` data class + 4个实例 → ConsoleWidgetBuilder
