## 一、影响链路

### FR-6: 问候语响应式更新

| 变更文件 | 直接影响 | 间接影响 | 影响说明 |
|---------|---------|---------|---------|
| `LifeScreen.kt` | 新增 DisposableEffect + LifecycleEventObserver | 无 | 仅影响 LifeScreen 自身行为 |

**影响路径清单**:
- IA-1: LifeScreen 从后台恢复时问候语更新 → 验证跨时段问候语切换

### FR-5: Calendar→java.time + 硬编码清理

| 变更文件 | 直接影响 | 间接影响 | 影响说明 |
|---------|---------|---------|---------|
| `LifeScreen.kt` | Calendar → LocalDateTime | 无 | 仅 import 替换 |
| `LifeConsoleScreen.kt` | 5处时区常量化, formatTime → java.time | LifeConsoleViewModel.kt 通过 zoneId 参数间接依赖 | 时区常量定义在 Screen 文件中，ViewModel 通过参数接收 |

**影响路径清单**:
- IA-2: ZoneId 常量化后 LifeConsoleViewModel 调用不变化
- IA-3: formatTime 行为一致性（java.time 输出格式与 SimpleDateFormat 一致）

### FR-4: 跨文件重复逻辑提取

| 变更文件 | 直接影响 | 间接影响 | 影响说明 |
|---------|---------|---------|---------|
| `LifeConsoleUtils.kt` (新建) | 无 | 被以下文件引用 | 新增共享工具 |
| `LifeConsoleWidgetStore.kt` | 删除 isVideo/looksLikeVideoUrl/firstUsableImageUrl | Widget 渲染 | 函数行为不变，仅位置移动 |
| `LifeConsoleWidgetProvider.kt` | 删除 isVideo/formatTime | Widget 更新 | 函数行为不变，仅位置移动 |
| `LifeMediaQuickViewerActivity.kt` | 删除 looksLikeVideoUrl/firstUsableImageUrl | 媒体查看器 | 函数行为不变，仅位置移动 |
| `LifeConsoleScreen.kt` | 删除 formatTime | LifeConsoleHistoryPage 调用 | 函数行为不变，仅位置移动 |

**影响路径清单**:
- IA-4: isVideo() 在 Widget 渲染中行为一致
- IA-5: isVideo() 在 Widget 更新中行为一致
- IA-6: looksLikeVideoUrl 在媒体查看器中行为一致
- IA-7: firstUsableImageUrl 在媒体查看器中行为一致
- IA-8: formatTime 在 LifeConsole 历史页面中行为一致
- IA-9: formatTime 在 Widget 中行为一致

### FR-3: 路由管理 sealed class 化

| 变更文件 | 直接影响 | 间接影响 | 影响说明 |
|---------|---------|---------|---------|
| `LifeSubRoute.kt` (新建) | 无 | 被 YingShiApp.kt 和 LifeScreen.kt 引用 | 新增数据类型 |
| `YingShiApp.kt` | 6个 boolean/nonce 变量 → 1个 sealed class | 所有路由相关逻辑 | 大规模变更 |
| `LifeScreen.kt` | 3个回调 → 1个 onNavigate | YingShiApp 调用处 | 回调签名变更 |

**影响路径清单**:
- IA-10: 路由切换逻辑（3个互斥 boolean → 1个 sealed class）
- IA-11: BackHandler 行为（when 表达式 vs if-else）
- IA-12: 通知中心跳转（AppNavigationRequests → sealed class）
- IA-13: HomeScreen 打开账本
- IA-14: LifeScreen 路由分发
- IA-15: canNavigateBack 判断
