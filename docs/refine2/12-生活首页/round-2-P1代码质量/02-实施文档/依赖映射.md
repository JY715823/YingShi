## 四、数据流图

### FR-6 问候语更新流
```
[LifeScreen ON_RESUME]
    → LocalDateTime.now()
    → 计算 currentTimeLabel / currentDateLabel
    → UI 刷新
```

### FR-5 时区常量化
```
[LifeConsoleScreen zoneId 参数]
    ← DEFAULT_ZONE_ID 常量
    → 传递到 ViewModel
    → 传递到 LifeConsoleHistoryPage
    → 传递到 currentLifeConsoleDate / millisUntilNextLifeConsoleRefresh
```

### FR-4 工具函数提取
```
[LifeConsoleUtils.kt]
    ├── isVideo()            ← LifeConsoleWidgetStore, LifeConsoleWidgetProvider
    ├── looksLikeVideoUrl()  ← LifeConsoleWidgetStore, LifeMediaQuickViewerActivity
    ├── firstUsableImageUrl()← LifeConsoleWidgetStore, LifeMediaQuickViewerActivity
    └── formatTime()         ← LifeConsoleScreen, LifeConsoleWidgetProvider
```

### FR-3 路由管理
```
[AppNavigationRequests / LifeScreen 回调]
    → LifeSubRoute sealed class
    → YingShiApp 路由分发 when 表达式
    → 各子路由 Composable 渲染
    → BackHandler 返回 LifeSubRoute.Life
```
