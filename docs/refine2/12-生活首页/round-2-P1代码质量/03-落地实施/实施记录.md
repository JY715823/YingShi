## FR-5: Calendar→java.time + 硬编码清理

### 修改文件

| 文件 | 变更 | 说明 |
|------|------|------|
| `LifeScreen.kt` | 修改 | `Calendar` → `LocalDateTime`, 移除 `Calendar` import |
| `LifeConsoleScreen.kt` | 修改 | 定义 `DEFAULT_ZONE_ID` 常量, 替换硬编码 `"Asia/Shanghai"`, `formatTime` → `java.time` |

### 变更详情

**LifeScreen.kt**:
- `java.util.Calendar` → `java.time.LocalDateTime`
- `Calendar.HOUR_OF_DAY` → `now.hour`
- `Calendar.MONTH + 1` → `now.monthValue`
- `Calendar.DAY_OF_MONTH` → `now.dayOfMonth`
- `Calendar.getDisplayName()` → `now.dayOfWeek.getDisplayName(TextStyle.FULL, ...)`

**LifeConsoleScreen.kt**:
- 定义 `private const val DEFAULT_ZONE_ID = "Asia/Shanghai"`
- 替换 `val zoneId = "Asia/Shanghai"` → `val zoneId = DEFAULT_ZONE_ID`
- `formatTime`: `SimpleDateFormat` + `Date` → `Instant.ofEpochMilli` + `ZoneId`

## FR-3: 路由管理 sealed class 化

### 新建文件

| 文件 | 说明 |
|------|------|
| `LifeSubRoute.kt` | sealed class: Life, Console, Ledger, LedgerAdd, Chat |

### 修改文件

| 文件 | 变更 | 说明 |
|------|------|------|
| `YingShiApp.kt` | 修改 | 5个 boolean/nonce 变量 → 1个 `LifeSubRoute`；when 替换 if-else 链 |
| `LifeScreen.kt` | 修改 | 3个回调 → 1个 `onNavigate: (LifeSubRoute) -> Unit` |

### YingShiApp.kt 变更清单

| 变更点 | 原代码 | 新代码 |
|--------|--------|--------|
| 变量定义 | 5个 boolean/nonce 变量 | `var lifeSubRoute: LifeSubRoute = LifeSubRoute.Life` |
| clearProtectedUiRoutes | 3个 `= false` | `lifeSubRoute = LifeSubRoute.Life` |
| nonce 监听 (3处) | 设置多个 boolean | `lifeSubRoute = LifeSubRoute.Console/Ledger/LedgerAdd` |
| BackHandler | 3个 if 块 | 1个 when 表达式 |
| canNavigateBack (3处) | `!a && !b && !c` | `lifeSubRoute == LifeSubRoute.Life` |
| 通知中心 (3处) | 设置多个 boolean | `lifeSubRoute = LifeSubRoute.xxx` |
| HomeScreen ledger | 设置多个 boolean + nonce | `lifeSubRoute = LifeSubRoute.Ledger` |
| 路由分发 | if-else 链 | `when (lifeSubRoute)` |
| QuickAdd 记账 | 设置多个 boolean + nonce | `lifeSubRoute = LifeSubRoute.LedgerAdd` |

### LifeScreen.kt 变更

```kotlin
// 原签名
fun LifeScreen(onOpenLifeConsole: () -> Unit, onOpenLedger: () -> Unit, onOpenChatViewer: () -> Unit)

// 新签名
fun LifeScreen(onNavigate: (LifeSubRoute) -> Unit)
```
