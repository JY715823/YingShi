## 一、FR-6: 问候语响应式更新

### 代码定位

| 文件 | 行号 | 内容 |
|------|------|------|
| `feature/life/LifeScreen.kt` | L76-88 | `LaunchedEffect(Unit)` 计算问候语，仅执行一次 |
| `app/YingShiApp.kt` | L1629-1647 | LifeScreen 调用，通过 `LifecycleEventObserver` 环境 |

### 现状问题

- 当前 `LaunchedEffect(Unit)` 在 LifeScreen 首次组合时执行一次，后续不再更新
- 用户从子路由返回时，如果已跨时段（如午安→晚安），问候语不更新
- 使用 `java.util.Calendar` 而非 `java.time`

### 修复方案

- 添加 `DisposableEffect` 监听 `Lifecycle.Event.ON_RESUME`，在 onResume 时重新计算问候语
- 配合 FR-5 将 `Calendar` 替换为 `java.time`

### 当前路由变量


### 目标 sealed class 设计

```kotlin
sealed class LifeSubRoute {
    data object Life : LifeSubRoute()          // 首页（默认）
    data object Console : LifeSubRoute()       // 生活控制台
    data object Ledger : LifeSubRoute()        // 账本首页
    data object LedgerAdd : LifeSubRoute()     // 账本添加
    data object Chat : LifeSubRoute()          // 聊天查看器
}
```

### 技术约束

- sealed class 定义在 `app/` 包（与 YingShiApp 同包），或放在 `feature/life/` 包
- 由于 YingShiApp.kt 中直接使用 Int 状态（ledgerOpenAddNonce），LedgerAdd 需要携带 nonce 值
- LifeScreen 回调签名需要从 3 个独立回调改为 1 个统一回调
