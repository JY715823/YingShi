## 本模块依赖的外部模块/服务

| 依赖模块 | 本轮是否改动接口 | 说明 |
|---------|----------------|------|
| 通知 API (Retrofit) | 否 | 接口不变 |
| AppReadCacheStore | 否 | 读写方式不变 |
| SyncVersionTracker | 否 | stale 监听逻辑不变 |
| AuthSessionManager | 否 | 用户信息获取不变 |
| RepositoryProvider | 否 | 仓库获取不变 |
| OfflineAccessManager | 否 | 离线检测不变 |

## 依赖本模块的外部调用方

| 调用方 | 本轮是否影响 | 说明 |
|--------|------------|------|
| YingShiApp → 通知中心路由 | import 更新 | 模型路径变更（包名不变） |
| HomeScreen → 铃铛未读计数 | import 更新 | 模型路径变更 |
| NotificationDetailScreen → 通知详情 | import 更新 | 模型路径变更 |

## 前后端共享组件依赖

| 组件 | 是否受影响 | 说明 |
|------|-----------|------|
| NotificationModels.kt | 新建 | 公共模型集中管理 |
| NotificationCenterComponents.kt | 新建 | Composable 组件独立文件 |
| NotificationCenterPresentation.kt | 新建 | 视觉解析独立文件 |

```

  → NotificationCenterScreen Composable

```

```
NotificationCenterScreen.kt
  ├── ViewModel.uiState.collectAsState()

```
