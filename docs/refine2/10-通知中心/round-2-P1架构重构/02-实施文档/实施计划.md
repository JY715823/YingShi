## FR-2: 提取 NotificationCenterViewModel

**目标**: 从 NotificationCenterScreen.kt 提取状态管理和业务逻辑到 ViewModel。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |

| 2 | `feature/photos/NotificationCenterScreen.kt` | Android | 修改 | 使用 ViewModel，移除状态管理代码 |

### NotificationCenterViewModel.kt 设计

```kotlin
class NotificationCenterViewModel : ViewModel() {
    // 数据类
    data class UiState(...)  // 从 NotificationCenterUiState 移入
    data class ResolvedPresentation(...)  // 从 NotificationResolvedPresentation 移入
    sealed interface Visual  // 从 NotificationVisual 移入
    
    // 状态
    private val _uiState = MutableStateFlow(UiState(isLoading = true))
    val uiState: StateFlow<UiState> = _uiState.asStateFlow()
    
    // 过滤状态
    private val _selectedFilter = MutableStateFlow(NotificationCenterFilter.PHOTOS)
    val selectedFilter: StateFlow<NotificationCenterFilter>
    private val _selectedCategory = MutableStateFlow(NotificationCategoryFilter.ALL)
    val selectedCategory: StateFlow<NotificationCategoryFilter>
    private val _includeSelfActor = MutableStateFlow(false)
    private val _includePartnerActor = MutableStateFlow(true)
    
    // 业务方法
    fun init(sessionKey: String, source: String)
    suspend fun refresh(...)
    suspend fun markRead(itemId: String)
    suspend fun markAllRead()
    fun clearList()
    fun setFilter(filter: NotificationCenterFilter)
    fun setCategory(category: NotificationCategoryFilter)
    fun toggleSelfActor()
    fun togglePartnerActor()
}
```

### 关键设计决策
- ViewModel 使用 `StateFlow` 而非 `mutableStateOf`（与项目其他 ViewModel 一致）
- NotificationCenterMemoryCache 移入 ViewModel 的 companion object
- 路由持久化逻辑保留在 Screen 层（`onRouteSnapshotChange` 仍由 Composable 处理）
