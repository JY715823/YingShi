## 如何验证

### 快速验证（5分钟核心验证）

1. **推送偏好**: 打开设置 → 切换"照片系统推送"和"生活系统推送"开关 → 应正常保存不报错
2. **点击已读**: 打开通知中心 → 点击一条未读通知文案 → 应立即变为已读但不跳转 → 再点击已读通知 → 应跳转到目标页
3. **缩略图跳转**: 点击通知卡片上的媒体缩略图 → 应标记已读 + 跳转到目标页
4. **下拉刷新**: 在通知中心下拉 → 应触发刷新
5. **分页**: 如果通知超过30条，滚动到底部 → 应自动加载更多
