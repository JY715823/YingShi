## 实施详情

### 1. NotificationController.java — cursor 参数

- L36-L48: `listNotifications()` 新增 `@RequestParam(required = false) Long cursor` 参数
- 透传给 `notificationService.listNotifications(currentUser, limit, cursor)`

### 2. NotificationService.java — cursor 过滤

- L89-L97: `listNotifications()` 新增 `Long cursor` 参数，透传给 `materializeNotifications()`
- L99-L106: `getNotification()` 更新 `materializeNotifications()` 调用为 4 参数（cursor=null）
- L201-L217: `materializeNotifications()` 新增 `Long cursor` 参数
  - Step 1: cursor 过滤 `e.createdAtMillis() < cursor`
  - Step 2: limit 截断
  - Step 3: read status 解析（不变）

### 3. NotificationApi.kt — cursor query 参数

- L12-L16: `getNotifications()` 新增 `@Query("cursor") cursor: Long? = null`

### 4. Contracts.kt — 接口签名更新

- L155-L159: `NotificationRepository.getNotifications()` 新增 `cursor: Long? = null`

### 5. RealRepositories.kt — 透传 cursor

- L661-L663: `RealNotificationRepository.getNotifications()` 透传 cursor 到 API

### 6. FakeRepositories.kt — 签名更新

- L467: `FakeNotificationRepositoryShell.getNotifications()` 签名新增 `cursor: Long?`
- 内部逻辑不变（Fake 数据源忽略 cursor）

### 7. NotificationCenterViewModel.kt — 分页 + 刷新状态

- L48-L49: `NotificationCenterUiState` 新增 `isLoadingMore` / `hasMore` 字段
- L97: Companion 新增 `PAGE_SIZE = 30`
- L148-L150: Internal state 新增 `currentCursor` / `hasMore` / `loadMoreJob`
- L197-L281: `refresh()` 重构:
  - limit 从 100 改为 PAGE_SIZE(30)
  - cursor 传 null（首次加载）
  - 区分 `isLoading`(初始空列表) / `isRefreshing`(非空列表刷新)
  - 成功时设置 `currentCursor` 和 `hasMore`
  - 失败时清除 `isRefreshing`
- L323-L379: 新增 `loadMore()` 方法:
  - 防重复（`hasMore` + `isLoadingMore` 双重检查）
  - 传 cursor 获取下一批
  - 合并去重后更新列表
  - 持久化到 AppReadCacheStore

### 8. NotificationCenterScreen.kt — PullRefresh + 滚动检测

- L37: 新增 `import ExperimentalMaterial3Api`
- L42: 新增 `import PullToRefreshBox`
- L54: 新增 `import TextAlign`
- L67: 新增 `@OptIn(ExperimentalMaterial3Api::class)` 注解
- L167-L178: 新增滚动检测 `LaunchedEffect(listState)` —
  当 `lastVisibleItem >= totalItems - 3` 时触发 `viewModel.loadMore()`
- L288-L357: LazyColumn 包裹为 `PullToRefreshBox`:
  - `isRefreshing = uiState.isRefreshing`
  - `onRefresh` 检查 `!uiState.isOfflineReadOnly`
  - 底部新增 `loading-more` item（`isLoadingMore` 时显示）
  - 底部新增 `no-more` item（`!hasMore` 且列表非空时显示"没有更多通知"）
