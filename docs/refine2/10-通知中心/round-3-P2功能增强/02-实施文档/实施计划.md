#### 2b. `materializeNotifications()` (L200-L225)

**变更**: 新增 `Long cursor` 参数，在 limit 截断前按 `createdAtMillis < cursor` 过滤

```java
// 修改前
private List<NotificationDto> materializeNotifications(
        List<NotificationEvent> events,
        String userId,
        Integer limit
) {
    List<NotificationEvent> visibleEvents = limit == null
            ? events
            : events.stream().limit(limit).toList();
    // ... read status resolution ...
}

// 修改后
private List<NotificationDto> materializeNotifications(
        List<NotificationEvent> events,
        String userId,
        Integer limit,
        Long cursor
) {
    // Step 1: cursor 过滤（在 limit 之前）
    List<NotificationEvent> filteredEvents = (cursor == null || cursor <= 0)
            ? events
            : events.stream()
                    .filter(e -> e.createdAtMillis() < cursor)
                    .toList();

    // Step 2: limit 截断
    List<NotificationEvent> visibleEvents = limit == null
            ? filteredEvents
            : filteredEvents.stream().limit(limit).toList();

    // Step 3: read status resolution (不变)
    // ...
}
```

**边界条件**:
- cursor 为 null 或 <= 0 → 不过滤，行为与旧版一致
- 过滤后无事件 → 返回空列表
- 排序顺序不变（`collectNotificationEvents()` 已按 createdAtMillis DESC 排序）

#### 6c. `refresh()` 修改 (L190-L260)

**关键变更**: 首次加载 limit 从 100 改为 PAGE_SIZE(30)，设置 cursor 状态

```kotlin
companion object {
    // ... 现有 memory cache ...
    private const val PAGE_SIZE = 30
}

fun refresh() {
    refreshJob?.cancel()
    val requestVersion = ++refreshVersion
    refreshJob = viewModelScope.launch {
        // ... 现有离线/loading 逻辑不变 ...
        when (val result = RepositoryProvider.notificationRepository.getNotifications(
            limit = PAGE_SIZE,
            cursor = null,  // 首次加载不传 cursor
        )) {
            is ApiResult.Success -> {
                if (requestVersion != refreshVersion) return@launch
                // ... 现有缓存写入逻辑不变 ...
                val remoteNotifications = result.data.map { it.toNotificationCenterItemUiModel() }
                val hasMoreFlag = result.data.size >= PAGE_SIZE
                val nextCursor = if (hasMoreFlag && remoteNotifications.isNotEmpty()) {
                    remoteNotifications.last().createdAtMillis
                } else null
                currentCursor = nextCursor
                this@NotificationCenterViewModel.hasMore = hasMoreFlag
                // ... 更新 uiState 时设置 hasMore = hasMoreFlag ...
            }
            // ... 其他分支不变 ...
        }
    }
}
```

#### 6d. 新增 `loadMore()` 方法

```kotlin
fun loadMore() {
    if (!hasMore || _uiState.value.isLoadingMore) return
    loadMoreJob?.cancel()
    loadMoreJob = viewModelScope.launch {
        updateUiState(_uiState.value.copy(isLoadingMore = true))
        val cursor = currentCursor ?: run {
            updateUiState(_uiState.value.copy(isLoadingMore = false))
            return@launch
        }
        when (val result = RepositoryProvider.notificationRepository.getNotifications(
            limit = PAGE_SIZE,
            cursor = cursor,
        )) {
            is ApiResult.Success -> {
                val newItems = result.data.map { it.toNotificationCenterItemUiModel() }
                val hasMoreFlag = result.data.size >= PAGE_SIZE
                val nextCursor = if (hasMoreFlag && newItems.isNotEmpty()) {
                    newItems.last().createdAtMillis
                } else null
                currentCursor = nextCursor
                this@NotificationCenterViewModel.hasMore = hasMoreFlag
                // 合并：去重后排序
                val merged = mergeNotificationStreams(
                    remoteNotifications = _uiState.value.notifications + newItems,
                    localNotifications = NotificationCenterLocalStore.getNotifications(),
                )
                updateUiState(
                    _uiState.value.copy(
                        notifications = merged,
                        isLoadingMore = false,
                        hasMore = hasMoreFlag,
                    ),
                )
                // 持久化合并后的完整列表
                if (currentUserId != null) {
                    withContext(Dispatchers.IO) {
                        AppReadCacheStore.writeNotifications(
                            userId = currentUserId!!,
                            notifications = merged.map { it.toRemoteNotification() },
                        )
                    }
                }
            }
            is ApiResult.Error -> {
                updateUiState(
                    _uiState.value.copy(
                        isLoadingMore = false,
                        errorMessage = result.toBackendUiMessage("加载更多通知失败。"),
                    ),
                )
            }
            ApiResult.Loading -> Unit
        }
    }
}
```

**边界条件**:
- `hasMore == false` 时不触发加载
- `isLoadingMore == true` 时不重复触发
- `currentCursor == null` 时不触发加载
- 合并时 `mergeNotificationStreams()` 自带去重（distinctBy id）
- 加载更多后完整列表持久化到 AppReadCacheStore

#### 7b. FR-5: 滚动检测触发 loadMore

在 LaunchedEffect 中监听 listState 滚动位置：

```kotlin
// 在现有 LaunchedEffect 块后新增:
LaunchedEffect(listState) {
    snapshotFlow {
        val layoutInfo = listState.layoutInfo
        val totalItems = layoutInfo.totalItemsCount
        val lastVisibleItem = layoutInfo.visibleItemsInfo.lastOrNull()?.index ?: 0
        lastVisibleItem to totalItems
    }.collect { (lastVisible, total) ->
        if (total > 0 && lastVisible >= total - 3 && !uiState.isLoadingMore && uiState.hasMore) {
            viewModel.loadMore()
        }
    }
}
```

**注意**: 需要确保 `isRefreshing` 状态在 ViewModel 中正确控制。当前 `refresh()` 方法使用 `isLoading` 字段，需要区分：
- `isLoading`: 初始加载（列表为空时显示全屏 loading）
- `isRefreshing`: 下拉刷新（列表非空时显示 PullRefresh 指示器）
- `isLoadingMore`: 加载更多（列表底部显示 loading）

**修改 refresh()**: 当列表非空时设置 `isRefreshing = true` 而非 `isLoading = true`：

```kotlin
// 在 refresh() 的 updateUiState 调用中:
updateUiState(
    _uiState.value.copy(
        isLoading = _uiState.value.notifications.isEmpty(),
        isRefreshing = _uiState.value.notifications.isNotEmpty(),
        isOfflineReadOnly = false,
        errorMessage = null,
        infoMessage = null,
    ),
)
```

**refresh 成功时清除 isRefreshing**:
```kotlin
updateUiState(
    NotificationCenterUiState(
        // ... 其他字段 ...
        isLoading = false,
        isRefreshing = false,
        // ...
    ),

```

**refresh 失败时清除 isRefreshing**:
