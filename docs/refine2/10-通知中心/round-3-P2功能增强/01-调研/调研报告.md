## 一、FR-5: 通知列表分页加载

### Server 端

| 文件 | 位置 | 现状 |
|------|------|------|
| NotificationController.java | L36-L47 | `listNotifications()` 仅接受 `limit` 参数（Integer），无 `cursor` |
| NotificationService.java | L89-L96 | `listNotifications()` 透传 `limit` 给 `materializeNotifications()` |
| NotificationService.java | L616-L621 | `normalizeLimit()` 规范化 limit（默认100，最小1，最大100） |
| NotificationService.java | L148-L197 | `collectNotificationEvents()` 全量收集所有通知事件 |
| NotificationService.java | L200-L225 | `materializeNotifications()` 用 `limit` 截断，无 cursor 过滤 |

**关键发现**: 当前 `collectNotificationEvents()` 全量收集所有事件再 `materializeNotifications()` 截断。加 cursor 分页需要修改 `collectNotificationEvents()` 在每个数据源查询时传入 `cursor` 参数。

### Android 端

| 文件 | 位置 | 现状 |
|------|------|------|
| NotificationApi.kt | L13-L15 | `getNotifications(limit)` 无 cursor 参数 |
| Contracts.kt | L155-L169 | `NotificationRepository.getNotifications(limit)` 无 cursor |
| RealRepositories.kt | L661-L677 | `RealNotificationRepository.getNotifications(limit)` 无 cursor |
| NotificationCenterViewModel.kt | L190-L260 | `refresh()` 调用 `getNotifications(limit = 100)`，无分页状态 |
| NotificationCenterScreen.kt | L287-L321 | `LazyColumn` 无滚动检测，无 PullRefresh |
| NotificationCenterViewModel.kt | L140-L144 | 内部状态：sessionKey, currentUserId, refreshJob, refreshVersion — 无 hasMore/currentCursor/isLoadingMore |

### 变更范围

**Server**:
1. `NotificationController.java` — `listNotifications()` 新增 `cursor` 参数（Long?）
2. `NotificationService.java` — `listNotifications()` 新增 cursor；`collectNotificationEvents()` 传入 cursor；`materializeNotifications()` 在 cursor 非空时按 `createdAt < cursor` 过滤

**Android**:
1. `NotificationApi.kt` — `getNotifications()` 新增 `cursor` 参数
2. `Contracts.kt` — `NotificationRepository.getNotifications()` 新增 cursor
3. `RealRepositories.kt` — `RealNotificationRepository` 更新
4. `NotificationCenterViewModel.kt` — 新增 `loadMore()` 方法，管理 `hasMore`/`currentCursor`/`isLoadingMore`
5. `NotificationCenterScreen.kt` — LazyColumn 检测滚动到底部，触发 loadMore

## 四、技术约束

- FR-5 的 cursor 参数向后兼容（不传 cursor = 获取最新 N 条）
- cursor 使用 createdAt 毫秒时间戳
- 分页默认每页 30 条（初始加载），区别于旧版 limit=100
- FR-6 的 PullRefresh 与 stale 提示条共用 ViewModel.refresh() 方法
