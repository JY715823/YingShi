- 通过标准: HTTP 200, data 数组长度 ≤ 30

### TC-004: Server cursor 分页查询
- 对应: FR-5 AC-1
- 端: Server
- 前置条件: Server 运行中，已有 >30 条通知
- 步骤:
  1. `curl -s "http://localhost:8080/api/notifications?limit=30" -H "Authorization: Bearer <token>"` 获取第一批，记录最后一条的 createdAtMillis

- 预期结果: 第二批所有通知的 createdAtMillis < cursor
- 通过标准: HTTP 200, 每条通知 createdAtMillis < cursor
