# Round 1 影响分析

> 基于实施计划: Round 1 — P0 稳定性修复

---

## 变更文件影响链

### 1. PushNotificationService.java (Server)

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接变更 | `defaultPreferences()` L332-L343 | 新增 2 项默认偏好 |
| 直接影响 | `getPreferences()` L105-L119 | 返回列表从 6 项变为 8 项 |
| 直接影响 | `updatePreference()` L122-L128 | system 类别不再被拒绝 |
| 直接影响 | `defaultPreferenceEnabled()` L324-L330 | 新增 2 个默认值查询 |
| 间接影响 | `isPushEnabled()` | 可正确查询 system 类别 |
| 间接影响 | `notifyPhotoChanged()` | system 类别推送可被偏好过滤 |
| 间接影响 | Android SettingsScreen | 8 个开关全部可用（不再 400） |

**影响路径清单**:
- IA-1: GET /api/push/preferences 返回 8 项（含 photos:system=false, life:system=false）
- IA-2: PATCH /api/push/preferences 更新 photos:system 返回 200
- IA-3: PATCH /api/push/preferences 更新 life:system 返回 200
- IA-4: Android 设置页 8 个开关全部可切换

### 2. NotificationCenterScreen.kt (Android) — onClick 重构

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接变更 | `onClick` 回调 L593-L636 | 不跳转 + 持久化 + 错误回滚 |
| 直接影响 | 通知卡片点击行为 | 点击文案→仅标记已读，不跳转 |
| 直接影响 | 持久化路径 | 本地路径增加 persistNotificationUiState |
| 直接影响 | 错误处理 | API 失败不再强制设 isRead=true |
| 间接影响 | 首页铃铛未读计数 L215 | 持久化后计数与缓存一致 |
| 间接影响 | NotificationCenterMemoryCache | 无影响，仅读取 uiState |

**影响路径清单**:
- IA-5: 点击未读通知文案 → 标记已读 + 持久化到 AppReadCacheStore + 不跳转
- IA-6: 点击已读通知文案 → 跳转到目标页（保持现有行为）
- IA-7: 点击媒体缩略图 → 标记已读 + 跳转（保持现有行为）
- IA-8: API markRead 失败 → isRead 保持 false + 显示错误提示
- IA-9: 进程重启 → 已读通知仍显示为已读（从 AppReadCacheStore 恢复）
- IA-10: 离线只读模式 → 点击通知跳转到目标页（保持现有行为）

### 3. NotificationCenterScreen.kt (Android) — markAllRead

| 层级 | 影响 | 说明 |
|------|------|------|
| 直接变更 | `onMarkAllRead` L468-L504 | 确认持久化已存在 |
| 无变更 | persistNotificationUiState 已存在 | 无需修改 |

**影响路径清单**:
- IA-11: markAllRead → 所有通知 isRead=true + 持久化到 AppReadCacheStore

## 前端影响链

### ViewModel → Composable → 共享组件

**当前无 ViewModel**（FR-2 在 Round 2），所有状态在 Composable 中管理。影响链：

```
NotificationCenterScreen.kt (Composable)
  ├── onClick 回调 → 不跳转（行为变更）
  ├── onMediaClick 回调 → 不变
  ├── onMarkAllRead 回调 → 不变（已有持久化）
  ├── unreadCount L215 → 受 isRead 持久化影响（正向）
  └── AppShell/BottomNav → 铃铛未读计数 → 受持久化影响（正向）
```

### 共享组件依赖

| 共享组件 | 是否受影响 | 说明 |
|---------|-----------|------|
| AppShell | 否 | 铃铛读取 NotificationCenterMemoryCache，不受影响 |
| BottomNav | 否 | 无通知相关逻辑 |
| YingShiSurfaces | 否 | 未使用 |
| 通用 Dialog | 否 | 未使用 |
