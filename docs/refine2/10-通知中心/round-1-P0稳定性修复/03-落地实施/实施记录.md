**文件**: `YingShi-Server/src/main/java/com/yingshi/server/service/push/PushNotificationService.java`

**修改**: `defaultPreferences()` 方法 (L332-L345)，新增 2 行：

**逻辑**: 两个常量 `CATEGORY_PHOTOS_SYSTEM` (L47) 和 `CATEGORY_LIFE_SYSTEM` (L51) 已存在，无需新增。`defaultPreferenceEnabled()`、`updatePreference()`、`getPreferences()` 方法自动适配。

### 变更2: NotificationCenterScreen.kt (FR-8)

**文件**: `app/src/main/java/com/example/yingshi/feature/photos/NotificationCenterScreen.kt`

**修改**: `onClick` 回调 (L593-L637) 重构：

| 变更项 | 旧行为 | 新行为 |
|--------|--------|--------|
| 已读通知点击 | 标记已读 → 跳转 | 直接跳转（不改变状态） |
| 未读通知点击 | 标记已读 → 跳转 | 标记已读 → 不跳转 |
| 本地路径持久化 | 只改内存 | 改内存 + persistNotificationUiState() |
| API 错误处理 | 强制设 isRead=true | 保持 isRead=false + 显示错误 |
| API Loading 处理 | 强制设 isRead=true | 保持原 isRead 状态 |

**onMediaClick 不变**: 点击媒体缩略图仍然标记已读 → 跳转。
