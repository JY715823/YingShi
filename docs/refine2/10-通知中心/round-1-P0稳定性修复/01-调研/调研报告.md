### 问题分析

#### 问题 1: 本地路径不写 AppReadCacheStore（高）

**位置**: L601-L604
```kotlin
} else if (NotificationCenterLocalStore.contains(item.id)) {
    NotificationCenterLocalStore.markRead(item.id)  // 只改内存
    val updatedItem = item.copy(isRead = true)
    updateUiState(uiState.replaceNotification(updatedItem))
    updatedItem
}
```
此路径无 `persistNotificationUiState()` 调用，进程被杀后丢失。

#### 问题 2: API 失败时强制设 isRead=true（中）

**位置**: L623-L632
```kotlin
is ApiResult.Error -> {
    updateUiState(uiState.copy(errorMessage = ...))
    updateUiState(uiState.replaceNotification(item.copy(isRead = true)))  // 错误！
    item.copy(isRead = true)  // 错误！应回滚为 false
}
is ApiResult.Loading -> item.copy(isRead = true)  // 错误！应保持原状态
```
API 失败/Loading 状态下仍标记为已读，下次刷新变回未读。

#### 问题 3: 点击文案区域必然跳转（中）

**位置**: L635
```kotlin
onOpenNotificationTarget(targetItem)  // onClick 末尾无条件跳转
```
用户只想标记已读时被迫跳转。需求：点击文案仅标记已读不跳转，点击缩略图标记已读+跳转。

#### 问题 4: markAllRead 不写 AppReadCacheStore（高）

**位置**: L468-L504
markAllRead 成功后调用 `NotificationCenterLocalStore.markAllRead()` 和 `persistNotificationUiState()`，但 `persistNotificationUiState` 写的是 `uiState.notifications` 整体列表。如果 markAllRead 前已通过其他方式标记了部分通知为已读，这些状态可能不一致。

### 技术约束

- onMediaClick 保持不变（标记已读+跳转），只改 onClick
- 需要确保 NotificationCenterLocalStore 的修改不影响其他调用方（Brief 中提到 pushPostCommentNotification/pushMediaCommentNotification 也使用此 Store）
