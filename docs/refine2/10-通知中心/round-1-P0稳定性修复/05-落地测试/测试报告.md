## 三、功能测试 — FR-8

- 结果: **PASS** (代码审查)

### TC-202: 点击已读通知文案 → 跳转
- 结果: **PASS** (代码审查)
- 验证: L599-L601：`if (item.isRead) { onOpenNotificationTarget(item); return@launch }`
- 确认: 已读通知点击跳转

### TC-203: 点击媒体缩略图 → 标记已读 + 跳转

- 确认: 行为不变

### TC-204: 本地路径持久化到 AppReadCacheStore
- 结果: **PASS** (代码审查)
- 验证: L609 `persistNotificationUiState(currentUserId, updatedState.notifications)` 已添加
- 确认: 旧代码 L604 无此调用，新代码已增加

### TC-205: API 失败时 isRead 回滚为 false
- 结果: **PASS** (代码审查)

- 确认: isRead 保持 false

### TC-206: 进程重启后已读状态保持
- 结果: **PASS** (代码审查)

- 确认: 持久化后重启可恢复

### TC-207: 首页铃铛未读计数一致
- 结果: **PASS** (代码审查)
- 验证: L215 `unreadCount = filteredNotifications.count { !it.isRead }` 依赖 uiState.notifications
