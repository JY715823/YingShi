## 二、FR-13 依赖链

### 服务端依赖链

```
UploadTaskRepository.findVisibleHistoryPage (新增方法)
  └── UploadService.listUploadHistory (重构，新增 cursor 参数)
        └── UploadController.listUploads (新增 cursor 参数，返回真实 PageInfo)
              └── Android UploadApi.getUploadHistory (客户端，无需改动)
```

### 依赖本模块的外部调用方

| 调用方 | 依赖内容 | 本轮是否影响 |
|--------|---------|-------------|
| Android UploadApi | GET /api/uploads | 否（cursor 为可选参数，不传时行为不变） |
| Android LocalSystemMediaBridgeRepository | refreshRemoteUploadHistory() | 否（调用方式不变） |
| UploadService.dismissUploadBatch | findVisibleHistory (旧方法) | 否（保留旧方法） |

### 数据流

```
Android UploadApi.getUploadHistory(state?, operationType?, pageSize?)
  → HTTP GET /api/uploads?state=&operationType=&pageSize=&cursor=
    → UploadController.listUploads
      → UploadService.listUploadHistory (新增 cursor 支持)
        → UploadTaskRepository.findVisibleHistoryPage (Pageable 分页)
        → 返回 UploadHistoryResult(items, nextCursor, hasMore)
      → 构造 ApiResponse(data=items, pageInfo=PageInfo(page, pageSize, nextCursor, hasMore))
```

### Android 端兼容性确认

```
Android UploadApi.getUploadHistory()
  → 返回 ApiEnvelopeDto<List<UploadTaskDto>>
  → 不解析 pageInfo 字段
  → 不传 cursor 参数
  → 结论：后端改动对 Android 端完全透明，无需任何修改
```
