## 发现的 Bug

### BUG-1: cursor 参数被接收但未参与分页过滤

**严重度**: 严重
**问题**: `UploadService.listUploadHistory` 中 cursor 参数被接收但在初版实现中完全忽略，始终使用 `PageRequest.of(0, pageSize + 1)` 从第一页开始查询，导致传入 cursor 时仍返回第一页数据。
**根因**: 实施计划中采用了"cursor 预留、暂不实现"的简化策略，但需求要求 cursor 必须实际参与分页。
**修复**:
1. `UploadTaskRepository.findVisibleHistoryPage` 新增 `cursorUpdatedAt` 和 `cursorId` 参数，JPQL 查询添加 `AND (:cursorUpdatedAt IS NULL OR task.updatedAt < :cursorUpdatedAt OR (task.updatedAt = :cursorUpdatedAt AND task.id < :cursorId))` 过滤条件
2. `UploadService.listUploadHistory` 新增 cursor 解析逻辑：按 `:` 分割，前半部分解析为 `Instant`，后半部分为 `id`；无效 cursor 降级为无 cursor（返回首页）
**验证**: `mvnw.cmd compile` 编译通过 (exit 0)
