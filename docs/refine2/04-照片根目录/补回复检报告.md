## 三、发现并修复的 Bug

### BUG-1: FR-8 工具按钮缺少 pressedAlpha 和 motionEnabled

**问题**: Trae 实施的 PhotoPillToolButton 和 PhotoCircleToolButton 仅保留了 `yingShiClickable(pressedScale)` 的按压缩放，缺少 `pressedAlpha` 透明度动画和 `motionEnabled` 降级逻辑。

**修复**: 
1. 两个按钮均添加 `val motionEnabled = rememberYingShiMotionEnabled()`
2. 添加 `MutableInteractionSource` + `collectIsPressedAsState()` 追踪按压状态
3. 添加 `pressedAlpha` animateFloatAsState（Pill: pressed=0.72, Circle: pressed=0.84）
4. 将 `yingShiClickable` 替换为 `graphicsLayer { scaleX/scaleY/alpha } + clickable(interactionSource)`
5. 动画 duration 使用 `if (motionEnabled) motion.tapMillis else 0`
6. 补充 5 个缺失的 import

**验证**: Android 编译通过。
