# 04-照片根目录 需求文档

> 版本: v1.0 | 日期: 2026-07-09 | 状态: 已确认

## 一、模块目标

照片根目录模块在上一轮视觉精修（标题式导航 + 一体工具组 + 根层状态面 + 多选壳层底栏）的基础上，进行深度结构性精修：修复标题光晕与文字的中心对齐偏差，将硬编码颜色纳入 token 管理，清理 FAKE/REAL 双路径混杂的数据源风险，重构 1573 行单文件的状态管理架构，并统一全模块的 UI 表面语言（玻璃容器、工具按钮、对话框），使照片根入口从"视觉方向正确但工程粗糙"推进到"视觉精准 + 工程整洁"的成品级状态。服务端同步修复 N+1 查询、冗余方法和伪分页问题。

**描述**: 所有新增/修改的视觉元素必须通过 YingShiThemeTokens 引用颜色、间距、圆角。不允许引入新的硬编码颜色或固定 dp 值（除非是动画参数中的像素级微调）。新增 token 必须命名语义清晰、与现有 token 体系一致。

### NFR-3: 编译与回归安全

**描述**: 每轮实施完成后：(1) Android `gradlew.bat assembleDebug` 编译通过；(2) Server `mvnw.cmd compile` 编译通过（如涉及服务端改动）；(3) 现有 Testcontainers 测试全部通过（如涉及服务端改动）；(4) 无功能性回退——所有现有用户流程（分页切换、多选操作、新建大相册、加帖、删除确认、传输状态查看）行为不变或按 FR 要求改进。
