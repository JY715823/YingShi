## FR-8: 工具按钮视觉层级优化

**目标**：统一系统按钮和传输按钮的形状家族，增强按压反馈质感，微调 badge 位置。

### 变更文件清单

| 文件路径 | 端 | 变更类型 | 变更内容 |
|---------|-----|---------|---------|
| PhotosRootScreen.kt | Android | 修改 | PhotoPillToolButton + PhotoCircleToolButton 形状/按压态/badge |

### 组件级计划

#### PhotoCircleToolButton（L1404-L1517）— 传输按钮

**形状变更**：`CircleShape` → `RoundedCornerShape(24.dp)`（圆角矩形，与 PhotoPillToolButton 统一形状家族，但稍大以示主次）

**按压态增强**：当前 `yingShiClickable(pressedScale=0.94f)` 仅 scale。新增 `alpha` 动画：
```kotlin
// 在 Box 外包装 graphicsLayer
val pressedAlpha by animateFloatAsState(
    targetValue = if (pressed) 0.85f else 1f,
    animationSpec = tween(durationMillis = motion.tapMillis),
)
Modifier.graphicsLayer { alpha = pressedAlpha }
```

**badge 位置微调**：`offset(x=1.dp, y=0.dp)` → `offset(x=4.dp, y=(-4).dp)`（正右上角外侧，不遮挡按钮本体）

#### PhotoPillToolButton（L1350-L1401）— 系统按钮

**形状**：保持 `RoundedCornerShape(18.dp)`（比传输按钮稍小，体现主次）

**按压态增强**：同 PhotoCircleToolButton，新增 alpha 变化

### 颜色 token 使用

- 容器色: `colors.glassSurfaceBase`（已有）
- 边框: `colors.dividerSoft`（已有）
- 图标/文字: `colors.titleAccent`（已有）
- 渐变: `colors.glowWash`（已有）

## FR-9: 选择态顶栏与底栏视觉统一

**目标**：取消按钮增加胶囊背景，底栏四个按钮增加图标+文字 Column 布局。

### 变更文件清单

| 文件路径 | 端 | 变更类型 | 变更内容 |
|---------|-----|---------|---------|
| PhotosRootScreen.kt | Android | 修改 | 取消按钮包装 + PhotoSelectionBottomBarAction 图标化 |

### 组件级计划

#### "取消"按钮（L770-L790）

当前：纯 Text + yingShiClickable，无背景
修改：用 Surface 包裹，添加胶囊背景：
```kotlin
Surface(
    modifier = Modifier.width(58.dp),
    shape = RoundedCornerShape(16.dp),
    color = Color.White.copy(alpha = 0.30f),
    border = BorderStroke(1.dp, colors.dividerSoft.copy(alpha = 0.50f)),
) {
    Text(
        text = "取消",
        modifier = Modifier
            .yingShiClickable(shape = RoundedCornerShape(16.dp), pressedScale = 0.96f, onClick = onCancelSelection)
            .padding(vertical = 8.dp),
        textAlign = TextAlign.Center,
        ...
    )
}
```

#### PhotoSelectionBottomBarAction（L1296-L1347）

当前：仅文字居中，无图标
修改：增加 `icon: ImageVector` 参数，改为 Column 布局（图标在上，文字在下）：
```kotlin
@Composable
private fun PhotoSelectionBottomBarAction(
    icon: ImageVector,
    text: String,
    enabled: Boolean,
    modifier: Modifier = Modifier,
    destructive: Boolean = false,
    onClick: () -> Unit,
) {
    ...
    Column(
        modifier = Modifier.fillMaxSize(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center,
    ) {
        Icon(
            imageVector = icon,
            contentDescription = null,
            tint = ...,
            modifier = Modifier.size(18.dp),
        )
        Spacer(modifier = Modifier.height(2.dp))
        Text(
            text = text,
            style = MaterialTheme.typography.labelSmall.copy(fontWeight = FontWeight.SemiBold),
            color = ...,
            maxLines = 1,
            overflow = TextOverflow.Ellipsis,
        )
    }
}
```

#### 调用处更新（L1266-L1291）

四个按钮分别传入对应图标：
- 分享: `Icons.Rounded.Upload`
- 新建: `Icons.Rounded.Add`
- 加入: `Icons.Rounded.Folder`
- 删除: `Icons.Rounded.Delete`

- 取消按钮背景: `Color.White.copy(alpha=0.30f)`（纯装饰，无对应 token 需硬编码）

## FR-10: 顶栏玻璃容器背景自适应

**目标**：内部渐变去硬编码，感知 Aurora 变体调整玻璃色调。

### 变更文件清单

| 文件路径 | 端 | 变更类型 | 变更内容 |
|---------|-----|---------|---------|
| PhotosRootScreen.kt | Android | 修改 | PhotoTopGlassSurface 渐变 token 化 + variant 感知 |

### 组件级计划

#### PhotoTopGlassSurface（L700-L727）

**新增参数**：`variant: YingShiBackdropVariant = YingShiBackdropVariant.PHOTOS`

**渐变 token 化**：`Color.White.copy(alpha=0.38f)` → 根据 variant 选择不同的渐变顶层色：
```kotlin
val gradientTopColor = when (variant) {
    YingShiBackdropVariant.PHOTOS -> colors.titleAccent.copy(alpha = 0.08f)
    else -> Color.White.copy(alpha = 0.38f)
}
// 渐变改为: gradientTopColor → colors.glowWash.copy(alpha=0.24f) → Color.Transparent
```

**PHOTOS 变体**：顶层色使用与珍珠蓝背景融合的 `titleAccent.copy(alpha=0.08)`，叠加在 `glassSurfaceBase` 上形成更融合的玻璃感

#### 调用处更新（L831）

传入 `variant = YingShiBackdropVariant.PHOTOS`（PhotosRootScreen 中已有此值）

### 颜色 token 使用

- `colors.titleAccent`（已有）— PHOTOS 变体渐变顶层色
- `colors.glowWash`（已有）— 渐变中间层
- `colors.glassSurfaceBase`（已有）— 表面底色
