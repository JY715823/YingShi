# Round 3 影响分析

> 日期: 2026-07-09
> 基于实施计划 v1.0

---

## 变更文件影响链

### 1. PhotosRootScreen.kt — PhotoCircleToolButton（FR-8）

- **变更类型**: 形状 CircleShape → RoundedCornerShape(24.dp)，新增按压 alpha 动画，badge 位置微调
- **直接影响**: 传输按钮外观变化（圆形→圆角矩形），按压反馈增强
- **间接影响**: 无（该函数仅被 PhotoTopBar 调用，私有函数）
- **影响说明**: 纯视觉变化，不影响功能。形状变化可能导致用户短暂适应期

### 2. PhotosRootScreen.kt — PhotoPillToolButton（FR-8）

- **变更类型**: 新增按压 alpha 动画
- **直接影响**: 系统按钮按压反馈增强
- **间接影响**: 无
- **影响说明**: 纯视觉增强，零风险

### 3. PhotosRootScreen.kt — "取消"按钮（FR-9）

- **变更类型**: 纯 Text → Surface 包裹（胶囊背景 + 边框）
- **直接影响**: 选择态"取消"按钮视觉层次提升
- **间接影响**: 无
- **影响说明**: 纯视觉变化，不影响点击行为

### 4. PhotosRootScreen.kt — PhotoSelectionBottomBarAction（FR-9）

- **变更类型**: 新增 `icon` 参数，布局从纯文字 → Column（图标+文字）
- **直接影响**: 底栏四个按钮的视觉外观变化，按钮高度可能增加
- **间接影响**: 4 处调用点需同步更新（L1266-L1291）
- **影响说明**: 纯视觉变化，功能不变。需确保窄屏上不溢出

### 5. PhotosRootScreen.kt — PhotoTopGlassSurface（FR-10）

- **变更类型**: 新增 `variant` 参数，内部渐变顶层色根据 variant 动态选择
- **直接影响**: 玻璃容器在 PHOTOS 变体下颜色更融合
- **间接影响**: 1 处调用点需同步更新（L831）
- **影响说明**: 纯视觉优化，不影响功能。渐变色值变化细微

### 6. PhotosRootScreen.kt — 删除确认弹窗 AlertDialog（FR-11）

- **变更类型**: containerColor token 化，新增 border/shadow
- **直接影响**: 弹窗外观与玻璃容器风格统一
- **间接影响**: 无
- **影响说明**: 纯视觉变化，不影响删除功能

### 7. PhotosRootScreen.kt — 新建大相册弹窗 AlertDialog（FR-11）

- **变更类型**: containerColor token 化，新增 border/shadow，OutlinedTextField 定制颜色
- **直接影响**: 弹窗外观统一，输入框颜色与主题一致
- **间接影响**: 无
- **影响说明**: 纯视觉变化，不影响创建功能

## 风险评估

| 风险 | 严重度 | 说明 |
|------|--------|------|
| 传输按钮形状变化导致用户困惑 | 低 | 圆形→圆角矩形，变化明显但功能不变，需确保尺寸足够大以体现主次 |
| 底栏按钮加图标后高度增加导致溢出 | 低 | 当前高度 56dp，Column 布局（图标 18dp + 间距 2dp + 文字）可能超出，需调整 |
| PhotoTopGlassSurface 渐变色值变化导致视觉退化 | 低 | 新增 variant 仅影响 PHOTOS 变体，其他变体保持不变 |
| 硬编码 Color.White 在取消按钮背景中 | 低 | 取消按钮背景用 `Color.White.copy(alpha=0.30f)`，为纯装饰性微透明，无合适 token 替代，可接受 |
