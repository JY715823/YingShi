## 一、FR-8: 工具按钮视觉层级优化

### 涉及组件

| 组件 | 行号 | 形状 | 按压态 | 备注 |
|------|------|------|--------|------|
| PhotoPillToolButton | L1350-L1401 | RoundedCornerShape(18.dp) 圆角矩形 | yingShiClickable(pressedScale=0.96f) 仅 scale | 系统按钮 |
| PhotoCircleToolButton | L1404-L1517 | CircleShape 圆形 | yingShiClickable(pressedScale=0.94f) 仅 scale | 传输按钮 |

### 当前问题

1. **形状不统一**：系统按钮用圆角矩形，传输按钮用圆形——两个按钮视觉上不属于同一家族
2. **按压态单一**：均为纯 scale 缩放，无 alpha 透明度变化，反馈质感弱
3. **badge 位置**：传输按钮 badge 在 `offset(x=1.dp, y=0.dp)` + `Alignment.TopEnd`，非常轻微的偏移，几乎在按钮正上方

### 颜色使用

- PhotoPillToolButton: `colors.glassSurfaceBase.copy(alpha=0.68f)` + 内部渐变 `Color.White.copy(alpha=0.28f)` + `colors.glowWash.copy(alpha=0.18f)`
- PhotoCircleToolButton: 根据状态动态切换（error/active/default），容器色为 `colors.destructiveContainer` / `colors.primaryContainer` / `Color.White.copy(alpha=0.42f)`

### 调用位置

- L837-L863: 在 PhotoTopBar 的正常模式下被调用，包裹在 PhotoTopGlassSurface 内

## 二、FR-9: 选择态顶栏与底栏视觉统一

### 涉及组件

| 组件 | 行号 | 当前状态 |
|------|------|---------|
| 选择态"取消"按钮 | L770-L790 | 纯 Text，无胶囊背景，仅通过 yingShiClickable 提供点击区域 |
| 选择态"已选 N 项"文字 | L792-L809 | titleMedium + Bold + 白色阴影，居中显示 |
| 底栏四个按钮 | L1266-L1291 | PhotoSelectionBottomBarAction × 4，仅文字无图标 |
| PhotoSelectionBottomBarAction | L1296-L1347 | 56dp 高 × weight(1f) 宽，RoundedCornerShape(16.dp)，仅文字居中 |

### 当前问题

1. **取消按钮无视觉层次**：只是普通文字，缺少"可点击"的视觉提示（如胶囊背景）
2. **底栏按钮无图标**：四个按钮（分享/新建/加入/删除）仅有文字，辨识度低
3. **底栏按钮布局**：当前 Row 水平排列，改为 Column（图标+文字）需要增加高度

### 颜色使用

- 取消按钮: `colors.titleAccent.copy(alpha=0.92f)` + 白色阴影
- 底栏正常按钮: `colors.primaryContainer.copy(alpha=0.78f)` / `colors.titleAccent`
- 底栏删除按钮: `colors.destructiveContainer.copy(alpha=0.90f)` / `colors.destructive`
- 已选文字: `colors.textPrimary`

## 三、FR-10: 顶栏玻璃容器背景自适应

### 涉及组件

| 组件 | 行号 | 当前状态 |
|------|------|---------|
| PhotoTopGlassSurface | L700-L727 | 使用 `colors.glassSurfaceBase`，内部渐变硬编码 `Color.White.copy(alpha=0.38f)` + `colors.glowWash.copy(alpha=0.24f)` |

### 当前实现细节

- **表面色**: `colors.glassSurfaceBase`（已 token 化）
- **边框**: `BorderStroke(1.dp, colors.glassStroke.copy(alpha=0.70f))`
- **阴影**: `shadowElevation = 3.dp`
- **内部渐变**: `Brush.linearGradient` 从 `Color.White.copy(alpha=0.38f)` → `colors.glowWash.copy(alpha=0.24f)` → `Color.Transparent`
- **Aurora 感知**: 否。函数不接收 variant 参数，不感知当前背景变体

### 当前问题

1. 内部渐变中的 `Color.White.copy(alpha=0.38f)` 是硬编码
2. 不感知 AuroraBackdrop 的 PHOTOS 变体（珍珠蓝色调），玻璃色与背景融合度可提升
3. `glassSurfaceBase` token 已存在，但内部渐变未与之配套

## 四、FR-11: 对话框表面统一

### 涉及组件

| 组件 | 行号 | 当前状态 |
|------|------|---------|
| 删除确认弹窗 AlertDialog | L441-L511 | shape=28dp, containerColor=Color.White.copy(alpha=0.97f) 硬编码 |
| 新建大相册弹窗 AlertDialog | L309-L412 | shape=28dp, containerColor=Color.White.copy(alpha=0.97f) 硬编码 |
| SelectionActionChip | L1519-L1569（需确认） | 弹窗操作按钮 |

### 当前问题

1. **容器色硬编码**: 两个弹窗都用 `Color.White.copy(alpha=0.97f)`，未使用 `colors.raisedSurface` token
2. **无边框**: 弹窗没有 `border` 参数，与玻璃容器的 `glassStroke` 边框语言不统一
3. **无阴影控制**: 未设置 `tonalElevation` 或自定义 shadow
4. **输入框样式**: 新建大相册弹窗的 `OutlinedTextField` 使用默认 Material3 样式，focused/unfocused border 颜色未定制
5. **按钮已用 token**: SelectionActionChip 已使用 `colors.destructive` / `colors.primaryContainer` 等 token，但确认/取消按钮组的整体视觉与玻璃容器风格有差距

### 现有 token 可用

- `colors.raisedSurface` — 已定义，可用于弹窗容器色
- `colors.glassStroke` — 已定义，可用于弹窗边框
- `colors.glassSurfaceBase` — 已定义
