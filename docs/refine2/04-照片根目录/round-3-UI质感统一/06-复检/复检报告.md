## 二、发现并修复的 Bug

### BUG-1: 弹窗圆角值偏差（P1）

**问题**: 两个 AlertDialog 使用 `RoundedCornerShape(28.dp)`，需求要求 24dp。

**根因**: 28dp 为原始代码值，实施时未按需求文档修正。

**修复**: 两处 `RoundedCornerShape(28.dp)` → `RoundedCornerShape(24.dp)`（L325, L467）。

**验证**: `gradlew.bat assembleDebug` → BUILD SUCCESSFUL。

---

### BUG-2: 未使用的 CircleShape import（P2）

**问题**: `import androidx.compose.foundation.shape.CircleShape` 不再使用（PhotoCircleToolButton 已改为 RoundedCornerShape）。

**根因**: 形状变更后 import 未同步清理。

**修复**: 删除该 import。

**验证**: 编译通过。
