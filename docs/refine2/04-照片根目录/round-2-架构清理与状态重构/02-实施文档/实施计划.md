## FR-6: 状态管理重构

**目标**：将 17 个独立 mutableStateOf 按职责分组为 data class，减少变量数量。

### 变更文件清单

| 文件路径 | 端 | 变更类型 | 变更内容 |
|---------|-----|---------|---------|
| PhotoFeedInteractionModels.kt | Android | 新增 | 新增 `PhotosRootDialogState` data class |
| PhotosRootScreen.kt | Android | 修改 | 用 `remember { mutableStateOf(PhotosRootDialogState()) }` 替代 7 个独立状态 |

### 新增 data class 定义

```kotlin
// PhotoFeedInteractionModels.kt 新增
data class PhotosRootDialogState(
    val showDeleteConfirm: Boolean = false,
    val showAddToPostDialog: Boolean = false,
    val showCreateAlbumDialog: Boolean = false,
    val showConfirmation: Boolean = false,
    val showDestroyConfirm: Boolean = false,
    val addToPostDialogMessage: String? = null,
    val bulkDialogMessage: String? = null,
)
```

### PhotosRootScreen.kt 修改

**旧代码**（7 个独立状态）：
```kotlin
var showDeleteConfirm by remember { mutableStateOf(false) }
var showAddToPostDialog by remember { mutableStateOf(false) }
var showCreateAlbumDialog by remember { mutableStateOf(false) }
var showConfirmation by remember { mutableStateOf(false) }
var showDestroyConfirm by remember { mutableStateOf(false) }
var addToPostDialogMessage: String? by remember { mutableStateOf(null) }
var bulkDialogMessage: String? by remember { mutableStateOf(null) }
```

**新代码**（1 个 data class）：
```kotlin
var dialogState by remember { mutableStateOf(PhotosRootDialogState()) }
```

**所有引用处替换**：
- `showDeleteConfirm` → `dialogState.showDeleteConfirm`
- `showDeleteConfirm = false` → `dialogState = dialogState.copy(showDeleteConfirm = false)`
- 其他 6 个变量同理

## FR-4: FAKE/REAL 双路径清理

**目标**：FAKE 数据加载和操作仅在 FAKE 模式下执行，REAL 模式下委托给 RealPhotoFeedPage。

### 变更文件清单

| 文件路径 | 端 | 变更类型 | 变更内容 |
|---------|-----|---------|---------|
| PhotosRootScreen.kt | Android | 修改 | 新增 `isFakeMode` 判断，FAKE 数据加载加条件，删除/加帖加模式分支 |

### 函数级计划

**数据加载**（L191-L193）：
```kotlin
val isFakeMode = RepositoryProvider.currentMode == RepositoryMode.FAKE
if (isFakeMode) {
    val fakeAlbumSummaries = remember { FakeAlbumRepository.getAlbums() }
    val fakeAlbumPosts = remember { FakeAlbumRepository.getPosts() }
    val fakeFeedItems = remember { FakePhotoFeedRepository.getPhotoFeed() }
}
```

**删除确认弹窗**（L483-L555）：
- `onClick` 回调中：`if (isFakeMode) { ... 现有 Fake 逻辑 ... }` 
- REAL 模式：`photoSelectionState = photoSelectionState.without(selectedIds)` 后由 RealPhotoFeedPage 处理

**加帖对话框**（L557-L603）：
- `onPostSelected` 回调中：`if (isFakeMode) { ... 现有 Fake 逻辑 ... }`
