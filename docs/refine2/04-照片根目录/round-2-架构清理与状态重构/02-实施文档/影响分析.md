> 日期: 2026-07-09
> 基于实施计划 v1.0

## 变更文件影响链

### 1. TrashService.java（删除冗余方法）

- **变更类型**: 删除 `systemDeleteMediaAllowingEmptySmallAlbums` 方法（L208-L210）
- **直接影响**: 该方法的调用方 LifeConsoleService.java 编译失败
- **间接影响**: 无（方法实现与 systemDeleteMedia 完全相同）
- **影响说明**: 需同步修改 LifeConsoleService.java 的调用方

### 2. LifeConsoleService.java（修改调用方）

- **变更类型**: L199 替换 `systemDeleteMediaAllowingEmptySmallAlbums` → `systemDeleteMedia`
- **直接影响**: 无（两个方法行为完全相同）
- **间接影响**: 无
- **影响说明**: 零功能变化

### 3. PhotosRootScreen.kt — 删除 PhotoBellButton（FR-5 前端）

- **变更类型**: 删除 L1552-L1624 约 73 行代码
- **直接影响**: 无（该函数未被任何代码调用）
- **间接影响**: 无
- **影响说明**: 纯删除，零风险

### 4. PhotoFeedInteractionModels.kt — 新增 data class（FR-6 + FR-7）

- **变更类型**: 新增 3 个 data class
- **直接影响**: 无（纯新增，不影响现有代码）
- **间接影响**: PhotosRootScreen.kt 和 YingShiApp.kt 将引用这些 data class
- **影响说明**: 纯新增，零风险

### 5. PhotosRootScreen.kt — 状态管理重构（FR-6）

- **变更类型**: 7 个独立 mutableStateOf → 1 个 data class
- **直接影响**: 函数体内所有引用 dialogState 变量处需修改
- **间接影响**:
  - 删除确认弹窗（L483-L555）：`showDeleteConfirm` → `dialogState.showDeleteConfirm`
  - 加帖对话框（L557-L603）：`showAddToPostDialog` → `dialogState.showAddToPostDialog`
  - 新建大相册弹窗（L353-L458）：`showCreateAlbumDialog` → `dialogState.showCreateAlbumDialog`
  - 所有 `= false` / `= null` 赋值 → `dialogState.copy(...)` 模式
- **影响说明**: 纯重构，功能不变，但需仔细替换所有引用点

### 6. PhotosRootScreen.kt — 参数简化（FR-7）

- **变更类型**: 函数签名从 27 参数 → 8 参数 + 2 data class
- **直接影响**:
  - 函数体内 trash 相关参数的引用改为 `trashParams.xxx`
  - 函数体内 selection 相关参数的引用改为 `selectionParams.xxx`
- **间接影响**:
  - YingShiApp.kt 调用处需同步修改
  - 子组件（RealPhotoFeedPage 等）接收的参数不变（data class 透传）
- **影响说明**: 参数重组，功能不变

### 7. YingShiApp.kt — 调用处同步（FR-7）

- **变更类型**: PhotosRootScreen 调用处参数重组
- **直接影响**: 调用方式变化
- **间接影响**: 无
- **影响说明**: 仅参数包装方式变化

### 8. PhotosRootScreen.kt — FAKE/REAL 条件分支（FR-4）

- **变更类型**: 新增 `isFakeMode` 判断，数据加载和操作加条件分支
- **直接影响**:
  - FAKE 模式下：行为与修复前完全一致
  - REAL 模式下：不再加载 Fake 数据，删除/加帖操作由 RealPhotoFeedPage 处理
- **间接影响**:
  - RealPhotoFeedPage 的删除/加帖功能需正常工作
  - PhotosRootScreen 的 selection 状态管理需与 RealPhotoFeedPage 协调
- **影响说明**: 功能行为变化，REAL 模式下删除逻辑委托给 RealPhotoFeedPage

## 风险评估

| 风险 | 严重度 | 说明 |
|------|--------|------|
| dialogState.copy() 遗漏导致弹窗状态异常 | 中 | 需仔细替换所有 `= false`/`= null` 赋值点 |
| 参数简化后 YingShiApp.kt 漏传参数 | 中 | 需逐参数核对 |
| FAKE/REAL 分支遗漏导致 REAL 模式仍调用 Fake | 中 | 需在删除和加帖两个回调中都检查 |
| systemDeleteMediaAllowingEmptySmallAlbums 有其他调用方 | 低 | 已搜索确认仅有 LifeConsoleService 调用 |
