# Round 1 影响分析

> 日期: 2026-07-09
> 基于实施计划 v1.0

---

## 变更文件影响链

### 1. Color.kt（新增颜色常量）

- **变更类型**: 新增 12 个颜色常量
- **直接影响**: 无（仅新增常量定义，不影响现有代码）
- **间接影响**: Tokens.kt 中新增的 YingShiColors token 引用这些常量
- **影响说明**: 纯新增，零风险

### 2. Tokens.kt（YingShiColors 新增 12 个 token）

- **变更类型**: YingShiColors data class 新增字段
- **直接影响**: 所有使用 `YingShiThemeTokens.colors` 的位置自动获得新 token（无破坏性变更）
- **间接影响**: 无（data class 新增字段是向后兼容的）
- **影响说明**: 纯新增，零风险

### 3. PhotosRootScreen.kt — PhotoSelectedTitleAura（坐标修正 + token 替换）

- **变更类型**: 修改 Canvas 绘制坐标 + 颜色引用
- **直接影响**:
  - 光晕视觉效果变化（居中后更对称）
  - 颜色值不变（token 值与硬编码值相同）
- **间接影响**:
  - 父组件 PhotoBrandTabs 的 tab 选中态视觉效果
  - 三个 tab（照片/相册/回收站）的选中态外观
- **影响说明**: 视觉变化，功能不受影响

### 4. PhotosRootScreen.kt — PhotoBrandTabs（文字 offset 对称化 + token 替换 + 动效）

- **变更类型**: 修改文字 offset + 颜色引用 + 新增 AnimatedVisibility
- **直接影响**:
  - 选中态文字层视觉效果变化（offset 对称后重心居中）
  - 切换 tab 时出现过渡动画
  - 颜色值不变
- **间接影响**:
  - PhotoTopBar（父组件）的 tab 区域
  - 用户点击 tab 的交互体验（新增动画延迟 300ms）
- **影响说明**: 视觉变化 + 交互变化，功能不受影响

### 5. PhotosRootScreen.kt — PhotoTopGlassSurface（token 替换）

- **变更类型**: 替换 `Color.White.copy(alpha=0.62f)` 为 `colors.glassSurfaceBase`
- **直接影响**: 无（值相同）
- **间接影响**:
  - 选择态顶栏的玻璃容器外观
  - 工具按钮组（系统+传输）的玻璃容器外观
- **影响说明**: 零视觉变化，纯引用替换

### 6. PhotosRootScreen.kt — PhotoSelectionBottomBarAction（error* 替换）

- **变更类型**: 替换 `MaterialTheme.colorScheme.error*` 为 `colors.destructive*`
- **直接影响**: 底栏"删除"按钮颜色
- **间接影响**:
  - PhotoSelectionBottomBar（父组件）的删除按钮
  - 多选态底栏的视觉一致性
- **影响说明**: 颜色值可能略有不同（取决于 MaterialTheme 是否有自定义 error 色），需验证

### 7. PhotosRootScreen.kt — PhotoCircleToolButton（error* 替换）

- **变更类型**: 替换 7 处 `MaterialTheme.colorScheme.error*` 为 `colors.destructive*`
- **直接影响**: 传输失败态按钮的红色系
- **间接影响**:
  - 传输按钮在失败态下的 badge、图标、边框颜色
  - 用户对传输失败状态的视觉识别
- **影响说明**: 颜色值可能略有不同，需验证

### 8. PhotosRootScreen.kt — SelectionActionChip（error* 替换）

- **变更类型**: 替换 3 处 `MaterialTheme.colorScheme.error*` 为 `colors.destructive*`
- **直接影响**: 删除确认弹窗和新建大相册弹窗中 destructive 按钮的颜色
- **间接影响**:
  - 删除确认 AlertDialog 的"删除到回收站"按钮
  - 新建大相册 AlertDialog 的"取消"按钮（非 destructive，不受影响）
- **影响说明**: 颜色值可能略有不同，需验证

### 9. PhotosRootScreen.kt — PhotoPillToolButton（token 替换）

- **变更类型**: 替换 `Color.White.copy(alpha=0.42f)` 为 token 引用
- **直接影响**: 无（值相同）
- **间接影响**: 无
- **影响说明**: 零变化

## 风险评估

| 风险 | 严重度 | 说明 |
|------|--------|------|
| destructive token 色值与 MaterialTheme error 色不一致 | 低 | 需确认 Color.kt 中定义的 destructive 色值是否与 MaterialTheme 默认 error 色匹配 |
| 光晕居中后视觉效果不如预期 | 低 | 可能需要在真机上微调光斑位置 |
| 动画在低端设备上卡顿 | 低 | 受 rememberYingShiMotionEnabled 控制 |
| 动画 duration 导致快速切换时状态错乱 | 低 | Compose 的 AnimatedVisibility 原生支持中断处理 |
