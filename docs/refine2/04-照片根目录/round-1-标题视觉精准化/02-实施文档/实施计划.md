## FR-3: 标题切换动效增强

**目标**：选中态光晕呼吸动画（与 Aurora 同步）+ 切换 fade-in/out 过渡。

### 变更文件清单

| 文件路径 | 端 | 变更类型 | 变更内容 |
|---------|-----|---------|---------|
| PhotosRootScreen.kt | Android | 修改 | PhotoSelectedTitleAura 呼吸动画、PhotoBrandTabs 切换过渡 |

### 函数级计划

#### PhotoSelectedTitleAura — 呼吸动画

**新增**：
1. `rememberInfiniteTransition` 创建 `auraBreathPhase`（4000ms 周期，LinearEasing，RepeatMode.Restart）
2. 用 `sin(auraBreathPhase)` 计算 `breathAlpha`（范围 0.85-1.0）
3. 所有光晕元素的 alpha 乘以 `breathAlpha`
4. `rememberYingShiMotionEnabled()` 为 false 时 breathAlpha 恒为 1.0

```kotlin
// 伪代码
val motionEnabled = rememberYingShiMotionEnabled()
val infiniteTransition = rememberInfiniteTransition(label = "titleAura")
val breathPhase by infiniteTransition.animateFloat(
    initialValue = 0f,
    targetValue = (2 * PI).toFloat(),
    animationSpec = infiniteRepeatable(
        animation = tween(durationMillis = 4000, easing = LinearEasing),
        repeatMode = RepeatMode.Restart,
    ),
    label = "titleAuraBreath",
)
val breathAlpha = if (motionEnabled) {
    (0.85f + 0.15f * (sin(breathPhase) + 1f) / 2f).coerceIn(0.85f, 1f)
} else {
    1f
}
// 所有颜色的 alpha 乘以 breathAlpha
```

#### PhotoBrandTabs — 切换过渡

**新增**：
1. 用 `AnimatedVisibility` 包裹选中态内部的 Box
2. enter: `scaleIn(initialScale=0.9f) + fadeIn()` (300ms tween, easing=FastOutSlowInEasing)
3. exit: `scaleOut(targetScale=0.92f) + fadeOut()` (200ms tween)
4. `rememberYingShiMotionEnabled()` 为 false 时 duration=0
5. 用 `key(selectedSection)` 确保切换 tab 时重新触发动画

```kotlin
// 伪代码
val motionEnabled = rememberYingShiMotionEnabled()
val animDuration = if (motionEnabled) 300 else 0
val exitDuration = if (motionEnabled) 200 else 0

AnimatedVisibility(
    visible = selected,
    enter = scaleIn(
        initialScale = 0.9f,
        animationSpec = tween(durationMillis = animDuration, easing = FastOutSlowInEasing),
    ) + fadeIn(animationSpec = tween(durationMillis = animDuration)),
    exit = scaleOut(
        targetScale = 0.92f,
        animationSpec = tween(durationMillis = exitDuration),
    ) + fadeOut(animationSpec = tween(durationMillis = exitDuration)),
) {
    // 选中态内容
}
```

**边界条件**：
- 首次渲染时（初始选中 tab）不触发 enter 动画（使用 `MutableTransitionState(initialState = true)`）
- 快速切换时正确中断前一个动画（Compose 自动处理）
