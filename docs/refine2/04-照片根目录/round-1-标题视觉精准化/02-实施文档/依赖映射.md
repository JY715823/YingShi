## 本模块依赖的外部模块/服务

| 依赖模块 | 本轮改动接口 | 说明 |
|---------|-------------|------|
| YingShiThemeTokens (Tokens.kt) | **是** — 新增 12 个 token | YingShiColors data class 新增字段，向后兼容 |
| YingShiColors 常量 (Color.kt) | **是** — 新增 12 个常量 | 纯新增，无破坏性变更 |
| YingShiAuroraBackdrop | 否 | 仅参考其 sparkleBreath 动画周期（4000ms），不修改 |
| rememberYingShiMotionEnabled | 否 | 读取动效开关，不修改 |
| MaterialTheme.colorScheme | **是** — 不再直接使用 error* 系列 | 替换为 YingShiColors token，MaterialTheme 本身不改 |
