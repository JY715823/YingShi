## 一、FR-1 标题光晕居中对齐修复 — 代码定位

### 1.1 光晕 Canvas (PhotoSelectedTitleAura — L1042-L1114)

当前光晕的 6 个绘制元素使用**绝对坐标**定位，且主圆中心偏左上：

| 元素 | 当前 center | 当前半径 | 颜色 |
|------|------------|---------|------|
| 主圆 (径向渐变) | (0.44w, 0.42h) | 0.78*minDim | White→cool→透明 |
| 暖光斑 | (0.68w, 0.26h) | 0.48*minDim | WarmGold |
| 冷光斑 | (0.22w, 0.34h) | 0.40*minDim | CoolBlue |
| 高光点1 | (0.18w, 0.20h) | 0.038*minDim | White |
| 高光点2 | (0.80w, 0.18h) | 0.028*minDim | WarmSparkle |
| 高光点3 | (0.74w, 0.62h) | 0.024*minDim | CoolSparkle |
| 底部光轨 | (0.06w, 0.74h) | 0.80w×0.10h | 水平渐变 |

**问题**：主圆中心 (0.44, 0.42) 偏离几何中心 (0.5, 0.5)，导致光晕整体偏左上。光斑分布不对称（暖光斑 (0.68, 0.26) 偏右上，冷光斑 (0.22, 0.34) 偏左下但不对称）。

### 1.2 文字层 (PhotoBrandTabs — L932-L1013)

4 层文字 offset 不对称分布：
- Text#1: `offset(y = 3.dp)` — 向下偏移（拖尾层）
- Text#2: `offset(x = -1.dp, y = -1.dp)` — 左上
- Text#3: `offset(x = 1.dp, y = -1.dp)` — 右上
- Text#4: 无偏移 — 主文字层

**问题**：向下偏移 3dp 的 Text#1 是最大的不对称来源，导致视觉重心偏下。Text#2/#3 左右对称但 Text#4 无偏移，缺少"下方"方向的文字散射。

### 1.3 坐标参考系

光晕 Canvas 在 `Box(modifier = Modifier.fillMaxSize().clipToBounds().offset(y = (-1).dp))` 内，文字层在 `Box(modifier = Modifier.padding(start = 1.dp, end = 3.dp))` 内。两者都使用 `fillMaxSize()` 作为 size 基准，但 padding 不同导致文字实际可用宽度略小于光晕 Canvas。

**修复方案**：光晕 Canvas 不依赖外层 Box 的 padding，而是与文字层共享同一 padding Box。将 Canvas 移入 `padding(start = 1.dp, end = 3.dp)` 的 Box 内。

## 三、FR-3 标题切换动效增强 — 代码定位

### 3.1 当前动画状态

- PhotoBrandTabs 中选中/未选中切换**无过渡动画**——选中态光晕和文字是即时切换
- PhotoTopBar 中正常态↔选择态已有 `AnimatedVisibility` + `slideInVertically`/`fadeIn`（250ms）
- YingShiAuroraBackdrop 已有 `sparkleBreath` 呼吸动画（4000ms 周期，`breathPhase` 变量）

### 3.2 呼吸动画集成点

AuroraBackdrop 的 `breathPhase` 在 BoxScope 内可用，但 PhotoSelectedTitleAura 在 PhotosRootScreen 的 Column 内，不在 AuroraBackdrop 的 Canvas 内部。需要使用 `rememberInfiniteTransition` 或从 AuroraBackdrop 提取呼吸相位。

**方案**：在 PhotoSelectedTitleAura 中独立创建 `rememberInfiniteTransition`，使用相同的 4000ms 周期 + `LinearEasing` + `RepeatMode.Restart`，确保与 AuroraBackdrop 的 sparkleBreath 节奏一致。

### 3.3 fade-in/out 动画集成点

当前 PhotoBrandTabs 中选中态切换是直接 `if (selected) { ... } else { ... }`。需要改为：
- 用 `AnimatedVisibility` 包裹选中态光晕，实现 fadeIn(scale 0.9→1.0 + alpha 0→1, 300ms) + fadeOut(scale 1.0→0.92 + alpha 1→0, 200ms)
- `rememberYingShiMotionEnabled()` 返回 false 时降级为即时切换
