## 发现的 Bug 与修复

### BUG-1: 未使用的 import（3 个）
**问题**: `animateFloatAsState`、`widthIn`、`Path` 三个 import 未使用
**根因**: 实施过程中尝试了 `animateFloatAsState` 方案但最终未使用；`widthIn` 和 `Path` 是历史遗留
**修复**: 删除三个未使用的 import
**验证**: 编译通过，无 lint 警告

### BUG-2: 光晕高光点未使用 glassSurfaceBase token
**问题**: L1190 处 `Color.White.copy(alpha = 0.62f * breathMultiplier)` 应替换为 `colors.glassSurfaceBase.copy(alpha = breathMultiplier)`
**根因**: 实施时遗漏了该处的 token 替换
**修复**: 替换为 `colors.glassSurfaceBase.copy(alpha = breathMultiplier)`
**验证**: 值等价（glassSurfaceBase = Color.White.copy(alpha=0.62f)），语义一致

### BUG-3: 缺少 key(destination) 确保动画重置
**问题**: PhotoBrandTabs 的 forEachIndexed 中缺少 `key(destination)` 包裹
**根因**: 实施时未处理 Compose 重组优化
**修复**: 在 forEachIndexed 内添加 `key(destination) { ... }`
**验证**: 编译通过，确保切换 tab 时动画正确重置

### BUG-4: 首次渲染时播放 enter 动画
**问题**: 初始选中的 tab 在首次渲染时播放了 enter 动画
**根因**: 使用 `visible = selected` 时，首次组合的 `selected=true` 会触发 enter 动画
**修复**: 改用 `MutableTransitionState(initialState = selected)` + `visibleState = transitionState`
**验证**: 编译通过，首次渲染不播放 enter 动画
