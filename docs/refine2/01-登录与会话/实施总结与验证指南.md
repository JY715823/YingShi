## 如何验证

### 快速验证（5 分钟核心验证步骤）

1. `gradlew.bat installDebug` 安装到真机
2. 观察登录页：品牌标题在卡片上方，有金色装饰线；卡片有磨砂玻璃质感；背景有极光效果
3. 点击账号 A/B pill 卡片：选中态有浅蓝底 + 金色指示线，颜色平滑过渡
4. 点击输入框：边框变蓝 + 图标变金色 + 外发光
5. 点击登录按钮：有丝绸光泽扫过动画
6. 输入错误密码 5 次：显示中文锁定提示"账号已临时锁定，请 15 分钟后再试"，按钮禁用
7. 等待或切换账号：锁定自动解除

### 完整验证（每个 FR 的验证方法）

| FR | 验证方法 | 预期 |
|-----|---------|------|
| FR-1 | 观察登录页卡片 | 半透明白色卡片，圆角 28dp，有玻璃边框和阴影，内部有极轻光泽渐变 |
| FR-2 | 对比背景色调 | 底部有暖粉色（memoryWash），整体不偏冷 |
| FR-3 | 切换密码↔验证码、触发消息 | 有淡入淡出过渡，无布局抖动 |
| FR-4 | 观察品牌区域 | "映世"上方有金色细线，下方有"我们的共同空间"金色小字，再下方有淡蓝细线 |
| FR-5 | 连续输错密码 5 次 | 显示中文锁定提示，按钮禁用，15 分钟后自动恢复 |
| FR-6 | 观察底部连接设置 | 灰色小字 + 齿轮图标，不抢眼 |
| FR-7 | 观察背景闪烁点 | 有微弱呼吸明暗变化，周期约 4 秒 |
