## 一、FR-1 表单容器卡片 — 代码定位

### 当前结构
- **LoginScreen.kt L468-662**: 主 Composable 布局
  - L468-471: `YingShiAuroraBackdrop(variant=AUTH)` 包裹全局
  - L472-479: 外层 `Column`（`statusBarsPadding` + `navigationBarsPadding` + `verticalScroll` + `padding(28dp, 24dp)`）
  - L480: `Spacer(weight=0.72f)` 顶部弹性间距
  - **L482-654**: 表单区域 `Column`（`fillMaxWidth` + `widthIn(max=560dp)` + `spacedBy(18dp)`）
    - L488: `BrandHeader()`
    - L490-497: `PresetAccountRow`
    - L499-553: `YingShiTextField`（账号/密码/验证码）
    - L555-558: `AuthMessageBlock`
    - L560-618: `YingShiPrimaryMistButton`
    - L620-653: `LoginInlineActions`（仅验证码阶段显示）
  - L656: `Spacer(weight=1f)` 底部弹性间距
  - L658-660: `ConnectionEntryLink`

### 关键发现
- 表单区域（L482-654）目前是**裸 Column**，没有任何外层包裹容器
- 输入框 `YingShiTextField` 本身已有 `Surface` 包裹（`raisedSurface(alpha=0.82f)` + `dividerSoft` 边框），但整体缺乏统一的视觉承托层
- 现有 `YingShiMistCard`（Surfaces.kt L349-366）可参考但不够用：只有 `shadowElevation=2dp` + `dividerSoft` 边框，缺少 glassStroke 细边框和多层阴影

### 实施要点
- 在 L482-654 的 Column 外层包裹一个 `Surface` / `Box`
- 卡片样式：`raisedSurface(alpha=0.88f)` + `glassStroke(alpha=0.5f)` 边框 + `RoundedCornerShape(radius.xl=28dp)` + 多层阴影
- 内层叠加 `glowWash` 水平渐变做极轻光泽
- 不修改 `YingShiTextField` 组件本身，仅做外层包裹
- 卡片需设置 `widthIn(max=560dp)` 以保持宽屏适配
- 需要 padding 内边距（建议 24dp）

## 二、FR-4 品牌区域丰富 — 代码定位

### 当前 `BrandHeader()` (L706-718)
```kotlin
@Composable
private fun BrandHeader() {
    val colors = YingShiThemeTokens.colors
    Column(verticalArrangement = Arrangement.spacedBy(2.dp)) {
        Text(
            text = APP_NAME,  // "映世"
            style = MaterialTheme.typography.displayMedium.copy(fontWeight = FontWeight.SemiBold),
            color = colors.titleAccent,
        )
    }
}
```

### 关键发现
- 仅显示"映世"一个 `Text`，无副标题
- 使用 `displayMedium` 字号，`titleAccent` 颜色
- 当前 `Column` 只有 2dp 间距但只有一个子元素
- 设计计划提到：品牌标题+副标题（"我们的共同空间"），形成字重对比

### 实施要点
- 在"映世"下方添加副标题 `Text`
- 副标题文案：`"我们的共同空间"`
- 副标题样式：`bodyLarge` 或 `titleSmall`，颜色 `textSecondary` 或 `goldAccent`
- 主标题与副标题间距：4-8dp
- 颜色使用 `YingShiThemeTokens`，无硬编码

## 三、FR-6 连接设置入口视觉弱化 — 代码定位

### 当前 `ConnectionEntryLink()` (L826-851)
```kotlin
@Composable
private fun ConnectionEntryLink(onClick: () -> Unit) {
    val colors = YingShiThemeTokens.colors
    Row(
        modifier = Modifier.fillMaxWidth()
            .yingShiClickable(shape = CircleShape, onClick = onClick)
            .padding(vertical = 8.dp),
        horizontalArrangement = Arrangement.spacedBy(10.dp),
        verticalAlignment = Alignment.CenterVertically,
    ) {
        Icon(
            imageVector = Icons.Rounded.Settings,
            contentDescription = null,
            tint = colors.titleAccent.copy(alpha = 0.88f),  // ← 需要改
            modifier = Modifier.size(18.dp),
        )
        Text(
            text = "连接设置",
            style = MaterialTheme.typography.labelLarge.copy(fontWeight = FontWeight.SemiBold),  // ← 需要改
            color = colors.titleAccent,  // ← 需要改
        )
    }
}
```

### 关键发现
- Icon 颜色：`titleAccent(alpha=0.88f)` — 很抢眼
- Text 颜色：`titleAccent` — 全文最深的强调色
- Text 字号：`labelLarge` + `SemiBold` — 视觉权重过高
- 连接设置是低频操作入口，当前太抢眼

### 实施要点
- Icon tint 改为 `textSecondary(alpha=0.72f)`
- Text color 改为 `textSecondary`
- Text style 改为 `labelMedium`（去掉 `SemiBold`）
- 保持 `yingShiClickable` 功能不变

## 四、共享 Token 与工具

### 可用颜色 Token（Color.kt）
| Token | 值 | 用途 |
|-------|-----|------|
| `raisedSurface` | `#FFFFFFFC` | 珍珠白卡片底色 |
| `glassStroke` | `#FFA9E5F2` | 轻玻璃边线 |
| `glowWash` | `#FFE7FAFF` | 轻流光洗色 |
| `memoryWash` | `#FFFFF1EE` | 温暖记忆洗色 |
| `titleAccent` | `#FF26313A` | 深板岩标题色 |
| `textSecondary` | `#FF556B75` | 次级文本 |
| `goldAccent` | `#FF9A6A2A` | 暖金强调色 |
| `appBackground` | `#FFF1FBFD` | 珍珠浅蓝背景 |

### 可用间距/圆角 Token（Tokens.kt）
| Token | 值 |
|-------|-----|
| `radius.xl` | 28dp |
| `radius.lg` | 24dp |
| `radius.md` | 18dp |
| `spacing.xl` | 24dp |
| `spacing.lg` | 20dp |
| `spacing.md` | 16dp |

### 可用动画工具（YingShiMotion.kt）
- `rememberYingShiMotionEnabled()`: 检查是否启用动画
- `Modifier.yingShiSoftReveal(visible, motionEnabled)`: 淡入+缩放+位移
- `Modifier.yingShiRouteReveal(visible, motionEnabled)`: 路由切换动画

### 设计约束
- 所有颜色必须使用 `YingShiThemeTokens.colors.*`，不硬编码
- 颜色系统不可大改（不更换主色调、不重新定义核心 Hex）
- 登录页设计方向：珍珠浅蓝背景 + 珍珠白表单容器 + 浅蓝按钮 + 石墨字
