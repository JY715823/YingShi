## 四、Trae 自检发现的 Bug 及修复确认

Round 3 自检质量高，发现并修复了 3 个 Bug，QoderWork 审查确认修复有效：

### BUG-1 (P0): isAccountLocked 死锁 → 已修复
**问题**: 原 Boolean 方案一旦锁定无法自动恢复，按钮永久禁用。
**修复**: 改为时间驱动方案（lockedUntilMillis + lockedMessage + 派生 isAccountLocked），15 分钟到期自动恢复。
**QoderWork 确认**: 修复方案正确，LaunchedEffect 持续更新 nowMillis 并在到期时清除 lockedMessage。AC-4 满足。

### BUG-2 (P1): 账号切换不清除锁定 → 已修复
**问题**: 账号 A 锁定后切换账号 B，B 也被禁用。
**修复**: PresetAccountRow onSelect + account onValueChange 均重置 lockedUntilMillis=0L。
**QoderWork 确认**: 修复正确，服务端按账号名跟踪锁定，切换账号后锁定不适用。

### BUG-3 (P1): errorMessage 清除导致锁定提示消失 → 已修复
**问题**: 锁定提示放入 errorMessage 会被其他操作意外清除。
**修复**: 独立 lockedMessage 字段，优先级高于 errorMessage，不受 16 处 errorMessage 清除点影响。
**QoderWork 确认**: 修复正确，currentMessage 优先级链 `lockedMessage ?: errorMessage ?: statusMessage ?: sessionMessage` 设计合理。
