## 本模块依赖的外部模块/服务

| 依赖模块 | 依赖内容 | 本轮是否改动接口 | 说明 |
|---------|---------|----------------|------|
| `ui/components/YingShiAuroraBackdrop` | 极光背景组件 | 否 | 仅作为外层背景使用，不修改 |
| `ui/components/YingShiTextField` | 输入框组件 | 否 | 表单卡片仅做外层包裹，不修改组件 |
| `ui/components/YingShiPrimaryMistButton` | 主按钮组件 | 否 | 不修改 |
| `ui/theme/Tokens.kt` | YingShiThemeTokens 颜色/间距/圆角 | 否 | 仅引用，不修改 token 定义 |
| `ui/theme/Color.kt` | 颜色定义 | 否 | 仅引用，不修改 |
| `data/remote/auth/AuthSessionManager` | 会话管理 | 否 | 不修改 |
| `data/remote/config/BackendDebugConfig` | 后端配置 | 否 | 不修改 |
| `data/remote/connectivity/NetworkConnectivityMonitor` | 网络状态 | 否 | 不修改 |

| 调用方 | 调用内容 | 本轮是否影响接口 | 说明 |

## 回归测试范围

### 必须回归的模块
| 模块 | 回归范围 | 原因 |
|------|---------|------|
| 登录与会话 | 完整登录流程 | 直接修改 LoginScreen |
| 外壳与基础设备 (AppShell) | LoginScreen 路由 | sessionVersion 驱动登录页显示 |

### 不需要回归的模块
| 模块 | 原因 |
|------|------|
| 照片流 / 大相册 / 小相册 / 照片查看器 | 不涉及 |
| 系统媒体 / 回收站 / 通知中心 | 不涉及 |
| 评论系统 / 生活首页 / 今日足迹 / 足迹组件推送 | 不涉及 |
| 设置 / 个人主页 / 聊天展示 / 账本 / 提交传输中心 | 不涉及 |

### Android 编译范围
- 仅需 `assembleDebug` 编译通过
- 无新增依赖、无 Gradle 变更
