> 日期: 2026-07-08

## 变更文件影响链

### 文件: `LoginScreen.kt`

| 变更函数 | 直接影响 | 间接影响 | 影响说明 |
|---------|---------|---------|---------|
| `BrandHeader()` | 登录页品牌区域布局 | 无 | 仅新增一个 Text，不影响调用方（仅 LoginScreen 内部使用） |
| `LoginScreen()` (表单卡片包裹) | 登录页表单区域布局 | 表单区域宽度约束位置变化 | `widthIn(max=560dp)` 从 Column 移到 Surface，逻辑等价 |
| `ConnectionEntryLink()` | 连接设置入口视觉 | 无 | 仅颜色和字号变化，不影响调用方 |

### 影响链详细分析

#### 后端影响链
**无**。本轮不涉及任何 Server 端代码变更。

#### 前端影响链

**BrandHeader() → LoginScreen() → YingShiApp.kt**
- `BrandHeader()` 是 `private` 函数，仅在 `LoginScreen()` 中调用
- 新增副标题不影响 `LoginScreen()` 的状态管理或布局逻辑
- `LoginScreen()` 的签名不变（`sessionMessage`, `onLoginSuccess`, `modifier`）
- `YingShiApp.kt` 中调用 `LoginScreen()` 的方式不变

**LoginScreen() 表单卡片 → 子组件**
- 表单卡片仅作为外层包裹，不影响子组件内部实现
- `YingShiTextField` 组件本身不受影响（已有自己的 Surface 包装）
- `YingShiPrimaryMistButton` 不受影响
- `AuthMessageBlock` 不受影响（已在卡片内）
- `LoginInlineActions` 不受影响（已在卡片内）

**ConnectionEntryLink() → LoginScreen()**
- 仅颜色和字号变化，不影响交互行为
- `yingShiClickable` 保持不变
- `showConnectionSheet` 状态管理不变

## 颜色 Token 使用合规性

| 变更位置 | 使用的 Token | 硬编码 | 合规 |
|---------|-------------|--------|------|
| BrandHeader 副标题 | `colors.goldAccent.copy(alpha = 0.78f)` | 否 | 是 |
| 表单卡片底色 | `colors.raisedSurface.copy(alpha = 0.88f)` | 否 | 是 |

| 表单卡片光泽层 | `colors.glowWash.copy(alpha = 0.10f)` | 否 | 是 |

| 连接设置文字 | `colors.textSecondary` | 否 | 是 |

## 回归风险

| 风险项 | 风险等级 | 缓解措施 |
|--------|---------|---------|
| 卡片包裹改变布局高度，导致 Spacer 权重分配异常 | 低 | 卡片内边距替代了部分垂直间距，但 Spacer weight 是基于剩余空间分配，不影响 |
| 颜色 token 使用不当导致深色主题异常 | 低 | 当前无深色主题支持，所有 token 均为浅色主题定义 |
| 新增 import 遗漏 | 低 | 编译验证时自动发现 |
