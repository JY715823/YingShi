## FR-4: 品牌区域丰富

**目标**: 在"映世"标题下方增加副标题"我们的共同空间"，形成字重和字号对比。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `app/.../feature/auth/LoginScreen.kt` | Android | 修改 | `BrandHeader()` 函数增加副标题 Text |

### 函数级计划

**文件**: `LoginScreen.kt`, 函数 `BrandHeader()` (L706-718)

**当前代码**:
```kotlin
@Composable
private fun BrandHeader() {
    val colors = YingShiThemeTokens.colors
    Column(verticalArrangement = Arrangement.spacedBy(2.dp)) {
        Text(
            text = APP_NAME,  // "映世"
            style = MaterialTheme.typography.displayMedium.copy(fontWeight = FontWeight.SemiBold),
            color = colors.titleAccent,
        )
    }
}
```

**修改后逻辑**:
```kotlin
@Composable
private fun BrandHeader() {
    val colors = YingShiThemeTokens.colors
    Column(
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.spacedBy(6.dp),
    ) {
        Text(
            text = APP_NAME,
            style = MaterialTheme.typography.displayMedium.copy(fontWeight = FontWeight.SemiBold),
            color = colors.titleAccent,
        )
        Text(
            text = "我们的共同空间",
            style = MaterialTheme.typography.titleSmall,
            color = colors.goldAccent.copy(alpha = 0.78f),
        )
    }
}
```

**关键决策**:
- 副标题颜色：使用 `goldAccent(alpha=0.78f)` 而非 `textSecondary`，因为金色与珍珠玉蓝形成温暖对比，契合"安静但有华彩、克制但有温度"的设计方向
- 副标题字号：`titleSmall`，比 `bodyLarge` 更有设计感，与标题形成对比但不喧宾夺主
- 间距：6dp（spacedBy），在 4-8dp 范围内选择中间值
- 居中对齐：`Alignment.CenterHorizontally`，与标题对齐

### 边界条件
- 副标题文案固定，不涉及国际化
- 不影响 PresetAccountRow 的间距（表单 Column 使用 spacedBy(18dp)）

## FR-1: 表单容器卡片

**目标**: 在表单区域（BrandHeader + PresetAccountRow + 输入框 + 按钮 + AuthMessageBlock + LoginInlineActions）外层包裹半透明卡片容器。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `app/.../feature/auth/LoginScreen.kt` | Android | 修改 | 表单 Column (L482-654) 外层包裹 Surface 卡片 |

### 组件级计划

**文件**: `LoginScreen.kt`, `LoginScreen()` 主 Composable (L468-662)

**当前结构** (L480-660):
```
Spacer(weight=0.72f)
Column(widthIn(max=560dp), spacedBy(18dp)) {
    BrandHeader()
    PresetAccountRow(...)
    YingShiTextField(...)  // 账号
    YingShiTextField(...)  // 密码/验证码
    AuthMessageBlock(...)
    YingShiPrimaryMistButton(...)
    if (challengeState) LoginInlineActions(...)
}
Spacer(weight=1f)
ConnectionEntryLink(...)
```

**修改后结构**:
```
Spacer(weight=0.72f)
Surface(
    modifier = Modifier.fillMaxWidth().widthIn(max=560dp),
    shape = RoundedCornerShape(radius.xl = 28dp),
    color = colors.raisedSurface.copy(alpha = 0.88f),
    border = BorderStroke(1.dp, colors.glassStroke.copy(alpha = 0.50f)),
    shadowElevation = 6.dp,
) {
    Box(modifier = Modifier.background(glowWash 水平渐变)) {
        Column(
            modifier = Modifier.padding(24.dp),
            verticalArrangement = Arrangement.spacedBy(18.dp),
        ) {
            BrandHeader()
            PresetAccountRow(...)
            YingShiTextField(...)
            YingShiTextField(...)
            AuthMessageBlock(...)
            YingShiPrimaryMistButton(...)
            if (challengeState) LoginInlineActions(...)
        }
    }
}
Spacer(weight=1f)
ConnectionEntryLink(...)
```

**关键决策**:
- 卡片底色：`raisedSurface(alpha=0.88f)`，介于 0.85-0.92 之间，符合 AC-2
- 边框：`glassStroke(alpha=0.50f)`，细玻璃边线，符合 AC-2
- 圆角：`radius.xl = 28dp`，大圆角 >= 24dp，符合 AC-2
- 阴影：`shadowElevation = 6.dp`，比默认卡片(2dp)更明显，多层阴影由 Material 3 自动处理
- 内边距：24dp，保持内容与卡片边缘呼吸感
- 光泽层：`Box` 内叠加 `glowWash` 水平渐变，极轻光泽
- `widthIn(max=560dp)` 从 Column 移到 Surface，保持一致
- 所有颜色使用 `YingShiThemeTokens.colors.*`

### 额外 import 需要
- `androidx.compose.foundation.BorderStroke`
- `androidx.compose.foundation.shape.RoundedCornerShape`
- `androidx.compose.material3.Surface`
- `androidx.compose.ui.draw.clip`（已有）

### 边界条件
- 卡片内 `Column` 的 `spacedBy(18.dp)` 不变
- 不修改 `BrandHeader`、`YingShiTextField`、`YingShiPrimaryMistButton` 等子组件
- 卡片在宽屏上仍受 `widthIn(max=560dp)` 限制

## FR-6: 连接设置入口视觉弱化

**目标**: 降低连接设置入口的视觉权重，从 titleAccent 改为 textSecondary，字号缩小。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `app/.../feature/auth/LoginScreen.kt` | Android | 修改 | `ConnectionEntryLink()` 函数颜色和字号 |

### 函数级计划

**文件**: `LoginScreen.kt`, 函数 `ConnectionEntryLink()` (L826-851)

**当前代码**:
```kotlin
Icon(
    tint = colors.titleAccent.copy(alpha = 0.88f),
    modifier = Modifier.size(18.dp),
```


**关键决策**:
- Icon 颜色：`textSecondary(alpha=0.72f)`，与 ChevrRight 图标一致（Surfaces.kt L652）

- Text 字号：`labelMedium`，去掉 `SemiBold`
- 功能不变：`yingShiClickable` 保持
