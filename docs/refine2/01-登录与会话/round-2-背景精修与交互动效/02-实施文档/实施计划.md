## FR-7: 极光背景微动画

**目标**: 为 AUTH variant 的 24 个闪烁点添加 alpha 呼吸动画，周期 4 秒，alpha 在 0.3-0.8 之间缓变。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `app/.../ui/components/YingShiAuroraBackdrop.kt` | Android | 修改 | Canvas 外部添加 InfiniteTransition + sparkle alpha 呼吸 |

### 组件级计划

**文件**: `YingShiAuroraBackdrop.kt`, `YingShiAuroraBackdrop()` Composable (L31-315)

#### 新增动画基础设施（在 L37-40 之后，L41 Box 之前）

```kotlin
val motionEnabled = rememberYingShiMotionEnabled()
val infiniteTransition = rememberInfiniteTransition(label = "aurora")
val breathPhase by infiniteTransition.animateFloat(
    initialValue = 0f,
    targetValue = (2 * PI).toFloat(),
    animationSpec = infiniteRepeatable(
        animation = tween(durationMillis = 4000, easing = LinearEasing),
        repeatMode = RepeatMode.Restart,
    ),
    label = "sparkleBreath",
)
```

#### 修改 sparkle 循环 (L292-311)

```kotlin
repeat(24) { index ->
    val x = width * ((index * 29 + 17) % 100) / 100f
    val y = height * ((index * 13 + 23) % 100) / 100f
    val isWarm = index % 5 == 0
    // 呼吸 alpha: 基于索引相位偏移
    val phaseOffset = (index * 0.7f) % (2 * PI).toFloat()
    val breathMultiplier = if (motionEnabled) {
        (0.55f + 0.45f * sin(breathPhase + phaseOffset)).coerceIn(0.15f, 1f)
    } else {
        1f
    }
    drawCircle(
        color = if (isWarm) {
            spec.warmSparkle.copy(alpha = spec.warmSparkleAlpha * breathMultiplier)
        } else {
            spec.coolSparkle.copy(
                alpha = (if (index % 3 == 0) spec.coolSparkleAlphaStrong else spec.coolSparkleAlphaSoft) * breathMultiplier,
            )
        },
        radius = if (index % 4 == 0) 4.4f else 2.2f,
        center = Offset(x, y),
    )
}
```

**关键决策**:
- 动画周期 4000ms（4秒），在 AC-2 要求的 >=3 秒范围内
- alpha 呼吸范围: 0.55 ± 0.45 → 实际范围 [0.10, 1.00] × 原 alpha，coerceIn(0.15, 1.0) 保证最低可见
- 相位偏移: 每个点 index × 0.7 弧度，使 24 个点不同步呼吸
- motionEnabled=false 时: breathMultiplier=1f，等同于静态原效果
- 动画仅影响 sparkle，不影响 glow/aurora 层（避免性能问题）

#### 1. 密码 ↔ 验证码切换 (L533-574)

当前裸 `if/else`，改为 `AnimatedContent`：

```kotlin
AnimatedContent(
    targetState = challengeState != null,
    transitionSpec = {
        fadeIn(tween(if (motionEnabled) 250 else 0)) togetherWith
            fadeOut(tween(if (motionEnabled) 200 else 0))
    },
    label = "authFieldSwitch",
) { isChallenge ->
    if (!isChallenge) {
        // 密码字段 (原 L534-560)
    } else {
        // 验证码字段 (原 L562-573)
    }
}
```

**决策**: 使用 fade 而非 slide，避免字段位置跳变（AC-6）。用 `AnimatedContent` 而非双 `AnimatedVisibility`，确保切换时旧字段淡出、新字段淡入同步。

#### 2. AuthMessageBlock 显隐 (L576-579 + L795-810)

当前调用处直接调用 `AuthMessageBlock(...)`，函数内部早返回。

**方案**: 在调用处包裹 `AnimatedVisibility`，函数内部去掉早返回：

调用处改为：
```kotlin
AnimatedVisibility(
    visible = currentMessage != null,
    enter = fadeIn(tween(if (motionEnabled) 250 else 0)),
    exit = fadeOut(tween(if (motionEnabled) 200 else 0)),
) {
    AuthMessageBlock(
        message = currentMessage,
        isError = errorMessage != null,
    )
}
```

函数内部 (L795-810) 改为：
```kotlin
@Composable
private fun AuthMessageBlock(message: String?, isError: Boolean) {
    if (message.isNullOrBlank()) return
    val colors = YingShiThemeTokens.colors
    Text(
        text = message,
        modifier = Modifier.fillMaxWidth(),
        style = MaterialTheme.typography.bodyMedium,
        color = if (isError) MaterialTheme.colorScheme.error else colors.titleAccent,
    )
}
```
（函数本身不变，显隐由外部 AnimatedVisibility 控制）

#### 3. PresetAccountRow 选中指示器 (L781-789)

当前裸 `if/else`，引入 `animateColorAsState`：

```kotlin
val indicatorColor by animateColorAsState(
    targetValue = if (selected) colors.titleAccent.copy(alpha = 0.55f) else Color.Transparent,
    animationSpec = tween(if (motionEnabled) 200 else 0),
    label = "indicatorColor",

Box(
    modifier = Modifier
        .fillMaxWidth()
        .padding(top = 4.dp)
        .background(indicatorColor)

```

同时为文字颜色添加动画（在 PresetAccountRow 函数内部添加 motionEnabled 参数）：
```kotlin
val labelColor by animateColorAsState(
    targetValue = if (selected) colors.titleAccent else colors.textSecondary,
    animationSpec = tween(if (motionEnabled) 200 else 0),
    label = "labelColor",
)
val accountColor by animateColorAsState(
    targetValue = if (selected) colors.titleAccent.copy(alpha = 0.88f) else colors.textSecondary.copy(alpha = 0.88f),
    animationSpec = tween(if (motionEnabled) 200 else 0),
    label = "accountColor",
)
```

**函数签名变更**: `PresetAccountRow` 需接收 `motionEnabled: Boolean` 参数。

#### 4. LoginInlineActions 显隐 (L641-674)

当前裸 `if (challengeState != null)`，包裹 `AnimatedVisibility`：

```kotlin
AnimatedVisibility(
    visible = challengeState != null,
    enter = fadeIn(tween(if (motionEnabled) 250 else 0)) + slideInVertically(
        animationSpec = tween(if (motionEnabled) 250 else 0),
        initialOffsetY = { it / 4 },
    ),
    exit = fadeOut(tween(if (motionEnabled) 200 else 0)),
) {
    LoginInlineActions(...)
}
```

### 边界条件
- motionEnabled=false 时所有 tween duration=0，等同于即时切换（AC-5）
- AnimatedContent 的 fade 切换不导致布局抖动（AC-6）
- PresetAccountRow 签名变更：新增 `motionEnabled` 参数，调用处传递
