## 本模块依赖的外部模块/服务

| 依赖模块 | 依赖内容 | 本轮是否改动接口 | 说明 |

## 回归测试范围

### 必须回归的模块
| 模块 | 回归范围 | 原因 |
|------|---------|------|
| 登录与会话 | 完整登录流程 + 背景视觉 + 动画 | 直接修改 LoginScreen + AuroraBackdrop |
| 外壳与基础设备 | 其他页面 AuroraBackdrop variant | FR-7 动画基础设施影响所有 variant 的 Canvas |

### 需要验证 variant 不受影响的模块
| 模块 | variant | 验证内容 |
|------|---------|---------|
| 首页 | HOME | 背景视觉不变 |
| 照片流 | PHOTOS | 背景视觉不变 |
| 生活首页 | LIFE | 背景视觉不变 |
| 个人主页 | ME | 背景视觉不变 |
| 外壳 | SHELL | 背景视觉不变 |

### 不需要回归的模块
| 模块 | 原因 |
|------|------|
| 大相册/小相册/照片查看器/系统媒体/回收站 | 不使用 AuroraBackdrop |
| 通知中心/评论系统/今日足迹/足迹组件推送 | 不涉及 |
| 设置/个人主页(编辑)/聊天展示/账本/提交传输中心 | 不涉及 |

### Android 编译范围
- `assembleDebug` 编译通过
- 无新增依赖、无 Gradle 变更
