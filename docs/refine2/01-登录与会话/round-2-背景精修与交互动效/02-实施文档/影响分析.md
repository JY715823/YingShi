## 回归风险

| 风险项 | 风险等级 | 缓解措施 |
|--------|---------|---------|
| token 化后 AUTH 背景色差退化 | 中 | token 值与原 hex 接近，alpha 精调补偿；NFR-2 验证 |
| InfiniteTransition 性能开销 | 低 | 仅 1 个 animateFloat，24 个 sparkle 复用同一值 |
| AnimatedContent 切换时字段重叠 | 低 | fade 过渡 250ms，无 slide，不重叠 |
| PresetAccountRow 签名变更 | 低 | 新增 motionEnabled 参数，调用处传递 |
| 动画 import 遗漏 | 低 | 编译验证自动发现 |
| 其他 variant 受影响 | 低 | when 分支互斥，仅改 AUTH |
