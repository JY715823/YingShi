## 二、FR-7: 极光背景微动画 — 代码定位

### 当前动画基础设施
**完全无动画。** 无 InfiniteTransition、无 animateFloatAsState、无 rememberYingShiMotionEnabled()。

### 闪烁点实现（L292-311）
- 在 `Canvas` 内 `repeat(24) { index -> ... }` 循环
- `DrawScope.drawCircle()`，位置确定性伪随机
- alpha 静态：暖点 0.46f、冷强点 0.34f、冷弱点 0.18f
- 无时间维度变化

### 动画落点
1. Canvas 外部（L46 之前）建立 `rememberInfiniteTransition()`
2. 动画值传入 Canvas 的 drawLambda
3. 闪烁点 alpha 呼吸：基于 index 相位偏移的 sin 波
4. rememberYingShiMotionEnabled() 守卫：关闭时 alpha 取静态值

### 需新增 import
- `androidx.compose.animation.core.rememberInfiniteTransition`
- `androidx.compose.animation.core.animateFloat`
- `androidx.compose.animation.core.tween`
- `androidx.compose.animation.core.RepeatMode`
- `androidx.compose.runtime.getValue`
- `kotlin.math.sin` / `kotlin.math.PI`
- `rememberYingShiMotionEnabled`
