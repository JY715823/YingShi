## 二、用户流程

### 流程1: 首次登录（双步认证）
用户在登录页输入 QQ 邮箱账号和密码 → 点击登录 → Android 调用 `POST /api/auth/login/challenge` → Server 验证账号密码，生成 6 位验证码发送到 QQ 邮箱，返回 challengeId + 掩码邮箱 + 过期时间 → 用户查看 QQ 邮箱获取验证码 → 输入验证码 → Android 调用 `POST /api/auth/login/verify` → Server 校验验证码，签发 JWT (access + refresh token) + rememberedLoginToken → Android 存储 token 到 AuthSessionManager，保存 currentUserSnapshot → 跳转到首页。

涉及: `LoginScreen.kt`, `AuthApi.kt`, `AuthController.java`, `AuthService.java`, `AuthSessionManager.kt`, `RealAuthRepository.kt`

### 流程2: 同设备免验证码重登 (remembered-login)
用户退出后再次打开登录页 → 登录页预填上次账号 → 用户输入密码点击登录 → Android 先尝试 `POST /api/auth/login/remembered`（携带 deviceId + rememberedLoginToken）→ Server 校验账号密码 + rememberedLoginToken 有效性 → 成功则直接签发新 session（不发验证码）→ 失败则自动回退到 challenge 流程。

涉及: `LoginScreen.kt` (remembered-login 分支), `AuthApi.loginRemembered()`, `AuthController.rememberedLogin()`, `AuthRememberedLoginService.java`

### 流程3: Token 刷新
access token 过期 → API 请求返回 401 → AuthInterceptor (OkHttp) 捕获 → AuthRefreshCoordinator 加锁，用 refresh token 调用 `POST /api/auth/refresh-token` → 获取新 access + refresh token → 更新 AuthSessionManager → 重试原请求。

涉及: `AuthInterceptor.kt`, `AuthRefreshCoordinator.kt`, `AuthSessionManager.kt`, `AuthController.refreshToken()`

### 流程4: 会话失效 → 缓存只读
refresh token 也过期 / session 被服务端撤销 → 刷新失败 → AuthSessionManager.clearTokensPreservingReadCache() → 不清缓存，保留已加载的照片/资料 → UI 显示"缓存只读"提示 + "重新登录"按钮 → 用户重新登录后恢复实时同步。

涉及: `AuthSessionManager.clearTokensPreservingReadCache()`, `BackendAutoLoginManager.kt`, `OfflineAccessManager.kt`, `AppReadCacheStore.kt`, `YingShiApp.kt`

### 流程5: 手动退出
用户点击退出 → 调用 `POST /api/auth/logout` → Server 撤销 session → Android 清 session + 受保护缓存，但保留 remembered-login token → 回到登录页，预填上次账号。

涉及: `SettingsScreen.kt` (退出按钮), `AuthApi.logout()`, `AuthController.logout()`, `AuthSessionManager.kt`

### 流程6: 服务地址切换
用户在连接设置中修改 base URL → 保存 → 清旧 session + remembered-login token → 回到登录页。

涉及: `LoginScreen.kt` (连接设置弹层), `AuthSessionManager.kt`

## 三、数据流向

### 前后端数据流

```
用户输入(账号/密码/验证码)
  → LoginScreen (UI状态机)
    → AuthApi (Retrofit)
      → AuthController (Spring Boot)
        → AuthService (业务逻辑)
          → AuthLoginChallengeRepository (challenge持久化)
          → MailSender (QQ SMTP发信)
          → JwtProvider (JWT签发)
          → AuthSessionRepository (session管理)
          → AuthRememberedLoginService (remembered token)
        ← DTO响应
      ← DTO响应
    → AuthRepository → AuthSessionManager (token存储)
      → SharedPreferences (deviceId, tokens, currentUserSnapshot)
  → YingShiApp 观察 sessionVersion → 路由到首页/登录页
```

### 与其他模块的数据交互

| 模块 | 交互方向 | 交互内容 |
|------|---------|---------|
| **shell (AppShell)** | auth → shell | sessionVersion 驱动登录/主页路由；token 失效触发只读模式 |
| **photos (17+ 文件)** | auth → photos | BackendAutoLoginManager.loginDefault() 被多个 ViewModel 调用；token 用于 API 请求 |
| **me/profile** | auth → me | currentUserSnapshot 提供头像/昵称；sessionVersion 触发资料刷新 |
| **notifications** | auth → notifications | token 用于推送注册；FCM token 绑定依赖 auth 状态 |
| **sync** | auth → sync | isLoggedIn 决定是否启动同步轮询 |
| **chat** | auth → chat | ChatSyncBridge 检查 auth 状态 |
| **ledger** | auth → ledger | LedgerSyncBridge 检查 auth 状态 |
| **life** | auth → life | 上传/推送/widget 均需 auth token |
| **settings** | settings → auth | 退出登录、服务地址切换触发 auth 清理 |
