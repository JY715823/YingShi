## 三、共享组件依赖

### 需要修改的共享组件

| 共享组件 | 文件路径 | 修改内容 | 影响范围 |
|---------|---------|---------|---------|
| `yingShiClickable` | `YingShiInteractions.kt` | 新增可选 `onLongClick` 参数，非 null 时使用 `combinedClickable` | 全局（但有默认值，向后兼容） |

**修改方案**:
```kotlin
fun Modifier.yingShiClickable(
    enabled: Boolean = true,
    shape: Shape? = null,
    pressedScale: Float = Float.NaN,
    onLongClick: (() -> Unit)? = null,  // 新增，默认 null
    onClick: () -> Unit,
): Modifier = composed {
    // ... 原有逻辑 ...
    if (onLongClick != null) {
        // 使用 combinedClickable
        this
            .then(shapeModifier)
            .graphicsLayer { /* ... */ }
            .alpha(contentAlpha)
            .combinedClickable(
                enabled = enabled,
                interactionSource = interactionSource,
                indication = indication,
                onLongClick = onLongClick,
                onClick = onClick,
            )
    } else {
        // 原有 clickable 逻辑
        this
            .then(shapeModifier)
            .graphicsLayer { /* ... */ }
            .alpha(contentAlpha)
            .clickable(
                enabled = enabled,
                interactionSource = interactionSource,
                indication = indication,
                onClick = onClick,
            )
    }
}
```

**向后兼容性**: `onLongClick` 默认为 null，现有所有调用方无需修改。
