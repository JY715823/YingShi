## 三、跨文件影响路径汇总

### FR-8 前后端完整调用链

```
[Android UI] AlbumPostCard 长按
  → [Android UI] MoveSmallAlbumTargetPickerDialog 选择目标
    → [Android VM] AlbumPageRealViewModel.moveSmallAlbums
      → [Android data] RealAlbumRepository.moveSmallAlbums
        → [Android data] AlbumApi.moveSmallAlbums (Retrofit PATCH)
          → [Server] AlbumController.moveSmallAlbums
            → [Server] AlbumService.moveSmallAlbums (@Transactional)
              → [Server] AlbumRepository.findByIdAndLibraryIdAndDeletedAtIsNull (校验目标)
              → [Server] PostRepository.findByLibraryIdAndIdInAndDeletedAtIsNull (查询小相册)
              → [Server] PostEntity.setAlbumId + setLastModifiedByUserId + touch
              → [Server] PostRepository.saveAll
              → [Server] ContentMapper.toPostSummaryDto
            ← [Server] 返回 List<PostSummaryDto>
          ← [Android data] 解析 ApiEnvelopeDto
        ← [Android data] 返回 ApiResult.Success
      ← [Android VM] 更新 cachedDirectorySnapshot + persistAlbumDirectory
      ← [Android VM] _uiState.update (posts 移除被移动的小相册)
      ← [Android VM] notifyRealBackendContentChanged(postIds) → 全 6 scope 通知
      ← [Android VM] loadAlbumPosts(sourceAlbumId) → 刷新 source 列表
    ← [Android UI] Dialog 关闭
```
