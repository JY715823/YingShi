## 一、FR-8: 切换小相册所属大相册

### 目标
实现"将小相册从一个大相册移动到另一个大相册"的完整前后端功能。用户在 `AlbumPostCard` 长按弹出目标大相册选择器，确认后服务端批量更新 `PostEntity.albumId`，前端刷新 source/target 列表并通知 mutation bus。

### 需求修正决策（调研阶段确认）
1. **UI 入口位置**: 放在 `AlbumPostCard` 长按（非 `AlbumDirectoryDialog`），与 AC-3 "小相册卡片有移动到操作入口" 一致
2. **端点 HTTP 方法**: 沿用需求文档的 `PATCH`
3. **返回类型**: `ApiResponse<List<PostSummaryDto>>`（移动后的小相册列表），保持简单
4. **mutation bus 通知**: `notifyRealBackendContentChanged(postIds = smallAlbumIds.toSet())` 全 6 scope 通知
5. **无 Flyway 迁移**: 仅更新 `PostEntity.albumId` 字段值，无数据模型变更

#### 文件 3: `AlbumService.java`（修改）

**函数签名**:
```java
@Transactional
public List<PostSummaryDto> moveSmallAlbums(
        String targetAlbumId,
        MoveSmallAlbumsRequest request,
        AuthenticatedUser currentUser
) {
    String libraryId = currentUser.libraryId();
    // 1. 校验目标大相册存在且属于当前 library
    AlbumEntity targetAlbum = requireAlbum(targetAlbumId, libraryId);

    // 2. 过滤 null/blank 的 smallAlbumId
    List<String> smallAlbumIds = request.smallAlbumIds().stream()
            .filter(id -> id != null && !id.isBlank())
            .distinct()
            .toList();

    if (smallAlbumIds.isEmpty()) {
        throw new ApiException(HttpStatus.BAD_REQUEST, ErrorCode.VALIDATION_ERROR,
                "smallAlbumIds must not be empty");
    }

    // 3. 批量查询待移动的小相册（校验存在 + 未删除 + 属于同一 library）
    List<PostEntity> smallAlbums = postRepository
            .findByLibraryIdAndIdInAndDeletedAtIsNull(libraryId, smallAlbumIds);

    if (smallAlbums.size() != smallAlbumIds.size()) {
        List<String> foundIds = smallAlbums.stream().map(PostEntity::getId).toList();
        List<String> missingIds = smallAlbumIds.stream()
                .filter(id -> !foundIds.contains(id))
                .toList();
        throw new ApiException(HttpStatus.NOT_FOUND, ErrorCode.SMALL_ALBUM_NOT_FOUND,
                "Small albums not found: " + missingIds);
    }

    // 4. 逐条更新 albumId + 记录修改人 + touch updatedAt
    for (PostEntity post : smallAlbums) {
        post.setAlbumId(targetAlbumId);
        post.setLastModifiedByUserId(currentUser.userId());
        post.touch();
    }
    postRepository.saveAll(smallAlbums);

    // 5. 转换为 PostSummaryDto 列表返回
    List<String> postIds = smallAlbums.stream().map(PostEntity::getId).toList();
    Map<String, Long> mediaCountByPostId = postMediaRepository
            .findByLibraryIdAndPostIdIn(libraryId, postIds)
            .stream()
            .collect(Collectors.groupingBy(PostMediaEntity::getPostId, Collectors.counting()));

    List<PostSummaryDto> results = new ArrayList<>();
    for (PostEntity post : smallAlbums) {
        results.add(contentMapper.toPostSummaryDto(
                post,
                post.getAlbumId(),
                post.getCoverMediaId(),
                mediaCountByPostId.getOrDefault(post.getId(), 0L)
        ));
    }
    return results;
}
```

**伪代码逻辑**:
1. `requireAlbum(targetAlbumId, libraryId)` → 校验目标大相册存在且未删除，否则 404 `ALBUM_NOT_FOUND`
2. 过滤 null/blank + 去重 `smallAlbumIds`
3. `postRepository.findByLibraryIdAndIdInAndDeletedAtIsNull(libraryId, smallAlbumIds)` 批量查询
4. 比对查询结果数量 vs 请求数量，不一致 → 404 `SMALL_ALBUM_NOT_FOUND`（含缺失 ID 列表）
5. 逐条 `setAlbumId(targetAlbumId)` + `setLastModifiedByUserId(currentUser.userId())` + `touch()`
6. `postRepository.saveAll(smallAlbums)` 批量保存
7. 查询 mediaCount + 转换为 `List<PostSummaryDto>` 返回

**异常处理**:
- `ALBUM_NOT_FOUND` (404): 目标大相册不存在或已删除
- `SMALL_ALBUM_NOT_FOUND` (404): 部分或全部小相册不存在或已删除
- `VALIDATION_ERROR` (400): smallAlbumIds 为空或全部 blank
- `@Transactional` 保证原子性：任何异常都回滚

**边界条件**:
- 小相册已在目标大相册下 → 正常执行（idempotent），albumId 不变但 touch 更新时间
- 小相册来自不同大相册 → 正常移动，全部更新到 targetAlbumId
- 小相册有 systemKey → 正常移动（systemKey 不受影响）

#### 文件 10: `RealPhotoViewModels.kt`（修改）

**AlbumPageRealViewModel 新增方法**:

```kotlin
fun moveSmallAlbums(
    targetAlbumId: String,
    smallAlbumIds: List<String>,
) {
    if (_uiState.value.isOfflineReadOnly) {
        _uiState.update { it.copy(errorMessage = "缓存只读模式下不能切换小相册所属大相册。") }
        return
    }
    if (smallAlbumIds.isEmpty()) return
    val sourceAlbumId = _uiState.value.selectedAlbumId ?: return
    viewModelScope.launch {
        _uiState.update {
            it.copy(
                isAlbumMutating = true,
                errorMessage = null,
                postsErrorMessage = null,
            )
        }
        when (val result = albumRepository.moveSmallAlbums(targetAlbumId, smallAlbumIds)) {
            is ApiResult.Success -> {
                // 1. 从 source 的缓存中移除被移动的小相册
                val nextPostsByAlbumId = cachedDirectorySnapshot?.postsByAlbumId.orEmpty()
                    .mapValues { (albumId, posts) ->
                        if (albumId == sourceAlbumId) {
                            posts.filterNot { it.postId in smallAlbumIds }
                        } else {
                            posts
                        }
                    }
                // 2. 更新 albums 列表中的 smallAlbumCount（UI 层面的乐观更新）
                val nextAlbums = _uiState.value.albums.map { album ->
                    when (album.id) {
                        sourceAlbumId -> album.copy(/* count 减少由 refresh 覆盖 */)
                        targetAlbumId -> album
                        else -> album
                    }
                }
                // 3. 持久化缓存
                withContext(Dispatchers.IO) {
                    persistAlbumDirectory(
                        albums = cachedDirectorySnapshot?.albums.orEmpty(),
                        postsByAlbumId = nextPostsByAlbumId,
                    )
                }
                // 4. 更新 UI 状态
                _uiState.update {
                    it.copy(
                        isAlbumMutating = false,
                        albums = nextAlbums,
                        posts = if (sourceAlbumId == it.selectedAlbumId) {
                            it.posts.filterNot { post -> post.id in smallAlbumIds }
                        } else {
                            it.posts
                        },
                        statusMessage = "已将 ${smallAlbumIds.size} 个小相册移动到目标大相册。",
                    )
                }
                // 5. 通知 mutation bus 全 scope 刷新
                notifyRealBackendContentChanged(postIds = smallAlbumIds.toSet())
                // 6. 刷新 source 和 target 的帖子列表
                loadAlbumPosts(albumId = sourceAlbumId, showBlockingIndicator = false)
            }
            is ApiResult.Error -> {
                _uiState.update {
                    it.copy(
                        isAlbumMutating = false,
                        errorMessage = result.toBackendUiMessage("切换小相册所属大相册失败。"),
                    )
                }
            }
            ApiResult.Loading -> Unit
        }
    }
}
```

**逻辑要点**:
1. **离线只读保护**: `isOfflineReadOnly` 时拒绝操作
2. **乐观更新**: 从 source 的 posts 列表移除被移动的小相册
3. **缓存持久化**: 更新 `cachedDirectorySnapshot` + `persistAlbumDirectory`
4. **mutation bus 通知**: `notifyRealBackendContentChanged(postIds = smallAlbumIds.toSet())` 全 6 scope 通知
5. **刷新 source**: `loadAlbumPosts(sourceAlbumId)` 重新拉取 source 列表

**边界条件**:
- `smallAlbumIds` 为空 → 直接 return
- `selectedAlbumId` 为 null → 直接 return
- source == target → 服务端正常处理（idempotent），前端 posts 不变
- 网络失败 → 显示错误，不修改本地状态

```kotlin
fun moveSmallAlbums(
    targetAlbumId: String,
    smallAlbumIds: List<String>,
): List<AlbumPostCardUiModel> {
    // FAKE 实现：更新内存中的 post.albumId
    val movedPosts = posts.map { post ->
        if (post.id in smallAlbumIds) {
            post.copy(albumId = targetAlbumId)
        } else {
            post
        }
    }
    posts = movedPosts
    return movedPosts.filter { it.id in smallAlbumIds }
}
```
