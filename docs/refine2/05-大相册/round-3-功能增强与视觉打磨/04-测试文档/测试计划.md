| 环境 | 要求 |
|------|------|
| Android 编译 | JDK 17+、Gradle 8+、Android SDK 34+ |
| Server 编译 | JDK 17+、Maven 3.9+ |
| Server 测试 | Docker（PostgreSQL 16 + MinIO）、Testcontainers |
| Android 设备 | API 29+ 真机或模拟器（视觉测试推荐真机） |
| 网络 | REAL 模式测试需服务端运行中（`docker compose up -d`） |
