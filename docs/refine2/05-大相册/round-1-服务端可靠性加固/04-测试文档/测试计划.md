# 05-大相册 Round 1 测试计划

> 版本: v1.0 | 日期: 2026-07-10
> 覆盖需求: FR-1 + FR-2
> 测试环境: Testcontainers PostgreSQL 16-alpine + Spring Boot MockMvc

---

## 一、测试策略

### 1.1 测试类型

| 类型 | 范围 | 执行方式 |
|------|------|---------|
| 集成测试 | Album CRUD 5 端点 + largeAlbumDeleted 全链路 | MockMvc + Testcontainers PG |
| 回归测试 | 既有 6 个 trash 测试 + auth/upload/ledger 测试 | `mvnw.cmd test` 全量执行 |

### 1.2 测试基础设施

- **基类**: `AbstractPostgresIntegrationTest`（`@Testcontainers @SpringBootTest @AutoConfigureMockMvc @ActiveProfiles("test")`）
- **数据库**: Testcontainers `postgres:16-alpine`，Flyway V1→V25 自动迁移
- **种子数据**: `TestSeedDataInitializer` 预置 `library_shared` + `user_demo_a`(OWNER) + `user_demo_b`(MEMBER)
- **存储**: 本地文件（`app.storage.provider=local`），无 MinIO 依赖
- **认证**: `loginAndGetAccessToken()` 走完整 challenge → verify 流程
- **容器复用**: JVM 级 Testcontainers 复用，测试间共享数据

## 四、测试数据设计

### 4.1 数据隔离策略

| 策略 | 说明 |
|------|------|
| 唯一标识 | 所有测试用 `System.nanoTime()` 生成唯一 title/fingerprint |
| jsonPath 筛选 | 查询断言用 title 精确匹配，不依赖"空库"状态 |
| 容器共享 | Testcontainers JVM 级复用，数据不清空 |

### 4.2 测试数据流

```
loginAndGetAccessToken()
  → ACCOUNT_A (1085060329@qq.com) / password 123456
  → CapturingAuthLoginCodeSender 捕获验证码
  → loginAndGetAccessToken() 返回 accessToken

createAlbum(token, title)
  → POST /api/albums {"title": "..."}
  → 返回 albumId

uploadAndConfirmMedia(token, fingerprint)
  → POST /api/uploads/token → uploadId
  → POST /api/uploads/{uploadId}/file (MockMultipartFile)
  → POST /api/uploads/{uploadId}/confirm → mediaId

createSmallAlbum(token, albumId, title, mediaId)
  → POST /api/small-albums {"albumId":"...", "title":"...", 
      "participantUserIds":["user_demo_a"], 
      "displayTimeMillis": currentTime, 
      "initialMediaIds":["mediaId"]}
  → 返回 smallAlbumId
```

### 5.2 失败处理

| 失败场景 | 处理策略 |
|---------|---------|
| Testcontainers 启动失败 | 检查 Docker Desktop 是否运行 |
| Flyway 迁移失败 | 检查 V1→V25 迁移链完整性 |
| 小相册创建失败（participantUserIds） | 确认 CreatePostRequest DTO 字段名 |
| purge 失败 | 检查 FR-2 purgeLargeAlbumDeleted 改动 |
| 恢复后小相册数量不匹配 | 检查 restoreLargeAlbumDeleted 级联逻辑 |
