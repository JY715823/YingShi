## 四、基础设施修复（复检过程中发现并修复）

### 4.1 Testcontainers 版本升级
- pom.xml: 1.20.4 → 1.21.4（3个依赖）
- 原因: 1.20.4 与 Docker Desktop 29.4.3 不兼容

### 4.2 Spring Boot 4.0 兼容性
- `MediaRepository`: Optional + Pageable → List + Pageable（2个方法）
- `ImportedMessageSearchRepository`: Id → MessageId（3个方法）+ 调用方更新
- `ChatImportedZipService`: ObjectMapper 改为内部创建
- `AbstractPostgresIntegrationTest`: 添加 @Import + 单例容器模式

### 4.3 UploadService FK 约束
- 移除 `createUploadToken` 中的 `task.setMediaId(mediaId)`
- 原因: V24 迁移的 FK 约束要求 media_id 引用已存在的 media 记录
