## 六、风险与缓解

| # | 风险 | 严重度 | 缓解措施 |
|---|------|--------|---------|
| 1 | RenderEffect API 24-30 fallback 视觉差异 | 中 | fallback 用 viewerSurface alpha 0.78 模拟，真机验证两版本 |
| 2 | AnimatedContent 与视频 seek/retry 冲突 | 中 | 充分测试 seek 路径，必要时改用 AnimatedVisibility |
| 3 | ViewerOverlayChrome.kt 行数超限 | 低 | 当前 668 行，预估 780 行（< 800），若超限将 DropdownMenu 提取到独立文件 |
| 4 | DropdownMenu containerColor 在 Material3 版本差异 | 低 | shadowElevation + tonalElevation=0 确保深色一致 |
| 5 | VideoGlyphState ERROR 分支遗漏 | 低 | grep 搜索所有 when 分支，确保覆盖 |
