## 四、数据流图

### 4.1 FR-4 数据流（不变）

```
PhotoViewerScreen.kt
  ├─ ViewerAtmosphereLayer（不改）
  ├─ ViewerTopScrim ← 加 drawBehind drawLine（FR-4）
  ├─ ViewerBottomScrim ← 加 drawBehind drawLine（FR-4）
  ├─ PhotoViewerTopBar
  │   ├─ ViewerIconCircle ← linearGradient + blur（FR-4）
  │   └─ DropdownMenu ← containerColor + shadowElevation（FR-4）
  ├─ PhotoViewerEdgeActions
  │   ├─ ViewerCapsule ← blur（FR-4）
  │   └─ ViewerCommentEntry ← blur（FR-4）
  ├─ ViewerCommentPreviewLayer ← blur（FR-4）
  └─ ViewerNoticeHost ← blur（FR-4）
```

### 4.2 FR-5 数据流（重构）

```
ViewerImageCanvas.kt:378
  └─ ViewerVideoCanvas（重构）
      └─ AnimatedContent(videoUiState)
          ├─ PLAYING → PlayerView（不变）
          ├─ LOADING → CircularProgressIndicator（不变）
          ├─ ERROR → ViewerVideoErrorState（新增，FR-5）
          │   ├─ VideoGlyph(ERROR)（新增，FR-5）
          │   ├─ Text(errorMessage)
          │   └─ 重试按钮 → onRetry → retryState()
          └─ COMPLETED → 最后一帧（不变）
```

**状态映射**:
```
ViewerVideoPlaybackState → videoUiState
  errorMessage != null → ERROR
  !isPrepared || isLoading → LOADING
  isPlaying → PLAYING
  isCompleted → COMPLETED
  else → LOADING
```

## 六、API 契约一致性

### 6.1 Composable 签名变更

| Composable | 签名变更 | 影响 |
|-----------|---------|------|
| ViewerTopScrim | 无 | 仅内部加 drawBehind |
| ViewerBottomScrim | 无 | 同上 |
| ViewerNoticeHost | 无 | 仅内部加 viewerGlassSurface |
| ViewerTimeBadge | 无 | 仅内部改背景实现 |
| ViewerIconCircle | 无 | 同上 |
| ViewerCapsule | 无 | 同上 |
| ViewerCommentEntry | 无 | 同上 |
| ViewerCommentPreviewLayer | 无 | 同上 |
| DropdownMenu | 无 | 仅加参数 |
| ViewerVideoCanvas | 无 | 内部重构为 AnimatedContent |
| ViewerVideoErrorState | **新增** | 新 Composable |
| VideoGlyphState | **新增 ERROR 项** | 枚举扩展 |

**结论**: 所有现有 Composable 签名不变，仅新增 1 个 Composable + 1 个枚举项。

### 6.2 Token 访问变更

| Token | 变更 | 访问方式 |
|-------|------|---------|
| viewerOverlayEdgeGlow | 新增 | YingShiThemeTokens.colors.viewerOverlayEdgeGlow |
| viewerOverlayBorder | 新增 | YingShiThemeTokens.colors.viewerOverlayBorder |
| viewerScrimBlur | 新增 | YingShiThemeTokens.motion.viewerScrimBlur |
| viewerCapsuleBlur | 新增 | YingShiThemeTokens.motion.viewerCapsuleBlur |

**结论**: 纯新增，不修改现有 token 访问。
