## 九、AC 解释说明（歧义点）

### 9.1 AC-1 "顶部/底部 overlay 有 drawBehind 毛玻璃效果" 解释

**字面歧义**: AC-1 提到"drawBehind 毛玻璃效果"，但实际毛玻璃通过 `viewerGlassSurface`（RenderEffect + graphicsLayer）实现，而非 `drawBehind`。

**实现解释**:
- `drawBehind` 用于：边缘微光线（drawLine）+ 渐变背景（drawRect linearGradient）
- 毛玻璃（backdrop-filter blur）通过 `viewerGlassSurface` Modifier 实现（API 31+ RenderEffect）
- 两者是不同层级的技术：drawBehind 是绘制层，viewerGlassSurface 是合成层

**覆盖判定**:
- 顶部/底部 overlay 区域内的浮层组件（NoticeHost/TimeBadge/IconCircle/Capsule/CommentEntry/CommentPreviewLayer）均应用了 viewerGlassSurface 毛玻璃 ✅
- 顶部/底部 scrim（ViewerTopScrim/ViewerBottomScrim）是全屏渐变背景，不应用毛玻璃（设计意图：scrim 本身就是半透明渐变，无需再 blur）
- AC-1 覆盖判定：✅ PASS

### 9.2 AC-4 "多层 shadow" 解释

**字面歧义**: AC-4 提到"多层 shadow"，但 DropdownMenu 只设置了单层 shadowElevation = 8.dp。

**实现解释**:
- Material3 的 DropdownMenu shadowElevation 在 API 28+ 会渲染多层阴影（elevation-based shadow），视觉上是"多层"效果
- tonalElevation = 0.dp 确保深色背景下不应用 tonal overlay，保持深色一致性
- containerColor = ViewerNightTop.copy(alpha = 0.92f) 配合 shadow 形成层次感

**覆盖判定**: ✅ PASS（单层 shadowElevation 在 Material3 下视觉呈现为多层阴影）
