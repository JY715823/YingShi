## 五、RenderEffect 可用性判定

| 维度 | 结论 | 依据 |
|------|------|------|
| Compose API | **可用** | BOM 2024.09.00 → Compose UI 1.7.0 支持 renderEffect |
| 平台 API | **部分不可用** | android.graphics.RenderEffect 需要 API 31+ |
| minSdk=24 | **7 个版本缺口** | API 24-30 无法使用 |

**方案**: API 分级
- API 31+: `Modifier.graphicsLayer { renderEffect = RenderEffect.createBlurEffect(rx, ry, shader) }`
- API 24-30 fallback: 半透明深色叠层（viewerSurface.copy(alpha=0.78f)）+ 可选 radialGradient 模拟光晕

**项目中 RenderEffect 使用情况**: 全项目零使用，FR-4 将是首次引入。

## 七、design-plan.md 材质光影指导原则

### 7.1 三大材质维度

| 维度 | 设计意图 | FR-4 落地 |
|------|---------|----------|
| 磨砂玻璃 | 导航、浮层、选中态 | Overlay 毛玻璃 backdrop |
| 金属边线 | 渐变 border 高级质感 | Overlay 边缘微光线 |
| 丝绸渐变光泽 | 多层阴影、微妙渐变 | 时间胶囊渐变 |

### 7.2 核心约束

- Viewer 使用独立深色 token，不沿用浅色壳层
- 浮层薄、轻、克制，不能变成重色面板
- 图片和视频永远是 Viewer 主角，材质不能反客为主
- 微玻璃只用于浮层，普通内容卡片不做堆叠
- 多层阴影系统分层

### 7.3 颜色系统 v1.1 第 5.8 节约束

- 新增 token 必须命名 `viewer*` 前缀
- 不可复用浅色 glassStroke
- 模糊半径不宜过大，alpha 不宜过高
- 对比度需通过 AA

## 十、调研结论

### 10.1 FR-4 实施方向

| 改造类型 | 位置数 | 实施方式 |
|---------|--------|---------|
| 毛玻璃 backdrop | 5 处（TimeBadge/IconCircle/NoticeHost/Capsule/CommentEntry） | graphicsLayer + RenderEffect（API 31+）+ fallback 半透明 |
| 边缘微光线 | 8 处（上述 5 + TopScrim 顶/底 + BottomScrim 底） | drawLine + viewerAccent.copy(alpha=0.15f) |
| 渐变背景 | 2 处（TimeBadge/IconCircle） | Brush.linearGradient(viewerSurface → viewerSurface alpha) |
| DropdownMenu 阴影 | 1 处 | 自定义 modifier 注入 containerColor/shadowElevation |
| 新增 token | 5 个 | viewerOverlayBlur/EdgeGlow/Border/GradientStart/GradientEnd |

### 10.2 FR-5 实施方向

| 改造类型 | 实施方式 |
|---------|---------|
| 新增 ViewerVideoErrorState Composable | 错误图标 + 提示文案 + 重试按钮，替换 455-476 内联块 |
| 扩展 VideoGlyphState | 新增 ERROR 项 + 图标绘制 |
| 过渡动画 | AnimatedContent 包裹状态切换（正常/加载/错误） |
| Token 使用 | viewerSurface 背景 + viewerAccent 图标/按钮 + viewerText 文字 |
| 按压态 | yingShiClickable(pressedScale=0.94f) |

### 10.3 风险

| # | 风险 | 严重度 | 缓解 |
|---|------|--------|------|
| 1 | RenderEffect API 24-30 不可用 | 中 | Build.VERSION 分流 + fallback 半透明 |
| 2 | 毛玻璃低端设备掉帧 | 中 | 性能检测 + 降级开关（参考 rememberYingShiMotionEnabled） |
| 3 | AnimatedContent 与视频播放器状态机冲突 | 中 | 充分测试 seek/retry 路径 |
| 4 | DropdownMenu 深色化后样式不一致 | 低 | 对齐 viewer token |
