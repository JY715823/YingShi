## 关键代码变更

### PhotoFeedInteractionModels.kt

**新增 HeroOrigin 数据类**（行 82-86）:
```kotlin
@Immutable
data class HeroOrigin(
    val mediaId: String,
    val boundsInRoot: Rect,
)
```

**PhotoViewerRoute 新增字段**（行 95）:
```kotlin
val heroOrigin: HeroOrigin? = null,
```

### ViewerHeroTransition.kt（新建）

- `HeroTransitionMillis = 300`（AC-4: 250-350ms）
- `HeroGraphicsParams` data class（scaleX/scaleY/translationX/translationY/alpha）
- `computeHeroGraphicsParams(origin, containerSize, progress)` — 从缩略图位置到全屏的插值计算
- `Modifier.heroGraphicsLayer(origin, containerSize, progress)` — 应用 graphicsLayer 变换
- 对 size<=0 做降级处理（返回 alpha=progress）
- TransformOrigin(0f, 0f) 表示 TopLeft（缩放原点在左上角）

### PhotoFeedScreen.kt

**onMediaClick**（行 1852-1854）: 从 itemBoundsByMediaId 取 bounds 构造 HeroOrigin
**onOpenMedia**（行 1869-1871）: 同上

### PhotoViewerScreen.kt

**hero 状态**（行 116-142）:
- `heroOrigin = route.heroOrigin`
- `heroProgress = Animatable(if (heroOrigin != null) 0f else 1f)` — null 时直接 1f（无动画）
- `heroExiting` — 退出动画防重入标志
- `heroContainerSize` — 容器尺寸（onGloballyPositioned 获取）
- `LaunchedEffect` — 进入动画 animateTo(1f, 300ms, FastOutSlowInEasing)
- `handleBack` — 包装 onBack，退出时 animateTo(0f) 后调用真正 onBack

**背景层**（行 479）: `ViewerNightBottom.copy(alpha = heroOverlayAlpha)` — 背景渐暗（AC-3）

**overlayAlpha**（行 209-215）: `baseOverlayAlpha * heroOverlayAlpha` — overlay 跟随 progress 淡入

**userScrollEnabled**（行 500）: `... && !heroActive` — 动画期间禁用滑动（AC-5）

**初始页 PhotoViewerCanvas modifier**（行 574-589）: 仅当 page==initialPage && heroOrigin.mediaId 匹配 && progress<1f 时应用 heroGraphicsLayer

**5 处 onBack() → handleBack()**: BackHandler 主返回（行 424）、BackHandler 沉浸（行 427）、删除空列表 FAKE（行 442）、删除空列表 REAL（行 460）、PhotoViewerTopBar（行 609）
