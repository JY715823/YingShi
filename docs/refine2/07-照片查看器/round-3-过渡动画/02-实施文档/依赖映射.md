## 四、数据流图

### 4.1 Hero 进入动画数据流

```
[PhotoFeedScreen]
  PhotoFeedCard (onGloballyPositioned)
    └── coordinates.boundsInRoot() → itemBoundsByMediaId[mediaId]
  onMediaClick(item)
    ├── bounds = itemBoundsByMediaId[item.mediaId]
    ├── heroOrigin = HeroOrigin(item.mediaId, bounds)
    └── onOpenViewer(PhotoViewerRoute(mediaItems, initialIndex, sourceLabel, heroOrigin))
        └── [YingShiApp.kt:1578] photoViewerRoute = route
            └── [YingShiApp.kt:1828] PhotoViewerScreen(route = route)
                ├── heroOrigin = route.heroOrigin
                ├── heroProgress = Animatable(0f)
                ├── LaunchedEffect → animateTo(1f, 300ms)
                ├── 背景层 alpha = heroProgress.value
                ├── HorizontalPager.userScrollEnabled = (progress >= 1f)
                └── 初始页 PhotoViewerCanvas
                    └── modifier = heroGraphicsLayer(origin, containerSize, progress)
                        ├── scaleX/Y = lerp(originSize/containerSize, 1f, progress)
                        ├── translationX/Y = originCenter - containerCenter * scale
                        └── alpha = progress
```

### 4.2 Hero 退出动画数据流

```
[PhotoViewerScreen]
  用户点击返回（TopBar onBack / Back 键）
    └── handleBack()
        ├── if (heroOrigin != null && !heroExiting && progress >= 1f)
        │   ├── heroExiting = true
        │   ├── coroutineScope.launch
        │   │   ├── heroProgress.animateTo(0f, 300ms)
        │   │   ├── onBack()  ← 真正关闭（YingShiApp.kt:1847 photoViewerRoute = null）
        │   │   └── heroExiting = false
        └── else → onBack() 直接关闭
```

### 4.3 无 Hero 降级数据流（其他入口）

```
[PostDetailScreen / AppPhotoFeedPickerScreen / 通知]
  onOpenViewer(PhotoViewerRoute(...))  ← 不传 heroOrigin
    └── PhotoViewerScreen(route)
        ├── heroOrigin = null
        ├── heroProgress = Animatable(1f)  ← 直接 1f，无动画
        ├── 背景层 alpha = 1f（不透明）
        ├── userScrollEnabled 正常
        └── PhotoViewerCanvas modifier = Modifier.fillMaxSize()（无 heroGraphicsLayer）
```
