## 三、FR-6 功能测试（AC 覆盖矩阵）

### T-FR6-01: Hero 进入动画（AC-1）

**目的**: 从照片流点击缩略图进入 Viewer 时，图片有从缩略图位置到全屏位置的过渡动画。
**前置条件**: 设备已登录，照片流至少有 1 张图片。
**操作步骤**:
1. 打开照片流主页面
2. 观察任意一张缩略图的位置（记为 P_thumb）
3. 点击该缩略图
4. 观察 Viewer 打开过程
**预期**:
- 图片从 P_thumb 位置开始，平滑放大并移动到全屏位置
- 动画期间初始页应用 `heroGraphicsLayer`（scaleX/scaleY/translationX/translationY 随 progress 变化）
- 动画结束后图片稳定显示在 Viewer 全屏位置
**覆盖**: AC-1, IA-1。
**验证手段**: 真机观察 + logcat 无异常。

### T-FR6-02: Hero 退出动画（AC-2）

**目的**: 关闭 Viewer 时，图片从全屏位置回到缩略图位置。
**前置条件**: 已通过 T-FR6-01 进入 Viewer。
**操作步骤**:
1. 在 Viewer 中按下系统返回键 / 顶部返回按钮 / 下滑返回（任选其一）
2. 观察 Viewer 关闭过程
**预期**:
- 图片从全屏位置开始，平滑缩小并移动回原缩略图位置 P_thumb
- 动画期间背景由深色渐变为透明
- 动画结束后 Viewer 关闭，回到照片流
**覆盖**: AC-2, IA-3, IA-14, IA-15。
**验证手段**: 真机观察。

### T-FR6-03: 背景渐暗动画（AC-3）

**目的**: 过渡期间背景随动画进度渐变（透明→深色 / 深色→透明）。
**前置条件**: 同 T-FR6-01。
**操作步骤**:
1. 点击缩略图进入 Viewer
2. 观察背景层颜色变化
3. 按返回退出 Viewer
4. 观察背景层颜色变化
**预期**:
- 进入: 背景 alpha 从 0f 渐变到 1f（透明 → ViewerNightBottom 深色）
- 退出: 背景 alpha 从 1f 渐变到 0f（深色 → 透明）
- 背景色: `ViewerNightBottom.copy(alpha = heroProgress.value)`
**覆盖**: AC-3, IA-4。
**验证手段**: 真机观察背景颜色变化是否平滑。

### T-FR6-04: 动画时长与 easing（AC-4）

**目的**: 验证动画时长在 250-350ms 之间，easing 为 FastOutSlowInEasing。
**操作步骤**:
1. 检查 `ViewerHeroTransition.kt` 中 `HeroTransitionMillis` 常量
2. 检查 `PhotoViewerScreen.kt` 中 `tween(HeroTransitionMillis, easing = FastOutSlowInEasing)` 调用
3. 真机感知动画时长
**预期**:
- `HeroTransitionMillis = 300`（在 250-350ms 范围内）
- 进入和退出动画均使用 `FastOutSlowInEasing`
**覆盖**: AC-4。
**验证手段**: 代码检查 + 真机感知。

### T-FR6-05: HorizontalPager 左右滑动不受影响（AC-5）

**目的**: 动画完成后，HorizontalPager 左右滑动翻页功能正常。
**前置条件**: 已通过 T-FR6-01 进入 Viewer，且当前媒体列表 ≥ 2 项。
**操作步骤**:
1. 等待进入动画完成（约 300ms）
2. 左滑切换到下一张
3. 右滑切回上一张
4. 动画进行中尝试滑动（应被禁用）
**预期**:
- 动画完成后左右滑动正常，能切换页面
- 动画进行中（progress < 1f）`userScrollEnabled = false`，无法滑动
- 滑动过程中图片显示正确
**覆盖**: AC-5, IA-6, IA-7。
**验证手段**: 真机操作。
