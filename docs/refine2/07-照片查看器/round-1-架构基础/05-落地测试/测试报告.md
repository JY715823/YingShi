## 六、发现并修复的 Bug

### BUG-1: LongImageHeightWidthRatioThreshold 阈值错误

**问题**: 拆分后 `ViewerImageCanvas.kt` 第 60 行 `LongImageHeightWidthRatioThreshold = 3.8f`，与原始值 `2.2f` 不一致，导致 `PhotoViewerBehaviorTest` 中 2 个测试用例 FAIL:
- `longImageReadingUsesDimensionsThreshold` FAILED（width=1000, height=2200, 期望 true，实际 false）
- `longImageReadingFallsBackToAspectRatio` FAILED（width=null, height=null, aspectRatio=0.4, 期望 true，实际 false）

**根因**: 拆分过程中 `LongImageHeightWidthRatioThreshold` 常量值被错误地从 `2.2f` 改为 `3.8f`。通过 `git log -p -S` 检索历史值，确认原始值为 `2.2f`:
```
+private const val LongImageHeightWidthRatioThreshold = 2.2f
```

**修复**: 将 `ViewerImageCanvas.kt` 第 60 行的值改回 `2.2f`:
```kotlin
internal const val LongImageHeightWidthRatioThreshold = 2.2f
```

**验证**: 修复后重测，`gradlew.bat :app:testDebugUnitTest --tests "*PhotoViewerBehaviorTest*"` BUILD SUCCESSFUL in 38s，3 个测试用例全部 PASS。

**回归确认**:
- 测试1: width=1000, height=2200 → height/width = 2.2 >= 2.2 → true ✅
- 测试2: width=null, height=null, aspectRatio=0.4 → 1/0.4 = 2.5 >= 2.2 → true ✅
- 测试3: width=1000, height=1800 → height/width = 1.8 < 2.2 → false ✅

> BUG-1 在阶段5 已修复并验证，纳入复检前的基线状态。
