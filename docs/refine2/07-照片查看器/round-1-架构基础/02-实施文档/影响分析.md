## 一、变更文件影响链

### 1.1 ViewerZoomState.kt（新建）

**直接影响**:
- ViewerImageCanvas.kt — `viewerZoomGesture` 依赖 ViewerZoomState（调用 applyTransform/settleAfterGesture/panBy/reset）
- PhotoViewerScreen.kt 主容器 — `remember { ViewerZoomState() }` 创建实例，传递给 Canvas

**间接影响**:
- 无（ViewerZoomState 原为 private class，无外部引用）

**影响说明**: 拆分后 ViewerZoomState 从 private 升级为 internal，主容器和 ViewerImageCanvas 跨文件引用。公共 API 签名保持不变，仅可见性扩大到模块内。

### 1.2 ViewerBackHandler.kt（新建，含 FR-2 + FR-3）

**直接影响**:
- PhotoViewerScreen.kt 主容器 — 调用 `applyViewerStatusBarVisibility`（行 893 附近）、`ViewerStatusBarEffect`、新增 `ViewerBackHandlerChain` 替换内联 BackHandler

**间接影响**:
- 系统栏行为（沉浸/唤出）— FR-2 迁移后沉浸机制从 FLAG_FULLSCREEN+systemUiVisibility 改为 WindowInsetsControllerCompat.hide/show

**影响说明**:
- **行为变更风险**: FR-2 迁移是行为变更（虽然目标一致）。旧方案 API 30+ 走 insetsController，API 29- 走 deprecated；新方案全版本走 WindowInsetsControllerCompat（Compat 层处理版本差异）。需真机验证 Android 11/12/13/14。
- **颜色变更**: 2 处 Color.rgb 删除，statusBarColor 不再手动设置（由 controller 管理）。

### 1.3 ViewerVideoPlayer.kt（新建）

**直接影响**:
- PhotoViewerScreen.kt 主容器 — 调用 `ViewerVideoCanvas`、`ViewerVideoControls`

**间接影响**:
- 无（视频相关函数均为 private/internal，无外部引用）

**影响说明**: 纯文件拆分，无行为变更。

### 1.4 ViewerImageCanvas.kt（新建）

**直接影响**:
- PhotoViewerScreen.kt 主容器 — 调用 `PhotoViewerCanvas`、`viewerSingleTapGesture`（行 997）

**间接影响**:
- PhotoViewerBehaviorTest.kt — 测试 `shouldUseLongImageReading`（internal，拆分后仍 internal，测试 import 不变）

**影响说明**: 纯文件拆分。`shouldUseLongImageReading` 保持 internal 可见性，测试文件无需修改。

### 1.5 ViewerRelatedAlbumsSheet.kt（新建）

**直接影响**:
- PhotoViewerScreen.kt 主容器 — 调用 `ViewerRelatedPostsSheet`、`buildViewerRelatedPosts`、`viewerRelatedAlbumLabel`

**间接影响**:
- 无（sheet 相关函数均为 private/internal）

**影响说明**: 纯文件拆分。

### 1.6 ViewerOverlayChrome.kt（新建，含 FR-3）

**直接影响**:
- PhotoViewerScreen.kt 主容器 — 调用 `PhotoViewerTopBar`、`ViewerTimeBadge`、`PhotoViewerEdgeActions`、`ViewerNoticeHost`、`ViewerAtmosphereLayer`、`PhotoViewerCommentSheet`、`ViewerCacheActionSheet` 等

**间接影响**:
- 视觉层 — ViewerNightTop/Bottom/Middle 颜色别名若迁移到 token，overlay 渐变视觉效果可能微变（需视觉回归）

**影响说明**:
- 行数风险: 预估 ~900 行。若超 800 行，将 PhotoViewerCommentSheet（269行）独立为 ViewerCommentSheet.kt。
- FR-3 颜色清理: ViewerNight* 三别名需核查。

### 1.7 PhotoViewerScreen.kt（修改，主容器）

**直接影响**:
- YingShiApp.kt 第 1829-1863 行 — 调用 `PhotoViewerScreen(...)` 6 参数签名（**保持不变**）

**间接影响**:
- 无（主入口签名不变，外部调用方无感知）

**影响说明**: 主容器内部删除 51 个已抽出声明，import 新文件，替换 BackHandler 块。对外契约不变。

## 二、必须测试的影响路径清单（IA-N）

### IA-1: PhotoViewerScreen 主入口路由链
- **路径**: YingShiApp.kt:1829 → PhotoViewerScreen(route, onBack, ...) → 内部编排
- **验证**: 从照片流点击进入 Viewer 正常显示，Back 退出正常
- **端**: Android

### IA-2: ViewerZoomState 缩放体系
- **路径**: PhotoViewerScreen → remember { ViewerZoomState() } → PhotoViewerCanvas → viewerZoomGesture → ViewerZoomState.applyTransform/settleAfterGesture
- **验证**: 双指缩放（6x 稳定/9x 弹性）、双击缩放（原图↔2.5x）、焦点锚定、复位
- **端**: Android

### IA-3: 单击/双击手势识别
- **路径**: PhotoViewerScreen:997 → viewerSingleTapGesture → 单击切换 overlay / 双击缩放
- **验证**: 快速单击切换沉浸/唤出，双击缩放，两者不冲突
- **端**: Android

### IA-4: Back 键三级逻辑（FR-1 重构点）
- **路径**: ViewerBackHandlerChain → 缩放复位 / 沉浸切换 / 退出
- **验证**: 放大态按 Back → 复位缩放；沉浸态按 Back → 唤出 overlay；非沉浸按 Back → 退出
- **端**: Android

### IA-5: 沉浸式状态栏控制（FR-2 迁移点）
- **路径**: ViewerStatusBarEffect → applyViewerStatusBarVisibility → WindowInsetsControllerCompat.hide/show
- **验证**: 进入 Viewer 状态栏隐藏；唤出 overlay 状态栏显示；退出 Viewer 状态栏恢复
- **端**: Android
- **重点**: Android 11/12/13/14 真机验证

### IA-6: 视频播放体系
- **路径**: PhotoViewerScreen → ViewerVideoCanvas → ExoPlayer → PlayerView → ViewerVideoControls
- **验证**: 视频播放/暂停/seek/重播/错误重试/2.8秒自动隐藏控件
- **端**: Android

### IA-7: 所属小相册 sheet
- **路径**: 三横线菜单 → ViewerRelatedPostsSheet → viewerRelatedAlbumLabel（4级标题解析）→ onOpenPostDetail
- **验证**: 中文标题解析正确，点击跳转小相册详情
- **端**: Android

### IA-8: Overlay 控制栏显隐
- **路径**: PhotoViewerScreen → PhotoViewerTopBar/ViewerTimeBadge/PhotoViewerEdgeActions + AnimatedVisibility
- **验证**: overlay fadeIn/fadeOut + slide 动画正常，沉浸时隐藏，单击唤出
- **端**: Android

### IA-9: 评论预览层 + 评论 sheet
- **路径**: PhotoViewerEdgeActions → ViewerCommentEntry → ViewerCommentPreviewLayer → PhotoViewerCommentSheet
- **验证**: 评论入口点击展开 sheet，评论列表加载，新增评论
- **端**: Android

### IA-10: 颜色一致性（FR-3 清理点）
- **路径**: ViewerBackHandler.kt（删除2处Color.rgb）+ ViewerOverlayChrome.kt（ViewerNight*迁移）
- **验证**: 沉浸模式背景色与拆分前一致（深色 #101F26 系），overlay 颜色无变化
- **端**: Android

### IA-11: shouldUseLongImageReading 测试
- **路径**: PhotoViewerBehaviorTest.kt → shouldUseLongImageReading（internal）
- **验证**: `gradlew.bat test` 单元测试通过

### IA-12: 复用方零影响验证
- **路径**: SystemMediaViewerScreen/ChatMediaViewer/LifeMediaQuickViewerActivity/RealTrashScreens/PostMediaListScreen
