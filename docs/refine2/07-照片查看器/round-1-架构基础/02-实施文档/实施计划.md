```kotlin
internal fun applyViewerStatusBarVisibility(view: View, immersive: Boolean) {
    val window = findActivity(view.context)?.window ?: return
    val controller = WindowCompat.getInsetsController(window, view)
    controller.systemBarsBehavior = WindowInsetsControllerCompat.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE
    if (immersive) {
        controller.hide(WindowInsetsCompat.Type.statusBars())
    } else {
        controller.show(WindowInsetsCompat.Type.statusBars())
    }
}
```

**FR-2 迁移详细方案（ViewerStatusBarEffect 重写）**:

旧逻辑（行 533-592）:
```
DisposableEffect(immersive) {

    val previousSystemUiVisibility = ...  // 行 548
    onDispose {
        window.statusBarColor = previousStatusBarColor  // 行 574
        window.decorView.systemUiVisibility = previousSystemUiVisibility  // 行 572
```

新逻辑:
```kotlin
@Composable
internal fun ViewerStatusBarEffect(immersive: Boolean = false) {
    val view = LocalView.current
    DisposableEffect(immersive) {
        onDispose {
            // 退出时恢复状态栏显示
            applyViewerStatusBarVisibility(view, immersive = false)
        }
    }
    SideEffect {
        applyViewerStatusBarVisibility(view, immersive)
    }
}
```

**FR-3 颜色清理**:

**ViewerBackHandlerChain 新增 Composable**:
```kotlin
@Composable
internal fun ViewerBackHandlerChain(
    zoomState: ViewerZoomState,
    isImmersive: Boolean,
    onResetZoom: () -> Boolean,      // 缩放复位，返回是否消费
    onToggleImmersive: () -> Boolean, // 沉浸切换，返回是否消费
    onExit: () -> Unit,               // 退出 Viewer
) {
    BackHandler {
        if (zoomState.isZoomed && onResetZoom()) return@BackHandler
        if (isImmersive && onToggleImmersive()) return@BackHandler
        onExit()
    }
}
```

## FR-2: Deprecated Window API 迁移

### 目标
消除 5 处 @Suppress("DEPRECATION")，统一到 WindowInsetsControllerCompat。

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `feature/photos/ViewerBackHandler.kt` | Android | 新建（含 FR-2） | applyViewerStatusBarVisibility + ViewerStatusBarEffect 重写 |

### 详细计划（已在 FR-1 文件2 详述）

**消除清单**:
- 5 处 `@Suppress("DEPRECATION")`（行 464, 497, 508, 547, 571）
- 7 处 `FLAG_FULLSCREEN`（行 461, 462, 507, 561, 564, 565, 568）
- 8 处 `systemUiVisibility`（行 465, 466, 498, 499, 509, 510, 548, 572）
- 4 处 `statusBarColor`（行 539, 552, 574, 587）

**新方案**:
- `WindowCompat.getInsetsController(window, view)` 获取 controller
- `controller.hide(WindowInsetsCompat.Type.statusBars())` 隐藏
- `controller.show(WindowInsetsCompat.Type.statusBars())` 显示
- `controller.systemBarsBehavior = BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`（滑动恢复）

**边界条件**:
- minSdk 24: WindowInsetsControllerCompat 在 core-ktx 1.0+ 全版本可用（Compat 层处理）
- 不再需要 `if (Build.VERSION.SDK_INT >= 30)` 分支（Compat 自动处理）
- `findActivity` 保留（仍需从 View 找 Window）

**异常处理**:
- `findActivity` 返回 null → `return`（无操作，不崩溃）
- controller 为 null → `return`（WindowInsetsControllerCompat 可能为 null，安全处理）

### 目标

- 原用途: ViewerStatusBarEffect SideEffect 内设置 statusBarColor
- 迁移: **删除**（同上）

- 调研未确认其引用来源，实施时需读取这 4 行代码确认
- 若引用硬编码 Color → 迁移到 `YingShiThemeTokens.colors.viewer*`
- 若已是 token 别名 → 保留或内联
