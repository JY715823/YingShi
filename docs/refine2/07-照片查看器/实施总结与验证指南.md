## 如何验证

### 快速验证（5 分钟核心验证）

1. **编译**: `gradlew.bat assembleDebug` → BUILD SUCCESSFUL
2. **打开 Viewer**: 照片流 → 点击任意照片 → 确认全屏沉浸、图片加载正常
3. **缩放**: 双指放大 → 确认焦点锚定 → 双击 → 确认 2.5x 放大 → 再双击 → 确认回到 1x
4. **Back**: 放大状态按 Back → 确认先复位缩放 → 再按 Back → 确认退出 Viewer
5. **视频**: 播放一个视频 → 确认播放/暂停/进度条正常

### 完整验证（每个 FR 的验证方法）

**FR-1 拆分验证**:
- 从照片流/小相册详情/回收站/聊天/生活分别进入 Viewer → 确认所有入口功能正常
- 左右滑动翻页 → 确认 HorizontalPager 正常
- 打开所属小相册 sheet → 确认中文标题和大相册 chip 显示
- 打开评论面板 → 确认评论加载正常

**FR-2 Window API 验证**:
- 进入 Viewer → 确认状态栏隐藏
- 单击切换 overlay → 确认状态栏跟随显隐
- 在 Android 12+ 和 Android 11 设备上分别测试

**FR-3 颜色验证**:
- Viewer 内所有 UI 元素颜色与精修前一致（深色沉浸风格）
- 无颜色偏差或意外变化

**FR-4 Overlay 材质验证**:
- 观察顶部/底部 overlay 边缘是否有微光线
- 观察时间胶囊是否有渐变背景
- 观察三横线菜单是否有阴影层次
- 确认 overlay 文字/图标清晰可读（无模糊）

**FR-5 视频错误态验证**:
- 断网后播放视频 → 确认显示错误状态 UI（图标+文字+重试按钮）
- 点击重试 → 确认过渡动画流畅
- 恢复网络后重试 → 确认视频正常播放

**FR-6 Hero 动画验证**:
- 从照片流点击缩略图 → 确认图片柔和淡入全屏（无缩放变形、无闪烁）
- 关闭 Viewer → 确认图片柔和淡出（背景不闪）
- 从其他入口（小相册详情等）进入 Viewer → 确认无 crash
- 确认动画流畅不卡顿
