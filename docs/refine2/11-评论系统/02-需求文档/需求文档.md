# 评论系统 需求文档

> 版本: v1.0 | 日期: 2026-07-16 | 状态: 已确认

## 一、模块目标

评论系统精修后达到：交互状态统一管理（三处弹窗共用）、文件职责清晰（拆分 806 行大文件）、Fake 死代码清理、ViewModel 评论逻辑去重、文档同步、评论列表支持分页加载、操作菜单有动画、输入栏状态管理统一。

## 二、功能需求

### FR-1: 评论交互状态去重

**描述**: `RealCommentThreadContent`、`FakeSmallAlbumCommentSheet`、`PhotoViewerCommentSheet` 三处各自管理 6-7 个几乎相同的状态变量（actionCommentId、editingCommentId、editingDraft、selectedCommentId、pendingDeleteCommentId、selectedCommentValue），约 200+ 行重复代码。抽取 `CommentInteractionState` 统一管理。

**端**: Android

**优先级**: P0

**验收标准**:
- AC-1: 新建 `CommentInteractionState.kt`，包含 `CommentInteractionState` data class（6个状态字段）+ `rememberCommentInteractionState()` Composable 函数
- AC-2: `RealCommentThreadContent` 使用 `rememberCommentInteractionState()` 替代内联状态声明
- AC-3: `SmallAlbumCommentSheet`（拆分后）使用 `rememberCommentInteractionState()`
- AC-4: `PhotoViewerCommentSheet` 使用 `rememberCommentInteractionState()`
- AC-5: 三处弹窗的交互行为（编辑/删除/复制/选择）不变
- AC-6: 编译通过

**涉及文件**:
- 新建 `app/src/main/java/com/example/yingshi/feature/photos/CommentInteractionState.kt`
- `app/src/main/java/com/example/yingshi/feature/photos/CommentComponents.kt`（RealCommentThreadContent）
- `app/src/main/java/com/example/yingshi/feature/photos/SmallAlbumCommentSheets.kt`（拆分后对应文件）
- `app/src/main/java/com/example/yingshi/feature/photos/ViewerCommentSheet.kt`

- AC-4: 所有 Composable 仍使用 `YingShiThemeTokens`
- AC-5: 编译通过，功能行为不变

**涉及文件**:

### FR-3: CommentGateway Fake 硬编码修复

**描述**: `CommentGateway.kt` 的同步方法（getPostComments 等 6 个）直接调用 `FakeCommentRepository`，不走 `RepositoryProvider`。REAL 模式下 `FakeSmallAlbumCommentSheet` 和 `MediaCommentPlaceholderSheet` 是死代码。

**端**: Android

**优先级**: P1

**验收标准**:
- AC-1: `CommentGateway` 所有方法走 `RepositoryProvider.currentMode` 分支，或改为全 suspend 方法直接调 Repository
- AC-2: REAL 模式下不再有任何路径调用 `FakeCommentRepository`
- AC-3: 如 Fake 弹窗路径（FakeSmallAlbumCommentSheet / MediaCommentPlaceholderSheet）在 REAL 模式下完全不可达，标记为 dead code 或删除
- AC-4: 编译通过

**涉及文件**:
- `app/src/main/java/com/example/yingshi/feature/photos/CommentGateway.kt`
- `app/src/main/java/com/example/yingshi/feature/photos/SmallAlbumCommentSheet.kt`（FR-2 拆分后）
- `app/src/main/java/com/example/yingshi/feature/photos/MediaCommentSheet.kt`（FR-2 拆分后）

### FR-6: 评论列表分页

**描述**: Server 已返回 `hasMore` 字段但前端未使用，只请求 page=1。实现评论列表滚动到底部自动加载下一页。

**验收标准**:

- AC-5: 编译通过

**涉及文件**:

### FR-7: Popup 操作菜单动画

**描述**: 评论长按操作菜单（编辑/复制/删除）当前直接显示/消失，无过渡动画。添加 fade + scale 进入/退出动画。

**优先级**: P2

- AC-3: 动画遵循 `YingShiThemeTokens.motion` 的时长和曲线
- AC-4: 遵循系统"减少动画"设置
- AC-5: 编译通过

**涉及文件**:

### FR-8: CommentInputBar 统一为 TextFieldValue

**描述**: `CommentInputBar` 当前使用 `String` 管理输入状态，与编辑模式的 `TextFieldValue` 不一致。统一为 `TextFieldValue` 以获得光标/选择管理能力。

**端**: Android

**优先级**: P2

**验收标准**:
- AC-1: `CommentInputBar` 的 `value` 参数从 `String` 改为 `TextFieldValue`
- AC-2: `onValueChange` 回调参数从 `(String) -> Unit` 改为 `(TextFieldValue) -> Unit`
- AC-3: 发送评论时取 `textFieldValue.text`
- AC-4: 发送后清空输入框（`TextFieldValue("")`）
- AC-5: 编译通过，输入行为不变

**涉及文件**:
- `app/src/main/java/com/example/yingshi/feature/photos/CommentComponents.kt`（CommentInputBar）
- 引用方更新（RealCommentThreadContent / SmallAlbumCommentSheet / ViewerCommentSheet）
