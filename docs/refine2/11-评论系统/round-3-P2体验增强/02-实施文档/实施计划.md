## FR-8: CommentInputBar 统一为 TextFieldValue

**目标**: CommentInputBar 的 value 参数从 String 改为 TextFieldValue

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | CommentComponents.kt (CommentInputBar) | Android | 修改 | value 改为 TextFieldValue，onValueChange 改为 TextFieldValue |
| 2 | CommentComponents.kt (RealCommentThreadContent) | Android | 修改 | 调用方更新 |
| 3 | SmallAlbumCommentSheet.kt | Android | 修改 | 调用方更新 |
| 4 | ViewerCommentSheet.kt | Android | 修改 | 调用方更新 |

### 变更细节

**CommentInputBar** (L64-169):
- 新增 `value: TextFieldValue` 参数（默认 `TextFieldValue("")`）
- 新增 `onValueChange: (TextFieldValue) -> Unit` 参数
- 删除 `var value by rememberSaveable(stateKey) { mutableStateOf("") }`
- `BasicTextField(value = value, onValueChange = onValueChange)`
- 发送时: `val trimmed = value.text.trim()` → `onSend(trimmed)` → `onValueChange(TextFieldValue(""))`
- 保留 `stateKey` 参数用于 focus 管理

**RealCommentThreadContent** (新建评论 ~L860):
- 使用 `var inputValue by rememberSaveable(stateKey) { mutableStateOf(TextFieldValue("")) }`
- 传入 `value = inputValue, onValueChange = { inputValue = it }`

**RealCommentThreadContent** (编辑评论 ~L816):
- 使用 `interactionState.editingDraft` 作为 value
- `onValueChange = { interactionState = interactionState.copy(editingDraft = it) }`

**FakeSmallAlbumCommentSheet** (~L250):
- 使用 `var inputValue by rememberSaveable("fake-comment-input") { mutableStateOf(TextFieldValue("")) }`
- 传入 `value = inputValue, onValueChange = { inputValue = it }`

**PhotoViewerCommentSheet** (~L103):
- 使用 `var inputValue by rememberSaveable(mediaId) { mutableStateOf(TextFieldValue("")) }`
- 传入 `value = inputValue, onValueChange = { inputValue = it }`

## FR-7: Popup 操作菜单动画

**目标**: 评论长按操作菜单添加 fadeIn+scaleIn / fadeOut+scaleOut 动画

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | CommentComponents.kt (CommentListItem) | Android | 修改 | 用 AnimatedVisibility 包裹 CommentInlineActionMenu |

### 变更细节

**CommentListItem** (L349-367):
- 将 `Popup(...)` 替换为 `AnimatedVisibility(visible = showInlineActionMenu, enter = fadeIn(animationSpec = tween(150)) + scaleIn(initialScale = 0.8f, animationSpec = tween(150)), exit = fadeOut(animationSpec = tween(100)) + scaleOut(targetScale = 0.8f, animationSpec = tween(100)))`

- 遵循 `motionEnabled` 设置：当 `!rememberYingShiMotionEnabled()` 时，enter/exit 使用 `tween(0)` 或直接 `EnterTransition.None` / `ExitTransition.None`

## FR-6: 评论列表分页

**目标**: 评论列表滚动到底部自动加载下一页

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | CommentModels.kt (RealCommentThreadUiState) | Android | 修改 | 添加 hasMore/currentPage 字段 |
| 2 | CommentThreadManager.kt | Android | 修改 | 添加 loadMoreMediaComments，修改 loadMediaComments 传 page |
| 3 | CommentComponents.kt (RealCommentThreadContent) | Android | 修改 | 添加滚动到底部检测 + loading 指示器 |

### 变更细节

**RealCommentThreadUiState** (CommentModels.kt):
- 新增 `hasMore: Boolean = false`
- 新增 `currentPage: Int = 1`

**CommentThreadManager.kt**:
- `loadMediaComments` 从 L43 `getMediaComments(mediaId)` → `getMediaComments(mediaId, page = 1, size = 20)`
- 新增 `loadMoreMediaComments(mediaId: String)`:
  - 获取当前 page = threads[mediaId].currentPage + 1
  - 如果 `!hasMore || isLoading || isMutating` 则 return
  - 设置 isLoadingMore = true
  - 调用 getMediaComments(mediaId, page, size=20)
  - 追加评论到现有列表（不覆盖，用 `comments + newComments`）
  - 更新 hasMore 和 currentPage
- `toThreadUiState` 传递 `hasMore` 和 `currentPage`

**RealCommentThreadContent** (CommentComponents.kt):
- 在 LazyColumn 末尾添加加载更多触发
- 使用 `LaunchedEffect` + `snapshotFlow` 检测最后一项可见
- 底部添加 loading 指示器（`isLoadingMore` 时显示 CircularProgressIndicator）
- `RealCommentThreadUiState` 新增 `isLoadingMore: Boolean = false`

**RealCommentThreadContent** 中 `RealCommentThreadUiState`:
- 新增 `isLoadingMore: Boolean = false`
