## FR-1: 评论交互状态去重

### 目标
抽取 `CommentInteractionState` 统一管理评论交互状态，三处弹窗共用。

### 1. 新建 CommentInteractionState.kt

**文件**: `app/src/main/java/com/example/yingshi/feature/photos/CommentInteractionState.kt`

```kotlin
package com.example.yingshi.feature.photos

import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.saveable.rememberSaveable
import androidx.compose.runtime.setValue
import androidx.compose.ui.text.input.TextFieldValue

/**
 * 评论交互状态 — 统一管理三处弹窗（RealCommentThreadContent、
 * FakeSmallAlbumCommentSheet、PhotoViewerCommentSheet）的交互状态。
 */
data class CommentInteractionState(
    val actionCommentId: String? = null,
    val editingCommentId: String? = null,
    val editingDraft: TextFieldValue = TextFieldValue(""),
    val selectedCommentId: String? = null,
    val pendingDeleteCommentId: String? = null,
    val selectedCommentValue: TextFieldValue = TextFieldValue(""),
    val showSelectedCommentNotice: Boolean = false,
) {
    val isEditing: Boolean get() = editingCommentId != null
    val isSelecting: Boolean get() = selectedCommentId != null
    val isActionMenuOpen: Boolean get() = actionCommentId != null
}

@Composable
fun rememberCommentInteractionState(
    stateKey: String,
    initialSelectedCommentId: String? = null,
): CommentInteractionState {
    // 使用 mutableStateOf 包裹以支持 Compose 重组
    var state by rememberSaveable(stateKey) {
        mutableStateOf(CommentInteractionState())
    }
    // 不支持直接返回可变引用，而是返回一个可通过 copy 更新的对象
    // 调用方通过 state.copy(...) 和重新赋值来更新
    return state
}
```

**注意**: 由于 `rememberSaveable` 需要 `MutableState` 来触发重组，但我们需要一个 data class 而不是分散的变量。设计为：
- `rememberCommentInteractionState()` 返回 `CommentInteractionState`（通过 `by rememberSaveable { mutableStateOf(...) }` 委托）
- 调用方使用 `interactionState.copy(...)` 并赋值回给 `interactionState` 来更新

**边界条件**:
- `stateKey` 用于 `rememberSaveable` 的 key，确保状态与弹窗绑定
- `initialSelectedCommentId` 用于 PhotoViewerCommentSheet 的定位高亮

### 2. 修改 RealCommentThreadContent (CommentComponents.kt)

var selectedCommentId by rememberSaveable(stateKeyPrefix) { mutableStateOf<String?>(null) }
var pendingDeleteCommentId by rememberSaveable(stateKeyPrefix) { mutableStateOf<String?>(null) }
