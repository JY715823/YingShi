## 如何验证

### 快速验证（5分钟核心验证）

1. **小相册评论弹窗**: 打开小相册详情 → 点击评论图标 → 弹窗正常打开 → 发送/编辑/删除评论正常
2. **媒体评论弹窗**: 在 Viewer 中点击评论按钮 → 弹窗正常 → 发送/编辑/删除正常
3. **操作菜单动画**: 长按评论 → 操作菜单有淡入+缩放动画 → 系统"减少动画"开启后无动画
4. **评论分页**: 评论超过默认数量时 → 底部显示"加载更多"按钮 → 点击加载下一批
5. **CommentInputBar**: 输入评论 → 发送后输入框清空 → 光标位置正常
