## 四、数据流图

### FR-3 (CommentGateway 修复)

```
FAKE 模式:
  FakeSmallAlbumCommentSheet ──→ FakeCommentRepository (直接调用)
  MediaCommentPlaceholderSheet ──→ FakeCommentRepository (直接调用)

REAL 模式:
  RealSmallAlbumCommentSheet ──→ PostDetailRealViewModel ──→ CommentRepository ──→ Server API
  RealMediaCommentSheet ──→ PostDetailRealViewModel ──→ CommentRepository ──→ Server API
  RealViewerCommentSheet ──→ RealViewerCommentViewModel ──→ CommentRepository ──→ Server API

CommentGateway (仅保留通用方法):
  PostDetailRealViewModel ──→ CommentGateway.xxxRemote() ──→ RepositoryProvider ──→ CommentRepository
  RealViewerCommentViewModel ──→ CommentGateway.xxxRemote() ──→ RepositoryProvider ──→ CommentRepository
```

### FR-4 (ViewModel 去重)

```
RealViewerCommentViewModel:
  └── CommentThreadManager (scope, commentRepository, currentUserIdProvider, threadsProvider, threadsUpdater, onMutationSuccess)
      ├── ensureMediaComments → loadMediaComments
      ├── createMediaComment → mutateMediaComments → commentRepository.createMediaComment()
      ├── updateMediaComment → mutateMediaComments → commentRepository.updateComment()
      ├── deleteMediaComment → mutateMediaComments → commentRepository.deleteComment()
      └── retryMediaComments → loadMediaComments

PostDetailRealViewModel:
  └── CommentThreadManager (scope, commentRepository, currentUserIdProvider, threadsProvider, threadsUpdater, onMutationSuccess)
      └── (同上)
```
