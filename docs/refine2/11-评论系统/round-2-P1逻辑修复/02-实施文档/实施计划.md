## FR-4: 评论 ViewModel 逻辑去重

**目标**: 提取 RealViewerCommentViewModel 和 PostDetailRealViewModel 中共享的媒体评论管理逻辑到 CommentThreadManager

### 变更文件清单

| # | 文件路径 | 端 | 变更类型 | 变更内容 |
|---|---------|-----|---------|---------|
| 1 | `app/.../feature/photos/CommentThreadManager.kt` | Android | 新建 | 共享媒体评论管理类 |
| 2 | `app/.../feature/photos/RealViewerCommentViewModel.kt` | Android | 修改 | 委托媒体评论逻辑给 CommentThreadManager |
| 3 | `app/.../feature/photos/RealPhotoViewModels.kt` | Android | 修改 | 委托媒体评论逻辑给 CommentThreadManager |

### CommentThreadManager 设计

**类签名**:
```kotlin
internal class CommentThreadManager(
    private val scope: CoroutineScope,
    private val commentRepository: CommentRepository,
    private val currentUserIdProvider: () -> String?,
    private val commentThreadsProvider: () -> Map<String, RealCommentThreadUiState>,
    private val commentThreadsUpdater: (Map<String, RealCommentThreadUiState>) -> Unit,
    private val onMutationSuccess: ((mediaId: String) -> Unit)? = null,
)
```

**方法**:
- `ensureMediaComments(mediaId: String)` — 如果未加载则加载
- `loadMediaComments(mediaId: String, successMessage: String? = null)` — 加载媒体评论
- `createMediaComment(mediaId: String, content: String)` — 创建媒体评论
- `updateMediaComment(mediaId: String, commentId: String, content: String)` — 更新
- `deleteMediaComment(mediaId: String, commentId: String)` — 删除
- `retryMediaComments(mediaId: String)` — 重试加载

**私有方法**:
- `mutateMediaComments(mediaId, successMessage, deletedCommentId, block)` — 通用 mutation 模板
- `clearMediaCommentStatusLater(mediaId, expectedMessage)` — 自动清除状态消息

### RealViewerCommentViewModel 重构

- 删除 ensureMediaComments, loadMediaComments, createMediaComment, updateMediaComment, deleteMediaComment, retryMediaComments, mutateMediaComments, clearMediaCommentStatusLater
- 创建 `CommentThreadManager` 实例，注入 `commentThreads` Map 的读写
- `onMutationSuccess` 回调中调用 `notifyRealBackendCommentChanged`
- 保留 handleExternalCommentMutation（过滤逻辑差异大）

### PostDetailRealViewModel 重构

- 删除 ensureMediaComments, loadMediaComments, createMediaComment, updateMediaComment, deleteMediaComment, retryMediaComments, mutateMediaComments, clearMediaCommentStatusLater
- 创建 `CommentThreadManager` 实例，注入 `mediaComments` Map 的读写
- `onMutationSuccess` 回调中调用 `notifyRealBackendCommentChanged` + `NotificationCenterLocalStore` + `SyncVersionTracker`
- 保留 handleExternalCommentMutation（过滤逻辑含 postId，差异大）
- 保留 postComments 相关方法（createPostComment, updatePostComment, deletePostComment, retryPostComments, loadPostComments, mutatePostComments）— 这些是 PostDetail 独有的，不去重
