## 三、遇到的问题

1. **Testcontainers Docker 连接失败**：Windows 环境下 Testcontainers 1.20.4 无法通过 named pipe `\\.\pipe\docker_engine` 连接 Docker Desktop。Docker CLI 正常工作但 Java Docker client 失败。创建了 `LiveServerIntegrationTest` 作为替代方案。
2. **Ledger 端点 404**：运行中的 PG 在 V20，V21（ledger 表）未应用。`/api/ledger/sync` 返回 404 而非 401。测试调整为接受 401 或 404。
3. **Actuator 端点 404**：Docker profile 下 `/actuator/health` 返回 404。使用 `/api/health` 作为健康检查替代。
