## 三、遇到的问题

1. **data_extraction_rules.xml 已存在**：调研时认为文件不存在（manifest 引用但 grep 未命中），实际文件存在且为默认模板。已清理为正式空规则文件。
2. **const val 限制**：`BackendAutoLoginManager` 内 `DEFAULT_DEMO_ACCOUNT` 原为 `const val = DEFAULT_PRIMARY_ACCOUNT`。移除顶层 const val 后，BuildConfig 字段非 Kotlin 编译期常量，不能赋给 const val。统一改为 `val ... get()` 运行时 getter。
